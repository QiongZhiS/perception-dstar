按 docs/178 六层阶梯的架构，以下机制是**模态无关**的，预期归入 core/：

- **利害外置（docs/174/188）**：目标从哪来——外赋利害锚 + 连续性维持，不可从输入推断；
- **Top-K 威胁度分配（docs/186 §五）**：注意力 = 精度分配，O(N) 稀疏，需要维持目标；
- **否定注册（docs/178 第 5 层）**：感知 = 否定的在场；残差是原子，跨模态成立；
- **态势地图（docs/161/189）**：轨迹记忆 + 衰减，"看了会记得"的模态无关版；
- **拒绝的历史（docs/200/201）**：确认失败被保留 vs 被吸收——行为对输入的不确定性。

设计纪律：core/ 只放**被至少两个模态验证过**的机制；单模态机制留在各自目录。
