## C 路核心主张（草案）

1. **残差递归的上限** = 时间性/可预测性的判别（暗区检出、静止纹理 0 事件、运动耦合、
   时间尺度）——这是"落空"的领域；
2. **残差递归的边界** = 空间性/拓扑性/颜色性的判别（闭合轮廓、主轴方向、反射率跳变）
   ——转导层丢颜色（docs/187），这些原则上在残差递归内不可得（除非重设计转导层）；
3. **读层是必要的第二机制**（docs/187"读层结构假设重建"从欠账变成正式组件）——与
   docs/195 三通道分工、docs/219 DavisMind、docs/189 威胁度分配一致，是架构给定的分工；
4. **B 路是北星试探**：若运动耦合判别（行为路）能替代 V1/V3，手工规则收缩到 V4 颜色
   或阅历通道，"纯"前进一大步；若失败，边界被精确画出（负证据同样值钱）。
