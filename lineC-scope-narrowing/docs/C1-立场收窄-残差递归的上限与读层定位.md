## 〇、一句话

> **六层残差递归的"纯"主张必须收窄为"感知引擎的纯"：残差递归的主场是时间性/可预测性
> 的判别（检出、静止被预测掉、运动耦合、时间尺度），上限在此；空间性/拓扑性/颜色性
> 的判别（闭合轮廓、主轴方向、反射率跳变）因转导层丢颜色（docs/187）而原则上不在
> 残差递归内——读层是必要的第二机制（docs/187"读层结构假设重建"从欠账变成正式
> 组件）。B 路（运动耦合判别）是把它赎回来的北星试探：若行为量能替代 V1/V3，手工
> 规则收缩到颜色/阅历通道；若不能，边界被精确画出，负证据同样成立。**

## 一、正统 vs 实践：诚实对账

### 1.1 docs/221 的正统

```
深化算子：第 k+1 层 = "M_k 解释不了的剩余"成为新原子
  判据：M_k 对 S_{k+1} 的解释力不足
每一层的原子 = 上一层机制的不可约剩余
  L2 残差（预测解释不了的）→ L3 预测者（残差解释不了残差的来源）
  → L4 会失去（模型解释不了自己为什么跑）→ ...
```

正统形态的核心：**一切结构从残差行为涌现**——事件流 → 阈值自适应 → 模式表/原型
（docs/235/250/251 的命中率→升级/回收）→ 结构。**不手工造判据**，判据就是
"上一层解释不了"。

### 1.2 光影线的实际（docs/260-272）

| 部件 | 是残差递归吗？ |
|---|---|
| Pass A（常见亮度参考 0.95 分位） | ✅ 是——"该像素常见亮度 vs 当前" = 落空 |
| Pass B 暗区检出（ref_dark − L > δ） | ✅ 是——残差（变暗=落空） |
| 时间门（面积 + 移动） | 🟡 半——面积/移动从事件流算，接近行为 |
| V1 闭合轮廓 / V3 主轴沿光 / V4 反射率 | ❌ **不是**——手工几何/颜色/拓扑启发式，从 d_mask 显式计算 |
| θ_est 光照估计 | ❌ 不是——手工几何（亮-暗质心连线） |
| docs/270 计分制（v1∧v4≥2） | ❌ 不是——手工决策规则 |

**核心事实：光影线的"检出"是残差递归，但"判别"（阴影 vs 物体）全是手工启发式**——
V1/V3/V4、计分制，没有一个是"上一层机制解释不了的剩余"递归出来的。

### 1.3 这不是光影线独有的"背叛"

- docs/187 早写："颜色/形状/朝向**本身不进事件流**，具体属性**靠读层的结构假设重建**
  （读层缺的正是这个假设）"；
- docs/219 DavisMind 确认判据（frac>thr 且色距<30°）、docs/189 威胁度 Top-K、
  docs/195 三通道分工——**全是手工读层规则**。

所以光影线不是特例，是"残差做感知引擎 + 手工做读出层"这一混合模式的延续。但
docs/221 的递归读法暗示"深化 = 承认上一层的剩余"——**"阴影 vs 物体"判别应该是
哪个层级的剩余？** 我们跳过了这个递归，直接手工写 V1/V3/V4。这在工程上有效
（F1 0.77），但在主张上越界了——我们没证明"读层规则是残差递归长出来的"。

## 二、残差递归的上限（C 路的核心主张）

### 2.1 残差递归的主场 = 时间性/可预测性

| 判别类型 | 例子 | 残差递归能做吗？ |
|---|---|---|
| 时间性 | 静止被预测掉（docs/187 C1 0 事件）、变暗=落空（Pass B）、运动耦合、时间尺度（docs/250） | ✅ 主场——"落空"的领域 |
| 空间性 | 闭合轮廓、主轴方向、连通性 | ❌ 需要形状（转导层丢） |
| 拓扑性 | 边界所有权、开放/闭合 | ❌ 需要结构假设 |
| 颜色性 | 反射率连续/跳变 | ❌ 颜色被转导层丢掉（docs/187） |

**根本原因**：事件流只送三轴——强度（ΔL）、时间（变化速率）、空间范围（事件簇）。
颜色、形状、朝向、图案**本身不进事件流**（转导层第一行丢颜色）。所以"阴影 vs
物体"的颜色/形状判别**在残差递归内原则上不可得**——除非重新设计转导层把颜色送进
事件流（大改，且与 docs/195 分工冲突）。

### 2.2 边界不是缺陷，是架构选择

docs/195 三通道分工（颜色=区分主轴、明度=运动+遮挡主轴）本身就是承认：**单通道
（明度事件流）做不了区分**，需要颜色通道。docs/187 的"读层结构假设重建"是同一
承认。C 路把这条边界从"欠账"变成"正式架构"：

```
残差递归（感知引擎，时间/预测侧）→ 事件流（强度/时间/空间三轴）
   ↓ 转导层丢弃：颜色/形状/朝向
读层（第二机制，空间/形状/颜色侧）→ 结构假设重建（V1/V3/V4、DavisMind、威胁度）
   ↓
判别输出
```

**这不是"残差递归失败了"——是"残差递归的能力范围被 docs/195 的通道分工限定"**。
六层的"纯"主张收窄为"感知引擎的纯"。

## 三、B 路作为北星试探（为什么不放弃 B）

B 路（lineB-motion-coupling）的核心：**把判别从几何路换到行为路**——阴影 vs 物体的
本质区别是行为性的（轨迹耦合、可预测性），不是几何性的。若成立：

- docs/261 的"运动耦合"（阴影与遮挡物共享运动场）是**行为量**（从轨迹算），不是
  几何量——它正是残差递归能做、且不需要手工规则的领域；
- B 成功 → V1/V3 被行为判别替代，手工规则收缩到 V4（颜色）或阅历通道，"纯"前进
  一大步；
- B 失败 → 边界被精确画出（运动耦合也分不开阴影/物体），支持 C 的收窄主张，且
  失败本身是有价值的负证据（docs/247：找出不迁移的部分）。

**预期**：合成三臂（阴影/物体/暗物体）分离成功率 60-70%；**硬边界 = 静态图**（ISTD
无运动，运动耦合在静态图上无定义）——B 不能完全替代几何判别，只能把"运动场景"
这一块赎回来。

## 四、立场陈述（C 路正式版）

1. **六层残差递归 = 感知引擎的纯**：它的主场是时间性/可预测性判别（检出、静止被
   预测掉、运动耦合、时间尺度）——这些是"落空"的领域，docs/221 的递归在这些领域
   逐层成立；
2. **读层 = 必要的第二机制**：空间性/拓扑性/颜色性判别需要结构假设重建（docs/187），
   与 docs/195 三通道分工、docs/219 DavisMind、docs/189 威胁度分配一致——这是架构
   给定的分工，不是欠账；
3. **"纯"的边界在转导层**：事件流丢颜色/形状（docs/187），所以残差递归原则上做不了
   颜色/形状判别——除非重设计转导层（大改，与 docs/195 冲突，不推荐）；
4. **B 路是赎回路**：若运动耦合判别（行为路）能替代 V1/V3，手工规则收缩，"纯"的
   边界内移；若失败，边界被精确画出（负证据同样值钱）；
5. **对论文的意义**：审稿人会问"你的 V1/V3/V4 是手工规则吗？"——C 路的回答是：
   "是，且这是架构给定的分工（docs/187/195），残差递归的上限在时间/预测侧；B 路
   正在试探把它进一步赎回来。"——诚实，且主动。

## 五、诚实边界

1. 本文档是立场重标，无新实验；全部判据引用既有文档（docs/187/195/219/221/260-272）。
2. "残差递归的上限"是对既有实现（docs/187 转导层 + docs/260-272 判别）的归纳，不是
   对新机制的证明——重设计转导层后上限可能移动（未测，声明）。
3. B 路是规划/试探，未实现——60-70% 预期是判断不是承诺；失败则 C 的主张更强
   （边界精确画出）。
4. 与 docs/221 §七 一致：递归是读法不是大脑机制（docs/63 纪律）；利害外赋照旧
   （docs/174）。
5. 不混层照旧：他者/被看见的现象意义不可判定（docs/63/34）。
