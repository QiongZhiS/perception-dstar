## 〇、一句话

> **思考不是独立推理模块，是注意力的递归：每层注意决策 = 上一层"为什么注意这里"
> 的解释不了的剩余（docs/221 深化算子原样搬入注意轴）。感知是它的基层服务——预测-
> 残差事件流提供"哪里落空"的原料，注意决策从"落空×利害"的行为涌现（不是手工
> Top-K），注意的注意（docs/237 二阶残差升级）驱动注意转移，注意路径规划（扫视
> 序列）是思考的时序形态（= MC 深度规划的雏形）。前沿（主动推理/层级预测处理）
> 支持同一主张：感知与思考是层级预测的连续，不是两级。**"几乎没人意识到"的原因：
> 主流（LLM/认知架构）把感知当输入管道、思考当独立推理模块；本框架不做独立模块，
> 思考就是感知之上的注意力递归——这是差异化主张，也是 L5 展望的机械形态。**

## 一、前沿对思考的理解（三层印证）

### 1.1 主动推理 / 自由能原理（Friston 系）

- 主张：认知系统 = 最小化惊奇（自由能）的生成模型；**感知与行动是同一循环的两半**——
  感知 = 更新模型拟合世界，行动 = 改变世界拟合模型。
- 推论：思考（推理）= 生成模型的层级推断，感知 = 它的最底层——**"感知是思考的
  基层服务"在主动推理里字面成立**。

### 1.2 层级预测处理（Bayesian brain）

- 主张：大脑 = 层级预测机器——每层预测下层、把下层误差向上传递；**思考 = 高层对
  低层预测误差的再解释；注意力 = 给哪些层的预测误差更高权重（加权门控）**。
- 与本框架的同构：docs/221 残差递归（每层 = 上一层解释不了的剩余）正是层级预测
  误差传递的行为版；注意 = 误差加权 = 本文件要做的决策层。

### 1.3 注意作为认知控制（top-down gating）

- 主张：注意 = 自上而下门控——选择性放大/抑制表征轨迹（神经证据：抑制性信号编码
  自上而下信息）。
- 与本框架的同构：docs/190 目标驱动（想看什么就看见什么）是方向性门控的雏形；
  本文件的注意决策层把门控从"外赋目标"升级为"从残差×利害行为涌现"。

**收敛结论**：前沿主张感知与思考是**同一机制的层级连续**（不是两级模块）。本框架的
任务不是发明新机制，是把 docs/221 的递归从感知轴（残差）扩展到注意轴（资源分配）。

## 二、注意力递归的机械形态（完整设计）

```
层 0 感知（基层服务，已有）：预测-残差事件流
  资源 = 全部像素；投给"落空大×利害重"处
  ——docs/250 快慢原型（时间尺度）+ docs/186 Top-K（空间，但手工统计）

层 1 注意决策（思考的开始，缺）：把资源投给"哪里"的决策
  输入：上一窗口的残差场 R(x,y) + 利害场 S(x,y)（外赋/阅历）
  输出：注意焦点 f = argmax(R × S) 邻域（行为涌现，不是手工 Top-K）
  机制：焦点选择 = 快原型匹配的"下一个最该看的地方"
  ——"投给谁"从统计变成行为的关键一步

层 2 注意的注意（反思，docs/237 延伸）：检查"我注意的决策对吗"
  输入：焦点 f 被注意后，该区域的预测误差是否下降（预期收益）
  若没降 → 二级残差（"我注意错了"）→ 三级注意转向
  ——docs/237 已有二阶残差正证据（r=+0.085），本层把它从"探测"升为"决策驱动"

层 3 注意路径规划（思考的时序形态）：注意焦点序列 = 扫视规划
  输入：层 1-2 的焦点历史 + 阅历
  输出：下一跳焦点（docs/194 眼语言配合扫视的雏形）
  ——MC 的"深度规划"（目标→子目标→动作）就是这一层的空间×时序版
```

**核心主张（预注册候选）**：思考 = 注意力的递归——每层注意决策 = 上一层"为什么注意
这里"的解释不了的剩余（docs/221 深化算子原样）。这与前沿层级预测处理同构：预测
误差在注意层级间递归传递，注意 = 误差的加权门控。

**与 docs/221 的关系**：docs/221 把递归展开在 Ψ = n·S（残差×利害）；本文件把同一
递归展开在注意轴（资源分配×利害）。两条轴共享深化算子，是同一个递归的两种投影。

## 三、B2 实验设计（注意决策的涌现，docs/237 升级）

**这是 L5 层（能力涌现）——docs/247 明令"L5/L6 不得作为判据"**。所以实验按
**机制层可检验的行为签名**设计，不声称"证明它在思考"：

```
实验：注意决策的涌现（docs/237 二阶残差的升级）
场景：合成场景 + 两个候选注意目标（一个高残差低利害、一个低残差高利害）
主张：
  1. 注意焦点应 = argmax(残差×利害) 的行为涌现（不是手工指定）
  2. 焦点被注意后预测误差下降（预期收益验证）
  3. 若焦点收益为负 → 二级残差驱动注意转移（docs/237 预感误配升级为决策）
判据（展望形态，诚实标注 [L5][机制][涌现检验]）：
  - 焦点-收益一致性（焦点落在 R×S 最大邻域的比例）
  - 二级残差→注意转移的正确率
守卫：docs/237 二阶残差复现（同代码路径）
诚实边界：
  - 利害场 S(x,y) 第一版仍外赋（docs/188 纪律，docs/174）
  - 合成受控非真实域证明
  - L5 展望不作验收判据（docs/247）
```

**成功概率预期**：40-60%（中等偏上）——docs/237 已证二阶残差存在（正证据），本实验
把它从"探测"升为"决策驱动"，机制是现成的升级；不确定性在"二级残差是否足够强到驱动
注意转移"（这是新主张）。

"从感知到思考的连续"（前沿主动推理支持）。"纯"不是收窄成感知，是把递归推广到
注意——思考是感知的递归深化，不是独立层。

## 五、诚实边界

1. 本文档是立场 + 机制形态设计，无新实验；B2 实验按 §三 执行后填结果（或由 B2
   文档独立承载）。
2. "思考 = 注意力递归"是对 docs/221 递归读法 + 前沿（主动推理/层级预测处理）的
   机制化翻译，不是新脑科学主张（docs/63：不宣称人脑在做这个）。
3. 利害场 S(x,y) 第一版外赋（docs/174/188 纪律）；"利害从行为涌现"是更远的事。
4. L5 展望不作判据验收（docs/247 规则 2）；B2 的行为签名诚实标注"机制探索，非
   思考证明"。
5. 注意力递归的层 3（注意路径规划）与 MC 深度规划的关系是**方向性**的（雏形），
   不是已实现——E1/E2 行动层仍未做（docs/239 最大缺口）。
