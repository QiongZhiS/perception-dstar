# vision/ — 2D 事件驱动视觉管线（感知 d\* 的视觉线）

> 把普通视频当输入，模拟事件相机式转导层——"先以看视频去测试"。
> 全部实验纯本地可复现（Python 3.11 + numpy + opencv-python，无 API key）。
> 设计文档：`../docs/175-201`（编号时间线）；立场与边界：`../理念/`。

---

## 管线总览（docs/175 管线图的视觉版）

```
帧（视频/DAVIS）
  → Transduction2D（自适应增益 + 双时间尺度 EWMA + 侧抑制 + 事件流）
  → EventReader（事件 → 物体框 + 跟踪）
  → SituationReport（维持目标 + Top-K 威胁度分配）
  → SituationMap（轨迹记忆 + 40 tick 衰减）
  → Affordance → 行为 → 下一帧
```

核心设计（docs/177）：对数亮度 → 双时间尺度背景（快 α=0.5 视锥式 / 慢 α=0.03 视杆式）
→ 对比度 → ESIM 事件累积器（死区 + refractory）→ 2D 侧抑制残差面板。
**设计域教训**：同一套预测维持，放在 0.5s 降幅（暗适应尺度）下几乎全丢，放到 ~0.1s
眨眼尺度就工作——人眼三级时间结构（响应 10-100ms / 抑制窗 20-150ms / 适应秒-分钟）
是每一层机制的落点。

## 六个实验（按编号，均可复现）

### 实验 1 · 转导层闭环（docs/177）— `transduction.py` + `checklist.py`

| 检查 | 数字 | 判据 |
|---|---|---|
| C1 静态区事件率 | 0.0000 | 静态不该有事件 |
| C2 事件定位（物体区占比） | 0.566 | 事件该在动的东西上 |
| C3 下降沿沉降 | 快 3 帧 / 慢 5 帧 | 多时间尺度签名 |
| C4 稳态稀疏度 | 0.0223 | 只处理变化 |

自适应对照（`adaptive_test.py`）：噪声风暴下自适应参数比固定参数安静 **4.3×**
（稀疏度 0.0086 vs 0.0366），且不牺牲 C1。读信息闭环（`close_loop.py`）：只看事件流，
慢圆 78% / 快方块 76% 帧能找回位置（误差 7-16px）。

> ⚠️ 诚实修正：早期"闪变帧检出 1.000"是度量 bug（分子分母同分支 +1 恒等），
> 已独立统计修正为真实数字（慢圆 67% / 快方块 22%）。假指标比坏指标危险（docs/31）。

### 实验 2 · 信息度量：d\* 压缩率（docs/186 §三）— `dstar_compress.py`

**主张：事件数量 ≠ 信息。** 信息 = 单位时间内 d\*（失效距离）被压缩了多少，
不是事件数量。

- toy 3/3 PASS：风暴与降幅事件率几乎相同（0.305 vs 0.315，比 0.97），但压缩率背离
  **2×**（0.26 vs 0.51）——事件数量无法区分噪声风暴和结构事件，压缩率能；
- 真实视频（18167 帧）：切变帧 11/11 d\* 归 0、压缩脉冲占比 0.55 PASS。

### 实验 3 · 注意力 = Top-K 威胁度分配（docs/186 §五）— `topk_experiment.py`

**主张：值得注意是关系属性，不是框属性。** 两阶段：

1. **负结果**：无维持目标时，五轮特征诊断（面积/hits/速度/位置漂移/形状紧凑度/
   方向一致性）命中框与误报框**全部不可分**——car-turn 后段事件密度暴涨 25 倍时，
   背景事件块与真物体在事件层面同构；
2. **正结果**：给定维持目标（第一帧掩码）后，威胁度 = 候选框与目标预测框 IoU +
   方向趋近，Top-K 保留：

| K | 目标检出率 | 每帧框数 |
|---|---|---|
| 0（基线） | 0.975 | 76.5 |
| 3 | 0.963 | **3.0** |

**误报 76.5→3 框/帧（25× 压降），检出率 -1.2%**——利害（维持目标）给定后，
系统"只看该看的"。复杂度 O(N)（N=事件流，本身稀疏 1-2%）。

### 实验 4 · 视觉态势闭环（docs/189）— `situation.py` + `visual_loop.py`

外赋"车"为维持目标 → 态势每帧报告（Top-K=3）→ 态势地图（40 tick 衰减）→
affordance 朝目标走 → 行为。DAVIS car-turn 80 帧：

| 度量 | 值 |
|---|---|
| map_frac（地图记忆决策占比） | **1.00**（80/80） |
| agent-车距离 | 747px → 50px（后 20 帧中位 30px） |
| 维持目标 conf | 0.97 全程 |

诚实边界：虚拟 agent 无物理运动学——验证的是"感知→记忆→决策"链，不是导航。

### 实验 5 · 颜色恒常："何时校正"判据（docs/199/199b）— `color_constancy_temporal.py` + `davis_constancy.py`

**主张：视频色温变化时，校正与否由一个组合判据决定**（docs/101"越噪声越固执"
在颜色轴的落点）：

```
真染色（背景色相环形 MAD < 20°）   —— 色相集中 = 同一色温染的（噪声分散 ~47°）
AND 帧间一致（|Δshift| EWMA < 3°） —— 帧间连续 = 渐变/稳定该校正（突变该固执）
两条件 AND → 门开（通道级白平衡校正）；否则固执（不校正）
```

DAVIS 6 视频 × 4 扰动（24 条件）：

- **噪声（帧间增益跳变）：门 6/6 全关（0/60）**——帧间突变该固执 ✓
- **黄昏渐变/基线/阶跃：门全开（29-49/60）**——渐变也开（黄昏该校正）✓
- **白平衡通过率 24/24 全 1.0**（乘性增益不破坏确认）；色相旋转大多破坏 ✗

> ⚠️ 判据修正链（教科书级诚实）：docs/197 单帧 frac 门槛 → docs/199 组合判据 +
> 四重错误修正（排除带泄漏/阈值误拒/旋转破坏/度量假象）→ docs/199b 二度修正
> （frac→MAD、EWMA 方差→帧间|Δ|，因真实场景 frac 0.08-0.47 普遍被 0.5 门槛误拒）。

### 实验 6 · 拒绝的历史（docs/200/201）— `keep_reject.py` / `keep_reject_open.py` / `keep_reject_continuous.py`

**主张：确认失败被"保留"（第 6 层）vs 被"吸收"（第 5 层）——行为不同。**
docs/178 补刀："不是造更准的模型，是造一个愿意保留'不准'作为纪念的模型"。

**6a（docs/200）**：红球中段被外部染蓝（一次"不准"）后恢复红：

| 判据 | A 吸收 | B 保留 |
|---|---|---|
| P1 自我漂移（染色末 \|期望−任务红\|） | **120.0°**（被带偏到蓝） | **0.0°**（守住） |
| P2 染色段确认通过率 | 0.900（接受蓝=污染） | **0.000**（错色全拒） |
| P3 重信任延迟 ∝ 被拒时长 | — | 0→1、5→2、15→6、30→11、60→**21** 帧 |

**6b（docs/201 开放端）**：保留系统加滞回改判（连续被拒 ≥ K_switch 才改判、回改需
同等证据）——世界真变蓝时能学习（改判后通过 0.87），短暂染色时仍守住（同原版）；
阈值太松（K=25<30）被单次染色重写（恢复延迟 1→16 帧）。

**6c（docs/201 连续失败率）**：被拒从二值推广为失败率 0.5/0.8/渐变，P3 单调性跨模式
成立，且延迟按被拒计数对齐（**r = 0.999**）——**决定量是被拒历史（计数），不是时间
长度**。

## 运行方式

```bash
python transduction.py            # 实验 1：转导层 + 检查单（合成 demo，无外部数据）
python close_loop.py              # 实验 1b：事件→物体闭环
python dstar_compress.py          # 实验 2：d* 压缩率（toy 无数据；真实视频需 DAVIS）
python topk_experiment.py         # 实验 3：Top-K（需 DAVIS car-turn）
python situation.py / visual_loop.py  # 实验 4：态势闭环（需 DAVIS）
python davis_constancy.py         # 实验 5：颜色恒常（需 DAVIS 6 视频）
python keep_reject.py             # 实验 6a：拒绝的历史（纯 toy，无外部数据）
python keep_reject_open.py        # 实验 6b：守住 vs 改判
python keep_reject_continuous.py  # 实验 6c：连续失败率 P3
```

DAVIS 数据：下载 [DAVIS](https://davischallenge.org/) 后放 `out/davis/`（脚本内路径
见各文件头部）。toy 实验（1a/2-toy/6）完全无外部依赖。

## 边界纪律（docs/63）

- 全部实验是**行为签名**（残差/漂移/延迟/拒斥），不宣称任何"体验"；
- toy 场景（合成红球 + 真值掩码）是受控优势，真实视频实验标注清楚；
- 修正链（docs/197→199→199b、闪变检出度量 bug）是自我修正的样本，不是弱点。

## 一句话

**转导 → 读 → 态势 → 行为 → 拒绝：视觉线从"看"长到"被看见"，每一步都有可复现
的数字，每一步的边界都写在文档里。**
