# Line B — 运动耦合判别（残差递归路）

> **路线的定位**：docs/221 残差递归的正统主张是"一切结构从残差行为涌现、不手工造判据"。
> 光影线 docs/260-272 的"检出"是残差递归（Pass A/B），但"判别"（V1/V3/V4、计分制）
> 是手工几何/颜色启发式——docs/187 早已承认"读层缺的正是这个假设"。**B 路 = 把
> 判别从几何路换到行为路**：阴影 vs 物体的本质区别是行为性的（轨迹耦合、可预测性），
> 不是几何性的——用残差递归的主场（时间/运动/预测）重做判别，把手工规则赎回来。

## 存放约定（与主线隔离）

- `docs/` — B 路自己的预注册/结果文档，编号 B1, B2, ...（不占主线 docs/ 编号）
- `scripts/` — B 路实验脚本（import 复用主线 vision/ 机制，**零改写主线脚本**）
- `out/` — B 路工件（结果 JSON、日志；同样遵守"毒文件"纪律——人可读、模型禁读）

## 纪律（沿用主线，docs/63/247）

- 预注册冻结：判据/旋钮/守卫先于实现写入 docs/B<n>，运行后不改 §一
- 判据带 docs/247 层级标签
- 守卫：同代码路径复现前一格（主线 docs/260-272 数字逐位）
- 安全：stdout 只 R_LB_* ASCII；powershell 包装重定向；extract_r 纯正则；禁读毒文件
