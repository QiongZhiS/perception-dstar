## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

用户洞察的机制翻译（冻结）："多场景理解……单独理解物体，场景也像单独的整体理解（难
自我意识到）……缺陷呢？场景先行，那么单物体处理呢？再到纹路等" → 感知 = 沿粒度轴的
递归组织：**场景 gist 先行**（整体统计，<150ms 自动提取——docs/250 快原型 = 粗、即时；
本格 gist = 逐窗口粗布局统计），**物体**（焦点内判别、慢原型吸收），**纹路**（焦点内
细粒度、docs/187 纹路只在焦点+异常时浮现）。每层"解释不了的剩余"（docs/221 深化算子在
粒度轴的实例化）= 该粒度残差超预期的相干区域 = **缺陷**；缺陷驱动**下钻**（注意聚焦到
缺陷处，处理下一更细粒度）。感知层级的组织 = 缺陷（残差）沿粒度轴的逐层深化。

本格目标（冻结）= 首验该机制在合成受控域的行为签名：

1. **场景 gist 先行**：场景级整体统计（粗布局）先于物体/纹路判别可用，且凭 gist 统计
   可正确识别场景风格族（"这是海滩/森林/街道风格"的合成受控版 = 风格分类正确率）；
2. **缺陷驱动下钻**：每级缺陷（残差超预期）处注意聚焦到下钻粒度，下钻焦点落在该级
   真缺陷（GT）邻域（drill1 场景→物体落圆盘、drill2 物体→纹路落条纹/暗点、drill3
   纹路→终态落暗点）；
3. **粒度单调性**：下钻顺序 = 场景 → 物体 → 纹路（粒度由粗到细单调：永不回粗粒度），
   且内容在正确粒度被吸收（圆盘本体在物体级吸收、条纹只在纹路级吸收、暗点终态不吸收）。

**范围收窄（冻结）**：单一合成场景族（docs/232/235 风格，同分布多种子 = L1 域强度）；
**不做**：真实域（ISTD/DAVIS）、层 3 注意路径规划（C2 §五 5）、多目标交互、粒度 >3 的
递归（纹路为最细层，其缺陷 = 终态落空，交接 docs/260-272 判别器线——本格只报交接点、
不重跑判别机制）。

**诚实声明（冻结，§一 必须写明）**：本格测的是**机制层可检验的行为签名**——"场景 gist
先行 + 缺陷（残差超预期）驱动逐粒度下钻 + 粒度单调吸收"在合成受控域（L1 强度）的成立性；
**"缺陷"一词在本文档 = 残差超该粒度预期的相干区域（docs/221 原子），不是语义上的"破损"**
——场景构造里的"条纹/暗点/划痕"命名只是受控构造的标签，机制本身只算残差场、零手工语义；
**不声称任何"理解场景/理解物体/理解纹路"**（docs/63 行为签名纪律；docs/247 规则 2：L5
不作验收判据，本格判据为机制层 `[L1]` 标签，不涉及 L5 能力主张）。纹路细节只在注意焦点 +
异常时处理（docs/187 0 事件实证）以场景内静止纹理块 + "纹路粒度处理窗口全部在焦点内"
作诚实锚点（报告量，非判据）。

**与 B2/B3 的关系（冻结）**：B2/B3 的层 1 注意决策（焦点 = argmax(R×S)）与层 2 二级残差
驱动转移在本格被**复用为下钻机制**（每粒度缺陷处注意聚焦 = argmax(R×S)，S 第一版外赋 =
均匀 1.0——本格的下钻是"残差驱动的聚焦"，利害场第一版取均匀，见 §1.3 冻结声明）；B2/B3
的结论原样保留为守卫复现（R_B4_GUARD_B2 / R_B4_GUARD_B3 同代码路径）。docs/260-272 判别
器线的三连数字（det/ld/sfs）以 R_B4_GUARD_260 守卫复现（判别能力不退化）；纹路级终态
落空（暗点 = 非纹理运动结构）是交给该线的交接点，本格不重跑判别。

  （条纹 x≥0 vs 暗点 x≤−2）→ 连通域不合并（候选分离）✓；
- 暗点：相对盘心 |offset| ≤ 6、盘缘 ≤ 6+2=8 < 10 ✓ 全在盘内；与盘缘（中频边缘环带）
  分离（物体缺陷域 = 盘内部 r≤8，见 §1.3）✓；
- 亮域检测（物体级跟踪）：圆盘 255 vs 背景 96/128/48：log(256)=5.545 vs log(97)=4.575、
  log(129)=4.86、log(49)=3.89——余量 ≥ 0.69 log ≈ 15σ（σ_log≈0.046）→ 检测几乎恒成功

  ≤30-40）→ MAE 增量 ≤ ~1.5 ≪ 判别余量 → 分类鲁棒（诊断轮复核）。

### 1.3 机制（冻结；行为量可操作计算 + 三层预测器 + 下钻状态机 + 旋钮）

**感知层（docs/235 同代码路径，import 复用）**：全分辨率预测回路 CPLoop（对数域双 EWMA
bg_fast(α=0.5)/bg_slow(α=0.03) + 自适应阈值 + 死区）逐帧跑场景——**只作 docs/187 锚点
（静止纹理块事件量 ≈ 0）与守卫复用路径，不进入三层粒度机制**。

**三层粒度预测器（冻结；全部由残差场可操作计算，零手工语义）**：

| 层 | 预测器 | 操作定义 | 吸收的频率带 | 逃逸 = 该层缺陷 |
|---|---|---|---|---|
| **gist**（场景） | 粗布局重建 G | 逐窗口（10 帧均值）8px 块均值 L（20×15 粗图）→ 最近邻上采样重建；R_g = mean_t\|L(t) − G\| | 块尺度（<1/8 px⁻¹）：棋盘/风格带/静止纹理块均值 | 移动亮圆盘（块尺度解释不了的相干亮斑） |
| **object**（物体） | 焦点内平滑模板 P_o | 盘心亮域跟踪（L>log(221) top-1 质心，docs/260 同款阈值）；焦点裁剪 40×40（盘心居中、逐帧注册）；模板 T_o = EWMA(α_o=0.5)（仅物体窗口更新，首裁剪初始化）；预测 P_o = GaussianBlur(T_o, σ_o=2.5)；R_o = \|L_crop − P_o\|（域 = 盘内部 r≤8——排除盘缘环带，见冻结声明） | 中频物体本体（≤1/3 px⁻¹ 平滑变化） | 2px 细条纹（高频）+ 运动暗点（动态） |
| **texture**（纹路） | 焦点内锐模板 T_t | 下钻焦点 F2（盘相对偏移固定）处 16×16 裁剪（中心 = 盘心+偏移，逐帧注册）；模板 T_t = EWMA(α_t=0.5)（仅纹路窗口更新，首裁剪初始化）；R_t = \|L_crop − T_t\|（锐，无模糊） | 高频规则图案（条纹周期 2px，静态于注册裁剪 → 被吸收） | 运动暗点（非纹理结构，逃逸 → 终态落空） |

**冻结声明（域选择）**：物体缺陷搜索域 = 盘内部 r≤8（排除盘缘 r∈(8,10] 环带——盘缘
在 0.5px 注册量化抖动下 R_o 恒高，是物体边界不是内部异常；"物体级缺陷 = 物体内部局部
异常"的忠实操作化）；纹路缺陷搜索域 = F2 处 16×16 裁剪；gist 缺陷搜索域 = 全帧。
**冻结声明（利害场第一版）**：下钻候选价值 V_i = s_i·max_{候选 i}(R_ℓ)，s_i = **1.0 均匀**
（利害场第一版外赋 = "所有落空同等值得下钻"，docs/174/188 纪律：外赋"谁值得"标量；
本格下钻 = 纯残差驱动（缺陷=落空=引擎），B2/B3 的 argmax(R×S) 机制以 S≡1 复用——诚实
标注：利害不对称不在本格）。

**缺陷（= 该粒度解释不了的剩余）与下钻（冻结）**：

- **缺陷候选**：层 ℓ 残差场 R_ℓ 中"残差超预期"的相干 8-连通区域——阈值 **θ_ℓ = K·σ̂_ℓ**
  （σ̂_ℓ = R_ℓ 在该层域上的 MAD 噪声估计（docs/260 MAD 同款，median|R−median|/0.6745），
  K = **3.0**；"预期" = 该粒度自身的噪声底——残差超过噪声底 3 倍 = 该粒度解释不了的
  落空）；最小面积 A_MIN = 10 px（gist 层 25 px，同 docs/260——gist 域大、防盘缘碎屑）；
- **注意聚焦（下钻，L1 复用）**：候选 i 的价值 V_i = s_i·max_{候选 i}(R_ℓ)（s_i=1.0），
  焦点 F = argmax_i V_i（行为涌现，非手工指定位置）；F 落哪个候选的质心，即下钻到该处；
- **持久性确认**：缺陷需在窗口内 ≥ k_drill = 3 帧（≥30%）存在才判"缺陷发生"（防单帧
  噪声尖峰；条纹静态于注册裁剪 → 首帧即被锐模板吸收，无暖机假缺陷——见 §1.2/§1.3
  分析）；
- **粒度状态机（逐窗口，冻结）**：窗口 0 = gist；此后 L(w+1) = next(L(w)) 若 L(w) 窗口
  发现缺陷，否则回 gist；next(gist)=object、next(object)=texture、next(texture)=gist
  （纹路吸收 = 无缺陷 → 回场景；纹路终态缺陷 → 报告后回场景）。本场景各级缺陷恒在 →
  窗口序列 = 0,3,6,…,21 gist；1,4,7,…,22 object；2,5,8,…,23 texture（8 周期/种子）；
- **行为量记录（冻结；全部可操作）**：R_g/R_o/R_t（各层残差场均值）；θ_g/θ_o/θ_t（各层
  缺陷阈值）；缺陷候选集合；焦点 F1/F2/F3（各下钻事件）；drill 正确 = F 落在该级真缺陷
  GT（§1.2 构造标注，仅事后测量、绝不进机制）邻域（GT 掩码膨胀 2px）；backward = 下钻
  事件粒度不增（回粗）计数；吸收度量（见 C3）；风格分类（见 C1）；静止纹理块锚点。

**行为量定义汇总（冻结）**：

| 行为量 | 符号 | 定义 |
|---|---|---|
| gist 残差场 | R_g(w) | mean_t \|L(t) − G(t)\|（G = 8px 块均值重建，窗口 10 帧） |
| object 残差场 | R_o(w) | \|L_crop − blur(T_o, 2.5)\|（盘内部 r≤8，物体窗口） |
| texture 残差场 | R_t(w) | \|L_crop − T_t\|（F2 处 16×16，纹路窗口） |
| 缺陷阈值 | θ_ℓ | K·σ̂_ℓ（σ̂ = 该层域 MAD 噪声估计，K=3.0） |
| 缺陷候选 | C_ℓ | R_ℓ > θ_ℓ 的 8-连通区域（面积 ≥ A_MIN） |
| 下钻焦点 | F_ℓ | argmax_i (s_i·max_{C_i} R_ℓ)（s_i=1.0 外赋利害第一版） |
| 下钻正确 | — | F_ℓ ∈ 该级真缺陷 GT 膨胀 2px |
| 缺陷发生 | — | 候选在窗口内 ≥ k_drill=3 帧存在 |
| 粒度状态机 | L(w) | 缺陷 → next 粒度；无缺陷/终态 → gist |

**旋钮（冻结机制；载体旋钮 = §二 诊断定案对象，判据/机制语义不动）**：`K=3.0`（缺陷 =
超噪声底 3 倍；初值论证：高斯噪声 3σ 检出的标准口径，docs/260 同精神）；`σ_o=2.5`（平滑
模板 σ——须 ≥ 条纹半周期 1px 使条纹逃逸、且 < 盘半径余量使本体吸收；初值 2.5 = 条纹
周期 2px 的 1.25×）；`α_o=α_t=0.5`（= CPLoop α_fast 同款快吸收）；`条纹 120/255 周期 2px`
（对噪底 σ̂≈0.04 的残差余量 ≈ 0.44 log ≈ 11σ̂；初值论证）；`暗点 60/r=2`（对噪底余量
≈ 1.4 log ≈ 35σ̂）；`k_drill=3`；`A_MIN=10/25`；`LVCODE_B4=41/42/43`。所有旋钮先于任何
运行冻结，判据测行为（gist 先行/下钻正确/粒度单调/吸收）不测内部参数；载体旋钮（K、σ_o、
条纹/暗点参数、阈值口径）允许在 §二 按诊断数据定案（B2 §二 D1/B3 §二 D1-1 同款先例：
"最终运行前设计精化、判据未动"）。
