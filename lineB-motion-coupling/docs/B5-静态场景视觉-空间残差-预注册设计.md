## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/255 §六.5 的机制翻译（冻结）：docs/187 的"静止 = 0 事件"是**时间预测**（bg_fast
预测下一帧）的结论；**残差递归只需要"预测-落空"，预测源可以是时间的（下一帧）也可以是
空间的（邻域重建）**——**空间预测下静止结构依然可感知**。本格目标 = 首验该主张在合成
受控域的行为签名：

1. **静止帧有空间残差**：完全静止帧（无运动、无时间变化）上，时间残差 = 噪声底（事件率
   0，docs/187 前提复现）的对照下，空间残差在静态缺陷处显著 > 0——**"感知消失"只在时间
   预测下成立，空间预测打开静态通道**；
2. **静态缺陷被检出**：空间残差超预期（max(K·σ̂, 0.10)）的相干区域 = 静态缺陷——"缺陷 =
   该粒度解释不了的剩余"（docs/221 原子）在静止帧上同样成立；
3. **静态缺陷处粒度下钻**：缺陷处注意聚焦驱动 gist → object → texture 逐级下钻（B4
   机制**原样复用**），静止帧上同样工作（drill1 落圆盘、drill2 落条纹、drill3 落划痕），
   且下钻粒度单调（backward = 0）、内容在正确粒度被吸收（盘本体 object 级吸收 / 条纹
   texture 级吸收 / 划痕终态不吸收）。

**范围收窄（冻结）**：单一合成场景族（docs/232/235 风格，同分布多种子 = L1 域强度）；
**不做**：真实域（ISTD/DAVIS）、运动（本格场景**故意零运动**——运动是时间残差的来源，
要隔离它就必须把它关掉）、层 3 注意路径规划、粒度 > 3 的递归（纹路为最细层，其缺陷 =
终态落空，交接 docs/260-272 判别器线——本格只报交接点、不重跑判别机制，同 B4）。

**诚实声明（冻结，§一 必须写明）**：本格测的是**机制层可检验的行为签名**——"完全静止
帧上，纯空间残差（gist 块重建/局部模板/纹理统计的重建误差）超预期处 = 静态缺陷，缺陷处
粒度下钻（B4 机制复用）成立"在合成受控域（L1 强度）的成立性；**"缺陷"一词在本文档 =
空间残差超该粒度预期的相干区域（docs/221 原子），不是语义上的"破损/划痕"**——场景构造
里的"圆盘/条纹/划痕"命名只是受控构造的标签，机制本身只算残差场、零手工语义；**不声称
任何"理解场景/理解物体/理解纹路"**（docs/63 行为签名纪律；docs/247 规则 2：L5 不作验收
判据，本格判据为机制层 `[L1]` 标签，不涉及 L5 能力主张）。

**与 docs/187 的关系（冻结，推广而非反驳）**：docs/187 的"静止纹理 = 0 事件"是**时间
预测**（背景 EWMA 预测下一帧）的结论——本格 TIME_ZERO 对照在**时间通道**逐位复现它
（静止纹理块 0 事件、全帧事件率 ≈ 0），即**前提成立、结论成立**；本格的新主张 = 预测源
还可以是**空间的**（邻域重建），空间预测下静止结构（异常部分）依然可感知——**"静止 =
0 事件"的适用范围是时间预测；docs/255 §六.5"残差有时间维（运动）+ 空间维（结构）"的
操作化首验**。**不**声称 docs/187 错了——它是时间通道的正确结论；本格补充空间通道。

**与 B4 的关系（冻结）**：B4 = 粒度递归（三层预测器 + 缺陷驱动下钻）在**含运动**场景的
成立性；B5 = 同一机制在**完全静止**场景的独立主张（B4 的附带验证升级为独立格）。B5 的
三层粒度预测器与 B4 的**机制分工相同**（gist 粗布局重建 / object 焦点内局部模板 /
texture 焦点内纹理统计），但 **B5 全部为纯空间逐帧预测器**（无时间模板更新）——这是
"空间残差"的操作化硬约束：静止场景下时间模板会把一切静态内容吸收掉（docs/187 机制
本身），若用时间模板则静止缺陷永不可见（正是要对照的主张，见 §1.3 冻结声明）。B4 的
判据数字（GIST 1.0 / DEFECT_DRILL 1.0 / GRANULAR_ORDER 1.0）以 R_B5_GUARD_B4_* 守卫
逐位复现（同代码路径 import run_b4）；B4 的 docs/260/B2/B3/SO/COMPOSE 守卫为 B4 自己的
KEEP 内容，B5 不重跑（B5 只 import 未改 B4 代码路径，且 B4 三判据数字逐位复现即证明
B4 代码路径无退化）。

### 1.3 机制（冻结；行为量可操作计算 + 纯空间三层预测器 + 缺陷/下钻 + 旋钮）

**对照设计（冻结，本格核心）**：同一静止场景上跑两类预测器，测同一像素——

| 通道 | 预测器 | 操作定义 | 静止场景的行为 |
|---|---|---|---|
| **时间（对照）** | bg_fast EWMA（CPLoop，docs/187 同款） | 预测下一帧；残差 = \|L − bg_fast\|；事件 = max(r−db,0) > θ | 静止内容被预测掉 → 残差 = 噪声底（≈0.02-0.03）、事件率 ≈ 0（docs/187 前提复现） |
| **空间（本格）** | 三层纯空间预测器（§下） | 从**同一帧的空间邻域**重建；残差 = \|L − 空间重建\| | 规则结构被吸收（残差 ≈ 噪声）、异常结构逃逸（残差 ≫ 噪声底） |

**纯空间约束（冻结声明）**：B5 的三层预测器**全部为逐帧纯空间预测器**（每帧只读当前帧
的空间统计，无任何时间更新/时间模板）——这是"空间残差独立于时间残差"的操作化硬约束：
静止场景下时间模板（EWMA）会把一切静态内容吸收掉（docs/187 机制本身），若用时间模板则
静止缺陷永不可见（正是要对照的主张）。gist 块均值重建在 B4 已是逐帧纯空间（原样复用）；
object/texture 在 B4 是时间模板（EWMA），**B5 改为纯空间预测器**（局部空间平滑 / 空间
方向统计），机制分工不变、预测源变空间。

**三层空间预测器（冻结）**：

| 层 | 预测器 | 操作定义 | 吸收的静态结构 | 逃逸 = 该层缺陷 |
|---|---|---|---|---|
| **gist**（场景） | 粗布局重建 G | 逐窗口（10 帧均值）8px 块均值 L（20×15 粗图）→ 最近邻上采样重建（B4 coarse_image/coarse_recon import 复用）；R_g = mean_t\|L − G\| | 块尺度（<1/8 px⁻¹）：棋盘/风格带/静止纹理块均值 | 静态亮圆盘（块尺度解释不了的相干亮斑） |
| **object**（物体） | 焦点内空间平滑模板 P_o | 盘心亮域跟踪（L>log(221) top-1 质心，docs/260 同款，B4 同款检测循环）；焦点裁剪 40×40（盘心居中）；**P_o = 当前帧掩膜归一化高斯**（GaussianBlur(Lc·D)/GaussianBlur(D)，σ_o=1.5——纯空间，无时间模板）；R_o = \|L_crop − P_o\|（域 = 盘内部 r≤8——排除盘缘环带，B4 冻结声明同款） | 中频平滑本体（≤1/3 px⁻¹）：盘本体 255 均匀区 | 2px 竖条纹（暗列，高频）+ 划痕（薄线） |
| **texture**（纹路） | 焦点内纹理统计预测器 P_t | 下钻焦点 F2（盘相对偏移固定）处 16×16 裁剪（中心 = 盘心+偏移）；**主导方向 = 结构张量估计**（Sobel 梯度 → gxx/gyy/gxy → θ = 0.5·atan2(2gxy, gxx−gyy) → 纹理方向 = 垂直最大梯度的方向；张量迹 ≈ 0 时回退 3×3 中值）；**P_t = 沿主导方向的 1×N 中值滤波（N=5）**——"纹理统计（方向/周期/密度）"的操作化（docs/255 L-texture 层）；R_t = \|L_crop − P_t\|（域 = 裁剪 ∩ 盘内部 r≤8） | 高频规则图案（竖条纹：沿垂直方向的列中值 = 条纹值，被预测掉——docs/187 纹路被预测掉的空间版） | 静态划痕（水平线 = 非纹理结构，1-D 中值窗口内少数，逃逸 → 终态落空） |

**冻结声明（域选择）**：object 缺陷搜索域 = 盘内部 r≤8（排除盘缘环带，B4 同款——"物体
级缺陷 = 物体内部局部异常"的忠实操作化）；texture 缺陷搜索域 = F2 处 16×16 裁剪 ∩ 盘
内部；gist 缺陷搜索域 = 全帧。
**冻结声明（利害场第一版）**：下钻候选价值 V_i = s_i·max_{候选 i}(R_ℓ)，s_i = **1.0 均匀**
（利害场第一版外赋 = "所有落空同等值得下钻"，B4 同款；本格下钻 = 纯残差驱动（缺陷=落空=
引擎），诚实标注：利害不对称不在本格）。

**缺陷（= 该粒度解释不了的剩余）与下钻（冻结，B4 机制原样复用）**：

- **缺陷候选**：层 ℓ 残差场 R_ℓ 中"残差超预期"的相干 8-连通区域——阈值 **θ_ℓ = max(K·σ̂_ℓ,
  THETA_FLOOR)**（σ̂_ℓ = R_ℓ 在该层域上的 P50（B4 诊断定案的稳健噪声尺度："该粒度典型
  残差"），K = **3.0**，THETA_FLOOR = **0.10**（噪声底下限）；"预期" = 该粒度自身的噪声
  底——残差超过噪声底 3 倍 = 该粒度解释不了的落空）；最小面积 A_MIN = 25/5/5 px
  （gist 25、object/texture 5，B4 定案同款）；
- **注意聚焦（下钻，L1 复用）**：候选 i 的价值 V_i = s_i·max_{候选 i}(R_ℓ)（s_i=1.0），
  焦点 F = argmax_i V_i（行为涌现，非手工指定位置）；F 落哪个候选的质心，即下钻到该处；
- **持久性确认**：缺陷需在窗口内 ≥ k_drill = 3 帧（≥30%）存在才判"缺陷发生"（防单帧
  噪声尖峰；本场景内容逐帧恒同 → 恒满足，同 B4 语义）；
- **粒度状态机（逐窗口，冻结，B4 原样）**：窗口 0 = gist；此后 L(w+1) = next(L(w)) 若
  L(w) 窗口发现缺陷，否则回 gist；next(gist)=object、next(object)=texture、
  next(texture)=gist（纹路吸收 = 无缺陷 → 回场景；纹路终态缺陷 → 报告后回场景）。本场景
  各级缺陷恒在 → 窗口序列 = 0,3,6,…,21 gist；1,4,7,…,22 object；2,5,8,…,23 texture
  （8 周期/种子）；
- **行为量记录（冻结；全部可操作）**：R_g/R_o/R_t（各层残差场均值）；θ_g/θ_o/θ_t；缺陷
  候选集合；焦点 F1/F2/F3；drill 正确 = F 落在该级真缺陷 GT（§1.2 构造标注，仅事后测量、
  绝不进机制）邻域（GT 掩码膨胀 2px）；detect 正确 = 该级缺陷区（GT 定义）残差超该级
  阈值；吸收度量（盘本体 object 级吸收 / 条纹 texture 级吸收 / 划痕终态不吸收）；
  backward = 下钻事件粒度回粗计数；时间残差/事件（对照）；静止纹理块锚点。

**行为量定义汇总（冻结）**：

| 行为量 | 符号 | 定义 |
|---|---|---|
| 时间残差（对照） | R_tmp | mean_{t≥30} \|L − bg_fast\|（CPLoop，bg_fast EWMA 预测下一帧） |
| 时间事件率（对照） | ev_tmp | mean max(r−db, 0) > θ（CPLoop 事件掩码比例，t≥30） |
| gist 残差场 | R_g(w) | mean_t \|L − G\|（G = 8px 块均值重建，窗口 10 帧） |
| object 残差场 | R_o(w) | \|L_crop − P_o\|（纯空间掩膜归一化高斯，σ_o=1.5，盘内部 r≤8，窗口最大） |
| texture 残差场 | R_t(w) | \|L_crop − P_t\|（沿主导方向 1×5 中值，裁剪 ∩ 盘内部，窗口最大） |
| 缺陷阈值 | θ_ℓ | max(K·σ̂_ℓ, 0.10)（σ̂ = 该层域 P50，K=3.0） |
| 缺陷候选 | C_ℓ | R_ℓ > θ_ℓ 的 8-连通区域（面积 ≥ A_MIN） |
| 下钻焦点 | F_ℓ | argmax_i (s_i·max_{C_i} R_ℓ)（s_i=1.0 外赋利害第一版） |
| 下钻正确 | — | F_ℓ ∈ 该级真缺陷 GT 膨胀 2px |
| 检出正确 | — | 该级缺陷 GT 区残差 > θ_ℓ（gist：盘 GT 区 R_g 均值；object：暗条纹列 R_o 中位数；texture：划痕 R_t 中位数） |

## 五、诚实边界（预注册阶段已知）

1. **合成受控、非真实域证明（L1 强度）**：docs/232/235 风格 toy 场景族（棋盘 + 静态圆盘 +
   受控条纹/划痕），判据带 `[L1][机制][合成受控]` 标签——证据强度止于该场景族（同分布
   多种子），不构成任何 L2+ 泛化主张；真实域（复杂场景/遮挡/利害不确定性）的静态场景
   视觉未测。
2. **"缺陷" = 空间残差超预期（docs/221 原子），不宣称语义理解**：场景构造中的"圆盘/条纹/
   划痕"命名只是受控构造标签（GT 标注用），机制本身只算残差场（R_g/R_o/R_t 超 max(K·σ̂,
   0.10) 的相干区域），零手工语义、零 GT 使用（GT 仅事后测量）；"吸收" = 该粒度空间预测器
   把残差压回噪声底的行为签名，不宣称"识别出背景/物体/纹路"。
3. **对照设计的论证（空间残差 vs 时间残差）**：同一静止场景、同一像素，两类预测器的
   行为差——时间预测（bg_fast EWMA 预测下一帧）对**一切**静止内容收敛（残差 → 噪声底、
   事件 → 0，docs/187 结论本身）；空间预测（块重建/局部模板/方向统计）只吸收**规则/预期**
   结构（棋盘/风格带/静止纹理块/盘本体/条纹），逃逸**异常**结构（圆盘/条纹/划痕）。因
   此"空间残差 > 时间残差"不是把噪声当信号的假阳性：它发生在**构造标注的缺陷 GT 区**
   （事后测量），且背景区空间残差 ≈ 噪声底（报告量）——**空间残差是"静态结构中不合空间
   预期者"的检测器，不是"一切静态结构"的检测器**。诚实标注：空间预测器的"预期"是构造
   的（块对齐布局/平滑本体/方向条纹——块对齐避免重建边界伪残差是构造性选择），本格证明
   的是**机制形态**（空间预测-落空在静止帧上工作），不是空间预期的普适正确性。
4. **与 docs/187 的关系（推广而非反驳）**：docs/187"静止 = 0 事件"是**时间预测**的结论
   ——本格 TIME_ZERO 对照在时间通道逐位复现它（静止纹理块 0 事件、全帧事件率 ≈ 0、时间
   残差 = 噪声底），即**不反驳、前提与结论都复现**；docs/255 §六.5 的关键洞察是预测源
   可以是空间的，本格 = 该洞察的操作化首验："感知消失"只在时间预测下成立，空间预测下
   静止结构（异常部分）可感知。**"残差是原子"从时间维（运动）推广到空间维（结构）**。
5. **纯空间预测器 = 对照设计硬约束（冻结声明）**：B5 三层预测器全部逐帧纯空间（无时间
   模板）——静止场景下时间模板会把一切静态内容吸收掉（docs/187 机制本身），若用时间
   模板则"静止缺陷可见"无从谈起。这不是回避——这正是对照：**时间预测吸收一切静态（含
   缺陷），空间预测只吸收规则结构（缺陷逃逸）**，两者的差 = 本格主张。
6. **纹理统计预测器的方向 = 从像素统计涌现**：主导方向由结构张量估计（非手工指定）；
   本场景构造为竖条纹 → 方向 = 垂直 → 1-D 中值吸收竖条纹、逃逸水平划痕。诚实标注：方向
   统计是"纹理统计（方向/周期/密度）"（docs/255 L-texture 层）的操作化，真实域纹理方向
   的鲁棒性未测（L2+）。
7. **利害场第一版外赋 = 均匀 1.0**（docs/174/188 纪律）：下钻候选价值 V = s·max(R) 中
   s≡1——本格下钻 = 纯残差驱动（缺陷=落空=引擎）；利害不对称不在本格（B2/B3 先例）。
8. **docs/187 纹路纪律的诚实锚点**：静止纹理块——gist 块均值吸收（R_g 低于缺陷阈值）、
   全分辨率时间回路事件量 = 0（docs/177 C1 同款口径）；盘上条纹只在**下钻到纹路粒度**
   后被处理（纹路粒度处理窗口全部在焦点内，报告量 = 焦点外纹路处理窗口数 = 0）；纹路
   细节只在注意焦点 + 异常时浮现（docs/187 主张的行为签名，非判据）。
9. **纹路级终态 = 交接点，不重跑判别**：纹路级缺陷（静态划痕 = 非纹理结构）是 docs/260-
   272 判别器线的交接点；本格只报终态落空（空间残差超预期 + 无更细粒度），不重跑判别
   （B4 同款声明）。
10. **载体旋钮按诊断定案（判据/机制语义未动）**：K、σ_o、条纹/划痕构造参数、阈值口径为
    载体旋钮（§1.3），允许在 §二 按诊断数据（timing 冒烟 / 边界扫描 / diag）定案——判据
    阈值与机制语义（纯空间三层预测器分工、缺陷 = max(K·σ̂, 0.10) 超预期、下钻 =

11. **判据阈值为合成场景标定值**（0.001/0.0/0.10、5.0/0.20/0.80、0.80/0.80/0.80、
