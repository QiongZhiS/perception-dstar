### 1.1 目标与范围（冻结）

B2 的 PARTIAL 边界（§3.5-3 数学排除 + §五 12）："收益为负"在"注意 = 无限加速预测"形态下
数学上不发生（α 提高使残差 = (1−α)|L−bg| 恒降，信号项与噪声项同向缩小），二级残差→注意
转移**未获测试机会**——B2 §五 12 明确指出修复路径："需要注意执行有**代价或失效**的机制
形态（资源有限/抑制性干扰，docs/186 中央凹资源有限；或焦点落于噪声/饱和处——真实域条件）"。
docs/186 §五 是现成依据："注意力 = Top-K 威胁度精度分配……只对 Top-K 分配高精度计算资源
（高灵敏度转导/高帧率预测更新/等效中央凹），**低得分事件走低精度默认路径或弃用**"——资源
有限 = 注意有代价：资源投给焦点 f 意味着从别处撤走（机会成本）。

本格目标（冻结）= 首验 C2 §三 主张 3 的完整链路在**注意执行有代价**形态下的行为签名：

1. **"利害加权总收益为负"事件可发生**（B2 里是 0；代价形态下"收益为负"不再是数学不可能）——
   机制：机会成本 = 被忽略候选残差上升×利害，压过焦点残差下降×利害时总收益为负；
2. **二级残差（收益为负）驱动注意转移**（docs/237 从"探测"升为"决策驱动"——负收益窗口
   中被注意转移的比例；C2 层 2"我注意的决策对吗 → 不对就转"）；
3. **转移修复损失**（转移到次优候选后利害加权总收益转正——转移的正确性）。

**范围收窄（冻结）**：同 B2——单一注意决策层（层 1）+ 注意的注意（层 2）；合成受控域
（docs/235 风格，同分布多种子 = L1 域强度）；**不做层 3 注意路径规划**（C2 §五 5）；
真实域（ISTD/DAVIS）不在本格；"利害从行为内生"不在本格（§五 3）。

**诚实声明（冻结，§一 必须写明）**：本格测的是**机制层可检验的行为签名**——"代价形态下
利害加权收益为负事件能否发生 + 二级残差能否驱动注意转移并修复损失"（合成受控、非真实域
证明），**不声称"证明它在思考"**（docs/247 规则 2：L5 不得作验收判据；C2 §三：L5 展望形态
诚实标注"机制探索，非思考证明"）。判据标签 `[L5][机制][涌现检验]` 是**展望形态标注**（被测
对象属于 L5 能力层的行为签名），其证据强度止于 L1 合成受控域（同分布多种子），不构成任何
L2+ 泛化主张（§五 1）。

**与 B2 的机制差异与为何不回调 B2（冻结）**：B2 注意执行 = 焦点邻域 α 0.5→0.85、别处不动
（无代价 → 收益恒正 → sec 数学上不发生）；本格 = 焦点邻域 α 0.5→0.85（投入）+ **非焦点

### 1.3 代价形态选型（冻结；与 B2 的机制差异、为何不回调 B2、为何选此组合）

**候选代价形态评估（冻结）**：

1. **固定资源预算**（docs/186 §五 精神）：每窗口注意资源总量固定——投给焦点 f 的高精度
   （α 提高）意味着**从别处撤走**（被忽略候选 α 降低 → 其残差上升 = 机会成本）。**主形态**
   ——直接实施 docs/186 "资源有限 → 低得分走低精度路径"；机会成本有明确机制载体（残差
   上升×利害），可与"收益为负"定义直接连接。
2. **注意转移成本**（切换帧数/能量开销）：焦点切换有开销 → 收益略正但转移成本高时"不值得"
   → 理性行为是**不转移**——与判据"负收益窗口被转移比例 ≥0.7"方向冲突（转移成本使负收益
   的理性响应 = 停留），**不采用**（作为 §五 展望形态记录）。
3. **利害不对称**：低利害区域被注意 = 资源浪费 → 利害加权总收益为负（即使绝对残差下降）。
   **并入收益定义**（s 加权）——单独不产生负收益（无代价时被忽略候选残差不变，总收益 =
   焦点收益 ≥ 0），必须与撤走（形态 1）共同作用：s 不对称使"撤走造成的伤害"在利害加权下
   可能压过"焦点收益"。
4. **注意饱和度**：资源已满时新刺激无法获得注意 → 该刺激残差持续 → "我漏看了重要的东西"。
   其效果（未被注意候选残差持续/上升 → 负收益）是形态 1 撤走的特例；A 的三档 regime 换档
   （帧 80/160）天然提供"新刺激"事件（换档窗口残差跃升）。**不单独采用**，事件由场景提供。

**选型结论（冻结）**：**主形态 = 固定资源预算（docs/186 §五），配合利害不对称（s 加权）
与换档新刺激事件（A regime 切换）**。机制语义与 B2 完全一致（注意 = 资源分配、收益 = 残差
下降、二级残差 = 收益为负、转移 = 给次优候选），仅执行形态从"无限加速预测"（无代价）改为
"精度分配预算守恒"（有代价），收益定义从焦点局部扩展为利害加权全局（机会成本显式化）。

### 1.4 机制（冻结；行为量可操作计算 + 注意机制 + 旋钮）

**感知层（docs/235 同代码路径，import 复用）**：CPLoop 的预测回路（对数域双 EWMA 背景预测
bg_fast(α=0.5)/bg_slow(α=0.03) + 自适应阈值 + 死区），逐帧残差场 R(x,y,t) = |L − bg_fast|
（bg_fast 更新后的残差，CPLoop.step 同款）。

**注意机制（CostAttentionLoop，新脚本内定义，继承 B2 的 AttentionLoop 只加"撤走"掩码；
未修改主线与 B2 脚本）**：

- 逐像素 α 预测更新：`bg_fast = alpha_map·L + (1−alpha_map)·bg_fast`，默认 alpha_map ≡ 0.5
  （≡ CPLoop）；**注意执行（有代价）**：焦点候选邻域 alpha_map = **α_focal = 0.85**（资源
  投给焦点），**非焦点候选邻域 alpha_map = α_low = 0.15（资源从别处撤走——机会成本的机制
  载体）**；其余区域 0.5 不变。bg_slow 不变（α=0.03）。
- **预算守恒（冻结）**：α_low = 1 − α_focal（对称预算：投给焦点的能量 = 从别处撤走的能量，
  总注意能量 Σ_pixels(alpha_map − 0.5) ≈ 0 近似守恒；N_f ≈ N_g（两候选邻域同 R_FOCAL=18，
  B 邻域底部截断 ≤6 行 → 守恒近似在 6% 内）——docs/186 §五"资源有限"的焦点级行为版：
  注意执行 = 总资源固定的精度分配，投给焦点必然从别处撤走）。

**注意决策循环（冻结；窗口 = 10 帧，docs/235 同款）**：240 帧 = 24 窗口（W=24）。窗口 0
（帧 0-9）= 预热基线窗口（α 全 0.5，无注意执行），记录残差场与候选质心。对窗口 w ∈ [1, 24)
（帧 [10w, 10w+10)）：

1. **残差场聚合（决策输入）**：R_agg(w−1)(x,y) = mean_{t∈窗口 w−1}(R(x,y,t))——注意决策基于
   **上一窗口的实际残差场**（行为闭环：注意会改变残差场 → 改变下次决策）。
2. **候选注意价值**：V_i(w) = s_i · max_{N_i}(R_agg(w−1))（候选邻域残差×利害最大值；
   B2 D1-2 定案的候选级忠实实现——argmax(R×S) 像素落在哪个候选邻域，哪个候选的 V 最大）。
3. **焦点选择（层 1 决策）**：f_auto(w) = argmax_i V_i(w)（行为涌现，非手工指定位置）；
   次优候选 second(w) = 非 f_auto 的另一候选（两候选世界 V 排序第二）。候选检测失败（无
   质心）→ 该候选 V = 0（不可注意）→ 焦点 = 另一候选（冻结退化处理，同 B2）。
4. **转移覆盖（层 2 决策）**：若上一窗口二级残差 sec(w−1) = 1 → **f(w) = 另一候选**
   （注意转移：焦点给**非当前焦点**的候选——两候选世界的"次优"；覆盖 argmax 一个窗口，
   之后恢复 argmax）。**机制定义精化（冻结，与 B2 的文字差异说明）**：B2 冻结文字"转移 =
   焦点给次优候选 second(w−1)"在实现上取 V 排序第二的**陈旧**候选（决策时刻上一窗口的排序）；
   本格在**机制定义层面**冻结"转移目标 = 非当前焦点的另一候选"——语义同为"给次优候选"
   （两候选世界次优 = 另一候选），但目标取当前窗口的焦点补集而非陈旧 V 排序（B2 的陈旧
   排序在代价形态下可能出现"转移回当前焦点"的空转——被忽略候选被撤走后残差上升、其 V 排序
   可低于仍高残差的焦点——使转移失去修复功能；本格冻结"另一候选"保证转移的功能性 =
   "修复被忽略/受损的候选"。此为预注册时的机制定义（非运行后调整），记录于 §二 D3-1）。
5. **注意执行（有代价）**：窗口 w 内逐帧 `loop.step(gray, focal_mask_t, withdraw_mask_t)`：
   focal_mask_t = 以候选 f(w) 在 t 帧质心为中心、半径 R_FOCAL 的圆盘（注意跟目标走）；
   withdraw_mask_t = 以**另一候选**在 t 帧质心为中心、半径 R_FOCAL 的圆盘（撤走跟目标走）；
   平行无注意轨迹（loop_noatt）全程 α 0.5（对照，不施加注意也不撤走）。
6. **行为量记录**（候选邻域残差均值，B2 同款载体：逐帧质心邻域均值再窗口平均）：
   - R_f_att(w) = 焦点候选 f(w) 邻域在主轨迹（注意执行后）的残差均值；
   - R_f_noatt(w) = 同一候选在无注意轨迹的残差均值（"如果不注意它"的基线）；
   - R_g_att(w) = 被忽略候选 g(w) 邻域在主轨迹（被撤走后）的残差均值；
   - R_g_noatt(w) = 同一候选在无注意轨迹的残差均值；
   - **利害加权总收益（含机会成本）** BENEFIT(w) = s_f·(R_f_noatt − R_f_att) +
     s_g·(R_g_noatt − R_g_att)——第一项 = 焦点残差下降×利害（收益）；第二项 = 被忽略候选
     残差变化×利害（撤走使其上升 → 该项为负 = **机会成本**）；
   - **二级残差** sec(w) = 1[BENEFIT(w) < 0] = 1["我注意的决策对吗"——注意执行后利害加权
     总收益为负的事后检测]（docs/237 预感误配升级为决策驱动的事后检测形态；冻结声明：本格
     二级残差是**事后检测**（注意执行后收益为负），同 B2——升级语义 = 同一二阶信号从
     "探测/预感"变为"决策/驱动"）；
   - 退化处理：焦点或被忽略候选任一邻域残差为 nan（检测失败）→ BENEFIT(w) = 0（中性，不判
     降不判升，sec = 0）。

**行为量定义汇总（冻结；全部可操作计算）**：

| 行为量 | 符号 | 定义 |
|---|---|---|
| 候选注意价值 | V_i(w) | s_i · max_{N_i}(R_agg(w−1))（残差×利害） |
| 注意焦点（层 1） | f_auto(w) | argmax_i V_i(w)（次优 = 另一候选） |
| 实际焦点 | f(w) | sec(w−1)=1 → 另一候选（层 2 转移覆盖）；否则 f_auto(w) |
| 焦点邻域残差（注意后/无注意） | R_f_att / R_f_noatt | 主轨迹 α_focal / 无注意轨迹 α0.5 的候选邻域残差均值 |
| 被忽略候选残差（撤走后/无注意） | R_g_att / R_g_noatt | 主轨迹 α_low / 无注意轨迹 α0.5 的候选邻域残差均值 |
| 利害加权总收益 | BENEFIT(w) | s_f·(R_f_noatt − R_f_att) + s_g·(R_g_noatt − R_g_att)（含机会成本） |
| 二级残差 | sec(w) | 1[BENEFIT(w) < 0]（收益为负的检测 = "我注意错了"） |
| 注意转移 | — | sec(w−1)=1 → f(w) = 另一候选（覆盖 argmax 一个窗口） |

**旋钮（冻结，来源论证）**：`R_FOCAL=18`（同 B2 §1.2 几何：覆盖目标 r=10 + 窗口内移动 ≤8.2px
+ 质心量化噪声；两候选邻域不重叠）；`α_focal=0.85`（同 B2：快吸收，EWMA 时间常数 ~5× 缩短；
0.85 留噪声余量——α→1 会让 bg_fast 纯拷贝 L、残差→噪声，注意收益失真）；`α_low=0.15`
（**代价强度**：对称预算 α_low = 1−α_focal——投给焦点的能量等量从被忽略候选撤走；撤走使被
忽略候选 EWMA 时间常数从 τ≈1（α0.5）延长到 ≈5.7（α0.15）→ 其跟踪滞后与残差显著上升 =
机会成本的机制载体；docs/186 §五"低得分事件走低精度默认路径"的强度级）；`s_A=0.5`、`s_B=1.0`
（同 B2 定案值，零重调；利害差 2× 使"撤走伤害×利害"与"焦点收益×利害"的符号非平凡——
见 §1.5 阈值论证）；`regime [1.0, 3.0, 0.5]` 段边界 = 帧 [80, 160, 240)（换档窗口 = 完整注意
窗口；换档 = "新刺激"事件，配合撤走产生负收益事件的丰富来源）。所有旋钮先于任何运行冻结、
判据测行为（负收益发生/转移触发/转移正确）不测这些内部参数。

## 五、诚实边界（预注册阶段已知）

1. **L5 非验收判据（docs/247 规则 2）**：三条判据带 `[L5][机制][涌现检验]` 标签是**展望
   形态标注**——被测对象属于 L5 能力层（注意决策/反思）的行为签名，但**本格不声称"证明它
   在思考"**：验收对象是机制层行为签名（代价形态下利害加权收益为负事件发生 + 二级残差驱动
   注意转移 + 修复）在**合成受控域（L1 强度，同分布多种子）**上的成立性，不构成任何 L2+
   泛化主张、不构成能力证明。
2. **代价形态的引入是 B2 缺口的修复还是新机制（预注册论证）**：B2 §五 12 明确写明"收益为负
   → 注意转移"的测试事件"需要注意执行有**代价或失效**的机制形态（资源有限/抑制性干扰，
   docs/186 中央凹资源有限）"——本格是 B2 缺口所指明的**修复路径的实施**：机制语义（注意=
   资源分配、收益=残差下降、二级残差=收益为负、转移=给次优候选）与 B2 完全一致，仅执行
   形态从"无限加速预测"改为"精度分配预算守恒"（有代价），收益定义从焦点局部扩展为利害加权
   全局（机会成本显式化——无代价形态下焦点局部收益=全局收益，代价形态下必须含机会成本否则
   "我注意错了"不可测）。**不回调 B2**：B2 层 1 焦点涌现 + 预期收益结论原样保留为守卫复现
   （R_B3_GUARD_B2 同代码路径）。
3. **利害场第一版外赋（docs/174/188 纪律）**：s_A/s_B 与候选身份绑定是外赋参数（"谁值得"
   外赋，坐标由感知层锁定，docs/190 同款）；"利害从行为内生"是更远的事，本格不宣称。
4. **合成受控、非真实域证明**：docs/235 风格 toy 场景（160×120 棋盘 + 亮圆盘），结论域 =
   该场景族；真实域（复杂场景/遮挡/利害不确定性）未测。
5. **注意执行 = 预测更新速率分配 + 撤走**：本格把"资源"操作化为 bg_fast 逐像素 α（焦点
   α_focal 提高、非焦点候选 α_low 降低）——这是"把资源投给焦点并从别处撤走"的一个具体载体
   （docs/186 §五 精度分配 + 低精度路径的行为版）；对称预算 α_low = 1−α_focal 是"总资源
   固定"的一种操作化（N_f≈N_g 使守恒近似在 6% 内）；不宣称这是注意代价的唯一/最优形态
   （真实载体的代价多样：采样密度/时隙/抑制性干扰）。
6. **转移的相干性（运行后确认）**：预注册预期撤走使被忽略候选残差上升 → 其 V 上升 → 转移
   与层 1 argmax 同向（确认性）；**实测 OVERRIDE 39/64（61%）——转移在多数窗口覆盖层 1
   argmax（转移目标 = argmax 不会选的另一候选）**：弱代价（α_focal=0.55）下 V 排序不随注意
   充分翻转（B 被注意后 maxB 仍高），次优候选的 V 未必居首 → 转移目标 ≠ argmax → 覆盖性
   驱动。诚实标注：覆盖性由合成场景的**利害-残差错位**（B 高利害但残差低——被注意时收益小；
   A 高残差但低利害——被忽略时伤害大，但 s_A=0.5 使其 V 未必居首）承载，非真实域利害不确定
   性；真实域的覆盖性（利害不确定下的反思性转移）仍是展望。
7. **二级残差是事后检测**：sec = 1[收益为负] 是注意执行后的检测（docs/237 的升级语义 =
   二阶信号从"探测/预感"变为"决策/驱动"），不是事前预感（SO_conf）；docs/241 已证账本史
   长程携带"预感误配"预测力（守卫 1 复现），本格证其驱动能力（C2/C3）。
8. **BENEFIT 的时序语义**：BENEFIT(w) 用平行无注意轨迹（α0.5）对照主轨迹（α_focal/α_low）
   ——同窗口同候选残差差；换档窗口残差过渡/连续注意稳态可稀释符号——如实报告。
9. **范围**：单一注意决策层 + 注意的注意；**不做层 3 注意路径规划**（C2 §五 5）；真实域
   三分类不在本格。
10. **判据阈值为合成场景标定值**（0.05/0.70/0.70、R_FOCAL=18、α_focal=0.85、α_low=0.15、
    s_A/s_B=0.5/1.0），跨场景/真实域需重标定（docs/199 §五 同款声明）。
11. **候选检测用亮域阈值**（L > log(221)，docs/260 同款）：候选身份（上半 A / 下半 B）由场景
    几何保证；检测失败帧用最近有效质心保持跟踪（冻结退化处理）——"候选从检测涌现"的诚实度
