## 一、设计（预注册，冻结；候选发现选型规则/多候选判别流程/判据/守卫先于实现与最终运行冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/272（第七格 ADAPT_DELTA_PASS，pooled P/R/F1 = 0.9675/0.7316/0.8332）完成参数
自适应后，剩余漏检的主要结构性缺口（docs/267/270/272 §五 单候选局限 + 用户反馈
"明显阴影检测不出来"）：**候选发现缺位**——判别器每场景只取**一个最大暗连通域**
（`diagnose_frame` → `largest_component(dark)`），第二个阴影/小阴影/分散阴影**根本
进不了判别器**；判别器本身在候选已给定时的判别（docs/270 计分制 P=0.9813、docs/272
自适应 P=0.9675）很强，但"候选从哪来"只有最大连通域。行业口径（ST-CGAN/BDRAR 等）
为全图逐像素分割（BER 1.33-3.85%），我们单候选换算 BER 29.35%——**差距主要来自
候选发现（不是判别）**。本格目标：

1. **候选发现（核心，本格唯一机制新增）**：从"最大暗候选"升级为"全图多候选"——
   候选发现选型（A 全连通域列表 / B 超像素 SLIC）由诊断轮数据驱动定案（§1.3 选型
   规则冻结）；每个候选**独立**过现有判别器（docs/270 计分制 + docs/272 自适应，
   import 复用零改动）——第二个/小阴影/分散阴影从此进得了判别器。
2. **判据（与 docs/272 同尺可比）**：全图 pooled recall/precision vs 单候选
   （MULTI_RECALL_GAIN / MULTI_COUNT / PREC_KEEP）——直接量化"候选发现补齐后的
   recall 增益 + precision 不崩"。
3. **KEEP（能力不退化）**：守卫——单候选路径逐位复现 docs/267（G_BASE）/docs/270
   （G_FIX）/docs/272（G_ADAPT）+ 多候选退化守卫（G_MULTI_DEGEN：最大候选 ≡ 单候选
   adapt，逐位）+ 合成三连（G_SYNTH）+ 第四格 flamingo（G_CELL4）+ G_DET/G_MASK/
   G_REPRO。
4. **C5（报告性）**：候选数分布、新增候选（多 − 单）的 TS/FP 构成、新增 TP 像素、
   GT 分量覆盖率、train/test 分列、单位级统计。

范围收窄（诚实，同 docs/267/270/272）：判别对象从"最大暗域候选"扩为"全图暗域候选
列表（A）/超像素候选列表（B）"——**判别器语义不变**（同一测量层 + apply_fix +
adaptive_delta）；"纹理"通道在静态域 = 时间门不过的暗区（近零，如实报告）；真实图
无光照 GT → θ_est 仍是帧内估计行为读数；**候选发现 ≠ 逐像素分割网络**（§五 1）。

### 1.2 数据与预处理（冻结；逐字同 docs/272 §1.2）

- **数据源（冻结）**：ISTD（D:\datasets\ISTD），1870 场景三元组（train 1330 + test
  540），目录映射 _A=阴影图 / _B=阴影掩码（GT）/ _C=无阴影参考图（docs/267 §二 D1
  实测并冻结）。图像/掩码是数据（可读），非毒文件。
- **预处理（固定流水线，docs/272 §1.2 同款冻结）**：PNG → cv2.imread(IMREAD_COLOR)
  （BGR 640×480）→ 灰度 cv2.resize(160×120, INTER_AREA) → uint8；彩色帧同样 resize
  到 160×120（INTER_AREA）供 V4/E3 边界环带采样（BAND_EDGE=2px）；GT 掩码
  cv2.resize(160×120, INTER_NEAREST) → bool（>0）；V4/E3 前显式
  cv2.cvtColor(bgr, COLOR_BGR2RGB)。
- **单位（冻结）**：每场景一次运行（1870 单位）；每单位 2 帧 [B（无阴影参考）, A
  （阴影帧）]；Pass A 在 [B,A] 上算逐像素 0.95 分位（= 逐元素 max）；评估帧 = A
  （GT 掩码 C）；B 只作适应参考。
- **无注入、无 jitter、无 RNG**（docs/243 §1.1 声明同款）；统计外壳 = 单位级
  mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828）。

### 1.4 判据（冻结；每条带 docs/247 层级标签；真实域证明级，与 docs/272 同尺可比）

评估单位 = 每场景一次运行（1870 单位）；**预测** = 每单位 A 帧上全图多候选并集

（INTER_NEAREST）> 0。**C1/C2/C3 用 pooled 口径**（全部单位像素合并 → TP/FP/FN →
P/R/F1，docs/219 标准检测度量同款；同 docs/272），同时报告单位级分布与 train/test
分列。统计外壳 = 单位级 mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子
20260828）。

| 判据 | 标签 | 定义（冻结） | 阈值（冻结） |

阈值论证（冻结）：**+0.15** = 任务指定方向（"如 +0.15，多候选把第二个/小阴影检出
来"）——docs/272 单候选 recall 0.7316，多候选须把漏检 26.8% 中可由候选发现恢复的
部分（第二个/小阴影/分散阴影的像素）显著回收；+0.05 下界 = "有实质增益但不足"的
诚实分档（PARTIAL）；**2.0** = 多候选检出数在含 ≥2 阴影场景中须均值 ≥ 2（单候选恒
≤1，直接测"第二个阴影被检出"）；**0.85** = "P 不崩"高杠（docs/272 单候选 0.9675，
多候选把更多暗区纳入判别 → FP 代价被 C3 直接测出；0.85 仍远高于随机、允降 0.12）；
**0.20** = 候选-分量匹配的 IoU 门槛（docs/260 IOU_FP 同款语义："≥ 0.20 = 真检出"）；
**50000/30** = 行使门槛（docs/267 同款 / 多阴影场景样本量）。均为**判据口径参数**
（先于运行冻结，测行为不测参数，docs/261 §五 2 纪律）。

## 五、诚实边界（预注册阶段已知）

1. **多候选 = 接近行业"全图分割"口径的第一步，不是全图分割本身**：本格把"候选从哪
   来"从单最大连通域补齐为全图多候选（A 全连通域列表 / B 超像素），判别仍是逐候选的
   启发式联合判别（docs/270 计分制 + docs/272 自适应，测量层零改动）——不是学习式
   逐像素分割网络（ST-CGAN/BDRAR 的 BER 1.33-3.85% 是另一条技术路线）；本格的全图
   口径（并集标注 → 全图 pooled P/R）与行业 BER 的对比是**定位性**的（我们判别器
   P=0.97 保持、recall 向全图口径逼近第一步），不宣称达到行业分割水平。候选发现仍
   有边界：DELTA 下不成候选的极浅阴影/纹理阴影仍漏（§五 6）。
2. **超像素参数是否新旋钮的论证（B 未行使）**：B（SLIC）若实现，需新增**超像素数量
   K_sp**（分割粒度）旋钮——这是**新机制旋钮**（判别器与 A_MIN 之外的自由度）；A
   （全连通域列表）**零新增旋钮**（A_MIN 继承 docs/260 冻结值）。本格选 A 的双重理由：
   ①环境约束（cv2 5.0.0 headless 无 ximgproc、无 skimage；安装 contrib 会替换冻结的
   cv2 运行时——全部已冻结数字 docs/260-272 的载体，不冒险）；②零新增旋钮（预注册
   纪律最干净形态）。B 的 K_sp 若未来实现，必须**先于任何运行冻结**（docs/63 纪律：
   按结果调 K_sp = 隐式调参，违规）；本格对 B 的论证（覆盖更全 vs 旋钮代价）留作
   §二 诊断数据记录，不改变选型规则。
3. **per-candidate 独立 DELTA 的不可定义性**：放宽阈值是全局掩码操作，per-candidate
   独立 DELTA 重分割会把多个候选合并（候选归属歧义）——新规则即新机制，冻结拒绝。
   "每候选走 272 自适应"的操作化 = 场景级自适应工作点（f 冻结、种子候选 = 最大候选
   的 var_inner）+ 每候选在该工作点独立判别；每候选 var_inner_i/delta_i 报告性（C5），
   不进判定。
4. **C1 基线 = docs/272 自适应单候选（0.7316）**：增益只隔离 B6 的候选发现贡献；
   docs/272 的阈值放宽贡献（0.6382 → 0.7316）不在本格主张内（它已在第七格量化）。
   若候选发现增益 < +0.05 → R_GAIN_FAIL 照实报（诚实否定：候选发现未显著抬 recall）。
5. **P 是否守住**：由 C3 pooled P ≥ 0.85 直接量化（docs/272 单候选 0.9675）。多候选
   把更多暗区（包括可能的阴影外暗物体/噪声分量）纳入判别 → 其 FP 代价被 C3 直接测出；
   若 P < 0.85 → PREC_FAIL（多候选引入过量误检，诚实否定）。
6. **漏检剩余（候选发现的边界）**：即使多候选，仍漏 ①DELTA 下不成候选的极浅阴影/
   半影最浅边缘（自适应已放宽到 0.25 下限，0.25 以下不成候选）、②纹理表面阴影（暗度
   统计被表面纹理污染）、③候选被判 object 的单位（docs/270 计分制剩余 22 个 object
   单位）。C1/C2 判据直接量化可恢复部分，剩余照实报告。
7. **单候选局限的边界变化**：docs/267/270/272 的"单候选"局限在本格被机制级补齐
   （候选发现全图化）——但判别器语义不变（同一测量层 + apply_fix + adaptive_delta），
   守卫 G_BASE/G_FIX/G_ADAPT 逐位证明能力不退化。
