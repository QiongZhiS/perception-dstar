## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/260 §五.2 与 docs/261 的盲区链条：docs/260 C1（暗于长期背景 + 空间相干 + 时间移动）
无法区分"真阴影"与"暗色移动物体"；docs/261 用**几何否决门**（V1 闭合轮廓 / V3 主轴偏离
光照方向）把它补上（verdict=SHADOW_VETO_PASS）。C1 立场文档（lineC）的追问：V1/V3 是
**手工几何规则**，不是残差递归长出来的——docs/187"读层缺的正是这个假设"。**B 路假设：
阴影 vs 物体的本质区别是行为性的（轨迹耦合、可预测性），不是几何性的**；docs/261 的
"运动耦合"（阴影与遮挡物共享运动场，MT/V5）是行为量（从轨迹算），正是残差递归能做、
且不需要手工规则的领域。

本格目标（冻结）= **首验该假设**：在合成受控三臂上，用纯行为量（零几何规则）判别
"是阴影 / 是物体"，测：① 行为量能否把三臂分开（COUPLING_SEP）；② 行为分类正确率
（SHADOW_CLS）；③ 暗物体对照臂（C，adversarial 亮度匹配）被正确拒为"物体"的比例
（DARK_OBJ_REJECT）；④ 合成三连能力不退化（KEEP 守卫：docs/260 检出/光照方向/表面
朝向同代码路径复现）。**范围收窄**：单一移动暗候选的判别（合成受控域）；docs/187 的
"纹理弥散 vs 物体相干"完整判别、真实域（ISTD/DAVIS）不在本格（§五 2/6）。

**零几何规则声明（冻结）**：本格判别路径**不使用**闭合轮廓检查（V1）、主轴 PCA/朝向
（V3）、光照方向角度比较（θ_est/θ_L 的几何利用）、反射率/边界两侧亮度跳变（V4）、
连通域拓扑形状。θ_L 只在两处出现：① 场景生成（光源方位是场景参数，真值已知——docs/260
同款）；② KEEP 对齐度量（ld_med 误差需要 θ_L 作参考，仅报告不判机制）。判别用的全部
量从两候选质心轨迹 + 预测回路自身状态（bg_slow/事件掩码）计算。

### 1.3 机制（冻结；行为量可操作计算 + 分类规则 + 旋钮）

**检测路径（三臂共用，docs/260 §1.3 同代码路径，import 复用常量）**：
```
Pass A（适应）：全程 240 帧 → 每像素 0.95 分位亮度 ref_dark（排除遮挡物帧 L > log(221)）
Pass B（判断）：dark_mask = (log(ref_dark) − log(gray+1)) > δ_shadow（δ=0.35 log 域）
               bright_mask = log(gray+1) > log(221)（遮挡物亮度显著性）
8-连通域（largest_component，import 复用），保留面积 ≥ A_min=25
最大暗域 = 暗候选（A: 阴影带 / B,C: 暗物体）；最大亮域 = 遮挡物候选
每帧记录两候选质心 c_d(t)、c_o(t)（面积 < A_min → None）
预测回路：CPLoop(window=10)（critical_point 原样 import，LOOP_CFG 冻结值），逐帧 step
  ——行为量读回路自身状态：bg_slow（慢背景）与事件掩码（残差 > 自适应阈值）
```
**行为量定义（冻结；全从质心轨迹 + 回路状态算，零几何规则）**：

1. **轨迹耦合度 COUPLING**（主判别量）：`coup = Pearson([vx_d, vy_d], [vx_o, vy_o])`——
   两候选质心速度序列（x/y 分量拼接成一条序列）的皮尔逊相关；`v(t) = c(t+2) − c(t−2)`
   （5 帧中心差分，平滑质心量化噪声）。语义："同速同向 → 高耦合 = 阴影"（docs/261
   运动耦合的行为化：阴影与遮挡物共享运动场，速度场逐帧相等）。
2. **相位滞后 PHASE_LAG**：两候选质心轨迹（去均值）在滞后 τ ∈ [−10, 10] 帧上的互相关
   `ρ(τ) = Pearson([x_d(t), y_d(t)], [x_o(t−τ), y_o(t−τ)])`（有效重叠段）；`lag_peak =
   argmax_τ ρ(τ)`、`peak_val = max_τ ρ(τ)`。语义："阴影轨迹滞后遮挡物 = 滞后相位 →
   阴影"——阴影是遮挡物运动场的**相位锁定**副本（本场景有限长带：带质心 = 遮挡物质心 +
   常数偏移 → 相位锁定 lag≈0、峰值≈1；独立运动物体：无锁定峰值）。冻结解释：在合成
   场景中阴影为瞬时投影 → 锁定滞后 ≈ 0；**相位滞后判据是必要条件**（非充分）：任何
   与遮挡物轨迹无锁定关系的候选直接判为物体；有锁定关系的还需耦合度/预测比佐证。
3. **事件-预测比 EVENT_PRED**（docs/187"静止被预测掉"机制的载体）：`pred_ratio =
   1 − S_dark / S_occ`，其中 S_dark = Σ_t mean(|L − bg_slow| 于暗候选掩码像素)、S_occ =
   Σ_t mean(|L − bg_slow| 于遮挡物掩码像素)（评估窗内，bg_slow = 预测回路自身慢背景）；
   截断到 [−1, 1]；S_occ = 0 → pred_ratio = 0。语义：暗区相对遮挡物（场景中最"不被
   预测"的移动前景，残差参照系）的"被预测掉"程度——占空比高（阴影带 ≈0.45，慢背景
   吸收多）→ 残差小 → 预测比高；占空比低（物体 ≈0.21）→ 残差大 → 预测比低；静止
   内容（球面暗侧/棋盘）被完全吸收 → 残差≈0 → 预测比→1、且根本不构成暗候选
   （docs/187 C1 0 事件机制同款）。**冻结声明**：本格三臂的暗候选全部移动，预测比
   的判别力在"静态被吸收 → 不构成候选"的检出层（由球面暗侧 0 候选复现，见 §二/§三），
   在 A vs B/C 上预测比数值可分离但重叠（A 预期 ≈0.6-0.8 vs B/C ≈0.3-0.6），作为分类
   规则的必要门（低杠）而非主判别量（§五 5 诚实声明）。

**分类规则（冻结；运行级，每 (臂,级,种子) 一个判定）**：
```
轨迹连续性：两候选同时有效帧占比 coverage（缺口 ≤5 帧线性插值）；coverage < 0.6 →
   coup/peak_val = NaN（轨迹不可靠）
shadow = (coup ≥ COUP_HIGH=0.70) ∧ (peak_val ≥ PEAK_MIN=0.60) ∧ (|lag_peak| ≤ LAG_TOL=2)
         ∧ (pred_ratio ≥ PRED_MIN=0.30)      # NaN 任一项 → 该条件 False
判定：shadow = True → "阴影"（A 的 GT 类）；否则 → "物体"（B/C 的 GT 类）
```
**旋钮（冻结，来源论证）**：`COUP_HIGH=0.70`（阴影带与遮挡物速度逐帧相等 → 理论耦合
=1.0−质心噪声 ≈0.85-0.95；独立轨道理论 0±0.15 → 0.70 = 两分布之间的诚实分隔杠；
docs/260 C1 det 0.80 同量级杠）；`PEAK_MIN=0.60`、`LAG_TOL=2`（锁定峰值的低杠——
互相关峰在 τ=0 的理论值 ≈0.9，0.60 留噪声余量；|τ|≤2 允许 5 帧中心差分的时间对齐
抖动）；`PRED_MIN=0.30`（低杠必要门：预测比 ≥0.30 才可能是"被背景吸收的阴影类"，
全未吸收的纯前景干扰被拒；A 预期 ≈0.6-0.8 余量充足）；`LEN_SHADOW=40`、`OBJ_ORBIT=
(42,28,r=15,f=0.13)`、`OBJ_GRAY_B=40`、`OBJ_GRAY_C=32`（§1.2 几何/亮度论证）。所有
旋钮先于任何运行冻结、判据测行为（分离度/正确率/拒绝率）不测这些内部参数。

### 1.5 判定映射（冻结）

- 三判据全过 且 守卫全过 → **COUPLING_PASS**（行为路在合成受控域分三臂：轨迹耦合 +
