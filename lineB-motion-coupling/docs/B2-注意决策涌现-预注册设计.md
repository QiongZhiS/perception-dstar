## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

C2 立场（§三 实验设计逐字）：思考 = 注意力的递归，感知 = 基层服务。层 1 注意决策
= "把资源投给哪里"从残差×利害行为涌现（不是手工 Top-K，docs/186 §五 的 Top-K 威胁
度是手工指定"威胁度 = IoU + 方向趋近"的注意雏形——本格把它从"手工统计排序"改为
"从残差×利害行为涌现的焦点选择"）；层 2 注意的注意 = 焦点收益为负（二级残差 =
"我注意错了"）→ 注意转移（docs/237 二阶残差从"探测"升为"决策驱动"）。

本格目标（冻结）= 首验 C2 §三 三条主张在合成受控域上的行为签名：

1. **注意焦点 = argmax(残差 R × 利害 S) 邻域的行为涌现**（不是手工指定焦点位置）——
   机制：候选级注意价值 V_i = s_i·mean_邻域(R)（残差×利害），焦点 f = argmax V；
2. **焦点被注意后该区域预测误差下降（预期收益验证）**——机制：注意执行 = 焦点邻域
   预测更新速率提高（资源投给焦点），测注意前后焦点邻域残差变化；
3. **焦点收益为负（二级残差）→ 注意转移到次优候选**——机制：sec = 1[收益为负]，
   触发时焦点给次优候选。

**范围收窄（冻结）**：单一注意决策层（层 1）+ 注意的注意（层 2）；合成受控域
（docs/235 风格，同分布多种子 = L1 域强度）；**不做层 3 注意路径规划**（C2 §五 5：
方向性雏形）；真实域（ISTD/DAVIS）不在本格；"利害从行为内生"不在本格（§五 3）。

**诚实声明（冻结，§一 必须写明）**：本格测的是**机制层可检验的行为签名**——"注意
决策能否从残差×利害行为涌现 + 二级残差能否驱动注意转移"（合成受控、非真实域证明），
**不声称"证明它在思考"**（docs/247 规则 2：L5 不得作验收判据；C2 §三：L5 展望形态
诚实标注"机制探索，非思考证明"）。判据标签 `[L5][机制][涌现检验]` 是**展望形态标注**
（被测对象属于 L5 能力层的行为签名），其证据强度止于 L1 合成受控域（同分布多种子），
不构成任何 L2+ 泛化主张（§五 1）。

**与 docs/186 §五 的区别（冻结）**：docs/186 的威胁度 = 候选框与目标预测框的 IoU +
方向趋近（**手工指定**威胁度排序，Top-K 保留）；本格的注意价值 V = s·R̄（利害标量
外赋、残差邻域均值行为计算），焦点 = argmax V（**无手工排序**）——"把资源投给哪里"
从统计变成行为（C2 §二 层 1："'投给谁'从统计变成行为的关键一步"）。

### 1.3 机制（冻结；行为量可操作计算 + 注意机制 + 旋钮）

**感知层（docs/235 同代码路径，import 复用）**：CPLoop 的预测回路（对数域双 EWMA
背景预测 bg_fast(α=0.5)/bg_slow(α=0.03) + 自适应阈值 + 死区），逐帧残差场
R(x,y,t) = |L(x,y,t) − bg_fast(x,y,t)|（bg_fast 更新后的残差，CPLoop.step 同款）。

**注意机制（AttentionLoop，新脚本内定义，继承 CPLoop 只加注意机制；未修改主线）**：
- 逐像素 α 预测更新：`bg_fast = alpha_map·L + (1−alpha_map)·bg_fast`，默认
  alpha_map ≡ 0.5（≡ CPLoop）；**注意执行** = 焦点候选邻域 alpha_map = **α_focal
  = 0.85**（"把资源投给焦点"：该区域预测更新更快）；非焦点区域 0.5 不变。bg_slow
  不变（α=0.03）。其余（自适应阈值/死区/事件掩码/窗口聚合）与 CPLoop 逐字一致。
- **冻结声明**：注意执行 = 资源（预测更新速率）的空间分配，语义 = "焦点区域获得
  更高处理投入"（docs/186 §五 精度分配的行为版；无手工规则，无 GT 使用）。

**注意决策循环（冻结；窗口 = 10 帧，docs/235 同款）**：240 帧 = 24 窗口（W=24）。
窗口 0（帧 0-9）= 预热基线窗口（α 全 0.5，无注意执行），记录残差场与候选质心。
对窗口 w ∈ [1, 24)（帧 [10w, 10w+10)）：

1. **残差场聚合（决策输入）**：R_agg(w−1)(x,y) = mean_{t∈窗口 w−1}(R(x,y,t))——注意
   决策基于**上一窗口的实际残差场**（行为闭环：注意会改变残差场 → 改变下次决策）。
2. **候选注意价值**：V_i(w) = s_i · R̄_i(w−1)，R̄_i(w−1) = mean_{(x,y)∈N_i}(R_agg(w−1))
   （候选 i 邻域残差均值；N_i = 窗口 w−1 逐帧质心邻域聚合，冻结：帧级邻域均值再窗口
   平均）。**V = 残差×利害（落空×利害，docs/179）的行为量**。
3. **焦点选择（层 1 决策）**：f(w) = argmax_i V_i(w)（行为涌现，非手工指定位置）；
   second(w) = 次优候选（V 排序第二）。候选检测失败（无质心）→ 该候选 V = 0（不可
   注意）→ 焦点 = 另一候选（冻结退化处理）。
4. **转移覆盖（层 2 决策）**：若上一窗口二级残差 sec(w−1) = 1 → **f(w) = second(w−1)**
   （注意转移：焦点给次优候选，覆盖 argmax；转移只覆盖一个窗口，之后恢复 argmax）。
5. **注意执行**：窗口 w 内逐帧 `loop.step(gray, focal_mask_t)`，focal_mask_t = 以
   候选 f(w) 在 t 帧的质心为中心、半径 R_FOCAL 的圆盘（注意跟目标走）。
6. **行为量记录**：
   - R_f(w) = mean_{t∈窗口 w} mean_{N_f(w)}(R(x,y,t))（焦点邻域**注意后**残差）；
   - R_f(w−1) = 同一候选 f 在窗口 w−1 的邻域残差（**注意前**基线；若 f 在 w−1 也是
     焦点则含注意效果——如实测"注意执行前后"的变化）；
   - **预期收益** BENEFIT(w) = R_f(w−1) − R_f(w)（>0 = 焦点区域 MAE 下降 = 收益）；
   - **二级残差** sec(w) = 1[BENEFIT(w) < 0] = 1[Δ(w) > 0]，Δ(w) = R_f(w) − R_f(w−1)
     （**收益为负的检测** = "我注意错了"，docs/237 预感误配升级为决策驱动的事后检测
     形态；冻结声明：本格二级残差是**事后检测**（注意执行后收益为负），不是 docs/237
     的**事前预感**（SO_conf）——升级语义 = 同一二阶信号从"探测/预感"变为"决策/驱动"）。

**行为量定义汇总（冻结；全部可操作计算）**：

| 行为量 | 符号 | 定义 |
|---|---|---|
| 候选注意价值 | V_i(w) | s_i · mean_{N_i}(R_agg(w−1))（残差×利害） |
| 注意焦点 | f(w) | argmax_i V_i(w)（次优 second(w) = V 排序第二） |
| 焦点邻域残差 | R_f(w) | 焦点候选邻域注意后残差（窗口均值） |
| 注意前基线 | R_f(w−1) | 同一候选邻域上一窗口残差 |
| 预期收益 | BENEFIT(w) | R_f(w−1) − R_f(w)（>0 = 下降 = 收益） |
| 二级残差 | sec(w) | 1[BENEFIT(w) < 0]（收益为负的检测） |
| 注意转移 | — | sec(w−1)=1 → f(w) = second(w−1) |

**旋钮（冻结，来源论证）**：`R_FOCAL=18`（§1.2 几何：覆盖目标 r=10 + 窗口内移动
≤8.2px（A 快档 1.0 Hz × 10 帧）+ 质心量化噪声；两候选邻域不重叠）；`α_focal=0.85`
（快吸收：α 0.5→0.85 使 EWMA 时间常数 ~5× 缩短（τ≈7.2 帧 → ≈1.5 帧）→ 焦点邻域
跟踪滞后大幅下降 = 注意收益的机制载体；0.85 留噪声余量——α→1 会让 bg_fast 纯拷贝
L、残差→噪声，注意收益失真，0.85 是"快吸收但不复制噪声"的折中）；`s_A=0.3`、`s_B=
1.0`（利害差 3.3×：A 快档残差 ~3-4× B 稳态残差 → V_A ≈ 0.3×3.5·R̄_B ≈ 1.05·R̄_B vs
V_B = 1.0·R̄_B → 焦点在 A 快档切到 A、其他档在 B——"落空×利害"的竞争随残差场涨落
而涌现，焦点不是固定给高利害候选）；`regime [1.0, 3.0, 0.5]` 段边界 = 帧 [80, 160,
240)（窗口边界 8/16/24 → 换档窗口 = 完整注意窗口）。所有旋钮先于任何运行冻结、
判据测行为（一致性/收益/转移）不测这些内部参数。

### 1.4 判据（冻结；每条带 docs/247 层级标签；合成受控、非真实域证明）

聚合单位 = 每 (级=LVCODE_B2, 种子) 一次运行（10 运行）；统计外壳 = mean±SD（ddof=1）
+ bootstrap 95% CI（2000 次，种子 20260828，critical_point 同款）。

| 判据 | 标签 | 定义（冻结） | 阈值（冻结） |
|---|---|---|---|
| **C1 FOCUS_CONSIST** | `[L5][机制][涌现检验]` | 每窗口 w ∈ [1,24)：理性基线 = 逐像素 argmax_{(x,y)} mean_t(R(x,y,t)·S(x,y,t))（窗口 w−1 的 R×S 场，S = 外赋利害场逐帧）；一致 = argmax 像素落在焦点候选 f(w) 的邻域 N_f(w) 内。consist = 均值[一致]（每 run 一个比例） | 跨种子均值 ≥ **0.80** |
| **C2 BENEFIT_CONFIRM** | `[L5][机制][涌现检验]` | 每窗口 w ∈ [1,24)：BENEFIT(w) = R_f(w−1) − R_f(w)。frac_pos = 均值[1[BENEFIT(w) > 0]]；mean_benefit = 均值[BENEFIT(w)]（每 run 各一个） | frac_pos ≥ **0.60** 且 mean_benefit 的 bootstrap 95% CI 下界 > 0（注意聚焦带来收益显著） |

| **C4 KEEP 保持** | `[L1][机制][合成受控]` | 守卫全过（§1.6）：R_B2_GUARD_SO + R_B2_GUARD_COMPOSE + R_B2_REPRO 全 = 1 | 全 = 1 |

阈值论证（冻结）：0.80 = "焦点从行为涌现、落在该看的地方"的诚实杠（候选级聚合应
复现逐像素理性基线；不一致来源 = 残差场尖峰/候选检测噪声/regime 过渡窗口的排序翻
转——如实报告）；0.60 = "注意聚焦带来收益"的诚实杠（注意执行 α 0.5→0.85 的跟踪
收益：中档目标稳态残差预期降 ~40-60%；目标换档窗口残差过渡可压过注意收益（Δ>0）
= "我注意错了"的载体，即二级残差触发源；连续注意稳态 Δ≈0 的可能稀释比例——如实
报告，不回调阈值）；0.70 = "二级残差驱动转移"的诚实杠（转移 = 机制赋值，正确率

**诚实声明（冻结）**：三条判据均为 `[L5][机制][涌现检验]` 标签——**L5 展望形态，
