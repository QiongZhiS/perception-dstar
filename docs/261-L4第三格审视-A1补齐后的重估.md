### 2.1 问题①：A1 底子是否改变 docs/256 的负对照流论证（R0→R0B 换流）？

逐帧相同 → 任何确定性群级判据在两者上触发等价 → R0 无法继续担任负对照 → 换流 R0B）
在 A1 补齐后是否仍成立？"机制在真实流持续累积"的新证据是否要求重验 R0B 或恢复 R0？

**审视结论：换流论证仍成立，无需重验 R0B，不得恢复 R0。逐条论证**：

1. **A1 不改变机制与流，输入同一性论证的成立域不变**。docs/257 的基座 = DeferredLoop
   （docs/251 逐字），docs/256 的基座 = SlotLoop3(SlotLoop2(DeferredLoop))——A1 在
   docs/256 实现之后运行，未改动任何机制代码或流构造；R0/R1 的帧序列、窗口边界、
   step() 的首帧初始化语义（80 帧 = 7 窗 + 9 帧尾）均未变。输入同一性定理的成立域
   （同初始 θ/空原型表/同窗口边界 → 前 7 窗内部状态逐位相同）与 A1 的实证内容
   （累积动力学）**互不干涉**：定理是"同一输入 → 同一确定性输出"的机制级事实，
   A1 实证的是"该机制在真实输入上会累积结构"——两者都是对同一机制的描述，一个
   是同一性、一个是累积性，A1 的完成不改变同一性。
2. **docs/256 §四的 w7 边界经验修正仍然成立且是最终口径**。第 8 窗边界（R1 w7 含
   surf 首帧 → E=5674、c2 翻转；R0 w7 含循环首帧 → E=127、c2=1）是 step() 首帧不入
   窗缓冲的确定性后果，A1 未触碰 step()（其 R0/R1 ratio 与 docs/256 逐位一致即证明
   预测/窗口路径零改动）。"R0 与 R1-flamingo 段触发必然等价"的**强形式**不成立（w7
   两流不同），但 docs/256 的**弱形式**（负对照职责移交 R0B + R0 降级诊断）不受影响
   ——换流论证的结论是"R0 不能当负对照"，依据是"两流前 7 窗相同 → 任何在 w7 之前
   的触发在两者上等价 + 群级判据的设计目标正是让 flamingo 类段可达"（§1.3-5 推论
   2：若判据在 flamingo 上触发则 R0 首循环必触发；若在 flamingo 上不触发则机制目标
   落空——构造性冲突）。A1 没有提供任何推翻该冲突的证据（它测的是无槽位路径的
   累积，不是群级触发形态）。
3. **A1 的新证据反而印证 R0 诊断流的诚实性**。A1 的 R0（flamingo×5 循环）SC2_slow=1

   存活——这正是 docs/256 把 R0 降级为诊断流后"如实报告其触发形态"的内容（R0 的
   群级触发形态 = G1 结构性失败 GRP_G1=0，因 15/85 恒定倾斜使任意 8 窗纪元 c2=0 窗

4. **重验 R0B 无对象、恢复 R0 无意义**。R0B 的"干净"是**机制结构性保证**（bear 单场景

3. **G3 是最终瓶颈，且其性质是"机制缺口"而非"冻结取值问题"**。docs/256 §四收窄的
   结论：flamingo 达 G1+G2 但 G3 失败——0 侧 3 窗（w0/w1/w7）**从未在同一条匹配链上
   聚合成已确认慢原型**（特征距 ~1.2 >> r_slow=0.39885，各自由不同原型匹配，各自
   1-2 hits 后被 k_decay 回收或弱化）。这不是 k_g_confirm=1 取值过严（每侧 1 个锚的
   门槛极低），也不是 k_ledger=3 过严（G1 已经要求每侧 3 窗）——而是**"分散窗口 →
   持久记忆"的物化步骤在机制中不存在**：群级账本（epoch_hist）聚合了窗口（G1 可见），
   但从未把聚合结果物化为原型层记忆。A1 的新前提恰好补上论证：机制在真实流上的
   累积（慢原型持久、结构增强）是实证的，群级账本就是该累积的一部分——缺的只是
   "物化"这一步（见 2.3 候选②）。
4. **"更优冻结"的排除**：G_WIN 加大会稀释信息量（见 1）；k_g_confirm 提高（>1）只会
   让 G3 更难（反向）；k_ledger/δ_rel/k_split 属于 docs/253-256 冻结阈值，任务明确
   禁止触碰；纪元滑动窗形态（每参与窗重算）已被确定性复现（GROUP_HASH）锁定。结论：
   **群定义与 G1/G2/G4 无更优冻结；G3 的解法必须落在机制层（新增物化步骤），不是
   冻结取值层**。

**问题②裁决**：G_WIN=8、G1/G2/G4 保持冻结（无更优）；G3 是唯一可动点，且动法 =
机制级（跨窗口锚合并），非阈值回调。

### 2.3 问题③：G3 确认门的机制级解法空间（逐候选评估）

**审视问题**：G3（强信息量段 c2=0 侧无持久确认锚）在 A1 时间底子下有无机制级解法？
三个候选逐一评估——**每个候选必须给出与 docs/253-256 冻结阈值的关系（新增机制还是
阈值回调）；若解法实质等于放宽冻结判据 → 必须否决并说明**。

#### 候选 A：侧确认放宽（G3 只要求窗口数，不要求确认锚）

**机制形态**：G3 从"每侧 ≥ k_g_confirm 个已确认慢原型锚"改为"每侧纪元窗口数 ≥
k_g_ledger"（即 G3 ≡ G1，或 G3 删除），触发 = G1+G2+G4。

**评估**：
- 与冻结阈值的关系：不触碰 k_ledger=3/δ_rel=0.30/k_split=5 三个数值，但**删除了
  docs/256 §1.3-4 冻结的确认质量门**——G3 是冻结机制定义的一部分（"群级信息量必须
  已被两侧的持久记忆（确认慢原型）承载，而非仅纪元窗口的瞬态统计"，§1.6 论证），
  删除它 = **实质放宽冻结判据**（改的是判据结构，不是数值）。
- 语义脱钩：docs/256 §1.1 候选 (e)（无确认门的滑窗直判）已被**明确否决**，理由 =
  "无'条目确认性'质量门；'直判'把信息量判据从'该局部阅历'变成'全局窗口统计'，与
  '记忆按槽位组织'语义脱钩"。候选 A 就是候选 (e) 的群级版重演（docs/256 §1.1 候选表
  (e) 行：**否决**）。docs/256 否决 (e) 时的 R0 必触发理由在 R0B 负对照下已不适用
  （R0B/R0 均 G1 失败），但**语义脱钩理由完全保留**：触发只凭窗口统计、分裂产物
  （打标子条目）没有记忆来源（无锚可退休、μ/账本/hits 从哪来？）——"记忆按槽位
  组织"退化为"统计按槽位分裂"。
- **裁决：否决**。实质等于放宽冻结判据（删除确认质量门），语义脱钩（docs/256
  候选 (e) 的否决理由），且分裂产物无记忆来源。

#### 候选 B：锚的持久化（让分散窗口的锚持久存在）

**机制形态**（两种读法）：
- 读法 1：让匹配过 c2=0 窗口的原型不被回收（豁免 k_decay），以便它们累积成锚。
- 读法 2：维护每侧持久状态（side accumulator），分散窗口跨纪元累积到侧账本，侧账本
  达到 k_ledger 即视为"持久锚"。

**评估**：
- 与冻结阈值的关系：读法 1 **触碰 k_decay=5**（docs/250/251 冻结回收门槛，快原型
  短命且可回收是 docs/250 已确立的"短命但正确"行为）——**回调**；读法 2 不触碰数值
  阈值，但"侧账本 = 持久锚"改变 G3 的锚定义（锚从"原型实体"变为"侧账本统计"），
  实质滑向候选 A（窗口数即确认）。
- 与瓶颈的匹配：**误配**。docs/256 §四的瓶颈是"c2=0 侧 3 窗从未在同一条匹配链上
  聚合成已确认慢原型"——问题是锚的**形成**（formation），不是锚的**持久**
  （persistence）。A1 已经实证慢原型持久性成立（R0 SC2_slow=1 跨 5 循环存活；慢原型
  不回收 = 固化记忆长程保持）——**持久不是缺口**。让"从未形成的东西"持久是空操作；
  豁免回收（读法 1）只会让 1-2 hits 的弱快原型存活更久，其账本仍是单侧单值
  （<k_ledger），无法成为锚。
- **裁决：否决**。误配瓶颈（形成 vs 持久）；读法 1 触碰 k_decay 冻结值（回调）；
  读法 2 实质滑向候选 A（放宽）。

#### 候选 C：跨窗口锚合并（群级侧锚合并 / consolidation）——**选择**

**机制形态**：每参与窗口的群级检查中，在 G1 与 G2 成立之后、G3 评估之前，插入一个
确定性物化步骤：对每个 c2 侧 v，若**纪元内 v 侧窗口数 ≥ k_ledger=3**（G1 已保证）且
**v 侧无已确认锚**（无未打标已确认慢原型满足 G3 的锚条件），则把纪元内全部 v 侧窗口
（(win, E, U)，分散在多个原型上或被回收）**合并为一个未打标已确认慢锚**：μ = 该侧
窗口 (ln(1+E), ln(1+U)) 中位数向量（SlotLoop2 ③ 同款 μ 重初始化规则）、ledger = {v:
该侧全部窗口}、hits = 并集计数（≥ k_ledger=3 → 出生即确认，慢原型只以确认已满形态
存在的不变式保持）、n_match=0、created = 当前窗（纪元内）。随后 G3 以"自然锚 + 合并
锚"评估（文本逐字不变："创建/匹配于 epoch 内、账本 ≥ k_ledger 窗"——合并锚满足）；
G4 不变；G1-G4 全满足 → 群级分裂按 docs/256 §1.3-4 **逐字执行**（纪元内全部 v 侧锚
——含自然锚与合并锚——退休 → 每侧建打标慢原型，μ = 退休 v 侧锚账本并集中位数向量）。

**评估（逐条）**：
- **与冻结阈值的关系：纯新增机制，零回调**。k_ledger=3（合并账本/并集计数门槛 =
  G1 同一冻结值，**复用**）；δ_rel=0.30（G2 未动）；k_split=5（单原型分裂资格未动，
  群级分裂本无 k_split）；r_slow/r_fast/hits_min_slow/k_decay/α/G_WIN/k_g_confirm
  全部未动。**不引入新数值旋钮**：合并的门槛（每侧 ≥ k_ledger 窗）与来源（纪元 =
  G_WIN=8 窗口史）全部是冻结值/冻结结构的复用；合并产物的形态规则（μ 中位数向量、
  ledger 并集、hits=并集计数、出生即确认、created=当前窗）与 docs/256 §1.3-4 冻结的
  锚与分裂产物规则**逐字同款**。唯一的机制增量 = "物化"这一步（把群级账本已聚合的
  侧窗口写入原型层）。
- **不是判据放宽**：G3 的冻结文本逐字保留（"每侧 ≥ k_g_confirm=1 个已确认慢原型锚
