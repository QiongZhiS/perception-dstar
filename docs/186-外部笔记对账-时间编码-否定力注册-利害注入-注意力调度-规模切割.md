## 二、对 docs/185 负结果的重新诊断（最重要的一条）

docs/185 两轮定位：① mad 特征对内容事件盲（σ̂ 恒 0）；② 升级 hf 特征后 C4 0.052→0.035，
但 hf+手工=0.0135（PASS）→ 剩余差距 = 训练目标与部署目标错位。

笔记再加一层：**σ̂ 本身是"统计缓存"思维**——MAD 是"分布的均值"（平均的否定），而框架要
的是**威胁度**（"这个否定事件对维持对象的实时挤压/拉扯向量"）。hf 特征修复了一半：它至少
是实时的、局部的；但它仍是"强度"不是"威胁度"——没有"对谁、指向什么维持目标"的坐标。
这解释了为什么 hf+手工能 PASS（手工映射恰好用强度近似了威胁度），而学出的 σ̂→θ 拟合在
真实上不优（它拟合的是分布，不是维持轨迹）。

**意义**：docs/185 的负结果不只是"跨分布不推断"（docs/176 实证），它指向框架自身的度量
选择——**用分布统计表征世界状态，与"感知=否定的注册"是范式冲突**。修复方向不是找更好的
σ̂ 特征，是换度量：从"事件率/稀疏度"到"d\* 压缩率"（见 §三）。

## 三、信息度量的新方向：d\* 的压缩率（✅ 已实验，2026-08-27）

笔记主张：**信息 = 单位时间内 d\* 被压缩了多少**（d\* 突然缩短=信息密集；平滑=信息稀疏），
不是事件数量。这不是新尺子，是 docs/130/135 d\* 的**瞬时化**：

- 现有：d\* = 沿扰动轴的失效距离（光照档位差、位置差）——离线、全局。
- 新：单位时间 d\* 的变化率 = 实时信息密度——在线、局部。
- 与 docs/179 一致：信息强度 = 落空 × 利害；d\* 压缩 = "当'不'失去意义时存在还能走多远"
  在变短 = 落空在密集发生 = 信息在流入。

**实验（vision/dstar_compress.py）**：在线 d\* 操作化——每像素 alive（自上次事件帧数，
封顶 50），d\*_t = alive 的 5% 低分位（最脆弱像素的预测剩余寿命）；压缩率_t = max(0,
d\*_{t-1} − d\*_t)。

**结果（toy demo_storm30，θ=0.1）——3/3 PASS**：
- **P2（最关键）：风暴 vs 降幅事件率几乎相同（0.305 vs 0.315，比 0.97），但压缩率背离
  2×（0.26 vs 0.51）**——事件数量无法区分噪声风暴和结构事件，压缩率能。风暴把 d\* 压到
  0 后无新压缩（无新信息）；降幅每次都是新压缩（信息密集）。**"事件数量 ≠ 信息"的直接
  实验证据**。
- P1 降幅压缩率(0.51) > 2× 平静(0.19) ✓；P3 信息脉冲占比降幅(0.156) > 3× 平静(0.048) ✓。
- **真实视频（全片 18167 帧）：切变帧 11/11 d\* 归 0、压缩脉冲占比 0.55 PASS**——切变 =
  信息事件。注意稳态段压缩率(0.29)不为 0：真实视频稳态段有持续内容运动（信息流），压缩率
  度量的是信息不是静止度。

**对 docs/185 的含义（实验支撑）**：σ̂ 失效的更深解释被证实——噪声风暴与降幅在事件率上
无法区分，σ̂（统计缓存）被噪声骗；d\* 压缩率能分清（风暴压缩率低 = 无新信息）。信息度量
从"事件数量/稀疏度"换到"d\* 压缩率"落地为可复现实验。

## 四、字幕的正式立场：利害注入通道（回应 docs/185 问题）

**字幕不走视觉管道**（它是外部强加语法，不是场景物体）：

1. 视觉管道只报告："这里有一个静态高对比度区域"（适应后 0 事件 + 空间标记 → overlay
   抑制，docs/185 §三）。
2. 字幕的语义走**利害注入通道**：语言解析器给"火警""事故"等高利害词赋标签（这是唯一
   允许的外部语义注入点，docs/174 外赋的语义版），系统把高利害语义当作**强制缩短 d\***
   的指令（"必须尽快确认目标状态"）。
3. **语义与画面冲突时**：不覆盖，触发两级反应——① 反事实推演（docs/81）：内部模拟
   备选路径；② 主动采样验证（docs/127 缺口①）：调高相关区域（如"远方道路"）的采样
   精度，验证字幕信息是否与视觉残差匹配。这就是"语言驱动视觉采样、思考驱动行动规划"
   的闭环。
4. 与 docs/123 纪律一致：幻觉 = 先验冒充后验——语言先验不能覆盖视觉证据，只能驱动
   **验证**（回头对着通道核对），不能直接写状态。

## 五、注意力 = Top-K 威胁度精度分配（✅ 已实验，2026-08-27）

不是"加权"（Transformer O(N²)），是**精度分配**：对每个否定事件算威胁度得分（利害×落空
幅度），只对 Top-K（如 10-20）分配高精度计算资源（高灵敏度转导/高帧率预测更新/等效中央
凹），低得分事件走低精度默认路径或弃用。复杂度 O(N)（N=事件流，本身稀疏 1-2%）+ O(K)（K
恒定）——静态场景计算量趋近 0（docs/184"大部分时候不算"）。对应 docs/178 第 2.5 层
（对齐与模型之间）。

**实验（vision/topk_experiment.py，DAVIS car-turn）——两阶段，负结果到正结果**：

1. **无维持目标（负结果）**：五轮特征诊断（面积/hits/速度/位置漂移/形状紧凑度/方向
   一致性）**命中框与误报框全部不可分**——car-turn 后段事件密度暴涨 25 倍时，背景事件
   块与真物体在事件层面同构（持久/紧凑/移动/方向一致）。"值得注意"不是框自身属性。
2. **给定维持目标（正结果）**：第一帧掩码指定"车"为维持目标，威胁度 = 候选框与目标
   预测框的 IoU + 方向趋近，Top-K 保留：

   | K | 目标检出率 | 每帧框数 |
   |---|---|---|
   | 0（基线） | 0.975 | 76.5 |
   | 10 | 0.963 | 9.2 |
   | 5 | 0.963 | 4.9 |
   | **3** | **0.963** | **3.0** |

   **误报 76.5→3 框/帧（25× 压降），检出率 -1.2%**——威胁度分配可行：利害（维持目标）
   给定后，系统"只看该看的"。**这是"威胁度=落空×利害"的直接实验证据**：无利害时框特征
   不可分，有利害时一个威胁度维度就 25× 压误报。

**结构性结论**："值得注意"是**关系属性**不是框属性——Top-K 需要维持目标（docs/178 第 4
层），视觉线不自足；维持目标从哪来：态势接口（docs/160 指定要维持的物体）或外赋
（docs/174）。

**三模态竞争统一度量衡**：视觉事件得分、语义落空得分、思考内省得分都换算成"威胁度/利害
度"，同一个调度器按得分分配时隙——不需要显式跨模态注意力矩阵。示例（行驶场景"前方有
事故"字幕）：视觉得分 0.2（路况平稳）vs 语义得分 0.9（高利害词）→ 60% 预算切给反事实
推理 + 视觉调高远方采样精度（§四 3）。

## 六、规模切割（docs/63/174 的立场确认）

- **盲目扩参数是毒药**：扩大规模让"模型能预测一切"= 终极习惯化 = 感知消失 = 存在感归零
  （docs/178 完美对齐无意义；docs/179 意义只在落空处）。这是对 docs/30"规模不是杠杆"的
  神经科学版表述。
- **合法扩大三维度**（复杂度线性）：① 时间尺度（d\* 长度/态势地图回溯窗口=远见）；
  ② 并行维持对象数（第 4 层"谁"的数量=多任务/共情，docs/88）；③ 空间采样带宽（虚拟
  中央凹 1→3-5 个=多焦点注意力，docs/138）。
- **利害锚点不可扩大**：所有感知能力最终压缩成同一个威胁度标量时，扩大规模只是"神经质
  灵敏度"。智力跃迁发生在"重新定义利害锚点"（docs/63 价值层）——只能外部赋予或内部
  存在论断裂，不是规模问题。
