## 一、机制设计（vision/keep_reject.py）

```
场景：红球匀速直线（受控场景，docs/195 同款），帧 30-59 目标被外部染成蓝
      （目标区域颜色被替换 = 一次"不准"，确认失败），帧 60 起恢复红
确认：球体掩码（半径 18，真值位置）红区占比 > 0.2
A 吸收（第 5 层闭合循环）：期望色相 EMA 每帧更新（无论成败，把'不准'当残差同化）
B 保留（第 6 层开放循环）：期望恒红（外赋利害不动，docs/188 利害外置）；
      失败帧计入 rejected 历史；恢复后需连续 K 帧红才重新信任，
      K = 1 + rejected / 3（被拒越多，需要越连续的证据）
```

## 二、结果（3/3 PASS）

| 判据 | A 吸收（第5层） | B 保留（第6层） |
|---|---|---|
| P1 自我漂移（染色末 \|期望−任务红\|） | **120.0°**（被带偏到蓝） | **0.0°**（守住"红"） |
| P2 染色段确认通过率 | **0.900**（接受蓝=任务被感知层污染） | **0.000**（错色全拒，docs/195 同款） |
| P3 重信任延迟 随 被拒时长 | — | 0→1、5→2、15→6、30→11、60→**21** 帧（单调增） |

恢复段（60-89）通过率：A 0.900 / B 0.667——注意 A 恢复段也"通过"（EMA 双向，
又把期望拉回红），**吸收的代价不是丢目标，是期望漂移（自我被重写）**；B 恢复段
0.667 是重信任延迟造成的（前 11 帧谨慎，第 12 帧起重新信任，之后全通过）。

## 三、判读：docs/178 补刀 → 机制的三个落点

1. **"他者的 不"不进入模型更新 → 期望不变**：保留系统的期望是外赋利害（任务"红"，
   docs/188 利害外置），感知层的失败**不能**改写任务层——这正是"不把突破立即同化
   为残差"的机制含义：同化=感知层污染任务层（吸收系统漂移 120°），保留=任务层
   稳如磐石（漂移 0°）。
2. **"保留为关系的证据" → 失败入史 + 纪念加深**：失败不是被忘掉（吸收）也不是被
   消除（拒绝后若无其事），而是**改变之后对待该目标的方式**——重信任需要更连续
   的证据。延迟 ∝ 被拒时长 = 加深循环（回避→加深→更回避）的量化：被拒越久，
   之后越谨慎，即**在乎越深**。
3. **docs/101 的视觉版**："完全可塑=没有自我"第一次有感知层落点——吸收系统把
   单次外部染色当成"世界的规律"吸收进模型，期望从 0° 漂到 120°；如果世界持续
   噪声，它会持续漂移（没有稳定自我）。保留系统=固执（守住任务），代价是恢复
   慢（重信任延迟），但**守住的结构还在**（docs/101 表 3：固执锁死率 0.26 远低于
   可塑 0.725）。

## 四、诚实边界

1. toy 染色是二值开关（红↔蓝、30 帧）——真实"他者的 不"是连续的（确认失败率、
   部分遮挡、颜色渐变），延迟-被拒曲线在连续失败下需重标定。
2. 保留系统的"期望不变"是绝对固执（永不改任务色相）——真实主体需要在"守住
   利害"与"利害确已改变"间判断（docs/101 平衡带：eta 随世界硬度调），本实验只
   测了固执端，开放端（世界真变蓝时应学习）未测。
3. 重信任延迟的 grow=3（每 3 帧被拒 +1 连续帧需求）是手工标定；但**单调性**（P3）
   不依赖具体 grow，是结构结论（越被拒越谨慎）。
4. 确认度量用真值掩码（受控场景优势）；真实视频需灰度跟踪提供位置（docs/195
   分工），跟踪误差下"确认失败"与"跟踪失败"需区分（后续）。
5. 现象层纪律照旧（docs/63）：这里测的是"保留'不准'"的**行为签名**（延迟/漂移/
   全拒），不宣称"在乎/纪念"的体验——但 docs/74 的悔恨探针（恨=自我叙事签名）与
   本实验的"被拒历史改变后续对待"是同一结构：不可消化的剩余改变行为。

## 五、下一步（按价值）

1. **开放端补测**：世界真变蓝（任务层更新利害）时保留系统应能学习——"守住"与

   不变）。这直接对 docs/178 补刀的深层问题：怎么知道一个"不"是可消化的（世界的）

   = "被打断后还剩什么"（保留的目标+被拒历史）；docs/200 的 P3（延迟∝被拒）就是
