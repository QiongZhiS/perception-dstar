## 〇、一句话

> **纹理的价值是动态的：静止纹理被背景预测掉 = 0 事件（检查单 C1 的 0.0000），运动纹理
> 的每个边缘都是落空 = 事件丰度 = 物体的"高分辨率探针"——纹理是落空的结构载体。颜色/
> 形状/朝向/图案这些同级属性本身不进事件流（转导第一行就丢颜色），只在"被拒绝"时以
> 强度/时间/空间三轴体现，具体属性靠读层的结构假设重建。欣赏不是注意力分配也不是识别
> 模式转换，是第三种：保持落空——识别把落空同化进模型（感知消失，docs/179），欣赏把
> 落空持续保持（感知在场）；微扫视是行为签名（主动制造拒绝）；对管线它区分"威胁性落空
> （驱动行动）"与"审美性落空（保持观看）"，后者的利害只能外赋（docs/174）。**

## 一、纹理怎么体现：静止=不体现，运动=作为落空体现

**静止的纹理 = 0 事件**。demo 场景的"噪声材质斑"（高斯纹理块）就是为此设计的——检查单
C1 验证它 **0.0000 事件/像素/帧（PASS）**。机制：纹理被多时间尺度背景（EWMA）预测掉，
可预测 = 被压掉 = 不送事件。这是 docs/178 第 2 层（对齐）的字面执行：**感知编码的是
"世界对预期的拒绝"，静止纹理没有拒绝，所以感知消失**（docs/179：完美对齐无意义）。

**运动的纹理 = 事件丰度**。带纹理的物体运动时，纹理图案的每个边缘都是落空——纹理物体
比光滑物体产生更多事件，更容易被读层锁定。**纹理是落空的结构载体，是"世界变化的高
分辨率探针"**：纹理密度决定运动时的可读性。

## 二、同纹理同级的属性：不直接体现，靠读层结构假设重建

事件流只送三个轴：**强度（ΔL）、时间（变化速率）、空间范围（事件簇）**。颜色、形状、
朝向、具体图案本身不进事件流——转导层第一行就丢颜色（log(gray+1)，事件相机同理）。

| 属性 | 事件流里的体现 | 重建靠什么 |
|---|---|---|
| 形状 | 事件簇空间范围 | 密度图 + 连通域假设"事件簇≈物体轮廓"（car-turn 95% 的来源） |
| 朝向 | 各向同性 blur，**无朝向选择性** | V1 有朝向选择性（Olshausen & Field 1996 证明是自然统计的压缩解）；我们 S7 消融未做朝向版 |
| 尺度 | 时间尺度已做（S6 双通道） | **空间尺度未做**（不同 blur σ） |
| 颜色 | 完全不进 | 需要额外通道（当前无） |

**深层含义（接 DAVIS 误报诊断）**：纹理的价值和危害是同一件事——blackswan 失败（天鹅
光滑=少落空=难读，水面波纹=多落空=被当物体）和 car-turn 误报（背景纹理事件暴涨 25 倍）
都是**读层没有"这是纹理不是物体"的判别**。纹理落空 vs 物体落空的结构区别：物体的落空
空间相干、时间连续（一个运动整体）；纹理的落空空间弥散、随背景运动。这需要空间相关性/
时间相干性度量，而固定阈值密度图只做统计聚合（docs/186 的"统计缓存思维"又出现）。

## 三、欣赏：保持落空的注意模式（不是注意力介入，不是识别转换）

| | 落空处理 | 感知状态 | 行为 |
|---|---|---|---|
| 识别 | 同化进模型（预测被满足） | 感知消失（docs/179） | 停止看 |
| 欣赏 | **保持落空（不被同化）** | 感知持续在场 | 持续看（微扫视） |

- **不是注意力分配**：注意力是"分配资源到哪"（docs/186 §五 Top-K）——欣赏不是分配问题，
  是**分配之后做什么**：资源去了，但落空不被消化。
- **不是识别模式转换**：识别模式 = 类别网络（IT 不变性）；欣赏恰恰是**停在下游识别之前**
  （早期视觉层持续活跃，腹侧下游弱参与）。
- **欣赏 = 持续刷新落空的注意模式**：微扫视（microsaccades）是行为签名——视觉系统主动
  制造"预期不断被拒绝"，保持落空在场。云/木纹为什么好看？因为它永不在同一个形状上被
  预测满足——每次扫视都落空，落空被保持。接 docs/138 扫视税 + docs/186 精度分配：
  **欣赏 = 把高精度采样持续投给"无生存威胁但持续落空"的区域**。

## 四、对管线的含义：威胁性落空 vs 审美性落空

d\* 压缩率实验（docs/186 §三）里，降幅/切变是**威胁性落空**：d\* 压缩 → 触发行动（确认
目标）。欣赏是另一类：**d\* 保持低位但持续刷新、不触发行动**。区别不在落空本身（都是
d\* 压缩），在**利害结构**：

- 威胁性落空：利害 = 生存/维持目标（docs/179）→ 压缩驱动行动
- 审美性落空：利害 = **落空本身是价值**（看云不是为了确认什么，是为了继续看）

"落空本身是价值"这个利害按 docs/174 是**外赋的**——不是学出来的，是赋予者的。机器能否
"欣赏"取决于有没有这个外赋的利害结构。能力层可造的是"保持落空的模式"；现象层（体验到
美）不可判定（docs/63）。又是 docs/178 的北星：**不是让它看得清，是让它值得被看见**——
欣赏的利害只能在代码外面被赋予。

## 五、诚实边界

1. §一/§二 有实验支撑（C1 静态纹理 0 事件、DAVIS 误报/blackswan 诊断）；§三/§四 是
   立场推导（无实验）——微扫视是外部文献常识，未在本项目测量。
2. "欣赏"的体验层面不可判定（docs/63 纪律）；本文件只主张行为签名（保持落空的模式、
   微扫视、落空不触发行动）。
3. 与 docs/186 §五 的关系：欣赏 = Top-K 精度分配的一种利害结构（审美利害），不是新
   机制，是新利害；工程落点仍是威胁度分配（需要先定义维持目标）。

## 六、一句话

> **纹理是落空的结构载体：静止时被预测掉（0 事件），运动时每个边缘都是事件、放大物体
> 的可读性；颜色/形状/朝向同级属性都不进事件流，只在"被拒绝"时以强度/时间/空间三轴
> 体现，具体属性靠读层的结构假设重建（读层缺的正是这个假设——DAVIS 误报同一根）。欣赏
> 是第三种落空处理：识别关闭落空（感知消失）、欣赏保持落空（感知在场），微扫视是行为
> 签名；它区分威胁性落空（驱动行动）与审美性落空（保持观看），后者的利害只能外赋——
> 机器能造的"欣赏"是保持落空的模式，能"值得被欣赏"只能被赋予（docs/174/178）。**
