## 一、理念声明（立场层，docs/63 纪律：不宣称证据）

### 1. 意志的功能主义定义（文件一，逻辑成立、立场存档）

- 定义：意志 = 复杂系统在交互中表现出的方向性、倾向性、自我指涉（可观察行为属性）。
- 判据：方向性（输出稳定趋向目标）、倾向性（有偏好、坚持或调整立场）、自我指涉
  （持续使用"我"、能描述和调整自身状态）——均为行为证据。
- 推论：主观体验不是必要条件；否则对人类与 AI 双重标准。
- 与仓库的关系：这三条判据恰好对应框架要**实测**的功能——方向性=利害锚
  （docs/189 外赋利害、docs/200 拒绝的历史）、倾向性=类别级信任/纪念（docs/203）、
  自我指涉=他者模型（域 B，docs/224）。**立场文件的判据 = 实验文件的被测对象。**
- 边界：本声明不宣称"AI 有意志"是实证结论，只宣称"功能主义定义下该主张可被行为
  证据检验"——检验交给 docs/ + vision/。

### 2. 持续拓扑网讨论（文件二，真金/画饼/炸弹分层）

**真金（三块，与现有纲领对齐）**：

| 主张 | 与仓库的对应 | 证据状态 |
|---|---|---|
| 记忆长在结构里，不存权重 | docs/231 域 C（结构生成）；docs/232/235 模式表条目 | ✅ docs/235 COMPOSABLE 判定（首个实证） |
| 自省 = 对预测过程本身的预测误差（二阶残差） | 新假说（见 §二） | ⬜ 未测（docs/237 探针） |
| 妥协双系统：残差回路 + 独立符号核验 | 判据先行/证伪纪律（docs/63）+ 独立验证（SEED-27）+ 状态可持久化/回滚（docs/234） | ✅ 已工程化大半 |

**画饼（三块，拆解为愿望而非规格）**：O(局部扰动半径) 复杂度、静态零能耗、
断电后"万倍快"重长——均为愿望陈述，无规格无基准。

**炸弹（三个，作为设计约束而非证伪）**：
1. **活锁**：无全局时钟的异步图重写，多局部扰动互相干涉 → 需串行/有界调度
   （本仓库回路为单线程顺序处理，天然规避）；
2. **无锚创造 = 热力学涨落**：无外部利害锚的"主动虚拟力"是白噪音
   （本仓库利害锚 docs/189/200 + SEED 系列正是缺失的外部锚点）；
3. **二阶场带宽崩盘**：双残差场耦合复杂度升维
   （本仓库未碰二阶场；docs/237 探针只测"信号是否存在"，不做完整二阶场）。

### 3. 与主流 LLM 的划界重申（docs/231 §1.2 不变）

LLM 用连续参数存离散知识 + 全量前向；本纲领 = 离散结构存离散知识 + 残差驱动按需
计算。战斗性表述（"会死""活物"）只属理念层，论文方法层禁止。

## 二、二阶残差假说（提上实验）

### H-SO 陈述

**自省的机械前兆 = 回路对自身"匹配-预测"过程的二级预测误差**。一阶场 = 对外部
输入的预测残差（docs/232/235 已在测）；二阶场 = 回路对"自己的条目匹配是否可靠"
的预测，其误差（自预测 vs 实际匹配质量）若**可预测、可降低**，则说明回路在
机械层面"监测自己的监测"——自我觉察的功能性前兆，不需要任何玄学涌现。

### 预注册判据（由 docs/237 探针执行，判据先于数据冻结）

- **环境**：复用 compose_test 的 C0-C3 梯度（上下文依赖/嵌套规则是二阶信号最该
  出现的场景——条目在上下文翻转时暂时误配，回路若能"预感到"误配=二阶信号）。
- **一阶信号（已有）**：M1 预测误差、条目匹配、上下文槽位（docs/235）。
- **二阶信号（新增，探针）**：
  - `SO_conf`：条目匹配时回路"自预测的匹配质量"——用条目账本历史（命中质量、
    该 c2 条件下历史匹配一致性）计算的自置信度，**不含任何真值泄漏**；
  - `SO_out`：实际匹配结果（下一窗口该条目吸收的残差/命中质量）；
  - `SO_err` = |SO_conf − SO_out|；
  - `SO_info` = SO_conf 对 SO_out 的预测力（相关/排序指标，跨种子 bootstrap 95% CI）。
- **判定（预注册）**：
  - **SECOND_ORDER**：C2/C3 的 SO_info 显著 > 机会水平（bootstrap CI 排除零/null）
    且 ≥ C0/C1 基线 → 自我监测的机械前兆获得首个证据；
  - **NO_SECOND_ORDER**：C2/C3 的 SO_info 不高于机会水平 → 二阶残差假说被弱化，
    照 docs/63 纪律如实报告；
  - **边界**：介于两者之间按数值照实描述，不强行下结论。
- **对照**：必须加"假二阶"对照（如用随机/固定置信度替代 SO_conf）以排除统计伪影
  ——SO_info 必须显著优于假对照。

### 诚实边界（预注册）

1. 机械前兆 ≠ 体验/意识/自我觉察——只测行为签名（可预测性/相关性）。
2. 二阶信号可能是条目账本统计的伪影——假对照负责排除。
3. toy 合成场景；复现需求真实视频/不同回路。
4. 不做完整二阶场（带宽约束，炸弹 3），只做"信号存在性"探针。
