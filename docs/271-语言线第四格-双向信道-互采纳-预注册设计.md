## 一、设计（预注册，冻结；双向世界/信道/门/判据/守卫/旋钮/流/划分先于实现冻结，运行后不改）

### 1.1 双向世界构造（本格核心，冻结；先于任何机制运行）

**问题定义（docs/268 §五5 预告 + 用户决策）**：前三格为单向最小形态（A 发射、B 采纳；
A 的运动无 ctx 依赖，A 无可获信息）。本格 = G2 第二格：**B 的输出回流 A、互采纳、
"交换闭环"**。核心问题 = A 是否也自发采纳 B 的信号（此前 A 无信息可获），互采纳后双方
联合残差是否都下降。

**候选世界形态评估（冻结；本格核心决策）**：

| 候选 | 定义 | 裁决 | 理由（冻结） |
|---|---|---|---|
| (a) 最小对称 | 保持 docs/270 世界（A 匀速圆周、B 依 ctx），只加第二信道 CH2（B 发布 s_B、A 合成 ctx_A 注入 A 签名空间） | **否决** | A 匀速 → A 的能量单态 → A 无可获信息（A 的账本无分离条件）→ 互采纳退化为"A 有信道但不用"——测的是"无信息增量时零采纳"的对称版，**"互"未体现**（docs/268 §五5 的边界原样保留） |
| (b) **全对称（采纳）** | A 的运动也依 ctx：A 的乘子 a(t)=a1 if ctx_prev==0 else a2（B 侧 m1/m2 逐字）；CH2 使 A 的签名空间可观测到 ctx | **采纳（本格世界构造）** | 双方各自有"自身像素不可分、唯他者信号可分"的信息缺口（A 的两态能量同落 c0 档 2 + c1 档 1 → A 的自身签名 (c0,c1) 跨态恒定 → A 无法从自身像素分态；ctx 的机制可见投影 = A 的两态能量差，唯 ctx_A（来自 B 的信号）可分）→ 互采纳双方都有信息可获 → **"交换闭环"真实成立**（本格被测对象） |
| (c) 其他形态 | 如 A 乘子依赖信号直接注入、非对称世界等 | 不采纳 | 最小改动 + 双侧同构（A/B 乘子均为"ctx 的两值函数"）是"对称化"的最简实现；更多自由度留给后续格候选（噪声/延迟/多体） |

**冻结的世界规则（双向世界，a_ctx_dep=True）**：docs/268 §1.1 世界逐字（160×120 棋盘格
+ 亮圆双目标、A 恒在上半/B 恒在下半、240 帧 @30fps、噪声 σ=3.0 × jitter ±25% 按种子、
世界 rng = `default_rng(seed×7919 + 41×104729 + 13)`、每帧一次 `rng.normal`——draw 序列
与 docs/268/269/270 完全一致，噪声场逐位相同），唯一加法 = **A 的乘子规则**：

- ctx(t) = sign(A.x − B.x)（0：A 在 B 左；1：A 在 B 右；docs/235 真值逐字）；
- B：m(t) = m1=2.6 if ctx_prev==0 else m2=4.2（docs/269 逐字，1 帧滞后）；
- **A：a(t) = a1=1.6 if ctx_prev==0 else a2=2.6（本格冻结，1 帧滞后同款）**——A/B 同为
  "ctx 的两值乘子函数"（对称化）；a_ctx_dep=False 时 A 匀速（a≡1.0，= docs/270 世界
  逐位，CELL3_REPRO 用）。

**为何 (a1=1.6, a2=2.6, mirror=False)（冻结，docs/269 §1.1 环境预计算协议选择）**：
预计算器 = 世界几何（docs/268 §1.1 A/B 视域帧生成，a_ctx_dep 分支）+ 预测路径（docs/232/
235 CPLoop bg_fast EWMA + sigma_hat 自适应阈值 + 事件掩码窗口并集），**不含模式表/采纳/

### 1.2 信道定义（冻结；CH1 逐字沿用 docs/268 + CH2 对称定义）

**CH1（A→B，docs/268 §1.1 逐字）**：A 回路每窗口把**自己的感知输出**（事件掩码质心：
`s_A(w) = mean_x(A 事件像素, y<68 区)`，事件 <5px → 无效）在窗口收尾后发布到信道 CH1；
递送 = 每窗口同步（A 处理窗口 w → 发布 s_A(w) → B 在处理窗口 w 前收到）；B 合成
`ctx_B(w) = sign(s_A(w) − x_B(w))`，`x_B(w) = mean_x(B 事件像素, y≥68 区)`（B 的自身
位置感知）；任一侧 <5px → ctx_B = None。信道无噪声、无丢包、无延迟（docs/268 冻结，
后续格候选才加噪声）。

**CH2（B→A，本格对称定义，冻结）**：B 回路每窗口把**自己的感知输出**（事件掩码质心：
`s_B(w) = mean_x(B 事件像素, y≥68 区)`，事件 <5px → 无效）在窗口收尾后发布到信道 CH2；
A 合成 `ctx_A(w) = sign(s_B(w') − x_A(w))`，`x_A(w) = mean_x(A 事件像素, y<68 区)`（A
的自身位置感知）；任一侧 <5px → ctx_A = None。**递送 = 一窗滞后（冻结声明）**：B 的 w
窗输出在 w 窗末（B 闭窗步）才可得，而帧同步管线中 A 先于 B 闭窗（docs/268 run_dual 步
序逐字：A.step → A 闭窗发布 → B.set_signal → B.step），故 **A 的窗口 w 读到 s_B(w−1)**
（B 上一窗输出；CH1 仍为同窗——A 先闭窗使 B 能读到 A 的当前窗信号）。该非对称递送是
帧同步管线的一窗结构滞后（等价于世界规则的 1 帧滞后乘子），**冻结为 CH2 定义**；其对
ctx_A 保真度的影响（翻转窗错配）如实报告（M4 双侧保真度分列）。

**信道模式（冻结，四模式对称版）**：双侧各取 `off`（该信道不存在，对应 ctx 恒 None）、
`comm`（递送真实信号）、`null`（递送常量 s≡160 → 双侧 ctx 恒 1，信号无信息量）、
`scrambled`（递送与真值 ctx 不相关的错乱信号，诊断级/判据级 C3）。
**G2s 错乱源（冻结）**：B 的错乱信号 = (seed+5)%10 种子的 s_A 序列（docs/270 逐字）；
**A 的错乱信号 = 确定性每种子随机二元 ctx 注入**（rng 派生 0/1 序列经远阈值信号
v=131/31 实现 sign(v−x_A)=bit——docs/270 §二 C1"蒙特卡洛随机分裂"同款模型；§二 C3 记录：
初版"另一种子 s_B 序列"源因几何嵌套（A.x∈[67,93] ⊃ B.x∈[70,90]）与真值 ctx 高度相关
（corr 至 +1.0），违反 C3"与真值 ctx 不相关"前提，预最终运行修正）。

## 五、诚实边界（预注册阶段已知边界）

1. **"互采纳" = 双侧账本提升 + 双侧 JR 下降的行为签名，不宣称意图/对齐意愿（docs/268
   §五4 同款）**：A/B 的"采纳"仍是 docs/235 提升机制的逐字行为（账本信息量驱动、无开关、
   无回退）；"交换闭环"= 双侧自发使用的可测形态，不是"A/B 想交流"。F5 意识不测。
2. **CH2 一窗递送滞后（本格冻结的结构不对称）**：CH1 同窗（B 用 A 的当前窗信号）、CH2
   一窗滞后（A 用 B 的上一窗信号）——帧同步管线（A 先闭窗）的结构结果，非机制选择。
   影响：ctx_A 在翻转窗可能错配 → A 侧保真度略低于 B 侧 → A 侧门纯度/首提升窗可能更
   紧（如实报告双侧分列）；等价于世界规则的 1 帧滞后乘子，语义一致。
3. **A 乘子环境校准的循环风险（docs/269 §五4 同款对冲）**：a1/a2 由机制无关的纯 numpy
   预计算（锚定 docs/269 预计算表 + a_ctx_dep=False ≡ docs/270 逐位）预先冻结，判据/
   门阈值未动；对冲 = ① 预计算先于任何机制运行（§1.1 协议冻结）；② CELL3_REPRO 单向
   关闭 ≡ docs/270 逐位（双向加法是纯加法）；③ 合成场景 + 参数校准需真实流/不同回路
   复现才能升级为强证据。

   vs 5-9），态内中位压缩 → 双侧设计种子比值 1.3333-1.4221（余量 3.3%+）；若某种子
   账本中位比值在提升窗 <1.30 → 该种子不采纳（照实报告，C2 阈值 0.6 不动）。窗口级
   能量双侧零跌破 450（§1.1）是该薄余量的对冲（签名稳定性最强）。
