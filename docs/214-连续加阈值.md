## 一、机制（vision/continuous_threshold.py）

```
二值 thr（docs/210 对照）：色相在 见过的类别 ± 带宽 内 → 全量共享该类别最大 thr
连续 thr（本文件）：
  thr(hue) = base + Σ rejected[sh] × w(circ(hue,sh)) × thr_gain（cap_thr 封顶）
  w(d) = max(0, 1 − d/带宽)（线性衰减）——距被拒类别 0° 最高、边缘渐低、带宽外基线
训练：染蓝 ×100 遍（漂移 ±5°，见过 std≈3.5° → 带宽≈7.0°）
```

## 二、结果

**P1/P2 thr(距蓝距离) 连续下降 vs 二值（训练 ×100）**

| 距蓝 | 二值 thr | 连续 thr |
|---|---|---|
| 0-6° | 0.80 | 0.80（饱和顶格） |
| **7°（带宽边缘）** | **0.80（全量）** | **0.47（部分加权）** |
| 8°+ | 0.20 | 0.20 |
| 120°（红） | 0.20 | 0.20 |

**P4 未饱和 vs 饱和（thr 曲线形态 × 被拒累计）**

| 被拒累计 | 0° thr | 4° thr | 7° thr | 8° thr | 形态 |
|---|---|---|---|---|---|
| 30 | 0.80 | 0.20 | 0.20 | 0.20 | 连续曲线（未饱和） |
| 300 | 0.80 | 0.80 | 0.46 | 0.20 | 部分饱和 |
| 3000 | 0.80 | 0.80 | 0.47 | 0.20 | 饱和顶格（退化二值） |

**P3 不误伤**：红（120°）二值/连续都 thr=0.20 ✓

## 三、判读

1. **阈值与怀疑连续联合沉积**：thr(距离) 连续下降——近同类 thr 高（"看得更仔
   细"）、边缘渐低、带宽外回基线。被拒越多/越近 → thr 越高，与 docs/213 的 k
   完全同构（怀疑与阈值一起连续沉积）。
2. **二值 vs 连续的差异在带宽边缘**：7° 处连续 thr=0.47（部分加权——边缘色相
   也受一点怀疑）vs 二值 0.80（全量——一个像素的色相差决定"同类与否"）。连续
   消除硬边界（docs/178 否定层：差异强度连续）。
3. **饱和退化二值（与 docs/213 同构）**：被拒累计超过阈值后 0-6° 全顶格 0.80、
   连续差异只在带宽边缘（7° 处 0.47）可见——**饱和掩盖连续差异**，连续性的
   可观测窗口 = 未饱和区 + 带宽边缘。
4. **不误伤保持**：红（120° 远超带宽）两种都基线——连续性/饱和度不影响目标色
   的永远开放（docs/205 类别特异）。

## 四、诚实边界

1. thr_gain=0.02、cap_thr=0.8、线性衰减都是标定值——"被拒多少该多严、边缘留多少
   怀疑"是设计参数（docs/101 固执度旋钮的连续版）。
2. 连续 thr 与 k 共享同一加权（w 相同）——真实系统里怀疑与阈值可能用不同衰减
   （怀疑快衰减、阈值慢衰减），未测。
3. 一维色相距离——多维特征空间（H,S,V）的连续 thr 是自然推广。
4. 现象层纪律照旧（docs/63）。

## 五、下一步（按价值）

1. **回图像版**：非纯蓝（docs/211）真实漂移分布下，连续 thr 的完整曲线——真实
   像素连续色相的阈值加权（docs/211/213 §五 同一线）。
2. **怀疑与阈值不同衰减**：k 用高斯（快衰减）、thr 用线性（慢衰减）——"该疑的
   范围窄、该严的范围宽"的分层策略（docs/101 的多旋钮）。
3. **连续 + 语言**（docs/204）：连续 thr 状态转录成"它有点可疑，我看仔细点"——
   怀疑强度连续 → 语言强度连续（docs/204 §五 4 的连续版）。
4. **饱和点自适应**（docs/213 §五 2）：cap 随场景噪声水平（docs/101 sigma）——
   世界越噪声该越固执到更迟饱和（饱和点也是阅历）。
