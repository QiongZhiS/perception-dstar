## 〇、一句话

> **语言内化三层落地（无 LLM）：①符号槽——颜色/可疑/持续标签由确认通过/被拒的
> 规则表自动贴（感知确认通过→"红"、被拒→"可疑"），不依赖外部语言模型；②态势
> 转录——维持层状态经确定性模板投影成句子（"我看到一个红球在移动，持续 150 帧"），
> 是翻译不是生成；③自反接口——维持层对自身的注视可转录（否定注册→"我刚才可能
> 认错了"、时间门固执→"我不确定，但我先不调整"、纪念加深→"我需要更连续的
> 证据才重新信任"）。语言第一次和感知共享同一状态（docs/160 toText 的机制版），
> 不再是挂在感知外面的"嘴"。**

## 一、三层机制（vision/language_internal.py）

```
第一层 符号槽（维持对象自带标签，规则表自动贴）：
  确认通过(红区占比>0.2) → slots.color = "红"（感知确认通过 → 颜色标签）
  确认失败 → slots.color = 实际色相名 + slots.suspect = True（被拒 → "可疑"）
  轨迹持续 → track_len 计数（持续标签："持续 N 帧"）
第二层 态势转录（维持层状态 → 模板句子）：
  "我看到一个[颜色]球在移动，持续 [N] 帧了"（docs/160 toText 的语言版）
第三层 自反接口（维持层对自身的注视）：
  否定注册（第一次被拒）→ "我刚才可能认错了"
  时间门固执（持续被拒）→ "还是蓝，不是红。我不确定，但我先不调整"
  纪念加深（重信任中）→ "我需要更连续的证据（K/K）帧才重新信任"
  重信任完成 → "我确认了它——但我花了 K 帧才重新信任它"
场景：红球（docs/200 同款），帧 30-59 被外部染蓝（确认失败），60 起恢复
```

## 三、判读：语言从"嘴"到"脑"的机制化

1. **语言和感知共享同一状态**：每一句话都能追溯到具体机制状态——"红"来自颜色
   确认通过（docs/195 三通道分工）、"可疑"来自被拒注册（docs/200 拒绝的历史）、
   "我不确定但我先不调整"来自时间门固执（docs/199b）、"需要更连续的证据"来自
   纪念加深的 K 值（docs/200/203）。语言不再是外部 LLM 对感知的翻译，是维持层
   状态在符号空间的投影。
2. **翻译不是生成**：全部是确定性规则 + 模板（docs/160 toText 的语言版）——快、
   确定、不幻觉。这正是外部对话"语言内化"的主张：机器不需要"像人一样说话"，
   只需要把内部状态转录成人类可读形式（协作路线的接口）。
3. **自反 = 维持层对自身的注视**：否定注册（docs/178 补刀的"他者的不"被保留）、
   固执选择（docs/101 越噪声越固执）、纪念加深（docs/200 的"被拒历史改变后续
   对待"）——这些 docs/200/203 的机制状态，在第三层变成"我刚才可能认错了"/
   "我先不调整"/"我需要更连续的证据"。系统能谈论自己的状态，是因为这些状态
   真实存在（机制），不是 LLM 编的。
4. **docs/194 的升级**：docs/194 是"眼+语言闭环"（语言给先验、视觉核对）——语言
   还是外部通道；本文件是语言内化的起点：语言成为维持层的投影（docs/154 混合
   架构"视觉感知层独立、LLM 在外围"的语言侧雏形）。

## 四、诚实边界

1. 本文件是 **demo 不是实验**：无量化判据、无对照（三层是否真的"内化"没有度量）；
   它是一个"把已有机制状态转录成人话"的工程演示，验证**可转录性**（每句可追溯
   到机制）。
2. 符号槽是手工规则表（颜色名映射、模板字符串）——标签的"语义"仍是设计者给的
   （docs/174 外赋：语言标签也是外赋的）；"内化"目前是"状态→标签"的确定性映射，
   不是"标签→状态"的自主理解。
3. 单目标、单场景（红球染蓝）——多目标/多通道（docs/195 三通道）的转录未做；
   符号槽只覆盖颜色/可疑/持续，威胁度/扫视/预算（docs/160 态势字段）未转录。
4. 没有"语言影响感知"的闭环（docs/194 的"语言给先验"方向）——本文件只有
   "感知→语言"单向；"语言→感知"（符号标签驱动注意力）是下一步。
5. 现象层纪律照旧（docs/63）：转录的是行为签名状态（确认/被拒/固执），不宣称
   "系统在表达内心"。

## 五、下一步（按价值）

1. **语言→感知闭环**：符号标签反过来驱动感知（"它在找红色"→ 颜色通道优先、
   确认阈值随标签调）——docs/194"语言给先验"的机制化，符号槽从输出变输入。
2. **态势全字段转录**：威胁度/扫视/预算（docs/160 objects/threats/saccade/budget）
   全部接模板——"它正在靠近我"/"我正看着那片区域"/"我还有 N 帧的维持能力"，
   完整态势报告的自然语言版。
3. **量化可转录性**：给"语言内化"一个判据（如"每句话能反向定位到机制状态"的
   覆盖率/保真度）——从 demo 变实验（docs/183 纪律：每步可判）。
4. **阅历的语言化**（docs/203 前置）：saturate 记忆的阈值偏移转录成"这个目标我
   需要更连续的证据"（本文件帧 60-69 已是雏形）——阅历变成可表达的自反状态，
   接 docs/203 §五 3。
