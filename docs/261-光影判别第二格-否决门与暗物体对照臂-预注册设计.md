## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/260 §五.2 明确：第一格 C1（暗于长期背景 + 空间相干 + 时间移动）**无法区分
"真阴影"与"暗色移动物体"**（无遮挡几何验证）。本格目标 = 把 C1 升级为人眼式联合
判别的**第 1 步**，范围收窄为**单移动暗区**的判别（合成受控域）：

- **否决门**（负向硬判，任一触发即判为物体/非阴影）：
  - **V1 闭合轮廓**：候选连通域**不触图像边界**（闭合）→ 否决为物体。
  - **V3 主轴偏离光照方向**：候选（非各向同性时）主成分主轴与光照方向夹角超容差 →
    否决为非阴影。
- **证据门**（正向支持，与否决门同一几何量的正表述）：
  - **E1 开放拓扑**：候选触图像边界（阴影带被图像边界裁剪成开放带）。
  - **E2 主轴沿光照方向**：主轴与光照方向夹角在容差内。
- **暗物体对照臂**（本格核心新增）：加一个**不产生阴影的暗色移动圆盘**（与遮挡物
  同轨道/同频率/同相位/同噪声，灰度 32 = 阴影最暗值）作为干扰物——测 ① docs/260
  C1 口径对它的误报率（诚实暴露第一格边界，预期 ≈ 1.0）；② 加否决门后对它的误报率
  （机制增益，预期 ≈ 0）；③ 正样本（真阴影）检出率保持（否决门不误伤，预期 ≈ 1.0）。

docs/187 的完整缺口（纹理"空间弥散、随背景运动"的度量、纹理 vs 物体判别）超出本格
范围（本场景只有单一静态纹理背景），见 §五 8。

### 1.2 合成场景（冻结；主场景逐字复用 docs/260，对照臂为新构造）

**主场景（正样本载体）** = docs/260 §1.2 逐字复用（`import make_shadow_scene`，
160×120 灰度、240 帧 @30fps、24px 棋盘 64/96、静态朗伯球面（圆心 (18,60) 半径 16，
25+170·max(0,n·L)）、移动亮圆遮挡物（轨道 (80,60) 半径 14、频率 0.18 Hz、圆半径 10、
灰度 255）、投影阴影带（dist_perp ≤ 10 且 (p−o)·L < 0，×0.5，只投背景地面）、噪声
σ=3.0 × jitter 0.25；光源方位 θ_L 为场景参数，lvcode 30-33 → 45°/135°/225°/315°）。
GT 掩码（阴影/遮挡物/球面）只用于评估，绝不进入机制。

**对照臂场景（暗物体载体，新构造）** = 与主场景**全同**（背景/球面/噪声/轨道/频率/
相位逐位相同——同一 rng 派生公式 seed×7919 + lvcode×104729 + 13，同一噪声乘子、同一
相位），**唯一差异**：

| 元素 | 主场景（docs/260） | 对照臂（本格新增） |
|---|---|---|
| 移动物体 | 亮圆遮挡物，灰度 255 | **暗圆盘，灰度 32**（= 阴影最暗值 64×0.5——亮度与阴影同值域，只可被几何判别分离，adversarial match） |
| 阴影投影 | 有（半无限暗带 ×0.5） | **无**（不投影阴影；GT 阴影掩码全 False） |
| 运动学 | 轨道 (80,60) r=14、0.18 Hz、相位按种子 | **与主场景逐位相同**（配对场景） |

主/控为**配对场景**（matched pairs）：10 种子 × 4 级 = 主 40 运行 + 控 40 运行，每对
除"暗圆盘 + 无阴影"外全同 → 对照臂测到的任何差异都归因于否决门（机制），不含场景
混杂。

**几何验证（预注册，先于任何运行的分析；已用独立数值脚本复核，见 §二 D0）**：
- 阴影带（主场景）：**4 级 × 6 帧 × 4 相位 = 24/24 触图像边界**（半无限暗带被图像
  边界裁剪 → 开放拓扑；退出点像素在带内且为背景像素）；PCA 主轴与光照方向无向夹角
  均值 1.45-1.57°、最大 2.92°；特征值比（长/短）均值 18.6-19.1、最小 11.1（强各向异性）。
- 暗圆盘（对照臂）：**0/24 触图像边界**（轨道 x∈[66,94]、y∈[46,74] 距四边 ≥ 36px，
  圆半径 10 → 圆盘边缘距边界 ≥ 26px）；PCA 特征值比均值 1.022、最大 1.096（各向同性，
  主轴无稳定定义）。
- 球面暗帽：闭合（不触边界）、特征值比 1.000（各向同性，被 ref_dark 吸收不构成候选）。
→ 零成本结论：**开放-闭合拓扑在本场景天然可分离**（V1 对圆盘 100% 否决、对阴影带
0% 误否决）；主轴判据对阴影带 0% 误否决（30° 容差 vs 实测 ≤2.9°，10× 余量）、对圆盘
跳过（各向同性）；亮度上圆盘与阴影不可分（32 vs 阴影值域 [32,48]），分离只能靠几何。

### 1.3 机制（冻结；预测路径零改动，检测路径复用 docs/260 + 新增否决/证据门）

**预测回路与检测路径** = docs/260 §1.3 逐字复用：`CPLoop(window=10)`（LOOP_CFG 冻结值）
每帧 step；检测读 ref_dark（**Pass A 全程 0.95 分位亮度、排除亮遮挡物帧**（L > log(221)），
诊断轮 D2 冻结口径）+ L；`dark = (ref_dark_log − L) > δ_shadow`（δ=0.35 log 域）、
`bright = L > log(221)`；8-连通域（largest_component），保留面积 ≥ A_min=25；最大暗域 =
阴影候选、最大亮域 = 遮挡物候选；时间门（docs/199b 两条件 AND 的明度版）：
`legacy_active[t] = (面积 ≥ A_min) AND (1 − IoU(d_mask_t, d_mask_{t−10}) ≥ 0.05)`
（MOVE_IOU=0.05，K_MOVE=10，诊断轮 D2 冻结口径）。本脚本对同一检测路径输出
legacy（无门）与 gated（有门）两套指标——**同一掩码、同一 active 判定，唯一差异 =
否决门** → "无门 vs 有门"是干净的单因子对照。

**否决门（新增，冻结；在 legacy_active 之后）**：
```
V1（闭合轮廓否决）：touches = 候选掩码在 y∈{0,H−1} 或 x∈{0,W−1} 有像素
                    veto1 = NOT touches                      # 闭合 → 判为物体
V3（主轴方向否决）：
  对候选掩码做像素坐标 PCA：特征值 λ1 ≥ λ2，主轴 = λ1 特征向量（无向角 α∈[0°,180°)）
  若 λ1/λ2 < RATIO_MIN（各向同性，主轴无定义）→ 跳过 V3（veto3 = False）
  否则 err = min(|α − θ_L mod 180|, 180 − |α − θ_L mod 180|)
       veto3 = (err > TOL_AXIS)                               # 偏离光照 → 判为非阴影
veto = veto1 OR veto3
gated_active[t] = legacy_active[t] AND (NOT veto)            # 任一否决 → 判为物体/非阴影
```
**证据门（新增，冻结；与否决门同一几何量的正表述，仅测量不参与判定）**：
```
E1（开放拓扑）: touches（= NOT veto1）；E2（主轴沿光照）: NOT veto3（各向同性记不适用）
```

**旋钮（冻结，来源论证）**：
- `TOL_AXIS = 30.0°`：光照方向四级间隔 90°（1/4 间隔）；阴影带主轴实测误差 ≤ 2.92°
  → 30° = 10× 余量，真阴影 0% 误否决；长条形非光照方向暗物（≥30° 偏离）被否决。
- `RATIO_MIN = 1.5`：阴影带特征值比 ≥ 11.1 vs 圆盘 ≤ 1.096 → 1.5 落在两者之间（对圆盘
  上限 1.37×、对带下限 7.4× 间距），各向同性即主轴无定义、跳过 V3（圆形物体 V1 已
  否决，V3 的跳过是诚实的不适用而非失效）。
- `CTRL_OCC_GRAY = 32.0`：= 阴影最暗值（64×0.5）——对照臂亮度与阴影同值域，只能被
  几何判别分离（adversarial match 的强度来源）。
- 新增旋钮 vs 既有旋钮的论证见 §五 2（均为几何派生、先于运行冻结、判据测行为不测参数）。

**SfS（报告性，复用 docs/260）**：M = mean(灰度[WARMUP:])；暗帽 = largest_component(
M < 45)；θ_sfs = angle(argmax M − 暗帽质心)。本格不判 SfS（C3 已由第一格验证），仅报告
主/控一致性（球面不变 → 两场景 SFS 应接近）。

### 1.4 判据（冻结；每条带 docs/247 层级标签；合成受控、非真实域证明）

评估窗口 = 帧 [60, 240)（180 帧，同 docs/260）；GT 掩码只用于评估；统计外壳 =
mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828，critical_point 同款）；
聚合单位 = 每 (级,种子) 一次运行（主 40 + 控 40）。

| 判据 | 标签 | 定义（冻结） | 阈值（冻结） |
|---|---|---|---|

## 五、诚实边界（预注册阶段已知）

1. **合成受控、非真实域证明**：三判据均为 `[新][机制][合成受控]`——docs/247 阶梯的
   L0/L1 域（同分布多种子），**不构成任何 L2+ 泛化主张**。否决门与对照臂的结论域 =
   docs/260 同款合成场景族，光源方位已知受控。
2. **否决门参数是否引入新旋钮（任务指定论证）**：是——新增 `TOL_AXIS`（30°）、
   `RATIO_MIN`（1.5）、`CTRL_OCC_GRAY`（32）三个机制参数，且 V1 的"触边界"检查本身为
   无参二值几何谓词。但：**(a) 全部为几何派生、先于任何运行冻结**——TOL_AXIS 由光照
   方向四级间隔 90° 与实测轴偏差 ≤2.92° 的 10× 余量推出（不是拟合判据通过）；RATIO_MIN
   由阴影带长宽比 ≥11.1 vs 圆盘 ≤1.096 的拓扑间距推出；CTRL_OCC_GRAY 由阴影最暗值
   64×0.5 推出（adversarial match 而非放宽）；**(b) 判据测行为（误报率下降/检出率保持/
   角度误差），不测这些内部参数**——参数值改变只会改变机制内部工作点，判据是"机制
   语义（闭合=物体、偏离光照=非阴影）是否成立"的行为测试；**(c) 参数值透明归档于
   config，任何改动都会破坏 R_GS_REPRO 与守卫一致性**。诚实结论：新增旋钮存在，但其
   标定先于运行、几何驱动、判据在行为层——不构成"结果驱动的旋钮调整"。
3. **"闭合轮廓 = 物体"依赖本场景构造**：阴影带被图像边界裁剪成开放带（半无限投影的
   图像内形态）；真实域阴影可能闭合于遮挡物身后/场景内物体上（不触图像边界），V1 会
   误否决。本格只证明"图像边界裁剪的合成阴影下闭合=物体"，不宣称闭合永远=物体。
4. **V3 对圆形物体不可用**（各向同性跳过，RATIO_MIN=1.5）；本格的圆盘分离全部由 V1
   承担（零成本验证：V1 对圆盘 100% 否决）。V3 冻结但可能在对照臂上从未触发（各向
   同性跳过）——如实报告 V1/V3 分率；V3 的通用对象（长条形非光照方向暗物）本场景
   无对应样本，未验。
5. **对照臂只测一个亮度匹配点**（圆盘 32 = 阴影最暗值）：亮度上圆盘与阴影同值域
   （[32,48]）不可分，只靠几何判别——这是对照臂强度的来源也是边界：真实暗物体亮度/
   形状分布多样，本格只测一个构造点。
6. **噪声鲁棒性未测**：σ=3.0 固定 + jitter 0.25（docs/228 主协议），"越噪声越固执"
