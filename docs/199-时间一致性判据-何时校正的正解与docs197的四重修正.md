## 一、实现（vision/color_constancy_temporal.py）

```
裸色温估计：背景彩色像素（S>100，完整排除球轨迹带 x40-460,y130-270）
            色相中位数 shift_i + 环形 MAD（色相分布集中度）
组合判据 TemporalGate（docs/199b 修正：MAD + 帧间|Δ|）：
  真染色（环形 MAD < 20°）       —— 色相集中=同一色温染的（噪声色相随机分散~47°）
  AND 帧间一致（|Δshift| EWMA < 3°）—— 帧间连续=渐变/稳定该校正（突变=噪声该固执）
  两条件 AND → 门开（校正）；否则固执（不校正，docs/101）
校正（门开时）：背景 BGR 均值 m → 增益 g=(mG/mB, 1, mG/mR) → 全图乘 g
  门关时不校正（默认白光，docs/101 越噪声越固执）
确认度量：球体掩码（半径 18，真值位置）内彩色像素红区占比
```

> 注：docs/199 初版用过 frac 门槛（0.5）+ EWMA 均值方差，docs/199b（DAVIS 回填）
> 发现两个缺陷并修正：frac 在真实场景（0.08-0.47）误拒（→MAD 集中度），EWMA 方差
> 把黄昏渐变误判为噪声（→帧间 |Δ|）。本表为修正后结果。

## 二、结果（验收 4/4 PASS）

| 模式 | 无校正红区 | 无校正通过 | 色相旋转红区 | 旋转通过 | 白平衡红区 | 白平衡通过 | 门开帧 |
|---|---|---|---|---|---|---|---|
| bright | 1.000 | 1.000 | 1.000 | 1.000 | **1.000** | **1.000** | 0/90 |
| dark | 0.966 | 1.000 | 0.754 | **0.756** | **0.966** | **1.000** | 0/90 |
| yellow | 0.777 | 1.000 | 0.278 | 1.000 | **0.977** | **1.000** | 81/90 |
| dark+yellow | 0.777 | 1.000 | 0.252 | **0.667** | **0.942** | **1.000** | 81/90 |

- **dark：门 0/90 全关**（MAD 46-47° > 20° 分散）→ 不校正 → 红区 0.966、通过率 1.0
  （旧 docs/197 单帧门槛误校正 → 通过率 0.767，本实现回 1.0 ✓）
- **yellow/dark+yellow：门 79/90 开**（MAD 1-7° 集中 + shift 恒 85 帧间一致）→ 白平衡 →
  红区 0.777→0.972/0.937（球体更纯红、背景回灰）、通过率 1.0
- **bright：门 0/90 关**（无彩色像素）→ 不校正 → 通过率 1.0
- **alpha 鲁棒**：alpha 0.05-0.5 时 dark 都 0/90 关、dark+yellow 都 79/90 开
  （MAD 门槛主导；门对记忆长度不敏感）

## 三、docs/197 的四重修正（本实验的核心收获）

1. **"dark shift 抖动"是排除带缺陷的假象**：旧 estimate_color_temp 排除带 x40-320
   让球轨迹后半段（球 x 80→436、半径 18，最右 454）泄漏进背景估计——球是纯红
   H=0，污染背景色相中位数，"dark shift 0→138 抖动"正是球污染。完整排除球带
   （x40-460, y130-270）后，dark 的 shift 稳定在 88-91（5 个随机种子全验，std<1）。
   **推论：时间一致性（shift 稳定性）单独区分不了 dark 与真染色——两者都稳定；**
   真区分是 **色相分布集中度 MAD（dark 47° vs 真染色 1-17°）**（docs/199b 从
   frac 修正而来：frac 在真实场景失效）。
2. **max_frac=0.5 误拒 yellow**：estimate_color_temp 的 `frac > max_frac → 不校正`
   把 yellow（frac≈1.0）拒了——docs/197 代码里 yellow 实际从未校正（H 停在 83），
   文档声称的"yellow 校正 83→178"并未发生。正解：frac 门槛只设下限（真染色信号
   足够），不用上限拒"占比太高"。
3. **色相旋转校正方向错误**：docs/197 用 H−shift 旋转。但乘法黄染（R×0.5）对纯红球
   （BGR 0,0,200，无 G/B 分量）是特征向量——球体 H 恒 0 从未被染；减 shift 85 反而
   把球体推到 95（青），yellow 球体红区 0.777→0.278、dark+yellow 通过率 0.667。
   **正解是通道级白平衡**（每通道乘性增益）：乘性增益对纯红球无色相影响，球保持红、
   背景回灰（yellow 红区 0.777→0.977）。
4. **"H 漂移 83°"是度量假象**：docs/196 用 patch（半径 25）彩色像素 H 中位 = 83，
   但 patch 内含背景（被染 H≈85、像素数更多），中位被背景主导——球体掩码（半径 18）
   内 H 恒 0。**确认度量应用球体掩码，不含背景像素**；否则"通过率"会被背景撑住
   （docs/196 自己也承认"边缘残红假象"，但没修度量，只加了色相校正——方向错了）。

## 四、判读：docs/101 在颜色轴的精确落点

- docs/197 的设想是"真染色稳定该校正、噪声抖动该固执"——方向对，但**噪声的签名
  不是 shift 抖动**（噪声中位数稳定 88-91），而是**色相分布分散（MAD 47°）**：
  噪声染色的像素色相随机（S 刚好过阈值的灰噪声像素各方向都有），真染色是场景
  属性（整片背景被同一色温染、MAD 1-17° 集中）。
- 正解判据（docs/199b 最终版）= **MAD 真染色门槛 × 帧间 |Δ| 一致性**：
  - MAD 大（像素级噪声）→ 固执（不校正）——docs/101"越噪声越固执"的空间版；
  - |Δ| 大（帧间突变）→ 固执——docs/101 的时间版；
  - MAD 小且 |Δ| 小（真染色、帧间连续）→ 开放（校正）。
- 校正动作 = **通道级白平衡**（乘性增益）：符合 docs/133 §二.1"先验在硬件里"的
  增益控制同构——不是旋转色相（破坏纯色特征向量），是缩放通道（让中性参照回灰）。

## 五、诚实边界

1. toy 场景：合成红球匀速直线 + 四扰动模式（docs/196 同款）；DAVIS 真实视频回填见
   docs/199b——真实背景上门行为干净（噪声全关、渐变全开），但参数需跨视频标定。
2. MAD 门槛 20°、|Δ| 门槛 3° 是场景标定值（toy + DAVIS 首验）；跨场景鲁棒区间需
   多视频扫描（docs/195 §八）。组合判据的鲁棒性来自"两条件 AND"而非单阈值。
3. 白平衡增益用 G 通道做亮度基准（mG/mB, 1, mG/mR）——场景背景灰对称时合理；
   非灰背景（场景本身偏色）会把场景固有偏色当色温误校正（人类色彩恒常同样有
   "白平衡猜错"失败模式，后续可加"中性参照可验证"，docs/199b §六 4）。
4. 球体掩码用真值位置——这是受控场景优势（docs/183 合成方案）；真实视频需灰度
   跟踪提供位置（docs/195 分工已锁），误差下球体掩码略偏移，红区占比度量会退化
   （docs/199b 用合成球叠真实背景，未验跟踪闭环的误差传播）。
