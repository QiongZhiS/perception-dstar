## 一、设计（预注册，冻结；判据/旋钮/守卫/信道/划分先于实现冻结，运行后不改）

### 1.1 他者环境构造（本格核心，冻结；先于任何结果）

**世界（冻结）**：docs/235 C2（context_dep）同款双目标合成场景，160×120 灰度棋盘格
（24px，64/96）+ 亮圆目标（255，半径 10），240 帧 @30fps（8 秒），噪声 σ=3.0（乘性
jitter ±25% 按种子）。几何逐字复用 docs/235 §1.1 D5 冻结值：

| 目标 | 中心 | 轨道 | 频率 | 区带 |
|---|---|---|---|---|
| A（他者） | (80, 36) | 13 | 0.33 Hz | 恒在上半（y ∈ [23,49]，y<68） |
| B（本回路） | (80, 96) | 10 | 0.25 Hz × m(t) | 恒在下半（y ∈ [86,106]，y≥68） |

**上下文规则（世界级事实，冻结）**：ctx(t) = sign(A.x − B.x)（A 在 B 左 = 0，A 在 B
右 = 1，docs/235 真值定义逐字）；B 的瞬时角速度乘子 m(t) = m1（ctx_prev=0）或 m2
（ctx_prev=1，1 帧滞后，docs/235 逐字）。翻转动力学与 docs/235 同构（A.x=80+13cos(ω_A)/
B.x=80+10cos(ω_B)：两态占比 ~60-70%，每 run ~5-6 次翻转，态停留 3-8 窗口——由
docs/235 §1.1 诊断验证的几何保证）。**ctx 翻转时点不可由 B 的像素流预测**（B 看不见
A）——"部分可预测但永远有落空"的他者化版本（docs/232 L5 中间态语义在双回路下的直译）。

**环境常量（冻结，论证来源）**：**m1=2.0、m2=3.2**。m2=3.2 为 docs/235 冻结值直接
复用；m1 从 docs/235 的 1.0 调整为 2.0（**环境校准，docs/235 D5 同款先例，非机制
旋钮**），理由（冻结）：docs/235 中 B 的单目标能量 ≈ 联合能量 − A 区能量 ≈ (590-620) −
340 ≈ 250-280（m1=1.0 时）；m1=1.0/m2=3.2 下 B 单目标两态能量 ≈ 250-280/620-690，
分落 c0 档 1/2——**B 自身即可分态，组合压力消失**（docs/235 D1 同款诊断动机）。m1=2.0
后 B 单目标两态能量 ≈ 500-560/800-900：同落 c0 档 2（[450,2000)，下界余量 ~11%）、
两态中位比 ≈ 1.6 ≥ 1+δ_rel=1.30（提升条件满足）——**B 自身像素无法分态、唯信号可分**，
"也需要对齐的他者"的最小成立条件。该能量带余量脆弱点（θ jitter 高种子可能掉档，
docs/235 §五.3 seed-8 先例）如实写入 §五。

**双回路（冻结）**：两个同款回路 A、B，均为 `LangCommLoop`（= CompLoop 逐字继承 +
信道注入，见 §1.2）。各自只接收**自己的圆盘视域**（渲染时把另一目标的圆盘剔除——
A 回路只看到 A，B 回路只看到 B；背景/光照/噪声完全一致）：

- **A 回路（发射侧）**：A 的视域 = 仅 A 圆盘。A 的运动 = docs/235 C1 A 同款匀速圆周
  （频率 0.33，轨道 13，无 regime 换档）——A 自身运动对 A 完全可预测（1 个稳定条目），
  但 A 是 B 的上下文源（A.x 决定 ctx 翻转）。
- **B 回路（采纳侧）**：B 的视域 = 仅 B 圆盘。B 的运动 = 上下文依赖（m1/m2 随 ctx
  切换）。B 自身的签名空间退化为 docs/235 的"上区能量"恒空（B 恒在下半，y<68 区
  事件 <5px → c1≡0、像素 c2≡None）——**B 从自己像素里得不到上下文**，这正是信道存在
  的理由。

**信道定义（冻结，可计算、纯 numpy、无外部依赖）**：

1. **信号不是设计的**：A 回路不"发射消息"，只把**自己的感知输出**（每窗口事件掩码的
   质心 x：`s_A(w) = mean_x(A 事件像素, y<68 区)`，事件 <5px → 无效）在窗口收尾后
   发布到信道 CH。这是 A 自身回路必然计算的状态，不是按通信协议设计的载荷。
2. **递送**：每窗口同步——A 处理窗口 w 的帧 → 发布 s_A(w) → B 在处理窗口 w 前收到
   s_A(w)。信道无噪声、无丢包、无延迟（冻结；噪声/丢包/延迟是后续格候选）。
3. **B 的合成**：B 收到 s_A(w) 后与自身感知合成上下文可观测 `ctx_B(w) = sign(s_A(w) −
   x_B(w))`，其中 `x_B(w) = mean_x(B 事件像素, y≥68 区)`（B 的自身位置感知，docs/235
   质心计算同款）；任一侧 <5px → ctx_B = None。ctx_B 即 docs/235 c2 槽位的"信道版"。
4. **信道模式（冻结）**：`off`（信道不存在，ctx_B 恒 None）、`comm`（递送 s_A）、
   `null`（递送常量 s_A≡160 → ctx_B 恒 1，信号无信息量）、`scrambled`（递送另一
   种子相位错乱的 s_A'，与真值 ctx 不相关，诊断级）。

**为什么这是"也需要对齐的他者"的最小成立构造（冻结论证）**：① B 的运动受 A 的状态
支配（ctx 规则）——他者对 B 的预测有真实影响；② B 自身可观测不足以预测切换（ctx
不可从 B 像素推出）——他者的信息**不可被替代**；③ A 是回路不是脚本——A 的输出来自
A 自身的预测-残差过程（感知状态），不是预置的信标；④ 是否使用 A 的信号由 B 的行为
涌现决定（§1.2），无预设开关。

### 1.2 采纳机制（冻结；机制零改动优先）

**B 如何"尝试"采纳 A 的信号——账本式试采纳（冻结，docs/235 §1.2-3 提升机制逐字）**：

不采用软加权、不采用并行预测取更优。唯一采纳规则 = 既有冻结的"信息量驱动的槽位采纳"
（docs/235 §1.2-3 逐字），c2 的来源从"本回路像素"换成"信道信号 ctx_B"（LangCommLoop
只覆写 `_window_components` 的 c2 判定，其余全部逐字继承 CompLoop）：

1. **创建**：仅按 B 的基线 2 分量 (c0, c1)（c1 恒 0）连续 k_consist=3 窗口一致 →
   arity-2 条目；创建时用一致性窗口的 (ctx_B, 事件量) 回填条目账本（出生证据，
   docs/235 D6 逐字——使"尝试采纳"不晚于结构形成）。
2. **匹配**：arity-3 (c0, c1, ctx_B) 优先，arity-2 次之（docs/235 §1.2-2 逐字）；
   匹配时把窗口事件量记入条目账本的 ctx_B 条件组（= 每窗口都"试"把信号值写进账本）。
3. **采纳（提升，组合事件）**：arity-2 条目 E 满足全部条件时被拆分提升：① 命中 ≥
   k_split=5；② 账本中 ≥ 2 个非 None ctx_B 值各 ≥ k_consist=3 窗；③ ctx_B 条件**中位
   事件能量**差 ≥ 1+δ_rel=1.30（max ≥ 1.30·min）——即**信号对该条目的窗口能量携带
   信息量**。提升 = 退休父条目，按每个合格 ctx_B 值各建一个 arity-3 信号条件条目
   （继承命中 1）。**采纳是自发涌现**：无任何"开启通信"开关；触发 ⟺ 账本证据满足。
4. **"采纳后残差下降→保留；不下降→忽略"的机制级对应（冻结）**：采纳（提升）是不可逆
   结构事件（docs/235 退休语义逐字）；"忽略"的机制形态 = **提升条件不满足 → 不提升**
   （信号无信息量时条目保持 arity-2，零采纳——docs/235 C1 已实证该信息量门在无关
   信号下不误触发）；"保留"的后果由 C1 的联合残差下降实测（采纳后条目按 ctx 条件化
   → 窗口能量贴合更紧 → JR 下降）。机制内无"采纳后回退"路径（CompLoop 逐字无降级），
   如实声明。

**LangCommLoop 与 CompLoop 的差异清单（显式，冻结）**：

| 条目 | CompLoop（docs/235 逐字） | LangCommLoop（本格） | 差异语义 |
|---|---|---|---|
| c2 判定 | `_window_components` 像素质心（上/下组） | 像素计算保留（守卫模式 pixel 用）；comm 模式 c2 = ctx_B（信道信号合成）；off/null/scrambled 模式 c2 = 像素值（B 单目标视域下恒 None） | 唯一差异 = c2 来源（信道 vs 像素）；c0/c1/账本/匹配/提升/回收/churn 会计逐字继承 |
| 预测路径 | bg_fast/bg_slow/自适应阈值 | **零改动** | B 的 MAE 在 G0/G1 逐位一致（构造性控制项 §1.3 M1） |
| 其余全部 | 匹配/创建/提升/退休/churn | 逐字继承 | 守卫可逐位核对（R_L2G_GUARD_D235） |

## 五、诚实边界（预注册阶段已知边界）

1. **合成环境的局限与远期性（本格最核心的边界）**：本格是 160×120 合成棋盘格 + 圆盘
   的 toy 环境；"信号" = 事件质心 x（A 的感知状态）；"采纳" = 模式表条目按 ctx 条件化。
   语言涌现是**远期目标**（docs/231 §四.4"听觉线/语言线之后"、docs/252 北星"语言是
   后期产物——不急着做，等回路+基质"）：本格只是语言线**第一格**（G2 沟通最小版），
   离 F2 符号系统、F4/F5 证伪检验还差整个领域（docs/266 §四）。证据强度止于行为签名。
2. **"通信有用" ≠ "语言涌现"（F2 是后续格）**：C1 的联合残差下降 = **结构层组织残差**
   （窗口能量相对匹配条目典型值的偏离；采纳后条目按信号条件化 → 贴合更紧），**不是**
   像素预测变准（预测路径零改动，C1b 逐位一致证明），更不是符号系统的涌现（F2 语言 =
   符号→意义的压缩/传递，docs/240 G2→F2，未做）。"通信有用"在这里 = 采纳带来结构层
   组织增益的行为签名。
3. **他者信号可能无信息增量（诚实负 COMM_FLAT 的语义）**：若 ctx_B 保真度不足（质心
   噪声/相位）使 ctx_B 与真值 ctx 错配、或两态能量比 < 1.30、或翻转停留段 < k_consist
   的种子过多，采纳不触发（COMM_FLAT）或触发但 JR 不降（COMM_NO_GAIN 子形态）——如实
   报告 adopt_frac/compound/保真度/能量比/停留段分解，**不允许用结果回调阈值**
   （docs/63 负结果不回调，docs/255 §七4）。COMM_FLAT 本身是有价值的诚实结果（"他者
   信号在最小构造上无信息增量"是反方证据的精确形态）。
4. **行为签名纪律（docs/63/231 §六3、docs/266 §2.3）**：只宣称可观察行为（条目结构、
   采纳触发窗、联合残差、命中率、保真度），**不宣称** A/B 有"意图"、"理解"、"对齐
   意图"、"体验"；F5 意识不测。信道不是"A 想说话"，只是"A 的输出可被读取"。
5. **单向信道 + 最小非对称（本格形态的边界）**：本格 = A 发射、B 采纳的单向最小形态
   （A 的运动无 ctx 依赖，A 无可获信息）；"信号交换"在最小形态下 = 发射侧自然可读 +
   采纳侧自发使用。双向对齐（B 的输出回流 A、互采纳）与"交换闭环"是**后续格候选**
   （G2 第二格），本格不宣称。
6. **采纳的不可逆性（机制层面的诚实声明）**：提升（采纳）是 docs/235 逐字的不可逆
   结构事件（父条目退休、无降级路径）；"不下降→忽略"的机制级对应 = 提升条件不满足
   → 不提升（§1.2-4），而非采纳后回退。若采纳后 JR 未降，本格如实报告 COMM_NO_GAIN
   （机制无回退 = 机制的诚实边界，非缺陷）。
7. **环境校准风险（docs/232/235 同款对冲）**：m1=2.0 是环境校准（docs/235 D5 先例），
   校准记录在 §二；**判据阈值 §1.4 冻结未动**。能量分档边界敏感（docs/235 §五.3
   seed-8 先例）：B 单目标能量 ~500-560 距 c0 档 2 下界 450 仅 ~11% 余量，θ jitter
   高种子可能掉档 → 该种子无采纳（照实报告，判据为多数种子口径 adopt_frac ≥ 0.6）。
   合成场景 + 参数校准存在循环风险，需真实流/不同回路复现才能升级为强证据。
8. **信号留出的"未见过"层级（比 docs/264 弱一档）**：留出段是时间后缀（H 的信号**时序
   实现**在校准时未见过），但 ctx 值 ∈ {0,1} 本身在校准段已出现（世界上下文持续翻转）
   ——本格的"未见过"是信号实现层面，不是 ctx 值层面（docs/264 的留出段内容是字面未
   见过的 DAVIS 视频）。防循环由 PREFIX_EQ 构造性证明承担（参数零重调 + 留出零贡献 +
   同前缀同状态），且 C4 采用 docs/264 的绝对下界 + 相对保持双闸。
9. **统计口径**：10 种子、描述统计（mean±SD + bootstrap CI）+ 配对比较（G0/G1 同帧）；
   无假设检验（合成场景确定性逐种子，docs/232/235 同款口径）；"多数种子"类阈值
   （0.6/0.5）为预注册冻结值。
10. **L5 判据纪律（docs/247 规则 2，docs/258 同款）**：本格全部判据标签为 [L5桥]/[L4]
    前兆形态，**不宣称 L5 能力涌现本体**；COMM_EMERGES 只是"通信行为自发出现的机制
    前兆"的最小可测正证据，L5 桥的正证据需多能力复现（docs/255 §四）；语言线本身
    距"语言涌现"（F2/F4/F5）仍差整个领域（docs/266 §四）。
