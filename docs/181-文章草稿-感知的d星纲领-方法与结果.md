## 一、方法

### 1.1 转导层（Transduction2D，docs/177）
帧 → 灰度 → 对数亮度 L = log(gray+1) → **双时间尺度背景估计**（快 α_f=0.5 视锥式 /
慢 α_s=0.03 视杆式 EWMA）→ 对比度 c = L − bg（韦伯式自适应增益）→ **事件累积器**
（ESIM：pending += Δc，|pending|>θ=0.15 发事件并归零；死区 0.015 杀噪声随机游走；
refractory 2 帧）→ 快/慢两路事件流。**2D 侧抑制**（中心-周围：residual = c − blur(c)）
单独作空间特征。输入先做光学模糊（σ=0.8，压传感器噪声）。

**自适应参数模式**（adaptive=True）：σ̂ = MAD(ΔL − median(ΔL))/0.6745（原始信号估、
减全局位移），EWMA 平滑；θ = max(θ校准, 15σ̂)、死区 = max(死区校准, 1.5σ̂)——**只抬
不降**（校准点是地板，世界变噪才抬杆，docs/101 越噪声越保守）。

### 1.2 读层（EventReader，docs/177）
事件流 → **密度图**（EMA）→ 平滑+阈值 → 连通域 → 包围框；**双窗口读者**（window=2
读快物体 + window=10 读慢物体，并集去重）；**闪变模式**（全局亮度突变=全帧事件淹没
局部信号，人眼眨眼/扫视抑制同款）：用轨迹二次外推（速度+加速度）预测维持目标；
**前导补偿**：框位置 = 前沿质心 + v/2（本帧事件是"旧带+新带"两段，均值滞后半步）；
**拖尾修正**：用最新一帧事件质心定位。

### 1.3 d\* 度量（docs/130/133/135）
d\* = 沿扰动轴（光照/噪声/运动/时间）平移，性能跌破阈值的距离。"任何声称理解的东西，
问它能走多远。"1D 版：光照档位 L=0..10，affordance 三判据，准确率跌破 0.5 的档位差。
2D 版：三类 24×24 patch（矿=亮+粗糙 / 平地=中亮+平滑 / 水=中亮+水平条纹），光子噪声
n ~ Poisson(A·L·s)+N(0,σ_read)（SNR ∝ √L），最近原型分类（L=7 校准）。

| 臂 | d\*（从 L=10 数） | 预言带（docs/133） |
|---|---|---|
| FIXED（固定曝光） | 6.18 | 3-4（未命中，toy 几何偏乐观 ~2.4 档） |
| **ADAPT（自适应增益）** | **9.66** | 8-10 **✓** |

胜因：固定臂死于**读出刻度错位**（信号按 L/7 收缩，判据坐标系失效）；自适应臂死于
**光子噪声地板**（SNR ∝ √L，物理上限）。落点判据：分类不落状态 = 行为恒等于没看见
（全天光下 +20 分/局 vs 0）。

### 2.2 感知 d\* 2D（vision/dstar2d.py，41 seeds）——本文新增

| L | FIXED-2D | EV-2D（增益+侧抑制） | EV-noHib（无侧抑制） |
|---|---|---|---|
| 0-5 | 0.333（全瞎） | 0.36→0.76 | 更低 |
| 7（校准） | 1.000 | 0.975 | 0.887 |
| 10 | **0.333（过曝崩）** | **0.960** | 0.643 |

**d\*：EV-2D = 8.68（预言带 8-10 ✓）；FIXED-2D = 4.67；EV-noHib = 5.77**

三个发现：
1. **预言带命中**（自适应 8-10）。
2. **固定曝光双端失效**（1D 没有）：暗端刻度错位 + **亮端过曝**（信号超校准范围崩回
   0.333）。自适应只在光子噪声地板失效——固定曝光在两个方向失效，自适应只在物理上限
   失效。
3. **侧抑制贡献 +3 档**（8.68 vs 5.77）：2D 空间结构（边缘特征）直接买失效距离——
   1D 特征向量版测不出来的结果，只有 2D 才有。

### 2.3 多时间尺度（S6）定量（vision/timescale_sweep.py，1×256 行受控信号）

| α | slow_detect（慢漂移事件） | settle（阶跃恢复帧） | fast_cost |
|---|---|---|---|
| 0.03 | **60** | 9 | 4696 |
| 0.10 | 42 | 15 | 4696 |
| 0.20 | 20 | 8 | 4682 |
| 0.30 | **0** | 4 | 4658 |
| 0.50 | **0** | 4 | 3982 |
| 0.80 | **0** | 1 | **94（漏快运动）** |
| 双通道(0.5+0.03) | 快组件：0 / 慢组件：**30** | 快组件 **4** | — |

**判据兑现（预言带）**：快轴（settle ≤ 5 帧）需要 α ≥ 0.3；慢轴（slow_detect ≥ 30）
需要 α ≤ 0.06——**单通道两区间不相交（无解区间）**；双通道组件级各满足。附加发现：
**快通道对慢漂移完全盲**（α ≥ 0.3 在 +30% 渐变 200 帧上 0 事件），α ≥ 0.8 连快运动
也漏（94 vs 4696）。

### 2.4 自适应参数 vs 固定（vision/adaptive_test.py，噪声风暴 σ 0.8→12）

| | 平静 C1 | 风暴 C1 | 风暴稀疏度 |
|---|---|---|---|
| 固定 θ=0.15 | 0.0000 | 0.0275 | 0.0366（2.7× 被淹没） |
| **自适应 θ=15σ̂** | 0.0000 | **0.0000** | **0.0086（4.3× 更安静）** |

θ 轨迹实测：平静 0.150 → 风暴 0.600 → 恢复——参数真的在跟世界走。

### 2.5 事件→物体闭环（vision/close_loop.py，demo 320×240@30fps，300 帧）

| 物体 | 检出率 | 质心误差 | 闪变帧检出 |
|---|---|---|---|
| 慢圆 | **0.783** | 16.4px | **0.667** |
| 快方块 | **0.757** | 6.9px | 0.222 |

闪变期预测维持（眨眼尺度 ~0.1s 设计域）：慢圆 67% 跟住；快方块 22%（快速加速目标在
全局突变时仍短暂丢失——人在频闪下同样抓不住，生理诚实）。误报 3.05 框/帧。
**设计域教训**：同一机制放在 0.5s 降幅（暗适应尺度）下几乎全丢，放到 ~0.1s 眨眼尺度
下工作——人眼三级时间结构（响应 10-100ms / 抑制窗 20-150ms / 适应秒-分钟）是每层
机制的落点。

## 四、讨论要点

1. **设计域**：机制成败取决于放在人眼三级时间结构的哪一级（2.5）。
2. **意义 = 落空 × 利害**（docs/179）：完美对齐=感知消失=无意义；自适应 θ 只抬不降=
   在正确的地方保持落空。
3. **闭眼走**（docs/178 第 3 层）：事件驱动系统的默认状态是闭眼走——世界模型是主体、
   对齐是维护、行动是验收。闪变预测维持不是补丁，是"输入缺席时存在继续"的第一实例。
4. **评价范式**：判不达标比判达标容易（docs/118）；假指标修正（闪变 1.000→真实 67%/22%，
   docs/177）——诚实指标是范式的一部分。

## 五、诚实边界

- 全部数字来自 toy 场景（1D 矿场 / 2D 合成 patch / 1×256 行 / demo 320×240）；真实
  视频（docs/177：12 分钟实测 7.8% 稀疏度）只做了定性冒烟。
- 帧级事件模拟（33ms）≠ 真事件相机（μs 级）；θ/α/死区是手调+自适应，不是学出来的
  （自适应映射学出来是下一步，目标 d\*）。
- 不宣称任何"理解/感知体验"（docs/31/63 纪律）：全部是行为签名。
