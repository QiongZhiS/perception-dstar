# 197 — 色彩恒常

> 缘起：2026-08-27。docs/196 标记色温脆弱（H 漂移 83°）后，实现色温适应（色彩恒常，
> docs/133 §二.1 的信息层版）：背景色相中位数 = 色温偏移 → 确认前旋转校正。结果：

## 一、实现（vision/color_constancy.py）

```
色温估计：背景彩色像素（S>阈值，排除目标区）色相中位数 = 环境色温偏移
确认校正：H_corrected = (H − 色温偏移) % 180，再判红区间
```

**方向验证（yellow 模式）**：红球主体 H=83（橙，被黄染），shift=85 →
校正后 (83−85)%180 = 178（红区间 [170,180]∪[0,10]）✓；通过率保持 1.0。

## 二、"何时校正"的判据缺口（本实验的核心失败）

| 模式 | 排除后彩色占比 | shift | 该校正？ | 单帧门槛判断 |
|---|---|---|---|---|
| bright | ~0 | 0 | 否 | ✓ 拒（占比<min） |
| dark（后期） | 0.19 | 87（噪声） | **否** | ✗ 信了（0.02-0.5 内） |
| yellow | 1.0 | 85（真染色） | 是 | ✓ 信（>min） |
| dark+yellow | 0.82 | 85（真染色） | 是 | ✗ 拒了（>max_frac） |

**单帧占比门槛（min_frac/max_frac）在 0.19-0.82 区间混叠**——dark 噪声（0.19）和
dark+yellow 真染色（0.82）无法用占比区分。dark 校正后通过率 0.767（误校正），
dark+yellow 校正失效（H 82 未回红区）。

## 三、判读：噪声的签名是时间抖动

- **dark 的 shift 帧间抖动**（帧 30→0、帧 80→87，单调漂移——噪声随机游走）；
- **yellow/dark+yellow 的 shift 帧间稳定**（85 恒定——真实色温不随时间变）；
- **时间一致性判据**：色温估计的 EWMA 方差小 = 可信（真染色），方差大 = 噪声（抖动）
  → docs/101"世界越噪声自我越该固执"的颜色版：**噪声大（估计抖动）时固执用默认
  （不校正），噪声小（估计稳定）时开放（校正）**。
