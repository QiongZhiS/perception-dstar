1. **环境带重调的边界（本格最核心）**：本格 = 只改环境常量 m1/m2（docs/235 D5 +
   docs/268 §二 C3 同款环境校准先例）。能量带预计算器与真实回路逐位等价（锚点证明），
   但**设计窗口 ≠ 实际采纳**：采纳还依赖账本时序（双 ctx 值填满窗序、提升触发窗）、
   ctx_B 保真度（~0.95）与真值 ctx 的错配、留出段的转移命中——S4/S7（高 θ 噪声种子，
   docs/235 §五.3 seed-8 先例同型）预计算已示 E0 落档 1 → 混合档 → 零采纳路径，如实
   报告（判据为多数种子口径 adopt_frac ≥ 0.6，非全种子）。若实测采纳数 < 设计窗口
   （如账本时序导致部分种子提升晚于校准段），C2/C4 可能仍差——照实判定，不回调。
2. **两格同尺可比的前提与局限**：本格判据/机制/守卫与 docs/268 逐字相同、世界 rng
   同流（lvcode 40-43 沿用），差异仅 m1/m2 → 结果可直接对比；但**两格都是同一冻结
   机制在合成 toy 环境上的行为签名**，COMM_EMERGES 仍是"通信行为自发出现的机制
   前兆"（docs/247 规则 2，不宣称 L5 能力涌现本体；不宣称意图/理解/对齐意图——
   行为签名纪律）。
3. **"通信有用" ≠ "语言涌现"（F2 是后续格）**：C1 的 JR 下降 = 结构层组织残差下降
   （预测路径零改动，C1b 逐位证明），不是像素预测变准，更不是符号系统的涌现
   （docs/240 G2→F2，未做）。
4. **环境校准循环风险（docs/232/235 同款对冲）**：m1/m2 由预计算（机制无关、锚定
   第一格实测）预先冻结，判据阈值未动；但"为测 COMM_EMERGES 而抬能量带"本身有
   "选环境直到可测"的循环味道——对冲 = ① 预计算先于机制运行（§1.1 协议冻结）；
   ② 判据/机制零改动；③ 备用候选与启用规则预注册；④ 合成场景 + 参数校准需真实流/
   不同回路复现才能升级为强证据（docs/268 §五7 同款）。本格如 COMM_EMERGES，应如实
   声明其证据强度边界。
5. **翻转频率随 m2 抬升的风险**：m2 3.2→4.2 使 B 角速度 ×1.31 → 上下文翻转更密
   （预计算中位 6.5，docs/268 6.8，量级相当；S3/S5 达 8-9）；预计算显示两态停留
   ≥k_consist 种子 10/10（(2.6,4.2)），但更高 m2 的网格点（m2=5.0、m1≥3.2）已出现
   seg_ok 下降——如实报告每种子翻转/停留数字。
6. **S4/S7 掉档种子的语义（非缺陷，如实）**：高 θ 噪声种子 E0 落档 1 → 混合档 →
   结构上不可采纳（docs/268 同型种子 S4 同样不可达）；本格把它们从"窄窗 4-5 种子"
   推到"已知失败 2 种子"，设计窗口 8/10 达 C2 多数阈值；若某掉档种子意外采纳（如
   经档 1 路径），按 spurious/旁路照实报告。
7. **信号留出的"未见过"层级（比 docs/264 弱一档，docs/268 §五8 同款）**：留出段是
   时间后缀（H 的信号时序实现在校准时未见过），但 ctx 值 ∈ {0,1} 本身在校准段已出现；
   防循环由 PREFIX_EQ 构造性证明承担，C4 采用绝对下界 + 相对保持双闸。
8. **统计口径**：10 种子、描述统计（mean±SD + bootstrap CI）+ 配对比较（G0/G1 同帧）；
   无假设检验；"多数种子"类阈值（0.6/0.5）为预注册冻结值。
9. **L5 判据纪律（docs/247 规则 2，docs/258 同款）**：本格全部判据标签为 [L5桥]/[L4]
   前兆形态，不宣称 L5 能力涌现本体；COMM_EMERGES 只是"通信行为自发出现的机制前兆"
   的最小可测正证据；语言线本身距"语言涌现"（F2/F4/F5）仍差整个领域（docs/266 §四）。
10. **第一格负结果不可回退（docs/63）**：本格不修改、不推翻 docs/268 的冻结设计与
    COMM_FLAT 判定（docs/268 §一 运行后不改）；本格是**新预注册重新冻结环境**（docs/
    268 §四 明文预告路线），旧环境数字保留为复现锚（R_L2H_CELL1_REPRO）。
11. **运行后发现：G2s spurious 6/10（诊断级，照实报告）**：docs/268 的 G2s（错乱
    信号）零 spurious（能量差 1.31-1.34 太小，随机 ctx_B 分裂不过 1.30 门）；本格
    能量带抬升（比值 1.39-1.45）后，6/10 种子的随机 ctx_B 分裂恰好把两态能量分到
    两组并越过 1.30 中位能量比条件 → 提升触发。这暴露"信息量"判据（§1.2-3 条件③）
    是**能量分离的代理**而非"与真值上下文的因果对应"——对真实信号与随机分裂同样
    敏感（阈值以上两者都触发）。G2s 按 docs/268 §1.4 冻结口径为诊断级不进判据
    （C2 只要求 G0/G1n 零采纳，均 10/10 过），但 **COMM_EMERGES 的"采纳由信息量
    驱动"须读作"由能量分离驱动"**；后续格若测 G2s 零 spurious 需收紧条件③（如加
    保真度/纯度门）——这是机制候选改进，不是本格判据回调。
