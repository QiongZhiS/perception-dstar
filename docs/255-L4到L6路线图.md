### 1.3 关键洞察（三格合并）

1. **信息量-可达性张力是组合泛化的真瓶颈**：强信息量组（flamingo 类，特征距离 ~2.5 >>
   r_fast）在**任何账本类机制**下都不可达——两 c2 组被不同原型各自匹配，单原型账本结构
   性见单值。这不是常数问题，是**单原型账本的表示边界**。
2. **R0 负对照的"干净"依赖账本不可达性（机制特性非数据特性）**：窗口级直判会把 R0
   （flamingo×5 循环，能量比 ~11.9971）判为"有信息量"——否决了"绕过账本"的修法。
3. **连续三格负结果 + 守卫全过 = "否"是稳的**：方法论上，这比"调参调到过"值钱得多——
   它把 L4 第一层的失败形态精确限定为"表示层的组合可达性"，且逐格收窄根因。
4. **A1 底子补齐改变 L4 语境（方向修正的回报）**：docs/257 DYNAMIC_PASS_REAL 实证了
   机制在真实流上的时间→累积→结构依赖链；L4 第三格在其之上首触发真实分裂——底子不是
   组合失败的根因，但它是组合尝试的前提（docs/240"依赖要全先"）。

## 二、L4 完整定义（何时算 L4 踩实）

L4 = 跨任务/组合：**在"校准时没见过的新任务/组合"上工作**。两个子主张都要成立：

1. **组合结构涌现**（行为证据，当前两格在做）：现行机制在真实像素上，面对可观测的上下文
   信息量，把记忆组织成按槽位索引的条件形态（compound_frac ≥ 0.5 等）。
2. **组合泛化测试**（docs/247 L4 证明方式）：**训练时未见过的组合在测试时仍工作**——把
   docs/246 的"留出"方法升级为"组合留出"：在真实流上划分组合（如：段对），留出部分组合
   校准、部分测试，测未见过组合的迁移。这是 L4 的**证明性**判据（第 1 条是行为形态，
   第 2 条是外推证明）。

**裁决**：第 1 条达成（COMPOSABLE_REAL）+ 第 2 条设计并跑出正结果 → L4 踩实。若第 1 条
最终仍负（第三格后），L4 停在"组合泛化不可达的负证据"——如实写入交接，不强行宣称。

## 三、L4 → L5 的桥：机制泛化（能力涌现的可测前身）

**L5 = 跨能力涌现**（没训练过的能力自己出现；证明方式 = 涌现检验）。docs/247 明确 L5
不可在单一基准证明。因此桥 = **先有可检验的涌现形态**，候选按价值排序：

1. **技能习得效率（首选）**：docs/247 §二 明确"智力 = 技能习得效率 = 机制泛化；参数泛化
   一次证明、机制泛化一生证明"。docs/252 §四4 说配额退役后下一步 = "把时间尺度涌现推向
   技能习得效率"。**机械前身已有**：快慢双原型的时间尺度从行为涌现（命中率→升级/回收）。
   可测形态：新技能（新场景族/新规则）的习得**速度**与**所需干预**随阅历下降——学习过程
   本身的高效习得。
2. **二阶残差/自省（已有正证据）**：docs/237 SO 探针翻案为正（自省的机械前兆）、docs/236
   理念沉淀。可测形态：回路对自身残差做二阶处理（"我在怀疑"的机械前兆）——自省作为能力
   涌现的前兆。
3. **态势转录（E1 决策维，工程侧）**：多目标 → "它在靠近我"级别报告（docs/252 §四2，
   B1.2 剩余）。更接近新能力出现，但证据形态偏任务工程，优先级低于 1/2。

**明确后置：语言**（docs/231/242 语言 = 副产物主张；docs/252 §七北星"语言是后期产物，需
学习+社会接触才有意义——不急着做，等回路+基质"）。语言是 L5 最强的主张，但按北星**不提前
做**——先做回路+基质（技能习得效率 + 二阶残差），语言等社会接触条件出现。

## 四、L5：涌现检验（展望，非判据）

L5 不是"再做几个实验"能跨过的，而是先有**可检验的涌现形态**：

- **候选能力**：技能习得效率（首选）、二阶残差自省（正证据在手）、态势转录（工程侧）。
- **检验方式（展望）**：涌现 = 未训练的能力自行出现 → 需要"前测-后测"式设计（能力出现
  前可测基线 vs 出现后），且该能力不是训练目标的平凡副产品（docs/247 捷径教训：排除
  表面相关）。
- **诚实边界**：L5 判据不得作为验收标准（docs/247 规则 2），只作为研究方向；若技能习得
  效率线证明"学习速度随阅历单调下降且可外推"，这是 L5 的第一块真证据，但"能力涌现"的
  强主张仍需多能力复现。

## 五、L5 → L6：方法论极限（不是实验目标）

**L6 = 开放世界**（任何世界情况；docs/247：AGI 层，无法在单一基准上证明）。安排三件事：

1. **把"泛化"定义为可逐层检验的楼梯**（docs/247 已做到）：L0-L4 各层有明确证明方式，
   L5 用涌现检验、L6 是开放性问题——"不是做出 AGI，是让泛化第一次有可逐层检验的定义与
   证据"（docs/247 §七），这是给业界的贡献本身。
2. **方法的迁移（docs/247 §六）**：L2 的留出+防循环+余量 → L3 跨域留出 → L4 组合测试 →
   L5 涌现检验——每一层升级都依赖上一层证明方法在迁移（**方法本身也在泛化**）。L6 是
   这个迁移的极限，不是另一个实验。
3. **诚实边界**：L6 不可证明，只能被逼近；项目承诺每层有可证伪判据，L5/L6 层拒绝模糊的
   "涌现"叙事。

## 六.5、空间统计与静态场景视觉（残差的空间维——docs/187 盲区的补丁，2026-08-30 新增）

### 6.5.1 问题：docs/187 的"静止 = 0 事件"是时间预测的结论

docs/187/179 立场：感知编码"世界对预期的拒绝"——静止场景被背景 EWMA 预测掉 → 0 事件
→ 感知消失。**但这不是框架缺陷，是预测源单一**：残差递归只需要"预测-落空"，预测源
可以是**时间的**（下一帧）也可以是**空间的**（邻域重建）。

### 6.5.2 空间统计的四层（B4 已证前三层，第四层候选）

| 层 | 空间统计 | 预测什么 | 落空（缺陷） | 状态 |
|---|---|---|---|---|
| **L-gist（整体）** | 低频块均值/能量布局/颜色统计 | 整幅图应该什么样 | 局部不符合整体 | ✅ B4（8px 块重建） |
| **L-object（中频）** | 局部模板/结构张量/边缘 | 物体应该什么样 | 物体内部异常 | ✅ B4（平滑模板） |
| **L-texture（高频）** | 纹理统计（方向/周期/密度） | 纹理图案应该什么样 | 纹路异常 | ✅ B4（锐模板） |
| **L-relational（关系，缺）** | 物体间相对位置/遮挡/大小/光照一致 | 物体应该如何排列 | 关系异常 | ⬜ B5 候选 |

### 6.5.3 机制：静态场景视觉 = 空间残差驱动的粒度递归

```
静止帧 → 多尺度空间统计（同时算）：
  gist 块重建 → R_g / 局部模板 → R_o / 纹理统计 → R_t / 关系统计 → R_r
  → 缺陷 = 任一层残差超预期 max(K·σ̂, 0.10) 的相干区域
  → 下钻 = 缺陷处（B4 机制，静止帧同样工作）
  → 吸收 = 空间预测器更新（docs/250 慢原型精神）
⟹ 静态场景通过空间残差被"看见"（无运动依赖）
```

**关键洞察**：docs/187 的"静止=0 事件"是**时间预测**的结论；**空间预测下静止结构
依然可感知**——"感知消失"只在时间预测下成立。这是"残差是原子"的推广：**残差不只
有时间维（运动），还有空间维（结构）**。

## 七、方法纪律（贯穿每一格）

1. **预注册冻结**（docs/63）：判据/旋钮/守卫先于最终运行写入实验文档；运行后不改。
2. **判据标签**（docs/247）：每判据必标 `[L#][参数/机制][证明方式]`；不带标签 = 无效。
3. **守卫**（docs/252 §三3）：每实验带"同代码路径复现前一格"守卫（如 Mode OFF≡docs/251
   逐位 32/32）；守卫不过先修实现，不判机制。
4. **负结果不回调**：两格 PARALLEL_ONLY_REAL 是负结果纪律的实例——根因逐层收窄（账本
   可达性 → 邻域信息量分布），下一格 = 新预注册，不调任何冻结阈值。
5. **安全纪律**：脚本输出落盘、只报元数据（exit/字节）、数字用纯正则抽取（extract_r.py）、
   输出文件人可读模型禁读（毒文件）、子代理隔离、零改写既有脚本（新实验 = 新文件 +
   import 复用）。
6. **北星不动**：语言后置；"给 AI 装上眼睛，不是让它看得清，是让它值得被看见"——L4-L6
   的每一格都是"值得"的泛化证明版（docs/252 §七）。
