### 1.3 关键洞察（三格合并）

1. **信息量-可达性张力是组合泛化的真瓶颈**：强信息量组（flamingo 类，特征距离 ~2.5 >>
   r_fast）在**任何账本类机制**下都不可达——两 c2 组被不同原型各自匹配，单原型账本结构
   性见单值。这不是常数问题，是**单原型账本的表示边界**。
2. **R0 负对照的"干净"依赖账本不可达性（机制特性非数据特性）**：窗口级直判会把 R0
   （flamingo×5 循环，能量比 ~11.9971）判为"有信息量"——否决了"绕过账本"的修法。
3. **连续三格负结果 + 守卫全过 = "否"是稳的**：方法论上，这比"调参调到过"值钱得多——
   它把 L4 第一层的失败形态精确限定为"表示层的组合可达性"，且逐格收窄根因。
4. **A1 底子补齐改变 L4 语境（方向修正的回报）**：docs/257 DYNAMIC_PASS_REAL 实证了
   机制在真实流上的时间→累积→结构依赖链；L4 第三格在其之上首触发真实分裂——底子不是
   组合失败的根因，但它是组合尝试的前提（docs/240"依赖要全先"）。

## 二、L4 完整定义（何时算 L4 踩实）

L4 = 跨任务/组合：**在"校准时没见过的新任务/组合"上工作**。两个子主张都要成立：

1. **组合结构涌现**（行为证据，当前两格在做）：现行机制在真实像素上，面对可观测的上下文
   信息量，把记忆组织成按槽位索引的条件形态（compound_frac ≥ 0.5 等）。
2. **组合泛化测试**（docs/247 L4 证明方式）：**训练时未见过的组合在测试时仍工作**——把
   docs/246 的"留出"方法升级为"组合留出"：在真实流上划分组合（如：段对），留出部分组合
   校准、部分测试，测未见过组合的迁移。这是 L4 的**证明性**判据（第 1 条是行为形态，
   第 2 条是外推证明）。

**裁决**：第 1 条达成（COMPOSABLE_REAL）+ 第 2 条设计并跑出正结果 → L4 踩实。若第 1 条
最终仍负（第三格后），L4 停在"组合泛化不可达的负证据"——如实写入交接，不强行宣称。

## 四、L5：涌现检验（展望，非判据）

L5 不是"再做几个实验"能跨过的，而是先有**可检验的涌现形态**：

- **候选能力**：技能习得效率（首选）、二阶残差自省（正证据在手）、态势转录（工程侧）。
- **检验方式（展望）**：涌现 = 未训练的能力自行出现 → 需要"前测-后测"式设计（能力出现
  前可测基线 vs 出现后），且该能力不是训练目标的平凡副产品（docs/247 捷径教训：排除
  表面相关）。
- **诚实边界**：L5 判据不得作为验收标准（docs/247 规则 2），只作为研究方向；若技能习得
  效率线证明"学习速度随阅历单调下降且可外推"，这是 L5 的第一块真证据，但"能力涌现"的
  强主张仍需多能力复现。

## 七、方法纪律（贯穿每一格）

1. **预注册冻结**（docs/63）：判据/旋钮/守卫先于最终运行写入实验文档；运行后不改。
2. **判据标签**（docs/247）：每判据必标 `[L#][参数/机制][证明方式]`；不带标签 = 无效。
3. **守卫**（docs/252 §三3）：每实验带"同代码路径复现前一格"守卫（如 Mode OFF≡docs/251
   逐位 32/32）；守卫不过先修实现，不判机制。
4. **负结果不回调**：两格 PARALLEL_ONLY_REAL 是负结果纪律的实例——根因逐层收窄（账本
   可达性 → 邻域信息量分布），下一格 = 新预注册，不调任何冻结阈值。
5. **安全纪律**：脚本输出落盘、只报元数据（exit/字节）、数字用纯正则抽取（extract_r.py）、
   输出文件人可读模型禁读（毒文件）、子代理隔离、零改写既有脚本（新实验 = 新文件 +
   import 复用）。
6. **北星不动**：语言后置；"给 AI 装上眼睛，不是让它看得清，是让它值得被看见"——L4-L6
   的每一格都是"值得"的泛化证明版（docs/252 §七）。
