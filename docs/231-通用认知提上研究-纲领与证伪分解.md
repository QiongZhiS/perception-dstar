## 〇、一句话

> **通用认知假说：通用认知不从语言涌现、也不从视觉涌现，而从"能持续预测并在预测落空时
> 修正自身的回路"涌现——语言/视觉/推理/规划是同一回路在不同信息环境下的行为（同一棵树的
> 三根枝）。提上研究的路径不是直接做语言，而是先做"临界点实验"：把回路放进复杂度恰到好处的
> 信息环境，观测它是否从空转变成自驱动、并发生结构自发变化。假说可证伪：若回路在任意
> 复杂度环境中都不发生结构自发变化，则假说作废。**

---

## 一、假说陈述

### 1.1 核心主张（H）

**H：存在一个模态无关的"预测-残差回路"，当其嵌入的信息环境复杂度越过某个临界点后，
会自发地发展出利害（惊奇→在乎）、意义（落空×利害）与技能（行为趋势固化），而语言是
回路遇到"也需要对齐的他者"后自然出现的行为，不是独立设计的能力。**

三个子主张，可分别证伪：

- **H1（残差原子性）**：预测-落空是认知的基本单元，而非像素/token/特征。
- **H2（利害从落空涌现）**：利害（维持什么、拒绝什么）由落空的历史产生，不需要外部
  设计的奖励/利害注入（惊奇本身就是利害的初始形态，FEP 同构）。
- **H3（回路自驱动）**：在复杂度恰当的中间态环境中，回路会自发发生**结构变化**
  （不调参数的新技能/新维度），而不是只在参数空间微调。语言是越过临界点后的副产物。

### 1.2 与主流 LLM 路线的划界

- LLM 用连续参数存离散知识（把知识打散进 FFN 分布表征）——隐式、不可读、冗余；
- 本纲领主张离散结构存离散知识（图存事实/规则库存模式/技能树存行为路径），连续参数
  只做预测器的精细调优（四域框架的域 D/C/A 分工）；
- LLM 在语言数据表面掠过（符号共现统计），没有嵌入真实的预测-落空回路——有语言无认知；
- 划界不是"击败 Transformer"，是"换存储与驱动范式"。战斗性表述（"Transformer 会死"等）
  只属于理念层，不进方法层（docs/63 纪律）。

## 四、缺失实验清单（按优先级）

### 1. 临界点实验（第一优先，纲领命门）
- **问题**：什么样的信息环境复杂度，能让预测-残差回路从空转变成自驱动、并发生结构
  自发变化？
- **设计方向**：对环境的可预测性做梯度（静态 → 规律运动 → 带噪声规律 → 近乎不可预测），
  逐级测量回路的：预测误差轨迹、残差利用率、参数 vs 结构的变化量。找"部分可预测但
  永远有落空"的中间态——若该区间内出现参数空间之外的结构变化（新技能/新维度），
  H3 得到首个直接证据。
- **风险**：环境太简单 → 回路收敛后空转；太复杂 → 残差恒非零、回路变噪声放大器。
  "恰好"区间的存在性本身就是 F3 的证伪判据。
- **与现有实验的关系**：建立在 docs/228 的统计外壳（davis_a2_stats.py 的多种子/JSON
  归档/checkpoint 模式）之上，机制零改动、纯新协议。

### 2. 惊奇→利害直接测量（H2 补测）
- 用残差/惊奇量的历史，预测"维持/拒绝"行为的发生——若利害确实由落空涌现，则
  surprise 统计量应能预测 docs/189/200 中观察到的利害锚行为，而不需要外赋标签。

### 3. 与 FEP/主动推理路线的对照基准（效率与结构）
- 对照对象：AXIOM（95 万参数 vs DreamerV3 4.2 亿、7.6× 样本效率）——证明
  "小参数+预测编码"路线在效率上的位置；不宣称超越，只做资格对照（docs/225 的
  "资格证明不是竞赛"精神）。

### 4. 语言涌现（远期，听觉线/语言线之后）
- 让回路进入"多智能体对齐"环境，观测信号交换是否自发出现——这是 H3 的最终验证，
  短期不做，路线图占位。
