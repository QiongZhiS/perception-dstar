## 一、批评原文（kikyo，逐条摘录）

1. **"我如果遇到现实与预测不一致那就会直接写进损失了。感觉跟传统的机器学习方法有不少区别"**——对"预测-残差"的理解：认为残差就是损失函数，与传统 ML 无本质区别。
2. **"所以这些结论是根据自己定的指标得出来的？那问题就出在自己定的指标了。自己定的指标不一定对，并不能说明什么"**——对指标可信度的质疑：认为结论完全来自自造指标，缺乏严谨性。
3. **"审稿人会认为你的结论只是来源于自己的一些指标，不是严谨的测试流程。但是我们一般会对比自己造的方法和传统方法相比有什么优点，或者有什么数学证明可以说明自己的方法一定对"**——对审稿风险的判断：需要（a）与传统方法对比，或（b）数学证明。

## 二、逐条回应（项目现状对照）

### 批评 1：残差 = 损失函数？

**回应：残差不是损失，是信号源。** 框架的学习主体不是梯度最小化预测误差，而是**残差驱动的结构生成**（docs/227/231 §一.2）：

| 传统 ML（kikyo 假设） | 本框架 |
|---|---|
| 端到端梯度最小化损失 | 预测残差 → 自适应阈值/事件 → **离散结构涌现**（模式表/快慢原型/条件记忆） |
| 连续参数存知识 | 离散结构存知识，连续参数只做预测器精细调优（docs/231 划界） |
| 参数微调 | 结构变化（新条目/新原型/升级/回收） |

**诚实承认**：若对外表述不清，审稿人第一眼会读成"预测误差最小化"——这是**表述/定位风险**，需一页写清"残差是信号源、结构生成是学习主体"的划界。docs/231 §六 纪律已说"战斗性表述不进方法层"，但"与传统 ML 的区别"值得显式成文。

### 批评 2：结论来自自定指标？

**回应：有方法论铠甲，但缺口真实存在。**

**已有的对冲**（docs/252 §三 方法论资产）：
- **预注册**（docs/63）：判据先于数据冻结，结果后不改判据；
- **守卫**：同代码路径复现前一格（本次 11 实验 Mode OFF≡docs/251 32/32 逐位贯穿）；
- **层级标签**（docs/247）：每判据带 `[L#][参数/机制][证明方式]`；
- **负结果不回调**：本次 6 个诚实负结果（L4 前两格、L5 跨迁移、A1 前序）全部如实收束——不是跑完挑数字。

**真实缺口（kikyo 点中）**：**跨方法对照缺失**。docs/252 §三 六条方法论资产里没有"与标准方法对照"；docs/228 的 flips 置换是统计检验（自己指标内部的 null 对照），不是方法间对照。

### 批评 3：需要方法对照 / 数学证明？

**回应：方法对照可补且应补；数学证明需定位清楚。**

- **数学证明**：现有的是机制内部一致性证明（docs/251 构造成立、docs/246 防循环论证），不是"泛化能力数学上界"——后者不存在也不必要（框架卖点 = 行为涌现的可检验性，非理论界）。审稿人要求时需诚实定位。
- **方法对照（缺，最该补）**：补一个**同环境、同数据、同判据**的传统基线对照（kNN/高斯过程/RNN 预测器 vs 本框架，在 DAVIS 上比预测误差、结构涌现、组合留出）——最直接的审稿人防御，优先级高于数学证明。
