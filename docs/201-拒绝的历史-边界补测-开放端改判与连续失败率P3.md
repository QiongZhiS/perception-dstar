## 一、实验 1（开放端）：守住 vs 改判的边界（docs/200 边界 #2）

### 1.1 机制设计（vision/keep_reject_open.py）

docs/200 的保留系统是绝对固执（期望恒红，永不改任务色相）。真实主体需要在
"守住利害"与"利害确已改变"间判断——docs/101 平衡带（eta 随世界硬度调）的颜色轴。
设计**双状态滞回机 KeepSig**，避免"一拒就改→改完被带偏→再改"的震荡：

```
守住态（任务=红）：ok = 红区占比 > 0.2（docs/200 同款确认）
  连续被拒帧数 ≥ K_switch → 判定"利害确已改变" → 改判（期望色相更新到蓝）
改判态（任务=蓝）：ok = |观察色相 − 蓝| < tau
  连续被拒帧数 ≥ K_back  → 世界回来了 → 回改（期望回到红）
改判与回改需要同等强度的连续证据（对称滞回 = 平衡带：不是绝对不变，也不是一拒就改）
```

对照：B0 绝对保留（docs/200 原版）vs B1 显著性改判（K_switch=35 / K_switch=25）。

### 1.2 结果

| 场景 | 系统 | 染色段通过 | 改判帧 | 改判后通过 | 末态 | 恢复延迟 |
|---|---|---|---|---|---|---|
| 场景1 短暂染色(30帧) | B0 绝对保留 | 0.000 | None | — | red | 1 |
| 场景1 短暂染色(30帧) | B1 K=35 | 0.000 | None | — | red | **1** |
| 场景1 短暂染色(30帧) | B1 K=25 | 0.167 | 54 | 0.556 | red | **16** |
| 场景2 世界长期变蓝 | B0 绝对保留 | 0.000 | None | — | red | 永不 |
| 场景2 世界长期变蓝 | B1 K=35 | 0.625 | 64 | **0.872** | blue | — |
| 场景2 世界长期变蓝 | B1 K=25 | 0.708 | 54 | 0.885 | blue | — |

### 1.3 判读

- **Q1 守住 ✓**：30 帧染色 < K_switch=35 不触发改判，B1 与 B0 行为完全一致
  （染色段 0.000、恢复延迟 1 帧）——**被拒但未达显著 → 守住**。
- **Q2 改判 ✓**：世界真变蓝，B1 第 64 帧改判（= 染色开始 + K_switch − 1，数学精确），
  改判后通过率 0.872、末态 blue——**利害确已改变 → 能学习**。B0 永远拒绝（守错）。
- **Q3 边界 ✓（阈值太松的代价）**：K_switch=25 < 30，短暂染色也触发改判（改判帧
  54 = 30+25−1），恢复后需 K_back=15 连续红帧才回改 → **恢复延迟 1→16 帧**。
  这是"被单次外部染色重写"的另一条路径（docs/101"完全可塑"的另一面）：改判阈值
  太松 = 把一次"他者的 不"误判为"世界变了"。

**结构性结论**："守住 vs 改判"不是二选一的立场，是**一个可标定的滞回阈值**：
K_switch 大 → 固执（守错：世界真变蓝时学不会）；K_switch 小 → 可塑（被带偏：单次
染色就重写）。docs/101 平衡带在颜色轴的落点 = K_switch 这个标定参数本身。

## 二、实验 2（连续失败率）：P3 单调性跨模式成立（docs/200 边界 #1）

### 2.1 机制设计（vision/keep_reject_continuous.py）

把"被拒"从二值开关推广为连续失败率 p（每帧以概率 p 染蓝 = 确认失败率）：
binary（p=1.0，docs/200 原版）/ partial_05（p=0.5）/ partial_08（p=0.8）/
ramp（被拒概率 0.1→1.0 线性爬升 = "他者的不"逐渐变强）。染色段 60 帧、恢复段 40 帧。
保留系统 Keep 同 docs/200：失败入史，K = 1 + rejected/3，恢复需连续 K 帧。

### 2.2 结果

| 模式 | 累计被拒 rejected | 重信任延迟 | 染色段通过 |
|---|---|---|---|
| binary | 60 | 21 | 0.000 |
| partial_08 | 48 | 17 | 0.017 |
| ramp | 32 | 11 | 0.217 |
| partial_05 | 30 | 10 | 0.117 |

延迟-被拒点：[(30,10), (32,11), (48,17), (60,21)] —— 单调增 [PASS]；
rejected-延迟相关系数 **r = 0.999** [PASS]。

### 2.3 判读

- **R1 单调性跨模式成立 ✓**：连续失败率（0.5/0.8/渐变）下，重信任延迟仍随累计
  被拒帧数单调增——P3 不是二值染色的特例，是结构结论。
- **R2 模式无关 ✓（关键新结论）**：以 rejected（被拒计数）为横轴时，各模式几乎
  落在同一条线上（r=0.999）。注意 partial_05（30 被拒→延迟 10）与 ramp（32 被拒→
  延迟 11）——染色段都是 60 帧（同一时间长度），若决定量是时间长度，两者延迟应
  相同；实际它们按 rejected 对齐。**决定量是被拒历史（计数），不是墙钟时间。**
  docs/200"失败入史"的机制含义在此精确化：纪念按被拒计数累积，不按时间累积。

**结构性结论**：docs/200 的 P3 从二值 toy 升格为**连续失败率下的结构事实**——
"重信任所需证据量 = 累计被拒计数的函数，与失败模式无关"。这同时支撑"行为对
输入的不确定性"（docs/200 同一输入流下吸收/保留分叉）的跨场景稳定性。

## 四、诚实边界

1. 两个实验仍是 toy（受控场景、真值掩码、二值颜色空间）——"连续失败率"是时间
   维度的概率化，不是空间维度的部分遮挡/渐变（真实"他者的不"两者都有）。
2. K_switch=35/K_back=15 是标定值；**单调性/模式无关是结构结论，不依赖具体阈值**
   （K_switch 只决定改判帧位置，不改变 Q1/Q2/Q3 的方向）。
3. ramp 模式的"渐变"是被拒概率的线性爬升，不是颜色/遮挡度的物理渐变（docs/200
   边界 #1 原意是物理渐变；这里是机制层面的第一步近似）。
4. 现象层纪律照旧（docs/63）：测的是"被拒历史改变后续对待"的行为签名（延迟/漂移/
   改判帧），不宣称"在乎/纪念"的体验。
5. 开放端改判的"蓝"是观察中位标定的（BLUE_HUE=120）——真实场景改判应更新到
   观察到的实际色相，而非固定标定值（后续：改判目标=观察中位）。
