### 1.1 机制选型（关键决策，冻结；先于任何结果）

**选型：候选 (b)——现行主机制 DeferredLoop（docs/251）接真实流。** 特征空间 x_w =
(ln(1+E_w), ln(1+U_w))、快慢双原型、延迟定级（快→慢仅当 hits ≥ hits_min_slow=3 才
最终化）、k_decay=5 回收、k_consist_fast=1 立即创建、预测路径零改动——全部逐字沿用
docs/251，**零重调**（旋钮表 §1.5 冻结）。

| 候选 | 机制 | 与"现行主机制 + L3 链"的关系 | 守卫强度（同代码路径复现前一格） | 诚实性 |
|---|---|---|---|---|

**选型理由（冻结，逐条）**：

1. **贴近现行主机制**：docs/252 §五 定义"现行主机制 = fastslow_test/quota_retire 的快慢
   双原型"。A1 是"累积"基质（docs/240 §二 关键路径 2），其真实域实证必须在**现行**的
   时间尺度载体（行为涌现）上做，而不是在被替换机制（CompLoop bins）上做——docs/243
   已经用 CompLoop 回答过"旧机制在真实流上判别失败"，本实验回答的是"现行机制在真实
   像素上，docs/241 四个 A1 签名成立吗"。
2. **守卫强度（本选型的关键优势）**：候选 (b) 与 docs/251 **同代码路径、同流** →
   R_A1R_GUARD_D251 必须 32/32 逐位复现 docs/251（容差 1e-4）——这是"同代码路径复现
   前一格"的最强形态（docs/252 §三3 守卫纪律）。候选 (a) 只能对齐 docs/243 的失败记录，
   守卫是"复现失败"。
3. **诚实性**：
   - **误差-结构解耦保持**（docs/235 §五2）：预测路径（bg_fast α=0.5 / θ / db）零改动
     → MAE 序列与 docs/243-251 **逐位一致** → REAL_STREAM_STABLE 的 ratio 是构造性
     控制项 + 与 docs/243 真实流数字的逐位对齐（同一 R0/R1 流、同一预测路径）。
   - **合成参考的诚实声明**（docs/241）：合成版用 CompLoop（2400 帧 chunk 重抽流），
     机制不同、数据不同 → 本实验**无法**逐位复现 docs/241 数字；对齐方式是**判据级**
     （阈值口径一致：ratio ≤1.5、churn 有界、结构长程保持）+ 预测路径数字（MAE/ratio
     因预测路径未动而逐位一致）+ 结构数字的机制差异如实标注（§1.4-3）。不声称合成↔
     真实逐位可比，只声称同一判据口径在真实域的行为签名。
4. **与 docs/243 的关系（为何不是再跑 CompLoop）**：docs/243 的 STATE_PERSIST 已在真实
   流上 6/6 全等（判据 3 的验证由它承担，本实验不重测，§1.3-3）；docs/243 的结构数字
   （CompLoop SC2=1/3、bridge 0.25）是旧机制记录；本实验的结构数字（DeferredLoop
   SC2_slow=1/5、gist_cov 0.8750）由 docs/251 同代码路径保证——与 docs/243 的对比是
   **机制差异对比**（docs/243-251 链条的既有叙事），不是守卫。
