### 1.3 认知支柱（docs/178/179，北星）

- **感知阶梯**：接收 → 对齐 → 模型（闭眼走）→ 维持 → 否定 → 被看见。
- **意义 = 落空 × 利害**：完美对齐 = 感知消失 = 无意义；自适应 θ 只抬不降 = 在正确的
  地方保持落空。
- **闭眼走**：事件驱动系统的默认状态是没有输入——世界模型是主体，对齐只是维护。

## 三、贯穿的判据与纪律

- **每一程都有 d\* 判据**（失效距离；判不达标比判达标容易，docs/118）——推进不是口号，
  是每步可判。
- **假指标比坏指标危险**（docs/177 教训：闪变"1.000"是度量 bug，已修正）——新实验先
  质疑自己的度量。
- **不宣称理解/体验**（docs/63）：全部是行为签名。
- **设计域**：同一机制放在人眼三级时间结构（响应 10-100ms / 抑制窗 20-150ms / 适应
  秒-分钟）的哪一级，决定它成不成立（docs/177 教训）。
- **先验在硬件里，不学编码统计**（docs/127 §3.8 / docs/176）：学出来的部分目标永远是
  d\*，不是重建。
