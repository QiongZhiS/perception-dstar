## 一、演示结构（vision/demo_app.py）

```
后端（Python 标准库 http.server，零依赖）：
  DemoMind（感知核心，复用已验证机制）：
    接收：合成红球匀速直线（docs/195 场景）
    确认：红区占比 > thr（thr 可被语言层调节，docs/206 闭环）
    被拒入史：rej_total 累计 + 纪念加深 k=1+min(rej_total,60)/3（docs/200/203）
    类别怀疑：suspicious[色相] 记账（docs/205）
    语言内化：符号槽→转录→自反（docs/204 三层）
  交互（观众注入）：
    染蓝 = 他者的不（docs/178 补刀）/ 噪声 = 世界的噪声（docs/101）
    恢复 / 换任务（找红/找蓝，外赋利害 docs/188）/ 重置记忆
前端（内嵌 HTML，无依赖）：
  场景画面（JPEG base64 实时推）+ 状态面板 + 语言流 + 交互按钮
用法：python vision/demo_app.py --port 8080 → 浏览器 http://127.0.0.1:8080
```

## 二、验证（完整周期）

| 阶段 | 状态 |
|---|---|
| 基线 | frac 1.0、ok ✓、thr 0.2、trusted |
| 染蓝（他者的不）×30 帧 | 被拒 30 次：rej_total 30、thr 0.2→0.8（docs/206 上调）、suspicious{120°:30}（docs/205） |
| 恢复红 | 需连续 **11 帧**（k=11，docs/200 纪念加深）才重新信任 |
| 语言 | "它变了，我认不出来了——刚才可能认错了"→"我需要更连续的证据（N/11）才重新信任"→"我确认了它"（docs/204 三层） |

API 验证：GET /state 返回完整状态 JSON；GET /act?action=blue|noise|none|reset|task_red|task_blue 注入交互；GET / 返回页面（200）。

## 三、判读：图纸变墙的第一步

1. **机制链第一次以"主体"形态连续运行**：docs/200（被拒入史）→ 203（饱和）→
   205（类别怀疑）→ 206（阈值闭环）→ 204（语言）在同一个循环里协同——观众按
   一下"染蓝"，看到的不是单张图，是主体从"确认红"→"认错了"→"被拒累积"→
   "恢复后需要更连续证据"→"重新信任"的完整连续过程。这正是外部对话说的
   "让人打开它，看到它在运转，看到它如何被世界否定、如何维持目标、如何选择
   固执或开放"。
2. **交互把"他者的不"与"世界的噪声"变成可注入的按钮**：染蓝 = 他者的不
   （docs/178 补刀：不可消化的剩余，保留为纪念）；噪声 = 世界的噪声（docs/101：
   该固执）。观众亲手注入两种否定，亲眼看到主体的不同处置——**这是 docs/178
   两种否定从概念到可演示的落地**。
3. **语言是主体状态的直接表达**（docs/204）：观众看到状态面板变化与语言流同步
   ——"被拒累计上升"对应"我不确定，我先不调整"，"恢复后连续帧累积"对应"我
   需要更连续的证据"——语言不是 LLM 编的，是维持层状态的转录（docs/160 toText
   的演示版）。

## 四、诚实边界

1. 合成场景（红球匀速直线）——不是真实视频/摄像头；机制已在真实图像（docs/209/
   211/215）与 DAVIS（docs/199b）验证过，但演示本身用合成场景保证可控可复现。
2. 单目标、单扰动类型——多目标/多通道（docs/195 三通道）的演示未做。
3. 无持久化——刷新页面/重启即重置（记忆不跨会话，docs/93"遗忘才是死亡"的
   演示版未做）。
4. 现象层纪律照旧（docs/63）：演示的是行为签名（确认/被拒/信任/语言转录），
   不宣称"它在体验"。

## 五、下一步（按价值）

1. **升级到真实输入**：摄像头/真实视频替换合成场景——"打开摄像头就能看到它在
   看什么"（外部对话原话）；DAVIS 视频流（docs/199b 已有闭环）作为演示素材。
2. **多目标 + 态势转录**（docs/160）：两个球 + 威胁度 → "它在靠近我"级别的完整
