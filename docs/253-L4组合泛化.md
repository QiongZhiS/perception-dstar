## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 机制选型（关键决策，冻结；先于任何结果）

**选型：候选 (a) 的细化形态 (a')——给现行快慢双原型/延迟定级机制（DeferredLoop，
docs/251）加"上下文槽位"这一名义可观测维度，原型变成可带槽位的 arity-2/arity-3
形态，槽位采纳由信息量驱动。** 特征空间（匹配用）仍为 x_w = (ln(1+E_w), ln(1+U_w))
逐字不变；c2 是**附加的名义可观测**（{0,1,None}，由同一事件掩码纯 numpy 计算），
只进入记忆组织路径，不进入预测路径。

| 候选 | 机制 | 贴近"现行主机制 + L3 基础" | 改动最小/可守卫 | 诚实性 |
|---|---|---|---|---|
| **(a') 槽位化 DeferredLoop（选择）** | 现行 DeferredLoop 逐字继承 + (i) c2 槽位可观测（同一事件掩码）；(ii) 原型 c2 账本；(iii) 慢原型信息量驱动的分裂（k_split/δ_rel/k_ledger 全部冻结值）；(iv) 打标慢原型 c2 门控匹配 | **最贴近**：基座 = docs/251 现行机制（docs/252 §五定义）；槽位加法只落在模式表路径 | **最小**：加法 = 一个可观测 + 账本 + 一个分裂规则 + 门控；**关槽位（Mode OFF）≡ DeferredLoop 逐位一致** → 守卫是精确的（docs/251 数字逐位复现） | **最诚实**：误差-结构解耦保持（预测路径零改动，MAE 逐位不变 → ratio 是构造性控制项）；不重新引入分档量化（docs/244 教训）；负对照（R0）+ spurious 度量直接测"信息量驱动"而非假定 |

**选型理由（冻结，逐条）**：

1. **贴近现行主机制**：docs/252 §五 定义"现行主机制 = fastslow_test/quota_retire 的
   快慢双原型"。L4 必须是**从现行机制的下一步**，而不是从被替换机制（CompLoop bins）
   的复活。(a') 的基座逐字是 docs/251 的 DeferredLoop，槽位是纯加法。
2. **改动最小且可守卫**：(a') 的 Mode OFF（槽位路径关闭）≡ DeferredLoop，必须逐位
   复现 docs/251 全部数字（R_L4_GUARD_D251，32 项）——这是"同代码路径复现前一格"
   的最强形态（docs/252 §三3 守卫纪律）。预测路径零改动 → MAE 序列逐位不变 →
   R_L4_REPRO_RATIO 内部复现成立。候选 (b) 的机制面更大、且数字不可与前一格对齐。
3. **更诚实**：
   - **误差-结构解耦**（docs/235 §五2）保持：预测器仍是 bg_fast（α=0.5），槽位/账本/
     分裂只作用于模式表（结构可观测仪表，不反哺预测）；判据主体是结构条件与行为证据，
     MAE 判据（ratio ≤ 1.5）是构造性控制项。
   - **不重犯 docs/244 的量化教训**：docs/244 的失败是**把连续能量轴等频分位量化**
     （边界切穿场景内部 → 一致性坍缩）。c2 是一个**本来就名义的**布局统计量（上/下
     事件质心左右关系），不是对连续轴的量化；docs/235 中它就是 {0,1,None}。(a') 在
     docs/246 工作点（r=0.39885）的连续原型基础上只加了这一名义门控，不引入新的
     连续轴分档。
   - **"信息量驱动"被直接测**：分裂由账本中位事件能量比 ≥ 1.30 触发（能量是签名空间
     所在的可观测，docs/235 D3 同款）；负对照 R0（单场景、槽位恒定/None → 无信息量 →
     零分裂）与 spurious_split_frac（分裂后是否真的继续获得匹配）把"信息量驱动"从
     假定变成判据。
4. **与 docs/243 的关系（为何不是再跑 CompLoop 模式表）**：docs/243 已经用 CompLoop
   在 R1 上观察到槽位采纳真实触发（promo=1 → arity-3 复合占比 0.667，camel 段）——
   这是"槽位机制在真实像素上可触发"的旧机制前兆，但 docs/243 同时证明旧机制的判别侧
   失败。L4 第一格的任务是：**在现行主机制（快慢双原型 + 延迟定级）上重建槽位采纳**，
   用行为证据重新回答"真实数据上是否形成组合结构"，并守住 L3 基础。这是从 docs/243
   的"部分迁移"升级为"现行机制的 L4 第一格"，不是重复旧实验。

**机制选型的第三个候选（明确拒绝并说明）**：在选型理由 3 之外，有一个看似更省的
变体——"快原型创建时直接携带出生窗的 c2 作为标签"（无信息量判据的标签化）。拒绝：
这使槽位采纳变成默认启用而非信息量驱动（docs/235 的核心主张是"无信息量 → 无采纳"，
C1 平行基线槽位保真度 0.99 但复合占比恒 0）；且出生标签会把单窗口噪声固化为条件记忆。
(a') 的"账本 + 中位能量比判据 + 分裂"保留了 docs/235 的信息量驱动语义。

### 1.2 上下文槽位在真实像素上的定义（冻结）

沿用 docs/235 的 c2 精神，逐字移植 compose_test._window_components 的定义到现行
机制的窗口事件掩码（**同一掩码，纯 numpy，无新数据路径**）：

- 每窗口事件掩码 ev_win（`|c| − db > θ` 并集，预测/阈值路径零改动）。
- **上组** = ev_win[y < 68, :]（y=0..67 行），**下组** = ev_win[y ≥ 68, :]
  （y=68..119 行）；CTX_SPLIT_Y = 68.0（docs/235/243 冻结值，不改）。
- 任一组事件 < **5px** → c2 = **None**（事件稀疏 → 无槽位语义，docs/235 冻结条件）；
  窗口总事件 < 10（E < 10）本身无签名、不参与匹配/创建（参与门冻结）。
- 两组各 ≥ 5px 时：c2 = 0 if mean_x(上组) < mean_x(下组) else 1，其中
  mean_x(组) = 该组非零像素的列索引均值（docs/235 冻结定义）。

**真实流无真值标签的诚实处理**（docs/243 §1.3 同款，labels=None）：合成场景的
"真值上下文"（A.x vs B.x）在真实视频上不存在 → **槽位保真度/条目纯度无真值可对**
（报告默认值并注明不可用，不进判据）。用**行为证据**替代（docs/243 的"无真值标签"
处理 + docs/235 的 M4 精神）：

1. **信息量判据本身是行为证据**：分裂仅在账本中位事件能量比 ≥ 1.30 时触发——槽位
   的采纳是"槽位值对窗口事件结构携带信息量"的可观测结果，不是人工指定；
2. **负对照**：R0（flamingo×5 单场景循环）槽位恒定/None → 零分裂（无信息量 → 无
   采纳）；S1-S4 野流分裂数作转移诊断（无判据）；
3. **自洽性证据（门控 + 分裂后持续命中）**：打标慢原型按 c2 门控匹配，分裂后是否

4. **段级信息量诊断（R1 有段边界 GT）**：R1 的 9 个视频段边界是真值（切换窗

   与分裂落点对齐作诊断（§1.4 M4/§1.8）——**段结构是真值，槽位语义是行为**。

### 1.3 机制（冻结；SlotLoop(DeferredLoop)，预测路径零改动）

**SlotLoop = DeferredLoop（docs/251 逐字）+ 以下冻结加法**（全部只落在模式表路径；
Mode OFF = 关闭 (ii)-(iv) → 与 DeferredLoop 逐位一致）：

1. **c2 槽位可观测**：每参与窗口（E ≥ 10）计算 c2（§1.2），记入 c2_trace。
2. **原型 c2 账本**：每个原型（快/慢）携带 `ledger = {c2v: [E, ...]}`；每次匹配把
   窗口的 (c2, E) 追加到该原型的账本（c2=None 的窗口记录在 `ledger[None]`，不参与
   信息量判据）；**创建窗即首个账本条目**（出生证据，docs/235 D6 精神；**无历史回填**
   ——快原型在首个未匹配窗立即创建（k_consist_fast=1），出生前无"窗口历史"可回填；
   docs/235 D6 的回填是其合成 C2 校准产物，真实流上按本定义冻结）。
3. **分裂（组合事件，信息量驱动）**：对每个**已确认的慢原型**（hits ≥ hits_min_slow=3，
   docs/251 延迟定级语义），每窗口检查：`hits ≥ k_split=5` **且** 账本中 ≥2 个非 None
   c2 值（0/1）各 ≥ **k_ledger=3** 个条目 **且** 两值中位事件能量比
   max(med_E(0), med_E(1)) / min(...) ≥ **1+δ_rel=1.30** → **分裂**：父条目退休
   （移出慢集、记 retired_log；docs/235"退休父条目 = 平行记忆→组合记忆的中间形态"），
   按每个合格 c2 值建一个**打标慢原型**（arity-3 形态）：tag=c2v、hits=账本计数
   （≥ k_ledger=3 → **出生即确认**，docs/251"慢原型只以确认已满形态存在"不变式保持）、
   μ=父条目 μ（α 滑动继续适应）、post_n_match=0、n_split += 1。
   - **有效触发时点**（冻结会计说明）：分裂需账本两值各 ≥3 条目 → 账本 ≥6 条目 →
   实际最早在 hits ≥ 6 时满足（创建窗 1 条 + 5 次匹配）；hits ≥ k_split=5 是外层
   资格、信息量判据是内层门槛，两者都满足才分裂——如实记录分裂窗口，不做时点回调。
   - **无回填**（冻结，理由见上）；**不做段长预测**（延续 docs/250/251：无帧差/位移
     等外部信号进机制决策，帧差只用于野流诊断）。
4. **打标慢原型门控匹配**：慢优先分支中，打标慢原型只匹配 `c2 == tag` 的窗口（距离
   ≤ r_slow 且槽位一致）；c2=None 的窗口不匹配任何打标慢原型（落入无条件慢/快/创建）。
   在合格的慢原型中取最近者（确定性）。无条件慢原型与快原型匹配逻辑逐字不变。
5. **其余全部逻辑**（延迟定级升级判定 `hits >= hits_min_slow`、立即创建、窗口末回收
   k_decay、churn 会计、GIST 度量、bridge 度量）与 docs/251 逐字一致。

**churn 会计（冻结）**：churn_slow 沿用 docs/251 公式
`(SC1_slow − SC2_slow)/max(1, SC1_slow)`（SC1_slow = 累计 promotion 数），分裂使
SC2_slow（当前确认慢原型，含打标子条目）可超过 SC1_slow → 定义
`churn_slow = max(0.0, ·)` 并**如实报告分裂前后的 (SC1_slow, SC2_slow, n_split)**；
"慢原型只以确认已满形态存在"的不变式保持 → churn_slow = 0.0 按构造成立（与
docs/251 语义一致：CHURN_MECH 的意义是"结构上不存在未完成慢原型"，学习有效性由
GIST/PROMOTION/分裂行为证据承担）。

### 1.4 度量定义（冻结；沿用 docs/235/243/250/251 冻结定义并适配）

## 五、诚实边界（预注册阶段已知边界）

1. **真实流无组合规则真值**（本格最核心的边界）：docs/235 的"真值上下文"（A.x vs B.x）
   由生成器提供，保真度/纯度可对；真实流上不存在"组合规则"真值——槽位保真度/条目纯度
   不可计算（报告默认值并注明不可用，docs/243 labels=None 同款）。本格证据止于**行为
   形态**：记忆组织（arity/复合占比）、信息量驱动的采纳（账本中位能量比判据 + 负对照 +
   spurious 度量）、L3 基础保持。**不宣称"回路发现了真实的组合文法"**——只宣称"现行
   机制在真实像素上，面对可观测的上下文信息量，把记忆组织成按槽位索引的条件形态"。
2. **槽位语义在真实流上的模糊性**：c2 = 上/下组事件质心横向比较是一个**空间布局统计量**，
   不是验证过的物体关系。真实视频的上/下半可能含多目标、背景运动、相机平移——槽位可能
   因非语义原因翻转（docs/243 的 camel 段提升是真实触发但语义未验证）。槽位是**行为
   可观测**，只按行为使用；段级信息量诊断（R1 有段 GT）给出槽位在真实流上的活跃度画像，
   但"槽位对应什么语义"不做主张。
3. **判别分辨率历史教训（docs/243→245/246 的借鉴）**：docs/243 判明粗分档在真实流上
   判别分辨率不足（9 场景坍缩 2 基签名）；docs/244 判明等频分位数把边界切穿场景内部导致
   一致性坍缩；docs/245/246 用连续原型距离解除了张力。本格：(i) 匹配基座沿用 docs/246
   工作点（r=0.39885）的连续原型，不重新引入连续轴分档；(ii) 但 c2 本身是 **3 级名义
   门控**——docs/244 的教训（边界切穿 → 一致性坍缩）在"槽位在段内频繁翻转"的流上有
   复发风险（门控使打标慢原型匹配密度下降 → spurious_split 或 gate cost），该风险由
   判据 2/3 兜底并如实报告；(iii) CTX_SPLIT_Y=68 与 5px 稀疏阈值是合成校准冻结值——
   存在"toy 校准残留"风险（docs/243 的分档教训），R0 负对照与段级诊断部分覆盖，但
   对槽位本身的真实校准超出本格范围（须新实验预注册）。
4. **compound_frac ≥ 0.5 的阈值风险**：沿用 docs/235 冻结阈值 + docs/243 在 R1 同流
   的旧机制实测 0.667 作为先例，但新机制（连续原型 + 账本 + 分裂）在 R1 上的采纳率
   运行前未知；确定性单流无 CI 可对冲。若复合占比落在 (0.3, 0.5) → 按冻结映射判
   BOUNDARY 或 PARALLEL_ONLY_REAL——**不允许用结果回调阈值**（docs/63）。
5. **信息量判据在连续原型上的可达性**：慢原型的匹配邻域（r_slow=0.3989 对数域）本身
