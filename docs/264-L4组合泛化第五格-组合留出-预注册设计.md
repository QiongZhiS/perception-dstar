## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 组合留出的操作化定义（本格核心，冻结；先于任何结果）

**组合（frozen）**：组合 = **槽位-内容条件记忆单元**——机制在真实流上产出的打标慢
原型（kind=slow、tag∈{0,1}、μ=(ln(1+E),ln(1+U)) 特征簇、账本 = 该侧窗口并集）正是
"(c2 槽位侧 × 特征簇内容)" 的组合记忆（docs/262 COMPOSABLE_REAL 的行为产物，判据 1
口径）。一个"未见过组合" = 校准段从未见过的**内容-槽位绑定**在留出段出现时的记忆
行为。

**组合留出（frozen）** = **机制不变 + 测量留出**：

- **机制不变**：SlotLoop4（docs/262 §一 逐字，import 复用）——匹配/创建/升级/回收/
  单原型分裂/群级检查（G1→G2→G4→锚物化→G3）/群级分裂/门控匹配/预测路径全部逐字
  不变；全部旋钮 = docs/262 §1.5 冻结表**零重调**；**无新数值旋钮、无新机制路径**。
  组合留出不做任何流内重排/遮盖/回放——只做**测量层归因**。
- **划分（frozen）**：R1 9 段（GT 段边界 [8,13,21,30,36,41,49,54]，只用于评估统计，
  **不进机制决策**——docs/250/251 纪律）按**预注册顺序规则**划分为：
  - **校准段 C = 段 0-4**（flamingo/surf/bear/camel/dog，帧 [0,367)，窗 [0,36]）；
  - **留出段 H = 段 5-8**（blackswan/car-turn/motorbike/soccerball，帧 [367,588)，
    窗 [37,58]）。
  - 窗口→段规则 = 帧跨度规则（与 docs/243-262 的 r1_segment_info/group_split_align
    同款）：w ∈ 段 i ⟺ spans[i][0] ≤ w×WINDOW < spans[i][1]。
  - **选型理由（冻结，逐条）**：① 每个 DAVIS 段 = 唯一视频 = 唯一内容（内容不重复），
    留出段的内容在机制记忆形成时从未出现过——"未见过内容"在段级是字面成立的；
    ② 顺序后缀划分使**留出段全部位于校准段之后**——机制在留出段窗口到达时的记忆 =
    纯校准形成（流序防循环的最简形式，docs/246 防循环纪律的流构造层面实现；
    docs/257 §五.4 无独立 save/load 序列化——"校准/留出分离"只能在流构造层面实现）；
    ③ 被测量的组合单元正是机制产物 (c2, 特征簇) 打标记忆（判据 1 口径延续）；
    ④ 不以 (c2, 段) 直接留出：单次通过流中段内 c2 侧交错出现、机制无法分离，段级
    留出是流层面可实现的最细粒度（(c2, 段) 留出无流可实现性）；⑤ 不以段对留出
    （docs/255 §二2 的"如：段对"是示例不是要求）：段对在机制层面无操作意义（机制
    处理窗口而非对），段对划分无机制行为可测。
- **防循环（frozen，docs/246 §1.3 升级）**：
  1. **参数零重调**：全部旋钮（r_slow/r_fast/hits_min/k_decay/k_split/δ_rel/k_ledger/
     W_BF/G_WIN/k_g_confirm/CTX_SPLIT_Y/参与门/α）来自 docs/262 §1.5 冻结表，**无任何
     数据依赖**——"参数只依校准集"在最强意义上成立（参数根本不依任何数据）；
  2. **留出集零贡献（机制侧）**：留出段在流序中全部位于校准段之后 → 留出段窗口对
     校准段形成的记忆**零贡献**（时间序保证；无重训、单次确定性 pass、无回调）；
  3. **PREFIX_EQ 构造性证明**（本格新增守卫）：校准流 C（仅段 0-4）与测试流 T（全 R1）
     在段 0-4 前缀（窗 0-36）逐窗 (c2, E, matched_pid) 逐位一致 + 窗 36 末原型种群
     哈希一致 → **"T 流在留出段到达时的机制状态 = 从未见过留出段的 C 流终态"**是
     被证明的，不是被声称的（机制是确定性纯函数，同前缀同状态）。

**组合留出的被测声明（frozen）**：校准段上形成的条件记忆（(c2, 内容) 打标慢原型）
在留出段（未见过内容）上**仍被门控使用且按槽位组织**——即"训练时未见过的组合在
测试时仍工作"。反证形态：若校准形成记忆在留出段零命中（特征域不重叠），如实报告
COMPOSITIONAL_FLAT（记忆级不迁移）+ 结构级数字（自形成记忆/静态覆盖）——诚实负。

## 五、诚实边界（预注册阶段已知边界）

1. **"未见过"的层级（本格最核心的边界）**：留出段的内容（像素/运动/特征分布）在校准
   段从未出现过（DAVIS 每视频唯一），但**机制在测试流上仍会处理留出帧**（匹配/创建/
   自适应）——本格的"留出段零贡献"指**参数与记忆形成**（校准形成记忆先于留出段、
   PREFIX_EQ 证明其与纯校准运行一致），**不是**"机制从未处理留出帧"（那要求冻结记忆
   静态评估——M9 已作诊断对照）。诚实声明：动态 transfer（M8）测的是"机制在未见内容
   上的实际匹配行为"，其归因按创建段区分校准/自形成；若校准形成记忆在留出段命中低而
   自形成高，如实报告 COMPOSITIONAL_FLAT + 分解数字。
2. **组合 ≠ 文法（docs/253/254/256/262 同款）**：真实流无组合规则真值；"组合"是
   (c2 槽位侧 × 内容) 的条件记忆形态的行为定义，不宣称发现组合文法。组合留出测的是
   该条件记忆在未见过内容上的使用（外推），证据止于行为形态。
3. **划分的先验性**：校准 = 段 0-4 / 留出 = 段 5-8 是顺序后缀划分（先于任何结果冻结，
   非按内容挑选）——它把强信息量段（flamingo/camel，docs/262 的触发来源）全部放在
   校准侧、把信息量未知段放在留出侧，这是**最保守**的排布（若按内容挑留出段会构成
   选择偏差）；代价是留出段特征域与校准记忆的重叠程度不可预知——数字多少算多少，
   不因结果改划分（docs/63）。
4. **seen_baseline 口径**：基线 = 校准段 w≥8 的打标命中率（首个分裂 w7 之后）——w<8
   无打标原型存在，平凡 0 不计入（预注册口径）；该口径使"见过"基线反映机制实际可
   达行为。相对判据（0.5×基线）+ 绝对下界（0.10）双闸，避免基线过低时相对判据虚过。
