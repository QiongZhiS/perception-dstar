## 〇、一句话

> **"想看什么就看见什么"是目标驱动识别的人脑侧印证：人眼不是先检出所有物体再识别，
> 是带着目标（利害）看——想找车，车跳出来（被维持），别的车是背景；远看近看识别结果
> 不同，不是物体变了，是采样精度变了（注意变了，目标变了）。这与我们做的链路同构：
> 外赋目标 → 威胁度分配（注意）→ Top-K 只报该看的（采样）→ 态势维持（识别）。docs/188
> 说"目标不能从画面分出来，只能被赋予"——人在自己身上也没有"自发涌现识别目标"的机制；
> 外赋利害不是妥协，是与人的一致。**

## 一、人识别 = 目标驱动，不是画面驱动

人的识别流程（与我们的链路逐段对应）：

```
目标（我想看什么）→ 注意（往哪看）→ 采样（中央凹/走近，分辨率）
→ 识别（看出是什么）
```

- **目标**：利害（docs/179 意义=落空×利害）——"车值得找"；
- **注意**：威胁度分配（docs/186 §五）——往哪看；
- **采样**：中央凹 2° 高清 + 扫视（docs/133）——走近/聚焦，分辨率随注意分配；
- **识别**：维持（docs/178 第 3 层）——"是车"。

**日常证据**：
- 想找车，画面里的车"跳出来"，其他车是背景（目标→注意→维持）；
- 没想找车，它经过面前也是背景（无目标 = 无威胁度 = 不被注意）；
- "远看是一回事近看又一回事"：同一个物体识别结果不同——不是物体变了，是**采样精度
  变了；采样精度变了，是因为注意变了（你走近了/朝它看了）；注意变了，是因为目标变了**。

## 二、与 docs/188 的合流：人也没有"自发涌现识别目标"

docs/188 七维勘探证明：感知层内部不存在"值得"的可计算判据（面积/hits/速度/漂移/形状/
方向/可预测性全部不可分）——**"值得注意"是关系属性，需要外赋利害**。

用户这句观察补上人脑侧：**人在自己身上也没有这个机制**——人识别就是目标驱动的，人
不会"从画面自发涌现识别目标"。想看什么才看见什么，反过来也成立：没想看的（无目标），
即使物理上在视野里，也不会被识别（注意不到的近旁、盲视、习惯化——docs/178 第 5 层
完美对齐=感知消失）。

**结论**：外赋利害不是工程的妥协（不是"我们造不出来所以给参数"），是**与人一致的
第一性事实**——人眼 = 外赋目标 + 维持，识别从来不是画面自足的函数。

## 三、识别 = f(目标, 注意, 采样)，不是 f(画面)

```
识别 ≠ f(画面)                # 通用检测器范式（先找所有物体再识别）——不是人眼
识别 = f(目标, 注意, 采样)    # 目标驱动：利害 → 注意 → 采样精度 → 识别
```

这解释了为什么"通用检测器"（YOLO 等，docs/133 §四② 批判的"学编码不学物理"）在哲学上
就与人不同：**它试图从画面自发给出"所有值得注意的"——而这个集合在无利害时根本不存在**
（docs/188 七维勘探）。人眼从不出这种集合，人眼只在利害给定的情况下"看出"该看的。

## 四、对管线的意义：外赋 = 给一次"谁值得"，不是每帧给"它在哪"

docs/189 闭环当前的外赋是**实验参数**（第一帧给坐标）。目标驱动识别给出正确形态：
**外赋的是"谁值得"（一个符号目标："车值得找"），坐标由感知层自己锁定**——利害给一次，
注意/采样/维持全自动。这是 docs/125 目标栈的视觉版：目标在任务层（符号），感知层执行
（锁定+维持+过滤）。

与 docs/187（欣赏=保持落空）的关系：欣赏是"目标 = 落空本身值得保持"（审美利害外赋），
识别是"目标 = 某个物体值得找"（任务利害外赋）——同一个机制（外赋利害驱动注意），
两种利害来源。
