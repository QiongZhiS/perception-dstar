> **连续加权的完整曲线在未饱和区可见：被拒 30 次时 k(距离) 连续下降

## 一、机制（vision/saturation_curve.py）

```
连续加权（docs/212）：k(hue) = 1 + Σ rejected[sh] × w(circ(hue,sh)) / grow
  w(d) = max(0, 1−d/带宽)（线性）或 exp(−d²/2σ²)（高斯，带宽边缘截断）
被拒累计 = 训练遍数 × 30（每遍染蓝段 30 帧被拒）
扫被拒：30 / 150 / 600 / 3000（遍数 1/5/20/100）→ 完整衰减曲线的形态变化
```

## 三、判读

1. **连续性的完整形态在未饱和区**：被拒 30 次时 k(0°)=11、k(2°)=5、k(4°)=1——
   "近同类最疑、边缘渐淡"的完整连续曲线（docs/212 的完整版）。docs/178 否定层
   "差异强度连续"的量化：怀疑随色相距离连续衰减，不是二值。
2. **饱和掩盖连续差异（核心发现）**：被拒累计超过 cap（60）后，带宽内 k 顶满 21，
   连续退化为二值——**docs/203 saturate 与连续性的交互**：阅历饱和后"同类都
   同样可疑"（顶格），连续差异只在未饱和区可观测。这解释 docs/212 为什么边缘
   收窄：不是连续失效，是饱和顶格。
3. **线性 vs 高斯 = 固执度旋钮的衰减形状版**：线性在带宽边缘有尾巴（300 次时
   7° 仍 k=5——"边缘也留一点怀疑"），高斯快衰减（7° k=17 但 8° 即 1）——线性更
   保守（疑得更远），对应 docs/101 固执度 eta 的带宽衰减维度。
4. **不误伤保持**：红（120°）在所有被拒量下 k=1——连续性/饱和度都不影响目标色
   的永远开放（docs/205 类别特异）。

## 四、诚实边界

1. 线性/高斯衰减形状、σ、cap 都是标定值——"怀疑怎么随距离衰减、饱和点在哪"是
   设计参数（可随 docs/196 色温漂移物理锚调）。
2. 一维色相距离——多维特征空间（H,S,V）的连续衰减是自然推广（docs/212 §五 4）。
3. 被拒累计 = 遍数 × 30 的简化（每遍固定 30 帧被拒）——真实被拒率随场景变化，
   累计速度不同（docs/203 阅历深度与频率的交互）。
4. 现象层纪律照旧（docs/63）。

## 五、下一步（按价值）

1. **连续 + 阈值**（docs/212 §五 2）：k 连续化后 thr 也按距离加权（近同类 thr 高、
   边缘渐低）——阈值与怀疑的连续联合（docs/214 将做）。
2. **饱和点自适应**：cap 从固定常数变成"场景噪声水平"的函数（docs/101 sigma——
   世界越噪声该越固执到更迟饱和）——饱和点也是阅历的一部分。
3. **回图像版**：非纯蓝（docs/211）真实漂移分布下，未饱和连续曲线的完整形态
   （真实像素的连续色相距离）。
4. **多维距离**：(H,S,V) 特征空间的距离加权（docs/196 三通道）——真实颜色类别
   的连续边界。
