## 〇、一句话

> **怀疑与阈值分层衰减：带宽边缘 4-5° 处"疑窄严宽"——分层 k 已降到 1（窄高斯


## 三、判读

1. **疑窄严宽的分层**：怀疑（k）用窄衰减——只有很近的色相算"同类可疑"（不误伤
   远的相近色）；确认（thr）用宽衰减——被拒类别范围内都看得仔细（不漏近的）。
   这是 docs/101 多旋钮的衰减维度：怀疑和确认用不同的保守度。
2. **σ 假设修正（途中发现）**：直觉"高斯比线性更窄"是错的——σ=bw/2 的高斯在
   带宽内全程 ≥ 线性（中心尖、边缘更高），它是"更尖更宽"；真正的窄衰减是
   σ=bw/4（中心尖、边缘快降截断）。衰减形状的选择影响"疑的宽窄"，是设计参数
   （docs/101 固执度旋钮）。
3. **饱和交互（docs/213 复现）**：饱和区（被拒 3000）分层 k 顶满 21，疑窄差异被
   掩盖；未饱和区（150）才可见"疑窄严宽"——分层策略的适用窗口在未饱和区。
4. **不误伤保持**：红（120°）两种都基线——分层不牺牲目标色开放（docs/205）。

## 四、诚实边界

1. 窄高斯 σ=bw/4、thr_gain、cap 都是标定值——"疑多窄、严多宽"是设计参数
   （docs/101 多旋钮的完整版）。
2. 分层只分 k/thr 两个衰减——真实系统可能有更多层（注意力、采样频率）各自的
   衰减形状（docs/192 主动采样）。
3. 一维色相距离——多维特征空间（H,S,V）的分层衰减是自然推广。
4. 现象层纪律照旧（docs/63）。
