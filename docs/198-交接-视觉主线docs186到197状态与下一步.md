## 二、核心结论（续接者必读，每条都有实验支撑）

1. **"值得注意"是关系属性不是框属性**（docs/188）：灰度七维勘探全不可分 → 目标只能
   外赋+维持（docs/189），颜色是第一个可分维度（docs/192）但颜色=静态区分非运动
   （docs/195：颜色事件只在颜色变化时发）。
2. **外赋利害驱动的完整分工**（docs/195）：灰度跟踪（运动）+ 位置锚（空间）+ 颜色确认
   （身份验证）——"找那辆红车"先跟踪再确认，错颜色全拒（0/105）。
3. **人读字不是 OCR，是预测-核对闭环**（docs/194）：眼给弱似然、语言给强先验、视觉
   核对纠正（docs/125）；三条件：视觉弱时补（+30%）、强时不扰、错时拒（15/15）。
4. **屏幕感知 = 颜色×扫视×先验×语言**（docs/192/193/194）：静止≠盲，扫视主动制造
   落空；切分用语言先验（词长）+ 颜色分割（同亮度明度盲、颜色可分）。
5. **颜色确认的鲁棒性**（docs/196/197）：亮度稳健（HSV 分离 V）、色温脆弱（H 漂移
   83°）；色温适应方向对（83→178）但"何时校正"需要时间一致性判据（噪声抖动 vs
   真染色稳定）。
