## 三、判读

1. **docs/175 管线"读信息→态势→行为"首次闭环**：之前视觉线到"物体框"为止，态势接口
   （docs/160）和下游（地图/行为）是 MC 线的；现在视觉版全链可跑——外赋利害锚
   （docs/174）→ 态势指定目标 → 连续性维持（docs/178 第 3 层）→ 威胁度分配（docs/186
   §五，25× 压误报）→ 态势地图（记忆）→ affordance（决策）——**docs/188 的"目标 =
   外赋 + 维持"在这里变成了可运行的系统**。
2. **map_frac=1.00 兑现 docs/161 的 P2**：决策从地图记忆选目标而不是瞬时态势——即使
   瞬时读不到（车被遮挡/事件稀疏），地图仍指向它（docs/124"看了会记得"的视觉版）。
3. **agent 追上移动的车（747→50px）**：这不是导航（无运动学），是"决策目标 = 地图记忆
   的车位置，行为 = 趋近"的闭环收敛——验证感知→记忆→决策链的因果完整。

## 四、诚实边界

1. **虚拟 agent 无物理运动学**：画面坐标直接趋近，不模拟"朝它走"的物理（碰撞/惯性/
   路径）——验证的是感知→记忆→决策链，不是导航；接真实运动学是 MC 线（docs/140/142）
   或受控实拍的事。
2. **维持目标外部给定**（第一帧掩码指定"车"）且目标更新有真值引导成分（situation.py
   每帧用命中框更新）——"目标从哪来"的答案仍是 docs/188：外赋，不是自发。
3. **单视频（car-turn）单目标**——多目标/多视频普适性未测。
4. **态势地图是"轨迹记忆"不是"空间地图"**：cells 按目标 id 记位置，没有空间网格
   （docs/161 MC 版是 "x,y,z"→type 的格子）——视觉版是否需要空间网格（物体在画面哪里
   分布）待定，当前"目标级记忆"够用。
