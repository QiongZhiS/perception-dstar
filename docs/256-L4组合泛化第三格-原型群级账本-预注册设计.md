### 1.2 "群"的定义（本格最关键的设计决策，冻结；含纯行为性论证）

**冻结定义**：**群（group）= 最近 G_WIN=8 个参与窗口（E ≥ 10）的时间纪元（epoch）**：
`epoch = [(win, c2, E, U, matched_pid) × 最近 ≤ G_WIN=8 个参与窗口]`（含当前窗口；不足 8 个时取
全部）。**群的成员原型** = 在纪元窗口内被匹配或创建的全部原型（快 + 慢，打标 + 未打标）。
**群级账本** = 纪元窗口记录本身（跨原型的共享窗口流）——两 c2 组窗口无论被哪个原型匹配，都在
同一纪元内被聚合；群级信息量判据与群级分裂在该纪元上发生（§1.3-4）。

**候选对照（冻结否决，理由见 §1.1 候选表）**：(b) 窗口邻域特征聚类（特征空间聚类无法跨 2.5
距离聚合，且引入新超参）；(c) 特征空间 Voronoi（单元 = 单原型可达域，不聚合跨簇）；(d) GT 段
边界（作弊）；(e) 无确认门的滑窗直判（R0 必触发 + 语义脱钩）。

**纯行为性论证（冻结，逐条）**：

1. **无 GT**：纪元只依赖 (i) 参与门 E ≥ 10（冻结）、(ii) 窗口事件掩码的 c2/E/U（冻结可观测，
   纯 numpy）、(iii) 原型匹配/创建记录（机制内部状态）——R1 的真值段边界 [8,13,21,30,36,41,49,54]
   **不进入任何机制决策**，只用于 §1.4 的段级信息量/对齐**诊断与评估**（docs/250/251 纪律，
   docs/255 §一.4 同款提示）。
2. **直接对应瓶颈结构**：强信息量段 = 时间连续的局部（flamingo 段 = 8 窗、camel 段 = 9 窗），其
   两 c2 组因特征分离（~2.5 / ~0.36）被不同原型各自匹配；纪元按时间滑窗跨原型聚合，恰好恢复
   "同一局部、两特征簇"的结构——这是"群级比较信息量"的最小行为实现（docs/255 §一.4 候选方向
   直译）。
3. **确定性**：纪元 = 窗口史的纯函数（与 SlotLoop2 的 `_hist` 同构，仅窗口数不同），无 RNG、
   无排序依赖（按窗口序）。
4. **冻结值来源**：G_WIN=8 = docs/235 §1.1"两态持续段均 ≥ k_consist 窗口（诊断轮验证：各种子
   段长 **3-8 窗口**）"的上界 8（冻结复用）；且 8 ≥ 2×k_ledger=6（两 c2 值各 ≥3 窗共存的最小
   跨度），与冻结值组合一致（§1.6 论证）。G_WIN=8 使纪元足以覆盖 flamingo 整段（8 窗），保证
   强信息量段的"两 c2 组在群级可见"是可达的（§1.5 R1 可行性论证）。
5. **群的生命周期**：纪元是滑动窗口，每参与窗口重新计算（无离散边界、无持久群对象）——"群"是
   检查时点的计算视图，非持久实体；**每个局部一次性组织**由 G4 保证（见 §1.3-4）。

### 1.3 机制完整定义（冻结；SlotLoop3(SlotLoop2)，预测路径零改动）

**SlotLoop3 = DeferredLoop（docs/251 逐字）+ docs/253 SlotLoop 槽位加法 + docs/254 三条账本可达性
修复加法 + 本格群级加法**（全部只落在模式表路径；Mode OFF = 关闭全部槽位/群级路径 → 与
DeferredLoop 逐位一致）：

1. **c2 槽位可观测**：不变（docs/253 §1.2 逐字；每参与窗口 E ≥ 10 计算 c2 = sign(mean_x(上组) −
   mean_x(下组))，CTX_SPLIT_Y=68，任一组事件 <5px → None；记入 c2_trace）。

**R0 负对照可证伪性论证（本格命门，冻结；机制级论证而非假设）**：

1. **输入同一性定理（机制级事实）**：R0 = flamingo×5，R1 = flamingo + surf + ...（拼接）；两者
   均以**同一初始回路状态**（空原型表、初始 θ/db/bg）处理**同一 80 帧 flamingo 剪辑**的前 8 个
   窗口（同一窗口边界、同一事件掩码、同一 c2 计算）。回路无 RNG（确定性流声明）→ **第 8 窗后
   R0 与 R1 的内部状态逐位相同** → 任何确定性机制（含群级判据 G1-G4）在第 8 窗的检查结果在两者
   上**必然相同**。
2. **推论 1（候选 (f) 否决的机制级证据）**：任何形式的"确认门"（如 G3）都无法把 R0 与 R1-flamingo
   段分开——同输入 → 同触发。任务提示的"R0 单场景恒定布局可能不满足连续性条件"在**机制级不成立**
   于第 1 循环（它与 R1 的 flamingo 段是同一数据）。
3. **推论 2（R0 与机制目标构造性冲突）**：本格的目的正是让 flamingo 类强信息量段在群级可达
   （docs/254 §五.4 预告）。若群级判据在 flamingo 上不触发 → 本格机制目标落空（回到 camel 类弱-
   中信息量，第二格已证其不足）；若触发 → R0（flamingo×5）第 1 循环必触发 → 原负对照失败。因此
   **R0=flamingo×5 无法同时担任"本格要测的目标数据"与"负对照"**——这是 docs/254 §五.5 预告的
   "若未来机制改为窗口级直判，R0 负对照需重新设计"的必然兑现（群级账本 = 跨原型窗口池 = 直判的
   受控版本）。
4. **负对照重设计（冻结）**：判据 2 的负对照流改为 **R0b = bear×5**（单场景循环：bear 段
   [135,217) = 82 帧 × 5 = 410 帧 ≈ 41 窗）。R0b 上群级判据**构造性不触发**（三重门，任一成立即
   不触发）：
   - **门 1（G1 密度）**：bear 段在 R1 上下文实测 c2 单侧（n(c2=0)=0、n(c2=1)=4）——单场景稳定
     布局下事件质心关系不翻转 → 任意 8 窗纪元含 c2=0 窗数为 0 → G1（各 ≥3 窗）结构性失败；
   - **门 2（G2 比率）**：即使偶发翻转，单场景窗口能量同质，两 c2 组中位能量比 ≥1.30 需结构性
     分离，bear 实测两态能量接近；
   - **门 3（G3 确认）**：c2=0 侧若有零星窗口，其孤立性（相邻间隔 > k_decay=5 窗）使其无法在
     任意纪元内累积 hits ≥ hits_min_slow=3 → 无"已确认慢原型锚" → G3 失败。
   R0b 的"干净"（n_split(R0b)=0）由门 1 的构造性失败**保证到第 1 循环**（bear 单侧为实测），后续
   循环由密度门槛 + 确认门兜底；**残余风险如实声明**（§五.4）：若最终运行 R0b 触发 → 群级判据在
   单场景循环上误触发 = 机制的真实缺陷 → 按冻结映射判 BOUNDARY 并报告数字，**不回调任何阈值**。
5. **R0（flamingo×5）降级为诊断流（冻结）**：R0 的 n_split 与群级触发形态如实报告（不进判据）；
   若 R0 触发，其形态与 R1-flamingo 段分裂**同源**（输入同一性）——这是"强信息量单场景循环上
   群级组织的触发形态"诊断，不是负对照失败（负对照职责已由 R0b 承担）。
