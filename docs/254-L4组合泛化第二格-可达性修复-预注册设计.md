## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 机制选型（关键决策，冻结；先于任何结果）

**选型：候选 (a)+(b) 的组合修复 (a'b')——SlotLoop2 = docs/253 SlotLoop（逐字）+ 三条账本
可达性修复加法：① 出生回填（候选 (b)，docs/235 D6 直译 + 邻域约束）；② 账本生命周期继承
显式化（候选 (a)"升级并账"的诚实修正版）；③ 子条目 μ 重初始化（条件记忆维持修复）。候选 (c)
（降 k_ledger/k_split）与候选 (d)（窗口级信息量直判）**明确否决**（理由见下）。**

**第一格负结果的根因（代码级确证，docs/253 §四 + vision/l4_compose_test.py）**：

1. **账本条数不足（数量门槛不可达）**：R1 上 5 个慢原型（SC2_slow=5）的账本大小 = 其 hits
   （创建 1 条 + 每次匹配 1 条），平均最终 hits **5.4** 条 < 分裂所需的 **6 条**
   （{0:≥3,1:≥3} 合计 ≥6）；hits ≥ k_split=5 是外层资格、账本两值各 ≥ k_ledger=3 是内层门槛，
   两者都满足实际要求 hits ≥ 6。
2. **信息量-可达性张力（结构不可达）**：分裂判据要求两 c2 值**中位事件能量比 ≥ 1.30**——但
   能量是特征空间 (ln(1+E), ln(1+U)) 的所在维，能量比 ≥1.3 ⟺ 特征距离 ≥ ln(1.3)≈0.26。
   强信息量（flamingo 段 11.9971 ⟹ 特征距离 ~2.5）**远超 r_slow=0.39885** → 两 c2 组被不同
   原型各自匹配 → 任何单个慢原型账本都只见单 c2 值；弱-中信息量（camel 段 1.4300 ⟹ 特征距离
   ~0.36，勉强 < r_slow）可达，但账本条数不足 + 分布偏斜未触发。
3. **门控条件记忆未维持（S2 教训）**：S2 唯一分裂后子条目 μ 继承父 μ，父 μ 是两 c2 组的
   折中位置（或偏向一组）→ 打标子条目门控匹配（只匹配 c2==tag）零命中 → spurious=1.0000。

   数字（SC1_fast/SC2_fast/n_promo/n_recycle/ratio/MAE）与 docs/253 Mode ON 逐位一致**——机制
   改动面 = 分裂相关数字（n_split/SC2_tagged/compound_frac/sc2_slow/spurious）的唯一生成路径。
3. **判据结构沿用 = "负结果不是阈值问题"的证明**：判据 1-4 的标签与阈值与 docs/253 逐条一致

   "无回填"并预告"后果是分裂时点更晚，可能在短段上不可达；这是冻结设计，非缺陷"（§五.6）。

### 1.2 机制完整定义（冻结；SlotLoop2(DeferredLoop)，预测路径零改动）

**SlotLoop2 = DeferredLoop（docs/251 逐字）+ docs/253 SlotLoop 槽位加法 + 本格三条账本可达性
修复加法**（全部只落在模式表路径；Mode OFF = 关闭全部槽位路径 → 与 DeferredLoop 逐位一致）：

1. **c2 槽位可观测**：不变（docs/253 §1.2 逐字；每参与窗口 E ≥ 10 计算 c2 = sign(mean_x(上组) −
   mean_x(下组))，CTX_SPLIT_Y=68，任一组事件 <5px → None；记入 c2_trace）。
2. **原型 c2 账本（改：账本条目扩展为 (E,U)；出生回填；生命周期继承显式化）**：
   - 每个原型携带 `ledger = {c2v: [(E, U), ...]}`（**账本条目从 docs/253 的 E 扩展为 (E, U)**——
     U（上组事件量）为子条目 μ 重初始化所需；信息量判据只用 E 分量）；
   - 每次匹配把窗口的 (c2, E, U) 追加到该原型的账本（c2=None 的窗口记 ledger[None]，不参与
     信息量判据——与 docs/253 一致）；
   - **出生回填（本格加法 ①，docs/235 D6 直译 + 邻域约束）**：快原型创建时，除创建窗本身
     （首条目）外，用**创建窗之前最近 ≤ W_BF=4 个参与窗口**（E ≥ 10）中**特征距离 ≤ r_fast** 的
     窗口的 (c2, E, U) 回填账本；**回填不加 hits**（hits = 匹配确认计数；账本 = 阅历事件簿——
     会计区分冻结：分裂外层资格看 hits、内层门槛看账本条数）；回填窗口 c2=None 者记 ledger[None]；
   - **升级并账（本格加法 ②，显式冻结）**：快原型升级为慢原型时，账本（出生回填 + 快阶段全部
     匹配窗口）**完整继承**为慢账本——第一格实现已隐式成立（升级分支不动 ledger），本格将其
     **显式冻结为机制语义与分裂评估的会计口径**：分裂检查以**完整生命周期账本**（出生回填 +
     快阶段 + 慢阶段）为准；
   - **分裂继承**：分裂时子条目继承父账本中对应 tag 组的全部条目（含回填）。
3. **分裂（组合事件，信息量驱动；触发条件不变，子条目初始化改）**：对每个**已确认慢原型**
   （hits ≥ hits_min_slow=3，延迟定级语义，慢原型只以确认已满形态存在），每窗口检查：
   `hits ≥ k_split=5` **且** 账本中 ≥2 个非 None c2 值（0/1）各 ≥ **k_ledger=3** 个条目 **且**
   两值中位事件能量比 max(med_E(0), med_E(1)) / min(...) ≥ **1+δ_rel=1.30** → **分裂**：父条目
   退休（移出慢集、记 retired_log），按每个合格 c2 值建一个**打标慢原型**（arity-3 形态）：
   tag=c2v、hits=账本计数（≥ k_ledger=3 → 出生即确认）、**μ = 该 tag 组账本窗口的
   (ln(1+E), ln(1+U)) 中位数向量（本格加法 ③：μ 重初始化，不再继承父 μ）**、post_n_match=0、
   ledger={tagv: 该组全部条目}、n_split += 1。
   - **有效触发时点（冻结会计说明）**：分裂需账本两值各 ≥3 条目 → 账本 ≥6 条目 → 实际最早在
     hits ≥ 6 时满足；出生回填使账本条数可先于 hits 达到 6（回填窗计入账本不计 hits），故
     **分裂时点可早于第一格**（第一格需慢阶段匹配补齐账本）；如实记录分裂窗口，不做时点回调。

   split_hits 下降 → 判据 2（spurious ≤ 0.5 且 avg_post ≥ 1）明确兜底；判据 2 不过 = BOUNDARY
   照实报告，**不允许用结果回调**。分裂-段对齐诊断（align_rate）提供 R1 上的对齐证据（段级信息量
   ≥1.3 的段内分裂占比）。
2. **出生回填的"出生噪声固化"风险**：回填窗口是原型**未匹配过**的窗口（创建时原型尚不存在），
   其 (c2,E,U) 与原型实际内容的同质性由**特征距离 ≤ r_fast** 保证——若创建发生在内容过渡区
   （段边界附近），邻域内可能含跨段窗口 → 回填噪声。缓解（冻结）：回填半径 r_fast（快视野）限制 +
   W_BF=4 窗数限制 + 分裂信息量判据仍要求两 c2 组各 ≥3 且能量比 ≥1.3（多窗口统计，非单窗噪声）；
   残余风险由判据 2（spurious）与 R0 负对照兜底。诚实声明：docs/235 曾拒绝"出生标签"变体（单窗口
   噪声固化为条件记忆）；本格的多窗口回填 + 邻域约束是该风险的受控版本，仍不宣称零噪声。
3. **判据一致性边界**：判据 1-4 阈值与 docs/253 逐条一致 → 两格 verdict 同尺可比（第一格
   PARALLEL_ONLY_REAL vs 第二格 ?）；但账本修复改了分裂数字的生成路径 → **非分裂数字
   （SC1/SC2/n_promo/n_recycle/ratio/MAE/gist_cov）逐位一致（匹配/升级/回收/预测路径未动）**、
   **分裂数字（n_split/SC2_tagged/compound_frac/sc2_slow/spurious）是本格新机制的产物**——对比时
   显式标注两类数字的生成路径差异。
4. **信息量-可达性张力的残余（本格修复的边界）**：强信息量组（flamingo 段 11.9971 ⟹ 特征距离
   ~2.5 >> r_slow）在**任何**账本类机制下不可达（两 c2 组被不同原型各自匹配，回填/继承都无法让
   单原型账本见两值）——本格修复只覆盖弱-中信息量组（camel 段 1.4300 类，特征距离 ~0.36 < r_slow）。
   若修复后 R1 分裂仅来自 camel 类段、flamingo 类段仍不分裂，属预期（强信息量段的组合组织需要
   未来机制，如原型群级账本——须新实验预注册）。
5. **R0 负对照的"干净"依赖账本机制的不可达性（机制特性，非数据特性）**：候选评估（§1.1）显示
   R0（flamingo×5 循环）在窗口级直判下会被判为"有信息量"（c2 覆盖 1.0、0/1=15/85、能量比
   ~11.9971）→ 负对照失败。本格保留账本机制使 R0 保持干净，但**这一"干净"是账本不可达性的
   副产物**——诚实声明：R0 负对照检验的是"账本机制不误采纳"，不是"R0 无信息量"；若未来机制
   改为窗口级直判，R0 负对照需重新设计。
6. **真实流无组合规则真值**（沿用 docs/253 边界 1）：槽位保真度/条目纯度不可计算（labels=None）；
   证据止于行为形态（记忆组织、信息量驱动采纳、L3 基础保持）。不宣称"回路发现真实组合文法"。
7. **槽位语义模糊性**（沿用 docs/253 边界 2）：c2 是空间布局统计量，真实视频可能因非语义原因
   翻转；槽位只按行为使用。
8. **单确定性流**（沿用 docs/253 边界 8）：无种子协议；组合主张依赖 R1 段结构（GT）+ R0 负对照
   + S1-S4 支持。
9. **守卫语义**（沿用 docs/253 边界 7）：R_L4B_GUARD_D251 证明"关闭槽位 ≡ docs/251 逐位"（纯加法
   证明），**不证明槽位计算/回填语义正确**（无 GT）；回填正确性由确定性（R_L4B_BF_HASH）+ 负对照
   + 段级信息量诊断共同承担。
10. **toy 校准残留风险**（沿用 docs/253 边界 3）：CTX_SPLIT_Y=68、5px 稀疏阈值、W_BF=4、回填半径
    r_fast 均来自合成域冻结值——存在"toy 校准残留"风险；R0 负对照与段级诊断部分覆盖，槽位本身
    的真实校准超出本格范围（须新实验预注册）。
11. **修复语义边界（本格不修什么）**：本格修"账本来源的可达性"（条数 + 来源 + 子条目锚点），
    **不修"信息量判据本身"**（k_ledger=3/δ_rel=0.30/k_split=5 冻结不动）；若修复后 R1 仍 n_split=0，
    结论 = "账本可达性补齐后，r_slow 邻域内两 c2 组信息量分布仍不足"（更强负结果，如实报告），
    不是阈值回调的理由。
