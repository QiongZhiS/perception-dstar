## 〇、一句话

> **泛化 = 在"校准时没见过"的条件上仍然工作；难点全在"没见过"的程度。六层：
> L0 拟合 → L1 分布内插值 → L2 分布内偏移 → L3 跨域 → L4 跨任务/组合 →
> L5 跨能力涌现 → L6 开放世界。你的仓库：L2 已完整证明（docs/246，含留出与
> 防循环），L3 探到一半（docs/243），L4 只有合成前兆（docs/235）。规范：从
> docs/248 起，每篇实验的每个判据必须标注它测的泛化层——不带层级标签的
> "泛化"是自我表扬。**

## 一、泛化六层（按"没见过"的程度递增）

| 层 | 名字 | 定义 | 典型做法 | 仓库状态 |
|---|---|---|---|---|
| L0 | 拟合/记忆 | 见过的数据上工作 | 训练集指标 | ✅（不叫泛化） |
| L1 | 分布内插值 | 同分布新样本（留帧/换种子） | 同分布留出 | ✅ docs/228 多种子 |
| L2 | 分布内偏移 | 同家族新样本（新 DAVIS 视频） | 跨视频留出 + 防循环 | ✅ docs/246（半径留出 3/4，防循环，工作点余量） |
| L3 | 跨域 | 不同数据家族（合成→真实、另一数据集/相机） | 跨域测试 | 🟡 docs/243（合成→真实：机制迁移✅、判别分辨率经 docs/245/246 修复但只在 DAVIS 内） |
| L4 | 跨任务/组合 | 没训练过的新任务 | 组合泛化测试 | ⬜ docs/235 COMPOSABLE 是合成前兆 |
| L5 | 跨能力涌现 | 没训练过的能力自己出现 | 涌现检验 | ⬜ 语言=副产物主张，未测 |
| L6 | 开放世界 | 任何世界情况 | — | ⬜ AGI 层 |

**注**：L1-L2 靠"留出"证明；L3 靠"跨域留出"证明；L4 靠"新任务组合"证明；
L5/L6 无法在单一基准上证明（开放性问题）。

## 二、三个必须分开的区分（混在一起是折磨的根源）

1. **插值 vs 外推**：插值 = 新点在训练凸包内（容易，大部分"泛化"是它）；外推 =
   凸包外（难）。docs/232 的 L5 中间态就是外推区——"部分可预测但永远有落空"，
   落空 = 凸包外。**泛化难度 = 外推距离，不是留出比例。**
2. **参数泛化 vs 机制泛化**：docs/246 = 参数泛化（半径值跨场景迁移，一次可证明）；
   docs/231 H3/域 C = 机制泛化（学习过程本身高效获取新技能，需要长期证明）。
   Chollet 的"智力=技能习得效率" = 机制泛化。**参数泛化一次证明，机制泛化一生证明。**
3. **转移的是什么**：实例（不泛化）/ 规律（分布内）/ 技能（跨任务）/ 能力（跨域
   涌现）。每上一层，转移物从"数据"→"结构"→"过程"。

## 三、泛化的敌人：捷径（shortcut learning）

- 泛化失败的机制根源 = 模型学到测试集上"碰巧相关"的表面特征（背景/颜色/伪影），
  而非因果结构——测试集上"泛化"，真实世界崩（Geirhos 等，shortcut learning）。
- **docs/243→246 的完整故事就是一次去捷径**：toy 分档是捷径（在 DAVIS 上不迁移）——
  它碰巧把合成场景分对，但判别分辨率不迁移；软匹配去掉了档位量化这个捷径。
- **推论：泛化最难的工作不是"让它在测试集上工作"，是"找出不迁移的部分并删掉"。**
  删掉捷径 = 泛化进步（docs/244 的证伪、docs/245 的机制切换都是删捷径）。

## 四、泛化的本质（框架判读）

- 能迁移的 = 跨变化保持不变的结构 = **不变性**。
- **残差（"世界对预期的拒绝"）本身就是不变性探测器**——预测-落空机制在哲学上
  就是泛化机制：它对"变化中不变的部分"敏感、对"已预测的部分"免疫。
- 因此本框架的泛化路线 = 用残差驱动的结构涌现，逐层逼近"跨变化的不变结构"
  （L2→L3→L4 的每一层，都是把"不变"的尺度扩大一级）。

## 五、实验判据标签规范（docs/248 起强制）

每篇实验文档的每个判据，必须带如下标签之一：

```
[L0/L1/L2/L3/L4/L5/L6] + 泛化对象（参数/机制）+ 证明方式（留出/跨域留出/组合测试）
```

示例：
- docs/246 的工作点判据标签：`[L2][参数][跨视频留出+防循环]`
- docs/243 的迁移判据标签：`[L3][机制][合成→真实]`
- docs/235 的 COMPOSABLE 判据标签：`[L4][机制][合成组合（前兆，非证明）]`

规则：
1. **不带标签 = 无效判据**（审稿时视为未定义）；
2. **L5/L6 不得作为判据**（不可在单一基准证明，只能作为展望）；
3. **跨层对比必须显式**（如"L2 参数泛化 ✅ vs L4 组合泛化 ⬜"分列）；
4. 每篇文档的"一句话"必须总结**本实验把哪一层推进了多少**（如"L2 完整→L3 探到一半"）。

## 六、框架的泛化剖面（与 LLM 的不对称）

| 层 | LLM | 本框架 |
|---|---|---|
| L1-L2 | 极强 | ✅ 刚证明（docs/246） |
| L3 跨域 | 脆弱（ARC 低、真实世界接地崩） | 🟡 在爬（docs/243 + 待跨数据集） |
| L4 跨任务 | 惊人（上下文学习） | ⬜ 合成前兆（docs/235） |
| L5 | 争议（声称涌现） | ⬜ 未测 |
| L6 | 否 | 否 |

- **"有语言无认知"的泛化层读法**：LLM 的 L4 没有 L3 接地托底 → 悬空的上层；
  本框架先夯实 L2/L3 再往 L4 → 承重结构不同，不是谁强谁弱。
- **"把泛化推到极致"的含义**：把 L2 的证明方法（留出+防循环+工作点余量）逐层
  升级——L3 靠跨域留出、L4 靠组合测试、L5 靠机制涌现检验。**每一层升级都依赖
  上一层的证明方法在迁移（方法本身也在泛化）。**
