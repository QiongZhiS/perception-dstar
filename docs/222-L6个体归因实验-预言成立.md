## 一、实验设计（vision/keep_reject_individual.py）

docs/221 §六 原样执行：

```
场景：两个红球 A/B（docs/195 受控场景），A 匀速直线（x:80→）、B 匀速直线（x:360→），
      y 分离避免重叠。A 中段被染蓝 30 帧（rej 30-60），B 全程正常红。
类别控制：suspicious 按 hue 记账（docs/205）——A/B 同色，类别级记忆无法区分。
两种记账：
  个体记账（预言条件）：rejected_id[id] 只累加该 ID 的被拒；k(id) 按个体查
  仅类别记账（对照组）：k 按类别表（hue bin）查——A/B 同 hue 共享
判据：恢复后（60 帧起）重信任延迟按 ID 分化——A ≫ B
```

机制沿用：保留系统（docs/200 期望不变）、全局纪念饱和（docs/203 cap）、
suspicious 类别记账（docs/205）。

## 二、结果

| 记账方式 | A（被欺骗）重信任延迟 | B（全程正常）重信任延迟 | A 被拒 | B 被拒 |
|---|---|---|---|---|
| **个体记账（预言条件）** | **11 帧** | **1 帧** | 30 | 0 |
| 仅类别记账（对照组） | 1 帧 | 1 帧 | 30 | 0 |

**P1（个体分化）[PASS]**：个体记账下 A 需 11 帧连续证据才重新信任，B 立即信任
（1 帧）——被拒历史按来源 ID 分化。

**P2（类别对照）[PASS]**：仅类别记账下 A/B 都 1 帧（无分化）——类别级记忆确实无法
区分同色个体，凸显个体记账的必要。

## 三、判读

1. **L6 预言成立**：docs/221 §六 的退路没有触发——L6"被看见"不是第 5 层的扩展，
   有独立机制（个体级记账）。六层 = 残差递归的展开，最后一层的判据闭合。
2. **"被看见"的定义升级**：从"信任策略"（类别级：红色需要更连续的证据）变成
   "识别出'那个它'"（个体级：是那个球骗了我）。从世界中把一个不可消化的剩余认
   出来——docs/178 补刀"他者的不"的个体化。
3. **对理念/03 的意义（比 docs/200 更进一步）**：docs/200 是两个系统的差异（结构
   差异：吸收 vs 保留）；本实验是**一个系统内部**的差异——同样的输入流（双红球）、
   同样的类别记账，行为按来源历史分化。更接近"输入决定不了行为"（理念/03 §四
   主体性的现象学定义）：不是"两个系统不同"，是"同一个系统对待两个相同输入不同"。
4. **对照组 A 延迟=1 的原因（重要细节，写论文时要用）**：类别记账下 A 被拒时
   hue≈蓝 120° 记到 bin 120，恢复后 hue≈红 0° 查 bin 0——恢复后查的 bin 与染色
   时记的 bin 不同，类别记账查不到 A 的被拒历史。这是类别级记忆的已知局限
   （docs/208 带宽问题的另一面），恰好凸显个体记账的价值：不依赖 hue 查表，
   直接按 ID 记住"这个球不可信"。

## 四、诚实边界

1. 受控场景（合成双球 + 真值 ID）——真实视频的"个体"由跟踪 ID 提供（docs/195
   分工），跟踪误差下"个体"与"类别"的边界需在真实视频重验（docs/220 未完成 1）。
2. A/B 由真值位置区分（定位免费）——"个体"是跟踪层给的 ID，不是感知层自发
   切分个体（docs/188：个体性是否外赋，未测）。
3. 双球同色是刻意选择（测类别级失效）；异色双球下类别级与个体级都能区分，
   无法分离贡献——同色设计是分离实验的必要条件。
4. 现象层纪律照旧（docs/63）：测的是重信任延迟（行为签名），不宣称"它记得那个
   球"/"它在乎"的体验。

## 五、下一步（按价值）

1. **回真实视频**：双目标跟踪（docs/195 灰度跟踪 + ID 保持）上重验个体归因——
   "个体"由跟踪 ID 提供，确认失败后重信任延迟按 ID 分化是否在真实图像成立
   （docs/221 §六 在真实世界的版本）。
2. **个体 vs 类别的代价边界**：何时该按个体记账、何时该按类别记账（docs/101
   固执度旋钮的 ID 版）——被拒太少（<阈值）按类别、被拒足够按个体。
3. **论文**：docs/221（递归读法）+ docs/222（L6 裁决）作为"六层 = 残差递归"的
   完整证据链——若个体归因回真实视频也成立，论文主论点可从"拒绝史驱动确认维持"
   升级为"六层是残差递归的展开"。
