### 1.1 机制选型（关键决策，冻结；先于任何结果）

**选型：候选 (a)——群级锚合并（锚物化）：SlotLoop4 = docs/256 SlotLoop3（逐字）+

打标已确认慢锚（合并锚），G3 以"自然锚 + 物化锚"评估（文本逐字）；群级分裂逐字

**第三格负结果的根因（docs/256 §四 合并确证，第四格的修复对象）**：

   c2=0 侧 3 窗（w0 E=4067 / w1 E=1607 / w7 E=5674）分散且两两特征距离大（~1.2 >>
   r_slow=0.39885）→ 被不同原型各自匹配、各自 1-2 hits 后被回收/弱化 → **从未在同一
   原型上累积成已确认慢原型**（hits ≥ hits_min_slow 且账本 {0:≥3}）→ 无 0 侧锚 →
   G3 门不过 → 强信息量段在群级不可组织（camel 弱-中信息量段因两侧窗口各自紧凑而
   自然成锚，唯一触发）。

   记忆"的物化步骤在机制中不存在。

## 五、诚实边界（预注册阶段已知边界）

1. **物化 = G3 确认性的语义转移（本格最核心的边界）**：G3 从"自然匹配必须已形成持久
   锚"变为"群级账本的侧证据可被物化为持久锚"——确认质量门的作用从"验证自然累积"
   转为"确保侧记忆物化"。诚实声明：这不是删掉确认门（G3 文本、判据 2 逐字保留），
   而是把确认的来源从"匹配链"扩展为"群级账本（机制自身的累积）"；A1 前提（docs/257
   DYNAMIC_PASS_REAL：机制在真实流上持续累积）为物化的正当性提供实证（docs/261
   §2.3 候选 C）。**残余风险**：物化使触发集从"G1+G2+G3自然+G4"扩为"G1+G2+G4"
   （G3 因物化而可满足）——若物化在无真实两簇结构的流上频繁触发（S1-S4 诊断流观察），
   如实报告其触发形态；判据 2 的 spurious 门是对"物化是否产生可维持的条件记忆"的
   独立裁定，不回调。
2. **spurious 风险（docs/256 §五.3 原样保留，物化版）**：flamingo 分裂必在 w7（段末
   ——0 侧 3 窗直到 w7 才聚齐）触发，子条目出生后段内剩余窗口为 0，后续门控命中完全
   依赖后续段（surf/camel/car-turn/motorbike 等）的同 c2 窗口落入子条目 μ 的 r_slow
   邻域——若不足 → spurious_split_frac 上升、avg_post_split_hits 下降 → 判据 2 不过
   → BOUNDARY 照实报告，**不允许用结果回调**（docs/63）。
3. **物化使 S1-S4 的群级触发增多（如实报告，无判据）**：docs/256 中 S1/S2/S4 的
   G1+G2 纪元（14/11/42）多数被 G3 过滤（自然锚不足），物化后这些纪元可触发（G4
   过滤同局部）——采纳转移诊断的 n_split 数字显著变化，如实报告（S1-S4 无组合判据，
   判据 3 只查 ratio/SC2_slow）；R1 的 G1+G2 纪元（15 个）经 G4 过滤后预期 2 个局部
   触发（flamingo w7 + camel），compound_frac 预期 4/5=0.8——**不保证**，运行揭示。
4. **物化锚与匹配动态的相互作用（诚实声明）**：物化锚是真实的未打标慢原型，若在某
   窗口物化后未立即触发分裂（本格设计下物化仅发生在 G1∧G2∧G4 纪元且 G3 经物化后
   必满足 → 触发必然紧随，故物化锚不跨窗口存活——被同一群级分裂退休），但实现上
   若出现"物化后未触发"的路径（如实现缺陷或边界条件），须如实报告（consolidate_log
   会记录孤儿物化锚）；本格冻结设计下物化锚生命周期 = "物化 → 同窗群级分裂退休"。
5. **群定义的时间局部性近似（docs/256 §五.5 同款）**：纪元是"段"的行为代理，不保证
