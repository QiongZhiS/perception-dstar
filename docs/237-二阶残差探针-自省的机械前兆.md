## 〇、一句话（预注册 + 结论）

> **把 compose_test 的 C0-C3 环境梯度与 CompLoop 回路原样复用（零改动），在每一次
> "条目匹配"事件上做二阶探针：SO_conf（回路从自己条目账本历史算出的"自预测匹配
> 质量"，严格不含当前窗口结果与生成器真值）对 SO_out（下一窗口该条目是否真的再次
> 命中）的预测力 SO_info（point-biserial r，null=0；AUC，null=0.5）。假二阶对照 =
> 用固定 0.5 / 均匀随机置信度替代 SO_conf 跑同一套度量。预注册判定：C2/C3 的 SO_info
> 显著 > 机会水平（bootstrap CI 排除 0）且 ≥ C0/C1 基线且显著优于假对照 → SECOND_ORDER；
> C2/C3 不高于机会水平或与假对照无显著差异 → NO_SECOND_ORDER；介于两者 → BOUNDARY。
> **结论：NO_SECOND_ORDER（10 种子 × 4 级，8.72 秒，工件 so_main.json）。C2 的
> SO_info 显著**低于**机会水平（r=−0.255±0.107，CI [−0.316,−0.189]；AUC 0.263）——
> 失败窗口的平均自置信度（0.731）高于成功窗口（0.674）：回路"最自信的时刻恰是即将
> 误配的时刻"，与"预感误配"的假说方向相反；C3 为 null（r=+0.003，CI [−0.007,+0.015]）；
> C0 亦反向（r=−0.242，CI [−0.421,−0.077]）；假对照未被打败（C2 真实 r 显著**劣于**
> 随机假二阶，差 −0.321 CI [−0.416,−0.228]）。趋势（数字标签 ENHANCING，C3−C0=+0.246
> CI [+0.085,+0.423]）实为反向信号随复杂度减弱至零，而非正向信号涌现。**二阶残差假说
> 在 toy 探针上被弱化：账本史自置信度不携带任何正向的匹配可靠性预测信息。**

## 一、预注册设计（判据先于最终运行冻结，docs/63 纪律）

### 1.1 环境（复用 compose_test，零改动）

- 场景/回路/参数与 docs/235 完全一致：`vision/compose_test.py` 的 `make_scene` +
  `CompLoop`（160×120 灰度合成场景，240 帧 @30fps，window=10 → 24 窗口；对数域双
  EWMA 背景预测 bg_fast(α=0.5)/bg_slow(α=0.03) + 自适应阈值 + 事件累积 + 变长 arity
  模式表 + 上下文槽位采纳）。**禁止修改** compose_test.py / critical_point.py /
  其他既有脚本；vision/so_probe.py 只 import 复用。
- 梯度（lvcode 20/21/22/23）：
  - **C0**（20, single_regime）：单目标段式速度换档（3 档，每 ~80 帧切换，相位重抽）
    ——复现 L5 式结构涌现，机制基线；
  - **C1**（21, dual_independent）：双目标独立匀速——平行结构基线（B 规则不依赖 A）；
  - **C2**（22, context_dep）：B 的速度乘子依 A.x vs B.x 相对位置（m1/m2）——上下文
    依赖，翻转时点不可由 bg_fast 预测（惊喜源）；每 run ~5-6 次上下文翻转；
  - **C3**（23, nested）：A 带快/慢 regime，B 的规则在 A 快段内为上下文依赖、快段外
    固定 m1——嵌套规则。
- 二阶信号最该出现的场景：**上下文翻转时条目暂时误配**（上一窗口命中的条目在翻转
  后不再命中）。C2/C3 有 ~5-6 次/run 的翻转（每次翻转 = 一个"误配"事件）；C0 有
  2 次/run 的 regime 切换（同类误配）；C1 无（纯平行，条目恒命中）。

### 1.2 SO 度量的可操作定义（冻结）

对每一次"条目 E 在窗口 w 匹配"的事件（w 从 0 到 n_windows−2，末窗口无 w+1 排除）：

**SO_conf(E, w) ∈ [0,1]**：回路"自预测的匹配质量"——E 在 w+1 继续匹配的预测概率，
只从**条目账本历史**（回路自己的匹配事件序列）计算（细化版，§1.2'，冻结于最终
运行前）：

1. `g_all` = 严格早于 w 的全部匹配事件（回路账本的**全局匹配史**，所有条目的匹配
   事件序列；arity-3 条目键含 c2，故该史即"各 c2 条件下"的匹配史）；
2. `n_all` = |g_all|；`cont_all` = g_all 中续匹配比例（u+1 窗口同条目再次匹配）；
3. `d` = E 在 w 的**连续匹配深度**（从 w 往回数 E 连续匹配的窗口数，含 w 本身——
   当前匹配事件是预测的触发条件，见 §1.3 无泄漏论证）；
4. `g_d` = g_all 中"自身运行深度 ≥ d"的匹配；`n_d` = |g_d|；
   `cont_d` = g_d 中续匹配比例（n_d < 3 → 回退 cont_all，深度样本不足）；
5. **SO_conf(E, w) = clip( (n_all·cont_all + n_d·cont_d + 3·0.5) / (n_all + n_d + 3), 0, 1 )**
   ——全局续匹配率与深度条件续匹配率按样本量加权、朝 0.5 先验收缩。
   冷启动（n_all = 0，run 最早窗口）→ 0.5（诚实不确定）。

设计语义：回路用自己账本的全局匹配史估计"深度 ≥ d 的匹配续下去的概率"——运行越
接近末尾（翻转/换档前的"预感点"），深度条件续匹配率越低（若账本史支持）→ SO_conf
下降 → **回路"预感到"误配**。全局样本（~5-6 条运行段/run）比单条目样本（~2-3 段）
更能支撑深度条件估计（§1.2' 细化动机）。"命中质量/条目年龄"通过续匹配率与样本量
收缩进入（无泄漏的尺度自由选择）。

**SO_out(E, w+1) ∈ {0, 1}**：实际匹配结果 = E 在 w+1 窗口是否再次匹配（命中=1，
未命中=0；w+1 无签名/无匹配事件也计 0）。翻转/换档窗口即"误配"事件（上一条目
SO_out=0）。

**SO_err** = |SO_conf − SO_out|（两者均在 [0,1]，天然归一化）；报告逐级别均值。

**SO_info** = SO_conf 对 SO_out 的预测力：
- 主指标：**point-biserial r**（Pearson，二进制 SO_out；null = 0）；
- 次指标：**AUC**（Mann-Whitney 秩统计，ties=0.5；null = 0.5）；
- 统计：每 (级,种子) 一个 r/AUC（池化该 run 全部观察对），跨 10 种子 mean±SD
  （ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828，docs/235 同款）。
- 退化处理（预注册）：某 (级,种子) 观察数 < 2 或 SO_out 无方差（全 1）或 SO_conf
  无方差 → r=0、AUC=0.5（无信号可测，照实报告）。

**观察池与排除（预注册）**：所有 (E, w) 匹配事件（w ≤ n_windows−2）。排除仅两种：
① 末窗口（无 w+1）；② **E 在 w 退休（提升为复合条目）的窗口**——退休是回路自己的
结构性替换（提升规则由账本条件触发），不是匹配质量结果；父条目在退休窗口后的"不
命中"是其被自身决策替换，不构成"误配"观察（预注册说明，非结果驱动）。

### 1.3 无泄漏论证（冻结）

- SO_conf(E, w) 只用：① w 的匹配事件本身（触发条件：条目匹配时）；② 严格早于 w 的
  匹配事件序列及其运行深度；③ 样本量（条目经验/年龄）。**不使用**：w 的残差
  （MAE）、w 的事件能量、w 的 c2 槽位数值、任何生成器真值（labels）、w+1 及以后的
  任何信息。
- 被预测对象是 **w+1 的结果**；"当前匹配事件（E 在 w 命中）"是预测的触发条件而非
  被预测结果——这是"条目匹配时自预测"的语义本身（docs/236 §二 原文：SO_conf 在
  "条目匹配时"计算）。
- SO_out 是实际结果（被预测对象），不受无泄漏约束；但判定用 SO_info 只比较
  SO_conf（含假对照）对同一 SO_out 的预测力——对照与真信号在同一观察池、同一
  结果上比较，无信息不对称。
- 假对照（§1.4）进一步排除"条目账本统计的统计伪影"：若随机/固定置信度也能达到
  同等预测力，则 SO_conf 的信息量不成立。

### 1.4 假二阶对照（冻结，必须做）

- 同一 (级,种子) 的同一观察池，用替代置信度重算全部度量：
  - **fake_fixed**：SO_conf ≡ 0.5（固定置信度）；
  - **fake_rand**：SO_conf ~ U[0,1]（均匀随机；每 (级,种子) 独立 rng：
    `default_rng(seed×104729 + lvcode×7919 + 999331)`，与场景 rng 流错开）。
- 对照统计：每种子差值 d_s = r_real,s − r_fake,s；跨 10 种子 bootstrap 95% CI
  （2000 次，种子 20260828）；CI 排除 0 = 显著优于假对照。
- 判定采用 **fake_rand 为主对照**（"随机置信度"），fake_fixed 一并报告
  （固定 0.5 的 r 恒为 0，其差值与机会检验同信息，作透明性报告）。

### 1.5 判定（预注册，判据先于最终运行冻结）

定义（逐级）：`r_L` = 级 L 的 point-biserial r 种子均值；`CI_L` = 其 bootstrap 95% CI；
`diff_L` = r_L 与 fake_rand 的种子均值差，`CI_diff_L` 为其 CI。

- **机会水平**：`chance_ok(L)` = CI_L 下界 > 0（显著高于 null=0）；
- **假对照**：`fake_ok(L)` = CI_diff_L 下界 > 0（显著优于随机假二阶）；
- **基线**：`baseline_ok` = r_C2 ≥ r_C0 且 r_C2 ≥ r_C1 且 r_C3 ≥ r_C0 且 r_C3 ≥ r_C1
  （点估计；C1 无翻转、SO_out 零方差时 r_C1 = 0，退化为"≥ 0"）。

判定（冻结）：

- **SECOND_ORDER**：chance_ok(C2) 且 chance_ok(C3) 且 fake_ok(C2) 且 fake_ok(C3)
  且 baseline_ok → **自我监测的机械前兆获得首个证据**；
- **NO_SECOND_ORDER**：（¬chance_ok(C2) 或 ¬fake_ok(C2)）且（¬chance_ok(C3) 或
  ¬fake_ok(C3)）→ C2/C3 的 SO_info 不高于机会水平或与假对照无显著差异 → **二阶
  残差假说被弱化，照 docs/63 纪律如实报告**；
- **BOUNDARY**：以上皆不满足（如仅一级通过、或基线不成立但信号仍在）→ 按数值
  照实描述，不强行下结论。

### 1.6 随复杂度趋势（预注册，独立于判定报告）

- 报告 r_C0, r_C1, r_C2, r_C3 序列；配对差值 d_s = r_C3,s − r_C0,s（按种子配对），
  bootstrap 95% CI。
- **增强（ENHANCING）** = CI 下界 > 0（自省随环境复杂化涌现的直接形态）；
- **下降（DECREASING）** = CI 上界 < 0；
- **持平（FLAT）** = CI 含 0。

### 1.7 随机性与种子协议 / 计算预算与安全纪律

- 种子协议同 docs/235：10 种子（seed 0-9）× 4 级；每 (级,种子) 独立 rng：
  `default_rng(seed×7919 + lvcode×104729 + 13)`；强度抖动 jitter=0.25（噪声 σ
  乘性 ±25% 按种子采样）；相位按种子抽样；C0 的 dips 时点/regime 边界固定。
- 统计外壳（docs/228/232 模式）：每 (级,种子) 完成写 checkpoint
  `vision/out/results/ckpt_so_<config哈希>.json`（--resume 断点续跑）；汇总写
  `vision/out/results/so_<tag>.json`（自描述 config/逐级 per_seed/mean_sd/
  bootstrap/verdict/逐观察明细）；mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，
  种子 20260828）。
- 计算预算：先单次计时（1 种子 × 4 级）；总预算 ≤ 60 分钟（预期 ~10-30 秒）。
- 安全纪律（docs/228/234 同款）：脚本 stdout 只输出 ASCII 标签 + 每行一个数字的
  R_* 摘要块；运行经
  `powershell -NoProfile -Command "& python vision\so_probe.py <args> *> logs\so_<tag>.log;
  ...Write-Output('exit='+$c+' bytes='+$b)"` 包装重定向到 logs/；数字用纯 python
  正则（vision/extract_r.py）抽取；禁止读日志/JSON 原文。

## 六、诚实边界

1. 机械前兆 ≠ 体验/意识/自我觉察——本探针只测行为签名（自置信度对匹配结果的可预
   测性）；NO_SECOND_ORDER 只弱化"自省的机械前兆可测"这一主张，不涉体验断言。
2. **反向信号的机制（C0/C2）**：基于账本续匹配率的自置信度在两类窗口系统性错位——
   ① 冷启动窗口（新条目/run 早期，SO_conf=0.5）几乎都成功续配 → 成功窗口被低估；
   ② 运行末端（长运行把 SO_conf 抬到全局续匹配率水平后，误配到来）→ 失败窗口被
   高估。24 窗口 run 内深度条件项（"预感"的机制载体）样本不足，无法把运行末端的
   置信度压下来。这是"账本统计伪影"的实锤形态：假对照确认真实信号不优于随机。
3. **样本量边界**：每 (级,种子) 仅 24 窗口、~13-21 个观察对、C2/C3 每次翻转前只有
   ~2-3 条可学习运行段；深度条件续匹配率估计噪声大。NO_SECOND_ORDER 在本 toy 尺度
   上成立；不能排除"更长 run/更多翻转会让账本学到深度-翻转统计"的（未证实的）可能
   ——照实报告，不强行下结论。
4. **C1 的失败窗口来自噪声**（高 jitter 种子阈值升高 → 无事件窗口 → 条目暂时无
   签名），不是上下文翻转；其 conf_neg 均值 0.150 来自极小样本（~1-2/种子），仅作
   透明性报告。
5. 不做完整二阶场（带宽约束，docs/236 炸弹 3），只做"信号存在性"探针。
6. 趋势标签 ENHANCING 是 §1.6 数字规则的输出（C3−C0 差 CI 为正），但语义上不是
   "自省涌现"——是反向信号减弱至零；§五已如实区分。
7. 统计：10 种子 × 4 级 × 240 帧；mean±SD（ddof=1）+ 2000 次 bootstrap CI（种子
   20260828）；总计算 8.72 秒（预算 60 分钟）；工件 so_main.json（逐观察明细 +
   判定）；checkpoint ckpt_so_<hash>.json（断点续跑验证，cfg 含 formula 版本标记）。
