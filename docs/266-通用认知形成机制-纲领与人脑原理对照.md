## 〇、一句话

> **通用认知不从语言涌现、也不从视觉涌现，而从"能持续预测并在预测落空时修正自身的
> 回路"涌现（docs/231 H）。人脑有明确对应的公认机制（预测编码、多巴胺预测误差、海马-

> 他者环境（多智能体对齐）未做 + 信号交换自发涌现的实验设计未做 + 模态无关性未验证 +
> F4/F5 证伪检验未做——语言是纲领的远期验证场，不是近期目标（docs/231 §四.4、docs/252 北星）。**

## 一、纲领的形成机制链（docs/231 H 的三步）

**H：存在一个模态无关的"预测-残差回路"，当其嵌入的信息环境复杂度越过某个临界点后，
会自发地发展出利害（惊奇→在乎）、意义（落空×利害）与技能（行为趋势固化），而语言是
回路遇到"也需要对齐的他者"后自然出现的行为，不是独立设计的能力。**

| 步 | 机制主张 | 对应六层/维度 | 证据状态 |
|---|---|---|---|
| H1 残差原子性 | 预测-落空是认知基本单元，非像素/token/特征 | L2 对齐（docs/178） | ✅ docs/227/228（残差 3.3×、flips p=0.0156/0.0020）；**模态无关性只在视觉验证** |
| H2 利害从落空涌现 | 惊奇本身是利害初始形态，无需外部奖励注入 | 域 B（docs/231 §二） | ✅ docs/189-230（利害锚、拒绝历史、MAD×\|Δ\|、40/4/8） |
| H3 回路自驱动 | 复杂度"恰到好处"的中间态环境 → 结构自发变化（不调参数的新技能/新维度） | 域 C（结构生成） | 🟡→✅ docs/232（临界点 L5）+ 235（组合）+ **docs/253-264（L4 五格：结构涌现 + 组合留出 + 习得效率）**——H3 的首个直接证据走廊已建成 |
| 语言涌现（远期） | 回路遇到"也需要对齐的他者"后，信号交换自发出现 | Layer 7（docs/240：G1 他者→G2 沟通→F2 语言→G3 文化） | ⬜ 未做（docs/231 §四.4） |

## 二、人脑已知原理对照（分层）

### 2.1 有较强证据支持的公认机制

| 人脑机制 | 纲领对应 | 证据强度 |
|---|---|---|
| **预测编码**（Rao & Ballard 1999）：皮层自上而下预测输入，只上传残差 | 域 A（预测-残差回路） | 神经影像/电生理强支持（视觉层层级误差信号） |
| **FEP/主动推理**（Friston）：生物系统最小化变分自由能=最小化惊讶 | 域 B + 全域数学等价 | 数学框架 + 跨物种行为证据 |
| **多巴胺奖励预测误差**（RPE, Schultz）：编码"预测 vs 实际"之差，非奖励本身 | **H2 的神经对应物**（落空→利害） | 电生理铁证（猕猴） |
| **海马-新皮层互补**（CLS）：海马快速单次编码 + 新皮层缓慢整合 | 快慢双原型（docs/250/251 gist 快 + 确认慢） | 记忆科学主流 |
| **惊奇驱动注意**（oddball）：新异刺激优先捕获注意 | 残差驱动的注意 | 行为+电生理强支持 |
| **层级预测贯穿皮层**：从视网膜到联合皮层都是"预测+误差" | 残差递归（docs/221） | 解剖+功能证据 |

### 2.2 有方向性支持但机制未完全明确的

| 人脑机制 | 纲领对应 | 不明确处 |
|---|---|---|
| **皮层可塑性是结构变化**（突触生成/修剪/树突重塑），非仅权重微调 | H3（结构自发变化） | "结构变化 vs 参数微调"的边界、触发条件未完全清楚 |
| **前额叶-基底节技能自动化** | 域 C（技能=行为趋势固化） | 自动化的确切神经算法 |
| **睡眠/重放巩固**（海马回放→新皮层） | C4 保持vs变强（docs/250 初证） | 巩固的精确规则 |
| **默认模式网络/自指处理** | F3 自省（docs/237 SO 探针） | "自省"神经机制远未明确 |

### 2.3 诚实声明：没有"完整图纸"

人脑**没有给出**：① 临界点的确切条件（什么复杂度/信噪比让回路从空转变自驱动——纲领
F3 命门，docs/232 做了初步未闭环）；② 语言涌现的触发机制（"遇到也需要对齐的他者"如何
具体导致符号系统出现——F4/F5 未测）；③ 意识（docs/63 明确 F5 意识不测，行为签名纪律）。

## 四、距语言涌现还差多少（差距清单，docs/240 依赖图为框架）

语言在依赖图的 **Layer 7 涌现层**（docs/240）：`G1 他者 → G2 沟通 → F2 语言（G3 文化 →
加速 C3）`。按依赖链逐环盘点差距：

| 环节 | 内容 | 现状 | 差距 |
|---|---|---|---|
| 底层（已有） | A1 时间基质 + L2-L4 泛化 + L5 习得效率桥 | ✅ docs/257/246/248-251/262/264/258 | **无差距（本段已踩实）** |
| 符号槽接口雏形 | 语言内化/符号槽态势转录（docs/204-207） | 🟡 已有工程雏形（"把内部状态转录成符号"，语言作为内部表示/产物） | **这是"语言作为产物"，方向不同于"语言涌现"**——但可作为符号化的工程对照 |
| **G1 他者** | 多智能体环境（第二个"也需要对齐的系统"） | ✅ **已做（docs/268 起，双回路 = 最小他者）** | **无差距（最小版）**；多智能体规模（>2）未做 |
| **G2 沟通** | 对齐协议（信号交换如何自发出现、被采纳） | ✅ **单向 CLEAN（docs/268-270）+ 双向 MUTUAL_EMERGES（docs/271-275：ONE_WAY ×2 → stagger5 并行 → JR 口径 + spurious 治理，互采纳完全成立）** | **无差距（交换闭环最小版成立）**；噪声/丢包信道是后续格 |
| **F2 语言** | 信号系统自发涌现的测量（符号→意义的压缩/传递） | ✅ **第一格 SYMBOL_EMERGES（docs/276：行为涌现符号表——稳定性 0.86/0.83、可预测 0.57/0.53、压缩 11.5-12×、脱情境引用 0.875/0.90）** | **第一格踩实（含脱情境引用）；第二格（符号组合/语法结构，B6/F1 层）未做** |
| 模态 | 听觉线/语言线的信息环境 | ⬜ 未开工 | 模态无关性 H1 未验证（只在视觉） |
| 证伪 | F4（语言可从纯符号统计涌现 → 主张作废）/ F5（通用认知可从纯语言训练涌现 → 纲领作废） | ⬜ 未测 | LLM 现状是最强反方证据源 |

**量化估计（2026-08-30 二次更新）**：语言线八格（docs/268-276）完成后，进度从"前
1/3~1/2"推进到"**约前 1/2~2/3**"——G1 他者 ✅、G2 沟通 ✅（单向+双向）、F2 符号化第一格
✅（含脱情境引用）——docs/240 依赖链 `G1 他者 → G2 沟通 → F2 语言` 的三个环节全部有
正证据。距"语言涌现"本体还差：F2 第二格（符号组合/语法结构，B6/F1 层）、F4/F5 证伪
（远期对照）、模态扩展（听觉线）。docs/252 北星"语言是后期产物"的约束部分松动——先行
研究已证明"他者→沟通→符号化"这条前兆链可测且正证据成立。

**因此"差多少"的诚实回答**：语言线从"差一个尚未开工的领域"推进到"**前兆链三环（他者→
沟通→符号化）已踩实、本体（F2 第二格语法结构 + F4/F5 证伪）仍有明确待办**"——剩下的是
符号组合层与证伪对照，不再是"零起点"。

## 五、下一步候选（若推进语言线，按依赖序，2026-08-30 二次更新）

1. **F2 第二格（符号组合/语法结构）**：符号从"单个稳定映射"到"可组合序列"（docs/240
   B6 抽象层/F1 推理层）——测符号能否组合表达更复杂状态（序列预测/结构复用）。这是
   "语言本体"（语法结构）的最直接前身。
2. **信道现实主义**：docs/268-276 信道无噪声/无丢包/无延迟（冻结声明"后续格候选"）——
   加噪声/丢包/延迟，测符号化与互采纳的鲁棒性（更接近真实通信）。
3. **F4 证伪预研**（长期对照）：LLM 纯符号统计 vs 预测-落空回路的对照设计（docs/231
   §五文献划界 A7 种子）——"语言能否无回路涌现"的可测化。
4. **模态扩展**（远期）：听觉线 = 语言的最自然载体；模态无关性 H1 未验证（只在视觉）。
5. **演示化**（docs/217 巅峰版先例）：把"双回路 → 互采纳 → 符号化"链做成可视化演示
   （观众看到"它在看什么/预测什么/采纳什么/固化什么符号"）——工程侧，非实验。
