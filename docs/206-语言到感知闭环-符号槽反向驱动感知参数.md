## 〇、一句话

> **语言→感知闭环：符号槽状态反向调节确认阈值——被拒 → "可疑" → thr 上调
> （0.20→0.50，每次被拒 +0.05 封顶 0.50，"我要看得更仔细"）；持续信任 → thr 逐步
> 回落（0.50→0.20，"确认可以松一点"），完全可逆不锁死（docs/203 饱和精神）。**
> 语言层（docs/204 符号槽）从"感知→语言"单向转录，变成感知参数的调节器——
> docs/194"语言给先验"的机制化：语言给的不只是对话级先验（"那是什么字"），
> 是感知参数级的先验（确认阈值=先验强度）。**

## 一、机制（vision/language_closed_loop.py）

```
感知层：确认通过 = 目标区红区占比 > thr（thr 是感知参数）
语言层（docs/204 LanguageMind）：符号槽 {color, suspect, persist}
闭环（closed=True）：符号槽 → 感知参数 thr：
  suspect=True（被拒）→ thr 上调（每次被拒 +0.05，封顶 0.50）
    ——"我不确定，我要看得更仔细"（先验强度上调）
  persist≥20（持续信任）→ thr 逐步回落（每次 -0.05，回到基线 0.20）
    ——"确认可以松一点"（先验强度回落的可逆）
无闭环（基线）：thr 固定 0.20，语言只输出不调节
场景：红球，帧 30-59 染蓝（确认失败），60 恢复（docs/200 同款）
```

## 二、结果（关键帧）

| 帧 | 红区占比 | thr（闭环） | 确认 | 语言 |
|---|---|---|---|---|
| 0/15 | 1.000 | 0.20 | ✓ | 确认红，稳定 |
| 30 | 0.000 | 0.25 | ✗ | 它变了，我认不出来了——刚才可能认错了 |
| 31-34 | 0.000 | 0.30-0.45 | ✗ | 不是红，我不确定，我要看得更仔细 |
| 35-59 | 0.000 | **0.50**（封顶） | ✗ | 不是红，我要看得更仔细 |
| 60-78 | 1.000 | 0.50 | ✓ | 像红的了，但我还谨慎（N/20 帧） |
| 79-84 | 1.000 | 0.45→0.20 | ✓ | 持续信任，确认在放松（阈值回落） |

**无闭环对照**：thr 恒 0.20，语言只被动转录（"不是红，我不确定"）。

## 三、判读

1. **语言成为感知的调节器**：docs/204 是"感知→语言"（符号槽=维持层状态投影）；
   本文件补上"语言→感知"（符号槽状态反向驱动 thr）——双向闭环闭合。docs/194
   "眼+语言闭环"中"语言给先验"的方向落成：语言给的不只是"那是什么字"的对话级
   先验，是**确认阈值（先验强度）的参数级先验**。
2. **先验强度的自适应 = docs/101 在感知参数上的落点**：被拒越多（世界越噪声）→
   thr 越高（先验越强=越固执=要更确凿证据才接受）——docs/101"世界越噪声自我越
   该固执"从"期望更新步长"（docs/201）和"重信任延迟"（docs/200/203）之后，第三
   个实现面：**确认阈值本身**。
3. **可逆不锁死（docs/203 饱和精神）**：thr 有封顶（0.50）且持续信任后逐步回落
   （0.50→0.20）——谨慎（被拒后阈值高）不变成锁死（世界恢复后阈值回基线）。
   这是 docs/203"饱和累积"在感知参数上的对应：阈值上调有上限、回落可逆。
4. **符号槽从输出变输入**（docs/204 §五 1 兑现）：语言层不再只是"说话"，它说的
   状态（可疑/信任）反过来决定系统"怎么看"——语言是感知的调节器，感知是语言的
   原料，双向闭环（docs/154 混合架构的视觉-语言接口雏形）。

## 四、诚实边界

1. demo 不是实验：无可量化判据、无对照（闭环 vs 无闭环只有 thr 轨迹展示）；验证
   的是**可调节性**（符号槽能驱动感知参数）与**可逆性**（不锁死）。
2. thr 的调节量（+0.05/次、封顶 0.50、回落 -0.05/20 帧）是手工标定——"被拒多
   少该多严"是设计参数（可接 docs/203 saturate 的 cap/grow 学出来）。
3. 只调了确认阈值一个感知参数——注意力权重（docs/138 扫视）、颜色通道优先级
   （docs/192）等未接；"语言驱动注意力"只兑现了阈值面。
4. 现象层纪律照旧（docs/63）：调节的是感知参数（阈值），不宣称"语言在思考"。
