## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/260 §五.2 盲区（阴影 vs 暗物体不可区分）经 docs/261 补上第 1 步（V1 闭合轮廓 +
V3 主轴方向），但人眼判别多维线索表第三维——**反射率连续性**（intrinsic image：
图像 = 反射率 × 光照；阴影边界两侧 = 同一反射率（同表面被明暗分开）、物体边界两侧 =
不同反射率（不同材质））——尚未显式化。本格目标 = 把反射率连续性做成**显式判别**：

- **V4 反射率跳变否决**（负向硬判）：候选暗区边界两侧色相/饱和度跳变（ΔH > TOL_H
  或 ΔS > TOL_S）→ 判为物体/非阴影。
- **E3 反射率连续证据**（正向支持）：边界两侧连续（ΔH ≤ TOL_H 且 ΔS ≤ TOL_S）→
  支持阴影（同一表面被光照明暗分开）。
- **三场景臂**：main（真阴影）测"连续"判别正确率；ctrl（docs/261 暗圆盘）与
  band（新开放暗带）测"跳变"判别正确率与 V4 否决作用。
- **保留保持**：前两格能力不退化（阴影检出率、光照方向、对照臂否决）——彩色化
  保持灰度投影逐位一致，守卫 CELL1/CELL2 逐位证明。

范围收窄：判别对象 = **候选暗区（阴影候选掩码）的边界环带**（docs/260/261 的
检测路径产物），不含亮区/球面；反射率连续性用**边界两侧中位色相/饱和度差**量化
（docs/219 target_obs 口径的边界版）；合成受控域，非真实域证明（§五 1）。

### 1.2 彩色合成场景（冻结；三臂，灰度投影逐位 = docs/260/261）

**构造原则（本格核心）**：场景的**明度（灰度投影 Y）逐位 = 前两格灰度帧**（守卫
CELL1/CELL2 逐位一致的前提），颜色（反射率）叠加在明度上：每像素
RGB(t,x,y) = tint(surface) × Y(t,x,y)，其中 tint 是表面反射率向量（归一化使
灰度投影系数 0.299·t_R + 0.587·t_G + 0.114·t_B = 1 → Y(RGB) = Y 逐位）。tint 各分量
约束：该表面最大 Y × tint_i ≤ 255（不 clip，避免破坏色相）。HSV 中 V = max(RGB) 随
Y 缩放（阴影 Y×0.5 → V×0.5，H/S 不变）——**"同一反射率被光照明暗分开"的显式
构造**（docs/196"暗化只动 V、H 不变"的直接实现）。

**反射率表（冻结；场景参数，已知反射率，同 docs/260 θ_L 地位）**：

| 表面 | 反射率色相 H（OpenCV 单位，docs/219 惯例） | 饱和度 S | tint 构造约束 |
|---|---|---|---|
| 背景棋盘（64/96 两格共用） | **30°**（橙/黄） | 0.6 | Y 系数 = 1；96×tint_i ≤ 255 |
| 静态朗伯球面 | **60°**（绿） | **0.5**（D0 复核，见 §二） | Y 系数 = 1；195×tint_i ≤ 255 |
| 遮挡物（主场景亮圆） | 白 255（**无反射率**，同 docs/260/261 逐字） | — | 255（不乘 tint） |
| 对照圆盘（ctrl 臂） | **140°**（紫） | 0.6 | Y 系数 = 1；32×tint_i ≤ 255 |
| 开放暗带（band 臂） | **140°**（紫） | 0.6 | 同上（暗带亮度 = 背景×0.5） |
| 阴影（main 臂） | **30°**（= 背景反射率，同一表面） | 0.6 | tint = 背景 tint；Y = 背景×0.5 |

几何/色距验证（预注册，先于任何运行的分析）：背景 30° vs 圆盘/暗带 140° →
circ = min(|140−30| mod 180, 180−…) = min(110, 70) = **70° > TOL_H=15°（4.7× 余量）**；
阴影 vs 背景 = 同一 tint → ΔH = **0°**（理论精确，H/S 无噪声，§五 2）；球面 60° vs
背景 30° = 30° > 15°（跳变，但球面被 ref_dark 吸收不构成候选，不参与判别）；遮挡物
白 S=0 < SAT_MIN=60 被彩色过滤排除（不污染边界环带采样）。**阴影带不触球面**的几何
（docs/260 §1.2：最近 27.84px > 环带 2px）保证 main 臂边界环带不混入球面绿色像素。

**三臂定义（冻结）**：

| 臂 | 构造（冻结） | GT 阴影 | 语义（测什么） |
|---|---|---|---|
| **main** | docs/260 `make_shadow_scene` 逐字灰度帧 → 彩色化：背景 tint_BG、球面 tint_SPH、遮挡物白 255、阴影 = 背景×0.5 同 tint_BG（Y 逐位 = docs/260） | docs/260 逐字 | 真阴影正样本：边界应判连续；det/ld 保持 |
| **ctrl** | docs/261 `make_control_scene` 逐字灰度帧 → 彩色化：背景/球面同 main、暗圆盘 = 32×tint_DISK（紫，Y 逐位 = docs/261 对照臂） | 全空（docs/261 逐字） | 暗圆盘闭合物体：边界应判跳变；fp_gated ≤ 0.10 保持 |
| **band** | main 灰度帧 → 彩色化时阴影区域 tint 替换为 tint_DISK（紫，Y = 背景×0.5 不变）+ GT 阴影清空；遮挡物仍白 255 | 全空（本格新构造） | **开放暗带**（触图像边界、主轴沿光照）：V1/V3 不触发，V4 独立承担否决 |

band 臂几何（预注册分析）：暗带几何 = main 阴影带几何（仅 tint 不同）→ docs/260/261
几何验证直接适用：**24/24 触图像边界**（V1 不否决）、PCA 主轴与光照方向无向夹角
≤ 2.92° < TOL_AXIS=30°（V3 不否决）、特征值比 ≥ 11.1（强各向异性，V3 适用但误差
在容差内）→ 唯一剩余否决通道 = **V4（反射率跳变）**：band 臂 V4 独立作用可测。
亮度上 band 暗带与 main 阴影逐位相同（Y = 背景×0.5）→ 检测路径对 band 的 legacy
口径 = 对 main 阴影的 legacy 口径（fp_legacy ≈ 1.0，docs/260 C1 口径把它当"阴影"）。

### 1.3 机制（冻结；预测路径零改动，检测路径复用前两格，新增 V4/E3 反射率判别）

**预测回路与检测路径** = docs/260/261 逐字复用（import）：`CPLoop(window=10)`
每帧 step；Pass A 适应（排除遮挡物帧 L > log(221) 后 0.95 分位 ref_dark）；Pass B
判暗（ref_dark_log − L > δ=0.35）、判亮（L > log(221)，遮挡物白 255）；8-连通域
（largest_component），面积 ≥ A_min=25；时间门（掩码帧间 IoU 变化 ≥ MOVE_IOU=0.05，
K=10）→ legacy_active；否决门链 gated = legacy_active AND NOT(veto)。**本脚本的
明度通道操作全部在灰度帧（= docs/260/261 帧逐字）上进行**，彩色帧只用于反射率
判别——明度通道与前一格逐位同实现（守卫 CELL1/CELL2 的逐位基础）。

**否决门（复用 docs/261 冻结）**：
```
V1（闭合轮廓）：touches_boundary(候选) 为 False → 否决为物体（docs/261 逐字 import）
V3（主轴方向）：PCA 特征值比 ≥ RATIO_MIN=1.5 且主轴与光照夹角 > TOL_AXIS=30° → 否决
   （各向同性跳过；docs/261 逐字 import）
veto_geom = V1 OR V3
```

**V4 反射率跳变否决（本格新增，冻结）**：
```
在候选暗区 d_mask（面积 ≥ A_min）上：
  inner = d_mask AND NOT erode(d_mask, k=BAND_EDGE)      # 内侧边界环带（2px）
  outer = dilate(d_mask, k=BAND_EDGE) AND NOT d_mask     # 外侧边界环带（2px）
  彩色过滤（docs/219 target_obs 口径）：S ≥ SAT_MIN=60（HSV 中）
  hue_in  = median(H[inner & colored]); hue_out = median(H[outer & colored])
  sat_in  = median(S[inner & colored]); sat_out = median(S[outer & colored])
  ΔH = circ(hue_in, hue_out)        # circ = min(|a−b| mod 180, 180−…)，docs/219 同款
  ΔS = |sat_in − sat_out|
  E3（证据）：ΔH ≤ TOL_H 且 ΔS ≤ TOL_S → 反射率连续 → 支持阴影
  V4（否决）：ΔH > TOL_H 或 ΔS > TOL_S → 反射率跳变 → 判为物体/非阴影
veto = veto_geom OR V4
gated_active = legacy_active AND (NOT veto)
```

**V4 追加为否决门 vs 独立判据的接口论证（任务指定论证，冻结）**：
- **机制层：追加为第 3 否决门**（V4 与 V1/V3 并列进 gated 链）。理由：(a) 人眼判别
  多维线索表第三维 = 颜色（反射率），与 V1 拓扑、V3 光照方向是**正交独立线索**——
  机制上并列追加才构成"联合判别"（前两格的 gated 链 = legacy AND NOT(v1∨v3) 是本格
  gated = legacy AND NOT(v1∨v3∨v4) 的真子集，扩展不破坏旧链）；(b) V4 的跳变/连续
  二值判定天然是否决门形态（跳变 → 否决为物体），与 V1/V3 同构；(c) band 臂证明
  V4 有**独立价值**（V1/V3 均不触发时 V4 承担分离——若 V4 只是装饰，band 臂会 fp
  全报）。
- **判据层：独立判据**（C1 REFLECT_CONT / C2 REFLECT_DISCONT / C4 REFLECT_VETO 测
  V4 的行为正确率，C3 KEEP 测全链不退化）——判据测机制行为（判别正确率/否决作用/
  不误伤），不测内部参数，与前两格"判据测行为"纪律一致（docs/261 §五 2）。

**旋钮（冻结，来源论证）**：
- `TOL_H = 15.0`（OpenCV 色相单位，docs/219 惯例）：docs/219 确认带宽 30° 的一半
  ——反射率连续性（同一表面）比"类别确认"（同一目标）更严；样本间距 70°（背景 vs
  紫）与 0°（阴影 vs 背景）之间 4.7× 余量。
- `TOL_S = 80.0`（HSV S 0-255）：ΔS 判据的机制完整性（双轴：色相/饱和度）；本格
  tint 饱和度统一 0.6 → ΔS ≈ 0，**无 S 跳变独立样本**（§五 3 诚实：ΔS 轴报告性、
  未测）。

## 五、诚实边界（预注册阶段已知）

1. **合成受控、非真实域证明**：四判据均为 `[新][机制][合成受控]`——docs/247 阶梯的
   L0/L1 域（同分布多种子），**不构成任何 L2+ 泛化主张**。反射率 tint 为场景参数
   （已知反射率），光源方位已知受控；结论域 = docs/260/261 同款合成场景族的彩色版。
2. **灰度→彩色的转换边界**：彩色化 = 已知反射率 tint × docs/260 灰度明度，H/S
   **无噪声**（噪声只加在明度 V）——真实相机噪声（亮度-色度耦合、去马赛克伪影）会
   扰动 H/S，本格未建模；tint 是**理想朗伯反射率**（纯色、无纹理、无镜面），真实
   材质反射率分布（帧内色相 std 5-44°，docs/219 flamingo 实测）超出本格范围；遮挡物
   保持白色 255（无反射率——它是"光源侧亮物"角色，其反射率未建模）；"阴影 = 乘性
   变暗 H/S 不变"是理想模型（docs/196 亮度稳健的合成版），真实阴影含环境光抬升
   （阴影内不完全是 0.5 倍率）、半影、色温偏移（docs/196 色温脆弱：阴影在有色光源
   下 H/S 会漂移）——均未建模。
3. **反射率 vs 光照解耦的理论边界（intrinsic image 病态性）**：从单幅图像把 反射率
   × 光照 唯一分解是病态问题（Barrow & Tenenbaum 1978 原始主张 + Retinex 的假设
   约束）；本格测的是**简化形态**：(a) 合成域反射率已知（tint 是场景参数，非估计）；
   (b) 判别只比较**边界两侧的相对 H/S**（连续性/跳变二值），不做绝对反射率估计；
   (c) 假设"阴影只改 V 不改 H/S"（§五 2）。因此本格证明的是"边界两侧相对色距可判别
   阴影/物体边界"，**不证明**一般 intrinsic image 分解/反射率估计问题可解——后者是
   docs/219 文献划界 D 方向（Retinex/color constancy）的完整问题域，超出本格。
4. **TOL_S（饱和度轴）无独立测试样本**：本格 tint 饱和度统一 0.6 → ΔS ≈ 0，判
   "跳变"全部由 ΔH 承担；ΔS 判据（ΔS > 80 → 跳变）机制完整但**未触发**——如实报告
   （docs/261 §五 4 V3 同款诚实：冻结但无样本触发）。饱和度跳变的独立样本（同色相
   不同饱和度的相邻表面）需后续构造。
5. **V4 与 V1/V3 的分工**：ctrl 臂圆盘闭合 → V1 先否决（V4 同判跳变但非独立贡献）；
   band 臂（开放暗带）专测 V4 独立作用（V1/V3 不触发）。"开放 + 沿光照 + 异反射率
   暗物"是 V4 独有的分离对象；真实域中 V4 的独立贡献域（如开放暗条/树影状暗物）
   本格只测一个构造点。
6. **噪声鲁棒性未测**：σ=3.0 固定 + jitter 0.25（docs/228 主协议）；H/S 无噪声；
   "越噪声越固执"（docs/101）在反射率判别上的行为未验。
7. **判据阈值为合成场景标定值**（0.90/0.80/0.05/15°/0.10/0.50/15°/80/2/60），跨
   场景/真实域需重标定（docs/199 §五 同款声明）。
8. **与 docs/260/261 的衔接**：本格把光影判别推进到人眼三维联合的第 3 维——V1/V3
   （拓扑 + 光照方向，docs/261）+ V4/E3（反射率颜色，本格）。docs/187 的"纹理弥散
   vs 物体相干"完整判别、docs/260 §五.2 的"阴影 vs 暗色移动物体"语义完整解（真实
   域）仍不在本格范围；"运动耦合（MT/V5）"粗形态（docs/260 C1 时间门）与"光照平行性
   /半影"列为后续格。
