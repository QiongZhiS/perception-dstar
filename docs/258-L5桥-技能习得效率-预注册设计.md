## 一、预注册设计（冻结；机制与测量/判据/判定映射/守卫/旋钮/流先于任何运行写入本文件，docs/63+247 纪律）

### 1.1 缘起与目标（冻结）

docs/247 §二 2 的区分：**参数泛化**（docs/246：半径值跨场景迁移，一次可证明）vs
**机制泛化**（学习过程本身高效获取新技能，需要长期证明；Chollet"智力 = 技能习得效率"）。
docs/255 §三 把 L4→L5 的桥 = 机制泛化，首选形态 = **技能习得效率**，可测形态（docs/255
§三1 逐字引用）："新技能（新场景族/新规则）的习得**速度**与**所需干预**随阅历下降——
学习过程本身的高效习得"。

**机械前身（本实验的基座）**：快慢双原型 + 延迟定级的时间尺度从行为涌现（docs/250/251：
重匹配命中率 → 升级/回收，无段长预测）；docs/257 证明该机制在真实流上持续累积（A1
动态基质，DYNAMIC_PASS_REAL）。本实验把这些推向"技能习得效率"：**在单条真实拼接流上，
按段序数 k（新场景族）测量"习得成本"，看它是否随阅历（已累积的慢记忆集）非增**。

**关键实现事实（冻结引用）**：现行机制无独立 save/load 序列化（docs/257 §五.1：
prototypes/ledger 未实现独立序列化）→ 阅历效应**必须在单条长流内按段序数测量**
（机制流内持续累积 = A1 动态基质的载体），**不可用跨会话加载**（本格不实现序列化——
那不是本格的任务，若未来需要另行预注册）。

**本实验的增量（诚实声明）**：机制零改动（DeferredLoop 逐字 import 复用）→ 结构/稳定
数字与 docs/251 **必然逐位一致**（这正是守卫 Mode OFF≡docs/251 的形态，docs/252 §三3）；
本格的增量 = **段级习得成本度量口径 + 阅历效应判据 + verdict**（docs/257 诚实边界 4
同款：判据级增量，不是新机制数字）。

### 1.2 机制与测量（关键设计，冻结；本实验核心）

**机制（冻结）**：`quota_retire.DeferredLoop` + `quota_retire.run_deferred_stream`
（docs/251 逐字，import 复用）。**零重调、零机制改动**——本实验不修改 DeferredLoop 的
任何匹配/升级/回收/创建逻辑；只在其返回的 out（entry_log/created_log/promoted_log）与
loop（match_trace/soft_trace）之上做**最小纯测量加法**（段级度量，post-hoc 计算）。
预测路径零改动 → MAE/ratio 与 docs/243-251 逐位一致（构造性控制项，R_L5B_REPRO_RATIO）。

**技能习得效率的操作化定义（冻结，可计算）**：

数据源 = entry_log（含 promoted_at/hits/kind，慢条目）、created_log（created/
final_hits/recycled，快创建累计含回收）、promoted_log（pid/promoted_at/hits）、
loop.match_trace（每窗 (w, pid)，匹配记录）。**段边界 = 评估/诊断统计专用，不进任何
机制决策**（docs/250/251 纪律）：
- **R1（主测量流）**：GT 切换窗 [8, 13, 21, 30, 36, 41, 49, 54]（9 视频拼接切换帧
  [80,135,217,307,367,417,497,540] ÷ 10，0 基窗）→ 段 k 覆盖窗 [b_k, b_{k+1})，
  b = [0, 8, 13, 21, 30, 36, 41, 49, 54, 59]（9 段；末段 = soccerball [54, 59)）。
- **S4（第二测量流）**：V1+V2+V3 拼接，构造性边界 = 累计采样帧数 ÷ 10
  （b = [0, len(V1)÷10, (len(V1)+len(V2))÷10, n_windows]，3 段；V1/V2/V3 是不同的
  内容族，段边界即"新场景族"边界；构造性边界诚实声明，非 GT——本格用它做段级测量
  而非 gist 对齐判据）。

对段 k（窗范围 [w_lo, w_hi)，段长 len_k = w_hi − w_lo），冻结四项目得成本度量：

1. **gist 创建时延（gist_creation_latency_k）**：段内首个新条目创建窗 min(created)
   与段边界窗 w_lo 之差（窗；创建恰在段首窗 = 0 = 立即响应）；段内无创建 = **NA**
   （如实报告；k_consist_fast=1 使"有创建的段"时延多 ≈ 0——该度量的语义是"机制对
   新场景族的响应及时性"，不是主趋势度量）。
2. **确认时延（confirm_latency_k）**：段内创建的原型中，最终被升级（进入
   promoted_log）者的 min(promoted_at − created)（窗）——"从创建到确认固化"的耗时，
   即习得时间；段内创建无一升级 = **NA**（延迟定级下升级稀疏，NA 是预期形态，如实）。
3. **习得成本密度（cost_density_k，主度量）**：`(created_k + recycled_k + promoted_k)
   / len_k`（每窗干预量）。created_k = 创建窗 ∈ 段 k 的快创建数；recycled_k = 创建窗
   ∈ 段 k 且已回收的快创建数（失败尝试也计干预）；promoted_k = 升级窗 ∈ 段 k 的升级数。
   理由（冻结）：① 全部 12 段可计算（无 NA）；② 综合"创建（对新场景的响应）、回收
   （未确认的失败尝试）、升级（确认成功）"三类学习干预——"学习过程本身的开销"的
   直接操作化（docs/255 §三1"所需干预随阅历下降"）；③ 长度归一使不同长度段可比
   （R1 段 5-9 窗 vs S4 段 ~40+ 窗）。
4. **升级命中率（promo_hit_rate_k）**：升级窗 ∈ 段 k 的慢原型的最终 hits 均值
   （段内升级原型的最终 hits 均值；无 = **NA**）——确认技能在流末的保持强度。

**阅历效应（判据 1 口径，冻结）**：习得成本（主度量 cost_density_k）随段序数 k 的
变化——单调非增 / 下降斜率。R1 与 S4 分别测，两流都过才算 ACQ_DECLINE（统计口径诚实：
R1 9 段、S4 3 段，段少 → Spearman 为描述统计不声称显著性，数值 + 方向 + 前后一半均值
如实报告；附 pooled 12 段相对序数支持统计）。

## 五、诚实边界（预注册阶段已知边界）

1. **本格是"时间尺度涌现的推进格"，不是新机制格**：机制零改动（DeferredLoop 逐字）→
   结构/稳定数字与 docs/251 逐位一致（Mode OFF 守卫 32/32 的必然形态，docs/252 §三3）；
   本格的增量是**段级习得成本度量口径 + 阅历效应判据 + verdict**（docs/257 诚实边界 4
   同款声明）。若守卫全过而判据全过，结论 = "docs/251 已确立的机制行为，在技能习得
   效率口径下确实成立"（判据级增量）。
2. **阅历效应的统计口径（本格最大的边界）**：R1 9 段、S4 3 段——段少、内容异质（各段
   是不同的真实视频/野视频，段间差异部分是内容特性而非阅历）。Spearman ρ 为**方向 +
   量级的描述统计，不声称显著性检验**（确定性单次运行，无采样分布，docs/251 诚实边界 9
   同款）；前后一半均值比较为单调非增护栏。若方向不明（ρ > 0 或后一半 > 前一半），
   **如实报告负结果（ACQUISITION_FLAT），不回调**（docs/253/254 负结果纪律）。
3. **S4 段边界是构造性的，非 GT**：V1/V2/V3 是不同内容族（"新场景族"成立），但边界
   时点 = 累计采样帧数 ÷ 10（文档数据依赖，运行时按实际采样帧数计算）；S4 只用段级
   测量（判据 1 次测试 + 判据 2(c)），不做 gist 对齐判据。R1 才是 GT 段边界的主测量流。
4. **确认时延/升级命中率的 NA 语义**：延迟定级下升级稀疏（R1 仅 5 次升级、S4 7 次），
   多数段 confirm_latency/promo_hit_rate = NA——NA 是预期形态，如实报告 NA 计数，NA
   不参与 ρ（主度量 cost_density 全部 12 段可计算，无 NA）。
5. **"升级命中率均值 > 未升级均值"的构造性成分**（docs/251 诚实边界 9 同款）：延迟
   定级下升级均值 ≥ 3 按构造成立（定级门槛 = 3）、未升级均值 < 3（任何达 3 者已被
   定级）——判据 3 的分离部分是机制定义，非随机性检验；报告两侧数字与分离程度，如实。
6. **段级测量是 post-hoc 纯测量加法**：全部度量由 run_deferred_stream 返回的
   out/loop 计算（不修改机制、不注入边界信号、不重放流）；GT/构造性边界只进评估统计，
   不进机制决策（§1.7 纪律）。若未来要实现"跨段阅历的可分离证明"，需先实现
   DeferredLoop 态的无损 save/load（新实验预注册，docs/257 §五.1 同款）。
7. **野流支持流的诊断**：S1-S3 无段结构（单内容族），只承担判据 2(a)(b) 与守卫；
   scene_switch_diag 帧差近似为诊断级（无 GT，docs/248 §1.7 同款），不进判据。
8. **与 docs/253/254（L4 两格）的关系**：本格不依赖槽位分裂路径（§1.2 机制不含
   c2/账本/分裂），判据对象（段级习得成本 vs L4 组合结构）正交；docs/256（L4 第三格）
   不受本实验影响。
9. **安全纪律**：stdout 只输出 R_L5B_* ASCII 摘要行；运行经 powershell 包装重定向；
   数字用 extract_r.py 纯 python 正则抽取；未用 read 工具读取任何输出文件
