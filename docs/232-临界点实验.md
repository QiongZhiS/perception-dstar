## 〇、一句话（预注册 + 结论）

> **把预测-残差回路（docs/227 的 Transduction2D 同款：对数域双 EWMA 背景预测 +
> 自适应阈值 + 事件累积）放进参数化的环境复杂度梯度（L0 静态 → L6 近乎不可预测），
> 逐级测三个可操作度量：M1 预测误差轨迹、M2 残差利用率、M3 参数位移 vs 结构变化
> （离散记忆表的新条目/新技能节点/不可逆阈值跳变）。判据先写死：若存在某个中间级
> 出现"稳定新增的结构"（SC2 种子多数派 + 后半程仍在涌现 + 低 churn + 阈值未顶格）
> → H3 获得首个直接证据；若任何复杂度都不出现 → F3 触发、H3 作废（这本身是有效
> 结果，照实报告）。**结论：临界点存在（L5 regime_switch，部分可预测但永远有落空
> 的中间态）：SC2=2.8±0.42 稳定新增结构、SC_late 0.9、θ 未顶格；L1-L4 结构饱和、
> L6 噪声放大器（θ 顶格 0.987）；F3 不触发。**

## 一、设计（预注册）

### 1.1 环境复杂度梯度（参数化定义）

环境 = 160×120 灰度合成场景（24px 棋盘格背景 64/96 + 移动亮圆 255，240 帧 @30fps
（8 秒）。**参数化四元组**：`(n_obj, speed, regularity, noise)` + 附加 `light`：

| 参数 | 语义 | 取值说明 |
|---|---|---|
| `n_obj` | 移动目标数 | 0-3 |
| `speed` | 轨迹频率/振幅比例 | 匀速圆周运动的角频率/半径乘性标度（0-1.2；匀速 → 速度大小恒定，速度档不随相位漂移） |
| `regularity` | 规律性（确定性比例） | 1.0=纯确定性轨迹；0.2=近随机（位置叠加平滑随机游走，幅度 ∝ 1−regularity） |
| `noise` | 传感器高斯噪声 σ（灰度域） | 0.8-8.0 |
| `light` | 全局光照事件 | none / dips（两处 0.5s 降幅，docs/227 闪变段同款）/ flashes（4 次随机短闪） |

**梯度（复杂度单调递增，L0..L6）**：

| 级 | 名称 | n_obj | speed | regularity | noise | light | 复杂度直觉 |
|---|---|---|---|---|---|---|---|
| L0 | static | 0 | 0 | 1.0 | 0.8 | none | 完全可预测（收敛后空转） |
| L1 | regular_slow | 1 | 0.5 | 1.0 | 0.8 | none | 规律慢运动 |
| L2 | regular_fast | 2 | 1.0 | 1.0 | 0.8 | none | 规律快运动（多目标） |
| L3 | regular_flicker | 2 | 1.0 | 1.0 | 0.8 | dips | 规律运动 + 全局闪变 |
| L4 | noisy_regular | 2 | 1.0 | 1.0 | 3.0 | dips | 带噪声的规律（信号仍可分离） |
| L5 | regime_switch | 1 | 1.0 | 0.7 | 3.0 | dips | **部分可预测但永远有落空（中间态候选）** |
| L6 | near_unpredictable | 3 | 1.2 | 0.2 | 8.0 | flashes | 近乎不可预测（随机游走 + 跳变 + 高噪声 + 闪变） |

L5 的设计语义：目标是**段式规律（regime switching）**——每 ~80 帧切换一次速度
档（speed 乘子 [0.4, 2.2, 1.0]）并重抽相位（单目标，避免多目标交叠污染签名）。
段内匀速圆周运动可预测、切换点不可预测（相位跳变 = 惊喜）——"规律 + 落空"并存，
回路既不能把轨迹全吸收、也不能说它无规律。这就是 docs/231 §四.1 要的"部分可预测
但永远有落空"区间。对照：L4 是"确定规律 + 传感器噪声"（信号仍可完全分离），
L6 是"近随机"（随机游走 + 跳变 + 高噪声 + 闪变）。

随机性：每 (级, 种子) 一个独立 rng（seed×7919 + level×104729 + 13）驱动目标相位/
随机游走/噪声抽样/闪变时序；种子间强度抖动 jitter=0.25（噪声 σ 与游走幅度乘性
±25%，docs/228 主协议同款）。

### 1.2 预测任务（每一级相同）

回路每帧做**下一帧 log 亮度预测**：`prediction = 快 EWMA 背景 bg_fast`（α_fast=0.5，
docs/227/transduction.py 同款），`预测误差 = |L − bg_fast|`；慢通道 bg_slow（α=0.03）
作长积分背景（忠实保留双时间尺度机制，度量只用快通道残差）。预测任务在各级完全
一致——**只换环境，不换任务**（实验对照的唯一变量是环境复杂度）。

### 1.3 三个度量的可操作定义

**M1 预测误差轨迹**：每窗口（window=10 帧）的 `mean|L − bg_fast|` 时间序列。
摘要：全程均值 `mae_mean`；趋势斜率 `mae_slope = mean(后 1/4 窗口) − mean(前 1/4 窗口)`
（<0 回路在变好，≈0 收敛，>0 发散=噪声放大器）；事件率 `ev_mean`（残差超 θ 的
像素占比均值）。

**M2 残差利用率**（残差有多大比例被回路"接住"并用于学习）：
- `util_attention` = 超死区像素占比均值（`mean(|c| > deadband)`）——回路"注意到"了多少残差；
- `util_learning` = **结构学习响应窗口占比**——窗口内发生 pattern 节点匹配/创建的
  比例——注意到残差后有多少比例真正被用于**结构**学习（参数适应单独由 param 度量）。
头部指标取 `util_learning`（结构吸收率），`util_attention` 作支撑。

**M3 参数 vs 结构变化量**（本实验的操作化核心）：

| 指标 | 定义 | 计算 | 类别 |
|---|---|---|---|
| `param` | 连续参数位移 | Σ_t (|Δθ_t| + |Δdb_t|)；θ/db 只抬不降、有界 [θ0, 0.6]/[db0, 0.15]（docs/185 同款） | 参数 |
| `pin` | 阈值顶格占比 | 窗口内 θ ≥ 0.999·θ_max 的比例 | 参数（饱和信号） |
| `SC1` | 新记忆条目创建数 | pattern 表（签名→节点）新增节点总数 = 离散记忆表基数增长 | **结构** |
| `SC2` | 新增技能节点数 | 命中 ≥ 3 次的节点数（被反复使用、稳定的新技能节点） | **结构（头部）** |
| `SC_late` | 后半程仍涌现的**稳定**节点数 | 创建窗口 ≥ 总窗口/2 **且** 命中 ≥ hits_min 的节点数（结构在后期持续涌现并稳定=自驱动；饱和=空转） | **结构** |
| `SC3` | 不可逆阈值跳变数 | θ 一步 > 25%（θ_t > 1.25·θ_{t-1}）的窗口数；只抬不降 → 不可逆 | 结构（灰区） |
| `SC4` | 休眠后保留条目数 | 最后触发后 ≥ 5 窗口仍保留在表中的节点数（刺激消失后记忆条目不消失=不可逆） | 结构 |

pattern 签名 = **运动能量档**：窗口事件总量（union px）的对数分档
（[150, 450, 1000, 2500] px/窗口 → 档 0-4）。设计说明：运动能量 ∝ 目标扫过的新
像素量 ∝ 速度——匀速目标能量稳定；L5 速度换档（regime 切换）→ 能量档跳变 →
新条目；目标交叠/位置横穿不产生伪条目（预注册前诊断出的 centroid/region churn
已规避）；事件不足（<10px，静态/无事件窗口）无签名、不产生条目。同一签名连续
出现 k_consist=3 窗口且无此节点 → 创建节点（新记忆条目）。

**为什么 SC 指标能区分"参数微调"与"结构变化"**：
- **参数微调**：在 t=0 就已存在的固定槽位（θ、db）内做连续值移动——槽位数恒定、
  值有界（[θ0, θmax]）、位移可累加（param）。回路"变敏感/变保守"，但机制集合不变。
- **结构变化**：改变**离散记忆表的基数**——新槽位（pattern 节点）被分配，是
  t=0 不存在的实体，移除它即丢失行为（匹配/命中计数消失）；且带不可逆性
  （SC3 只抬不降的跳变、SC4 刺激消失后条目仍保留）。
- 判别式：**SC1/SC2/SC_late/SC4 > 0 且 param 有界** → 发生了参数空间之外的离散
  新增（结构变化）；param 高而 SC 恒 0 → 纯参数空间内的调优。SC3 是灰区（参数
  的离散化不可逆跳变），单独报告不并入结构主张。

### 1.4 分级判据与临界点判据（预注册，先于看数据）

对每级跨种子聚合：`sc1_frac`=SC1≥1 的种子比例、`sc2_frac`=SC2≥1 的种子比例、
`sc_late_frac`=SC_late≥1 的种子比例、`stab`=SC2 均值/max(1,SC1 均值)、`pin_mean`、
`att_mean`、`ev_mean`、`util_mean`。分级（自上而下首个命中）：

1. **idle（空转）**：`sc1_frac == 0` 且 `ev_mean < 1e-3` 且 `util_mean < 0.1` 且
   `pin_mean < 0.9`——回路无事件、无学习、无结构、阈值未顶格（环境被完全预测/
   没有可预测的东西；阈值顶格说明回路在"使劲"而非空转，归 noise_amp）。
2. **self_driven（自驱动）**：`sc2_frac ≥ 0.6` 且 `sc_late_frac ≥ 0.6` 且
   `stab ≥ 0.3` 且 `pin_mean < 0.9`——稳定新增结构 + 结构仍在涌现 + 低 churn +
   阈值未顶格（不是"噪声全开"）。**H3 的直接证据形态。**
3. **noise_amp（噪声放大器）**：`pin_mean ≥ 0.9` 或（`att_mean ≥ 0.05` 且
   `sc2_frac < 0.6`）——残差恒非零、结构无法稳定、阈值顶格。
4. **partial（中间态候选）**：`sc1_frac ≥ 0.6`——结构被创建但未进入持续涌现
   （饱和或创建无固化）。
5. **tuned（纯调参）**：其余——参数在动、无结构。

**临界点存在** = 升序扫描梯度，第一个 `self_driven` 级存在 **且** 它不是最高复杂度级
（必须是"中间态"，符合 docs/231"恰好区间"语义）。报告该级索引与现象。

**F3 证伪（H3 作废）** = 没有任何一级 `self_driven`。若出现"所有级都是 partial"
（创建无固化），按"无稳定结构变化"判读，偏证伪（H3 要求"不调参数的新技能/新维度"，
需要稳定），照 docs/63 纪律如实报告、不强行下结论。

### 3.2 临界点判定（按 §1.4 预注册判据，判据在最终运行前冻结）

| 判据项 | L5 数值 | 判定 |
|---|---|---|
| sc2_frac ≥ 0.6 | 1.00 | ✓ |
| sc_late_frac ≥ 0.6 | 0.90 | ✓ |
| stab = SC2/SC1 ≥ 0.3 | 0.97 | ✓ |
| pin_mean < 0.9 | 0.021 | ✓ |
| 升序第一个 self_driven | L0 idle / L1-L4 partial | ✓ |
| 非最高复杂度级 | L5 < L6 | ✓ |

**临界点存在：L5（regime_switch，"部分可预测但永远有落空"中间态）**。该级回路
出现参数空间之外的稳定新增结构（SC2=2.8±0.42），且结构在后半程仍在涌现
（SC_late 0.9），旧 regime 条目休眠后保留（SC4=1.8，不可逆记忆），阈值未顶格
（pin 0.02）——不是"噪声全开"的假结构。**H3（回路自驱动）获得首个直接证据形态。**

F3 判据：**不触发**（`R_F3=not_triggered`）——结构变化在 L1-L6 各级都存在（稳定
技能节点 SC2 ≥ 1），自维持的结构变化特定出现在中间态 L5，H3 未被证伪。

### 3.3 结构变化量（M3 的核心数值）

| 级 | SC1 新记忆条目 | SC2 稳定技能节点 | SC_late 后期涌现 | SC3 不可逆阈值跳变 | SC4 休眠保留条目 | param 参数位移 | 判读 |
|---|---|---|---|---|---|---|---|
| L0 | 0 | 0 | 0 | 0 | 0 | 0.026 | 无结构（空转） |
| L1-L4 | 1.0-2.0 | ~1.0 | ≈0 | 0 | 0-1.0 | 0.03-1.52 | 学会唯一规律后**饱和**（结构存在但不再涌现） |
| **L5** | **2.9** | **2.8±0.42** | **0.9** | 0 | **1.8** | 1.573 | **自驱动**：3 个新条目（3 个速度 regime 各 1 个）、持续涌现、休眠保留 |
| L6 | 1.0 | 1.0 | 0.1 | **2.1** | 0 | 0.569 | 阈值顶格（pin 0.987）→ 噪声放大器；SC3=2.1 次不可逆跳变 |

**"参数微调" vs "结构变化"的区分在本数据中的体现**：
- 参数指标（param 连续位移）随复杂度单调上升（L1 0.03 → L5 1.57），是固定槽位
  （θ/db，t=0 即存在、有界 [0.15, 0.6]/[0.015, 0.15]）内的连续值移动；
- 结构指标（SC1/SC2/SC4）是**离散记忆表的新增条目**（t=0 不存在的槽位），
  移除即丢失行为（命中/匹配计数消失），且带不可逆性（SC4 休眠保留、SC3 只抬
  不降跳变）。L5 的 SC2=2.8 是在 param 有界（θ 未顶格）的同时发生的离散基数
  增长——**参数空间之外的离散新增**，即 docs/231 要的"不调参数的新技能/新维度"
  的可计算版本。L5 的 3 个节点恰好对应 3 个速度 regime（seed0：`(1,)` c2、
  `(3,)` c9、`(2,)` c21）——速度换档 → 新记忆条目。

### 3.4 诚实边界（docs/63 纪律，全部照实）

1. **Toy 场景**：160×120 合成棋盘格 + 圆形目标，非真实视频；"技能节点"是运动
   能量档的记忆条目，不是真实技能树/维度——本实验只测行为签名（条目数/轨迹/
   阈值），不宣称体验或真实技能。
2. **校准循环**：环境/回路参数（目标亮度/半径、背景亮度、k_theta、能量档边界、
   regime 速度乘子、dips 位置、k_consist）在诊断轮中为消除伪条目做过校准；
   **分级判据（classify 函数）在最终运行前冻结**，未因结果调整。一处判据精化
   记录在案：SC_late 从"创建 ≥ 总窗口/2"精化为"创建 ≥ 总窗口/2 **且**命中 ≥ 3"
   （排除单次命中的伪后期条目）——精化发生在最终运行前，属于判据定义，非结果驱动。
3. **L6 的 SC2=1** 来自阈值顶格前的早期瞬态（θ 从 0.15 升至 0.6 的约前 10 帧内
   形成的 1 个条目），顶格后事件被压制——L6 的"1 个稳定节点"不是持续结构，
   判级仍为 noise_amp（pin 0.987）。SC3=2.1 次不可逆阈值跳变是该级的结构信号。
4. **L2/L4 各有 1/10 种子出现 SC_late=1**（目标交叠/速度对齐的偶发后期条目）——
   低于 0.6 阈值不影响判级，但说明"后期涌现"不是 L5 的绝对独有。
5. **负的 MAE 斜率**部分来自闪变/换档瞬态被吸收（L5 前 1/4 窗口含第一处闪变），
   不纯是"回路变好"；基线误差在闪变间基本持平（L5 seed0：0.019→0.020）。
6. **param 是每帧 |Δθ|+|Δdb| 的累积和**（θ 只抬不降），L4/L5 的 ≈1.5 是噪声驱动
   的渐进抬升累积，不是单次大跳（SC3=0 与之自洽：无单窗口 >25% 的跳变）。
7. **临界点主张的边界**：L5 是"第一个自驱动级"且非最高级，满足预注册定义；但
   环境梯度与参数是合成构造，"临界点恰好落在设计候选级"存在循环风险——判据
   冻结 + 校准记录（边界 2）是唯一的对冲，仍需真实视频/不同回路复现才能升级
   为强证据。
8. **统计**：10 种子 × 7 级，mean±SD（ddof=1）+ 2000 次 bootstrap CI；总计算
   16.2 秒（预算 60 分钟）；工件 cp_main.json 含全部逐窗口 trace 可复核。
