## 三、方法论资产（比任何实验值钱）

1. **预注册纪律**（docs/63）：判据先于数据冻结，结果后不改判据（除诚实边界记录的精化）。
2. **防循环/留出**：参数只依校准集、留出集零贡献、单次确定性 pass、无回调（docs/244/245/246 全程合规）。
3. **守卫**：每实验带"同代码路径复现前一格"的守卫（12/12 项比对，如 R_*_GUARD_D246）。
4. **泛化层级标签**（docs/247）：每判据必标 `[L#][参数/机制][证明方式]`。
5. **假对照**（docs/237）：排除统计伪影。
6. **安全纪律**：脚本输出落盘、只报 exit/字节、数字用纯正则抽取、输出文件人可读模型禁读、子代理隔离。
