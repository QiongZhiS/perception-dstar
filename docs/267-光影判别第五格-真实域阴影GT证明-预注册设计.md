## 一、设计（预注册，冻结；数据源/机制/判据/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

前四格的共同缺口 = **无真实阴影 GT**（docs/260/261/263 的 θ_L 与阴影掩码是合成场景
参数；docs/265 真实视频无阴影 GT → 第四格只能做行为诊断，docs/265 §五 8 明示下一步
= 带阴影 GT 的数据集）。本格目标 = **真实域证明**：

1. **REAL_SHADOW_PREC_REC（核心）**：在带阴影 GT 的公开数据集上，把合成三连判别
   机制原样（零重调）跑在真实像素上，对真实阴影标注量化标准检测度量（pooled 逐像素
   precision/recall/F1，docs/219 同款）。**直接回应 docs/265 的两个失败模式**：过检
   （整个背景被判阴影，precision 低）、漏检（阴影漏判，recall 低）。
2. **WHITE_OBJ_RECALL**：量化用户报告的漏检模式②——"阴影下的白色石头不被判为
   阴影"：GT 阴影内**亮目标**（无阴影参考图中亮度 ≥ 128 的表面）像素的召回率。用
   数据集自身的 shadow-free 参考图构造该分型（不注入、不合成）。
3. **KEEP**：合成三连 + 第四格能力不退化（守卫：import 第三格 run_unit_reflect 与
   第四格 flamingo 重跑，冻结数字逐位一致）。
4. **诚实对照 docs/265**：docs/265 = DAVIS 行为诊断（无阴影 GT）；本格 = ISTD 带
   GT 量化证明。分工与两失败模式的量化映射写入 §五 7。

范围收窄（诚实，与 docs/265 一致）：判别对象 = **最大暗域候选**（单候选，检测路径
产物，docs/260/261/263/265 同款）；"纹理"通道在静态域 = 时间门不过的暗区（静态域
近恒过，如实报告触发率）；多候选区域未建模；真实图无光照 GT → V3/E2 的"光照方向"=
帧内估计 θ_est（docs/265 同口径）。

### 1.2 数据与预处理（冻结）

- **数据源（冻结）：ISTD**（Jifeng Wang 等，CVPR 2018，ST-CGAN："Stacked Conditional
  Generative Adversarial Networks for Jointly Learning Shadow Detection and Shadow
  Removal"）——1870 场景三元组：阴影图 A + 阴影掩码 C（GT，255=阴影）+ 无阴影参考
  图 B（同场景人工去阴影）。官方划分 train 1330 / test 540。**选择理由（冻结，探测
  记录见 §五 1）**：任务优先序第一的 SBU-shadow（4085 图）官方下载在 Google Drive
  （本机不可达）且无 GitHub/HuggingFace 可达镜像；SRD 无可达镜像；ISTD 在
  hf-mirror.com（HuggingFace 国内镜像，本机可达，官方 HF 502）上有完整镜像
  （CK234/tmp_ISTD，5611 文件 = 1870×3 图像 + gitattributes，已核实目录结构
  test/test_A|B|C 各 540、train/train_A|B|C 各 1330）。**且 ISTD 的 shadow-free
  参考图 B 是 Pass A"该像素常见亮度"的忠实载体**（§1.3 论证）——这是 SBU（无参考图）
  给不了的机制贴合。数据下载到 **D:\datasets\ISTD**（项目外，路径注明）；图像/掩码
  是数据（可读），非毒文件。
- **预处理（固定流水线，docs/265 §1.2 同款冻结）**：PNG → `cv2.imread(IMREAD_COLOR)`
  （BGR 640×480）→ 灰度 `cv2.resize(160×120, INTER_AREA)` → uint8（机制工作点）；
  彩色帧同样 resize 到 160×120（INTER_AREA）供 V4/E3 边界环带采样（BAND_EDGE=2px 在
  160×120 空间标定）；GT 掩码 `cv2.resize(160×120, INTER_NEAREST)` → bool（>0）。
- **单位（冻结）**：单位 = 每场景一次运行（1870 单位：train 1330 + test 540）；每
  单位 2 帧 [B（无阴影参考帧）, A（阴影帧）]；**评估帧 = A**（有 GT 掩码），B 只作
  适应参考（同视频 WARMUP 帧不进评估窗口的先例，docs/260 §1.3）。评估全部 1870 单位
  （机制零训练 → 无泄漏；train/test 分列报告）。帧顺序 [B, A] 的理由：参考 = "无
  阴影的常见状态"，事件 = "阴影出现"（视频语义"常见亮度 → 此刻变暗"的静态等价）。
- **无注入、无 jitter、无 RNG**（docs/243 §1.1 声明同款）：数据集本身确定性；统计
  外壳 = 单位级 mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828，
  critical_point 同款）。
- 色彩空间注意（docs/265 §1.2 同款）：`reflect_stats` 期望 RGB 序——cv2.imread 给
  BGR，V4/E3 前显式 `cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)` 转换。

### 1.3 机制（冻结；import 复用四格判别核心，零重调、零改动）

**静态图像 → 流式机制的适配（论证并冻结）**：

1. **单帧门不可行（机械论证）**：冻结 Pass A = 全程帧每像素 0.95 分位亮度（排除
   L>log(221) 亮帧，docs/260 诊断轮 D2 冻结口径，`compute_ref_dark` 逐字）。单帧时
   n=1 → ref_dark = 帧自身 → dark = (L−L) > δ 恒 False → **单帧无法构造"常见亮度"
   参考**。静态数据集必须构造时间代理。
2. **冻结适配 = 场景对（2 帧单位）**：每场景 [B, A]，Pass A 在 [B_gray, A_gray] 上
   计算（同 `compute_ref_dark` 逐字，n=2 → 逐像素 0.95 分位 = 逐元素 max(B, A)，
   亮帧排除按冻结语义）。**B = 该场景"无阴影时该像素的亮度"（数据集人工构造的真
   参考）**——正是 Pass A 在视频里计算的语义（该像素常见亮度）；A 中阴影像素 =
   低于参考 → 判暗；A 中非阴影像素 ≈ B ≈ 参考 → 不判暗；B 自身（参考帧）判暗 ≈ 空。
3. **时间门**：A 帧 dark_prev = B 帧暗候选（≈ 空 → IoU=0 → move=1 ≥ MOVE_IOU →
   门过，active 由面积门单独成立）；静态域无自然运动 → "纹理/静态"通道几乎不触发
   （如实报告 texture 率；docs/265 §五4 已声明"纹理载体收窄"，静态域进一步收窄为
   近零——诚实边界 §五 3）。

**判别机制（逐字复用 docs/265 第四格 `diagnose_frame`，单帧判别函数同源）**：

```
Pass A（适应，每单位一次）：ref_dark = [B,A] 逐像素 0.95 分位（排除 L>log(221) 亮帧）
    → ref_dark_log = log(ref_dark+1)                    # compute_ref_dark 逐字
Pass B（判断，A 帧）：L = log(gray+1)
    dark = (ref_dark_log − L) > DELTA_SHADOW=0.35
    d_mask, d_area, d_c = largest_component(dark)        # 8-连通域，面积 ≥ A_MIN=25
    bright = L > log(221)；b_mask, b_area, b_c = largest_component(bright)  # θ_est 载体
时间门：active = (d_area ≥ A_MIN) AND (move is None OR move ≥ MOVE_IOU=0.05)
否决门链：V1 闭合轮廓（not touches_boundary）／V3 主轴方向（PCA 比值 ≥ RATIO_MIN=1.5
    时，主轴与 θ_est 无向夹角 > TOL_AXIS=30°）／V4 反射率跳变（边界环带 BAND_EDGE=2px
    两侧中位 H/S，SAT_MIN=60 过滤；ΔH > TOL_H=15° 或 ΔS > TOL_S=80）
证据门：E1 = 开放拓扑（V1 反）／E2 = 主轴沿光（V3 反，各向同性/无 θ_est 时不适用）
    ／E3 = 反射率连续（ΔH≤15° 且 ΔS≤80；彩色像素不足不适用）
标签：无候选 = none；候选且时间门不过 = texture；时间门过且 veto=V1∨V3∨V4 = object；
    时间门过且无 veto = shadow
```

- **θ_est（帧内估计，docs/265 同口径）**：`θ_est = angle(亮候选质心 − 暗候选质心)`
  （度，x 右 y 下，CCW 从 +x 起）；无亮候选 → θ_est = None → V3/E2 不适用（如实报告
  V3 适用率）。真实图无光照 GT → θ_est 是几何自洽的行为读数，非真值验证（docs/265
  §五 6 同款）。
- **预测回路（CPLoop）不进入判别**（docs/265 §1.3 同款声明）：真实静态数据直接
  Pass A/B，不含 CPLoop。
- **旋钮（冻结；全部继承四格冻结值，零新增机制旋钮、零重调）**：

| 旋钮 | 值 | 来源（冻结引用） |
|---|---|---|
| DELTA_SHADOW | 0.35 | docs/260 §1.3 |
| A_MIN | 25 px | docs/260 §1.3 |
| K_MOVE / MOVE_IOU | 10 帧 / 0.05 | docs/260 §1.3（D2 冻结） |
| OCC_LUM_THRESH（判亮/排除亮帧） | 220 | docs/260 §1.3（D2 冻结） |
| ref_dark 分位 / 排除带 | 0.95 / L>log(221) | docs/260 §1.3（D2 冻结） |

### 1.4 判据（冻结；每条带 docs/247 层级标签；真实域证明级，诚实口径）

评估单位 = 每场景一次运行（1870 单位）；**预测** = 每单位 A 帧上 label=**shadow**
时的 d_mask 像素（label≠shadow → 空预测）；**GT** = 掩码 C resize 160×120
（INTER_NEAREST）> 0。**REAL_SHADOW_PREC_REC 用 pooled 口径**（全部单位像素合并 →
TP/FP/FN → P/R/F1，docs/219 标准检测度量同款；与 docs/265 OBJ_NOT_VETOED pooled 先例
一致），同时报告单位级分布（信息性）。统计外壳 = 单位级 mean±SD（ddof=1）+
bootstrap 95% CI（2000 次，种子 20260828，critical_point 同款 import）。

| 判据 | 标签 | 定义（冻结） | 阈值（冻结） |
|---|---|---|---|
| **C1 REAL_SHADOW_PREC_REC** | `[L3][机制][真实域证明]` | pooled 逐像素 TP/FP/FN → precision = TP/(TP+FP)、recall = TP/(TP+FN)、F1 = 2PR/(P+R)（docs/219 同款公式）；行使门槛 = pooled GT 阴影像素 ≥ 50000（不足 → 判据未被行使，报 REAL_SHADOW_LOW） | pooled P ≥ **0.30** 且 R ≥ **0.35** 且 F1 ≥ **0.40**（三条件 AND） |
| **C2 WHITE_OBJ_RECALL** | `[L3][机制][真实域证明]` | 用户漏检模式②的量化：**亮目标像素** = GT 阴影 ∩ 参考图 B 灰度 ≥ **128**（uint8 中亮杠，= "被阴影覆盖的亮表面/白色石头"——用 B 帧本征亮度定义，不用变暗后的绝对亮度）；WHITE_OBJ_RECALL = 该子集内被预测为阴影（label=shadow 的 d_mask 像素）的 pooled 占比；行使门槛 = pooled 亮目标像素 ≥ **2000** 且 ≥ GT 阴影像素 **1%** | pooled 亮目标召回 ≥ **0.30** |
| **C3 KEEP** | `[L3][机制][合成→真实保持]` | 合成三连 + 第四格能力不退化：守卫 R_GT_GUARD_SYNTH（第三格 run_unit_reflect det_gated=1.0 且 cont_rate=1.0）+ R_GT_GUARD_CELL4（第四格 flamingo 重跑：obj_rate=0.7875、shadow_rate=0.2125、V3 触发率=0.7875、θ_med=287.38°，docs/265 §3.1 逐位） | 守卫 = 1（见 §1.6） |

阈值论证（冻结）：0.30/0.35/0.40 = 零重调迁移的**诚实工作杠**——显著高于 trivial
（预测全空 → F1=0）与随机猜测（真实阴影占比低时随机 P/R 远低于此），低于此 = 判别
语义在真实阴影上不成立（否定发现照实报告，docs/265 OBJ_VETOED_FAIL 先例：判定允许
失败作为有效结论）；L_WHITE=128 = uint8 灰度中亮杠（docs/219 判亮精神同域）；
50000/2000/1% = 行使门槛（pooled 像素足够才有统计意义，docs/265 ANCHOR_MIN_FRAMES=20
先例）。均非合成标定值——是**判据口径**参数，先于运行冻结，测行为不测参数（docs/261
§五 2 同款纪律）。

### 1.5 判定映射（冻结）

- 守卫全过 且 C1 过（P/R/F1 三条件 AND）且（C2 未行使 或 C2 过）→ **REAL_SHADOW_PASS**
  （判别机制在真实阴影 GT 上成立：过检/漏检双控）。
- 守卫全过 且 C1 不过（GT 像素 ≥ 50000，判据被行使）→ **REAL_SHADOW_FAIL**（按名报
  P_FAIL / R_FAIL / F1_FAIL——合成判别语义在真实阴影上不成立，诚实否定发现）。

  （按名报 C2_FAIL：C1 过但漏检模式②判据不过 → 整体失败，照实报告）。

  行为读数）。

  行使，不判过不过），不进主判定。

- C3 KEEP 为报告性（守卫载体，不进独立判定）。

> REPRO）、确定性成立（timing 两轮与 diag/main 逐位一致）。**过检/漏检两个失败模式
> 被分开量化：precision 0.99 = "判为阴影"几乎总是对（过检可控——ISTD 场景对下未
> 复现用户"整个背景被判阴影"的 DAVIS 现象）；recall 0.41 = "判为物体"代价高（漏检
> 显著——否决门链把 ~35% 真实阴影误判为物体，V1 闭合 0.1137 / V3 偏离 θ_est 0.1148 /
> V4 边界跳变 0.1916）；WHITE 0.43 = 用户"白色石头不被判阴影"部分成立（过冻结杠
> 0.30 但 57% 亮目标仍漏）。与 docs/265 的机制镜像：暗目标不触发否决被当阴影（第四
> 格）vs 真实阴影触发否决被当物体（本格）——合成"开放拓扑+沿光+连续反射率=阴影"
> 的语义在真实域两侧都不完全迁移，本格以带 GT 的 P/R/F1 把这一图景量化闭环。诚实
> 边界：零重调、单候选、静态域无纹理通道、θ_est 自指、ISTD 数据选择（SBU/SRD 无可达
> 镜像，§五 1 探测记录）——全部照实报告，本格不调参。**

   SBU-shadow（任务优先序第一）：官方下载在 Google Drive（不可达），GitHub/HF/gitee
   均未找到含数据的可达镜像 → **放弃 SBU，如实报告**。SRD：无可达镜像。ISTD：官方
   GitHub（csjfwang/ST-CGAN）README 给 Google Drive 链接（不可达），但 hf-mirror.com
   有完整镜像 CK234/tmp_ISTD（5611 文件，1870 三元组，目录结构已核实）→ **本格数据
   = ISTD**。若下载失败 → 执行降级方案（受控实拍：DAVIS 真实帧注入已知阴影，GT 由
   构造已知——诚实声明为受控实拍，非自然阴影），并在 §三 如实报告。
2. **静态图像进流式的适配代价**：2 帧场景对 [B, A] 中，B = 数据集人工构造的无阴影
   参考（"常见亮度"的真参考，Pass A 语义的忠实映射）；与视频流不同——无自然时间
   运动、无"静态暗区"纹理通道（时间门近恒过，texture 标签近零，如实报告）；B 帧
   与 A 帧的非阴影区在 ISTD 构造中应一致，若存在去阴影伪影则计入检测噪声（如实）。
3. **零重调代价（预期行为）**：三连旋钮标定于合成场景（docs/260 §五 8 / 261 §五 7 /
   263 §五 7 声明）；真实阴影深度/几何/光照任意 → Pass B 检测（δ=0.35 ≈ 半量阴影，
   浅阴影漏检）与否决门链触发率（V1 对闭合阴影误否决、V3 对偏离 θ_est 的阴影误
   否决、V4 对真实边界色相噪声误判）是**行为读数**——预期 recall 可能低（docs/265
   OBJ_VETOED_FAIL 根因的真实域量化），如实报告，不调参（调参 = 破坏预注册冻结）。
4. **判别对象 = 最大暗域（单候选）**（docs/265 §五 5 同款）：多阴影区域/阴影外的大
   暗物体未建模；单候选 + 否决门链 → recall 被"最大暗域必须是阴影"约束。GT 掩码
   resize INTER_NEAREST 有像素化误差。
5. **θ_est 自指性**（docs/265 §五 6 同款）：V3/E2 用帧内估计光照方向，真实图无光照
   GT；"沿光轴的暗区 = 阴影"是几何自洽行为读数，非光照方向真值验证。
6. **WHITE_OBJ_RECALL 的分型口径**：用 B 帧（无阴影参考）亮度 ≥ 128 定义"亮目标"，
   是数据集自带的分型（非注入）；若 ISTD 的 GT 阴影下亮目标像素不足行使门槛 → 报告
   WHITE_OBJ_LOW 不判过（判据未被行使，docs/265 ANCHOR_LOW 先例）。
7. **与 docs/265 的对照分工（冻结）**：docs/265 = DAVIS 真实流行为诊断（无阴影 GT，
   OBJ_VETOED_FAIL——否决门链把 GT 目标误判为阴影）；本格 = ISTD 带 GT 量化证明
   （P/R/F1）。两失败模式映射：**过检（整个背景判阴影）→ pooled precision**；
   **漏检（阴影下白石头不判阴影）→ pooled recall + WHITE_OBJ_RECALL**。docs/265 的
   机制层根因（暗目标大而触边界 V1 不触发 / 无亮候选或主轴沿估计光 V3/E2 失效 /
   边界色相连续 V4 不触发 → 判为阴影）在本格以"真实阴影被否决门误否决 → recall 低"
   的反向形态出现（真实阴影闭合/偏离 θ_est → 判为物体）——两格互为镜像，共同覆盖
   "合成语义不迁移"的完整图景。本格不调参、不宣称改进，只量化。
8. **统计口径**：单位 = 每场景一次运行（1870 单位）；固定确定性流（无种子协议，
   docs/243 §1.1 声明）；pooled P/R/F1（主判据）+ 单位级 mean±SD + bootstrap CI；
   train/test 分列报告。
9. **下一步（超出本格）**：多候选判别、放宽/自适应否决门（以本格数据驱动）、SBU
   数据可达后的跨数据集验证、光照方向真值验证（需带光源方位标注集，docs/265 §五 8）。
