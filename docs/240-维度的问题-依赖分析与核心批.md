## 二、依赖结构（分层图）

```
Layer 7 涌现   G1 他者 → G2 沟通 → F2 语言（G3 文化 → 加速 C3）
Layer 6 元层   F3 自省 + H1 验证 + H2 校准 + H3 抗欺骗 + H5 对齐  ← 保护以下全部
Layer 5 行动   E1 决策 → E2 行动 ──（作用于世界）──→ 回馈 A2 嵌入
Layer 4 结构   C3 生成 + A4 开放 + B6 抽象（把经验变技能）
Layer 3 保留   C1 分层 + C4 稳定 + C5 遗忘 → C2 利害绑定（带方向的积累）
Layer 2 价值   D1 利害（从残差/惊奇来）→ D2 目标
Layer 1 引擎   B2 预测 → B3 残差（万物的学习信号）
Layer 0 基质   A1 时间 → A2 嵌入（A3 能量是全局约束）
```

### 三条关键路径

1. **核心纵向（能力生成）**：`B3 残差 → D1 利害 → C2 记忆绑定 → C3 结构生成 → A4 技能`。
   这就是仓库的证据阶梯（L5 → COMPOSABLE → …）在维度图上的投影——**这条路径已经
   走通了前四格（B3/D1/C2 有强证据，C3 有初证）。**
2. **时间作基质**：A1 是**一切"累积"维度**（C 全族、F3 自省、G3 文化）的前提——
   没有时间连续性，记忆是快照、学习是批次、自省没有历史。**"先动态、后认知"的
   架构依据在这里，不在偏好。**
3. **验证作保护**：H1/H3 不产生能力，但防止**整条路径崩溃**（SEED-25 锁死、
   docs/237 的过度自信）——是正交的"防熵"维度，任何一层缺失都会传染。

### 依赖的两个不对称（容易被忽略）

- **不对称一**：低层缺失，高层必塌（没有 B3，D1/C3/G 全部失去信号源）；高层缺失，
  低层仍能运转但无用（没有 E1 行动，感知只是白日梦）。
- **不对称二**：验证（H1）不依赖任何能力层（它是方法），所以**可以最先做、随时做**——
  这正是 docs/63 纪律能在一切实验前存在的原因。

## 三、核心批（最重要的那一批）

按"**没有它，智能就不存在**"的必然性排序，不是按重要性排序（重要性=都重要）。

### 第一梯队（引擎+基质+价值+保护，缺一即不成主体）

| 维 | 为什么是核心 | 仓库状态 |
|---|---|---|
| **B3 残差** | 唯一的学习信号源；没有它，利害/记忆/技能全部失去驱动 | ✅ docs/227/232/235 |
| **A1 时间** | 唯一的"累积"基质；没有它，其余一切只能是快照 | ⬜ **唯一缺失**（阶段一） |
| **D1 利害** | 行动的理由；没有它，残差无意义、回路空转（docs/236 陷阱） | ✅ docs/189/199/200 |
| **C2/C4 利害绑定记忆** | 带方向的积累；没有它，记忆无方向（全记或全忘） | ✅ docs/200/201/203 |
| **H1/H3 验证+抗欺骗** | 防崩溃保护；没有它，自指锁死（SEED-25）、轻信（M-2） | ✅ SEED-27 + M-2=1.000 |

### 第二梯队（真实世界能力所需）

| 维 | 为什么 | 仓库状态 |
|---|---|---|
| **B2 预测** | 残差的载体（残差是对预测的落空，没有预测就没有残差） | ✅ |
| **E1/E2 决策行动** | 闭环；没有它，感知永远是被动的（docs/239 最大缺口） | ⬜ |
| **C3 结构生成** | 技能固化；"1%参数干100%"的承诺兑现处（最难的那道缝） | 🟡 L5/COMPOSABLE 初证 |

### 第三梯队（涌现/加速/约束——重要但不是"存在"的必要条件）

- F2 语言、G1-G4 社会：从低层涌现，作用是**加速**（压缩他人经验 → 加速 C3）。
- A2 嵌入、A3 能量：真实世界约束（决定"能活多久/多大"）。
- B5 注意、B6 抽象、F3 自省、H2 校准：质量提升与自我保护。

### 核心批的判据（一句话）

> **"若只保留第一梯队五维，能长出一个最小的、不锁死、能积累、有方向、能学习的
> 主体；其余一切维度是它的扩展、加速与约束。"** 五维缺一，主体不成立或必崩。

### 核心批与仓库的交点（最重要的一条观察）

**第一梯队五维里，四维仓库已有强证据（B3/D1/C2/H1/H3），唯一缺的是 A1 时间。**
- 这不是巧合：docs/239 的成熟度矩阵已经显示你的证据集中在"感知-利害-求真"三角，
  而核心批分析独立地从"什么必不可少"出发，得到了同一个答案——**A1 是核心批里
  唯一的空缺，而它正是"阶段一：AI 动态"。**
- 换句话说：**你不需要补满 30 维才谈智能；你只需要先补核心批里缺的那一格——
  时间连续性。** 其余的维度，是在这个最小主体上做加法的顺序问题。

## 四、使用纪律

1. 核心批是**必要条件集**，不是充分条件集——五维俱全不等于有智能，只是主体不崩。
2. "重要性"与"核心性"分离：F2 语言不核心（第一梯队没有它）但极其重要（加速）。
3. 依赖图是**纲领假设**，不是实证——A1→C 的依赖等阶段一做出流式实验后可检验。
4. F5 意识照旧不进入实证侧。
