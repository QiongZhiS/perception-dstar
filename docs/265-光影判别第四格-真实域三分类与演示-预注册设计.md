## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/260/261/263 三连全部是**合成受控、非真实域证明**（θ_L 与阴影 GT 是场景参数，
真实域不存在）。docs/243（半真实）已演示"真实像素上机制迁移检验"的形态（零重调、
无真值标签、窗口级统计、诚实声明）。本格目标 = 把三连的判别机制原样迁移到 DAVIS
真实流，做**真实域诊断**：

1. **三分类诊断**（核心）：在 DAVIS 真实像素上运行三连判别（检测路径 + 时间门 +
   否决门链 + 证据门），每帧对最大暗域给出"物体 / 纹理 / 阴影"标签，逐视频聚合，
   报告行为分布。**无真值可对 → 诊断级**（docs/243 §1.3"无真值标签"同款精神）。
2. **GT 锚判据**（唯一有真值可对的判据）：DAVIS GT 掩码（PNG）给出目标物体区域
   （flamingo/黑天鹅/车/人等），验证**否决门链不把 GT 目标误判为阴影/纹理**——
   "目标物体不被否决门误伤"是 docs/261 C2（POS_DETECT_KEEP）/ docs/263 C4
   （V4 假否决率）的真实域迁移形态。
3. **演示接入**：三分类读数接进 `vision/demo2_app.py`（新增"光影面板"），观众在
   真实视频上直接看见"它把什么当物体、什么当纹理、什么当阴影"。
4. **KEEP（诊断级）**：合成三连能力在真实域的迁移形态——光照方向估计（θ_est，
   docs/260 C2 口径）在 DAVIS 上的读数分布（无 GT，报告）；与演示现有读数
   （MAE/ratio/SC2，docs/257）不冲突。

范围收窄（诚实）：判别对象 = **最大暗域候选**（检测路径产物，docs/260/261/263
同款）；"纹理"在本格的载体 = **静态暗区**（时间门不过 = 静止暗内容 = 纹理/静态
明暗；被 ref_draw 吸收的静止纹理根本不构成候选 = docs/187"静止纹理被预测掉"的真实
域复现）；不建模"随背景运动的纹理"（docs/187 完整缺口，§五 7）。真实域无光照 GT：
V3/E2 的"光照方向"用**帧内估计 θ_est**（docs/260 C2 同口径，无亮候选时 V3/E2 = 不
适用，如实报告适用率）。

### 1.2 数据与预处理（冻结）

- **数据**：`vision/out/davis/<video>/` 的 JPEG 原帧（854×480 彩色，每视频 N 帧：
  flamingo 80 / surf 55 / bear 82 / camel 90 / dog 60 / blackswan 50 / car-turn 80 /
  motorbike 43 / soccerball 48，共 **588 帧**；`real_stream_test.VIDEOS` 同源）+ GT
  掩码 PNG（二进制：目标物体白、其余黑）。
- **预处理（固定流水线，docs/243 §1.1 同款冻结）**：JPEG → `cv2.imread(IMREAD_COLOR)`
  → 灰度 `cv2.resize(160×120, INTER_AREA)` → uint8（机制工作点）；彩色帧同样 resize
  到 160×120（INTER_AREA）供 V4/E3 边界环带采样（docs/263 BAND_EDGE=2px 在 160×120
  空间标定）；GT 掩码 `cv2.resize(160×120, INTER_NEAREST)` → bool（>0）。
- **无注入、无 jitter、无 RNG**（docs/243 §1.1 声明）：真实像素流本身确定性（固定
  JPEG 序列）；统计外壳 = 帧级聚合 + 跨视频单位 mean±SD（ddof=1）+ bootstrap 95% CI
  （2000 次，种子 20260828，critical_point 同款）。
- 色彩空间注意：`reflect_stats`（第三格逐字 import）期望 **RGB 序**数组（内部
  COLOR_RGB2HSV）——真实帧 cv2.imread 给出 BGR，V4/E3 前显式
  `cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)` 转换（实现细节，机制口径不变）。

### 1.3 机制（冻结；import 复用三连，零重调、零改动，预测路径不进入判别）

**检测路径（Pass A/B，docs/260 诊断轮 D2 冻结口径逐字复用）**：

```
Pass A（适应，每视频一次）：ref_dark = 全程帧 0.95 分位亮度（排除 L>log(221) 的亮帧）
    → ref_dark_log = log(ref_dark+1)
Pass B（判断，每帧）：L = log(gray+1)
    dark = (ref_dark_log − L) > DELTA_SHADOW=0.35
    d_mask, d_area, d_c = largest_component(dark)          # 8-连通域，面积 ≥ A_MIN=25
    bright = L > log(221)；b_mask, b_area, b_c = largest_component(bright)   # 亮候选（θ_est 载体）
```

**预测回路不进入判别**（如实声明）：docs/260/261/263 的检测全部基于 Pass A ref_dark
（诊断轮 D2 后冻结口径），合成脚本中的 CPLoop 只被 step 但输出不用于判别；真实域
诊断直接复用 Pass A/B，不含 CPLoop。

**时间门（docs/260 C1 同款）**：`move = 1 − IoU(d_mask, d_mask[t−10])`；
`active = (d_area ≥ A_MIN) AND (t ≥ K_MOVE) AND (move ≥ MOVE_IOU=0.05)`。

**三分类语义（冻结；真实域诊断口径）**：

| 条件（按序判定） | 标签 | 语义（docs 依据） |
|---|---|---|
| d_area < A_MIN（无候选） | **none**（无暗候选） | 无判别对象 |
| 候选 且 时间门不过（静态暗区） | **纹理/静态** | docs/187：静止暗内容 = 静态纹理/静态明暗（"静止纹理被预测掉"的适应不完全形态；被 ref_dark 吸收的静止纹理根本不构成候选 = docs/187 机制直接复现） |
| 候选 且 时间门过 且 veto = V1∨V3∨V4 | **物体** | docs/261/263：任一否决门触发 → 判为物体/非阴影 |
| 候选 且 时间门过 且 无否决 | **阴影** | docs/260 C1 + docs/261/263 联合判别：开放拓扑 + 沿光照 + 反射率连续 = 阴影 |

**否决门链（docs/261/263 逐字 import；V3 的"光照方向"= 帧内估计，见下）**：

```
V1 闭合轮廓否决：not touches_boundary(d_mask) → 否决（E1 = touches = 开放拓扑证据）
V3 主轴方向否决：PCA 特征值比 ≥ RATIO_MIN=1.5 时，主轴与 θ_est 无向夹角 > TOL_AXIS=30°
    → 否决（E2 = 夹角 ≤ 30°）；各向同性（比值 < 1.5）→ V3 跳过（不适用，E2 不适用）
V4 反射率跳变否决：边界环带（BAND_EDGE=2px）两侧中位 H/S（SAT_MIN=60 彩色过滤）；
    ΔH = circ(hue_in, hue_out) > TOL_H=15° 或 ΔS = |sat_in−sat_out| > TOL_S=80 → 否决
    （E3 = ΔH≤15° 且 ΔS≤80 = 反射率连续证据）；彩色像素不足（<5）→ V4 不触发、E3 不适用
veto = V1 OR V3 OR V4
```

**θ_est（光照方向，帧内估计；docs/260 C2 同口径，真实域无光照 GT）**：
`θ_est = angle(亮候选质心 − 暗候选质心)`（度，x 右 y 下，CCW 从 +x 起）。无亮候选
（b_c = None）→ θ_est = None → V3/E2 = **不适用**（如实报告 V3 适用率）。

**旋钮（冻结；全部继承三连冻结值，零新增机制旋钮、零重调）**：

| 旋钮 | 值 | 来源（冻结引用） |
|---|---|---|
| DELTA_SHADOW | 0.35 | docs/260 §1.3 |
| A_MIN | 25 px | docs/260 §1.3 |
| K_MOVE / MOVE_IOU | 10 帧 / 0.05 | docs/260 §1.3（诊断轮 D2 冻结） |
| OCC_LUM_THRESH（判亮/排除亮帧） | 220 | docs/260 §1.3（D2 冻结） |
| ref_dark 分位 / 排除带 | 0.95 / L>log(221) | docs/260 §1.3（D2 冻结） |
| TOL_AXIS / RATIO_MIN | 30° / 1.5 | docs/261 §1.3 |
| TOL_H / TOL_S / BAND_EDGE / SAT_MIN | 15° / 80 / 2px / 60 | docs/263 §1.3 |

新增加的量只有**判据口径参数**（非机制旋钮）：锚重叠 ≥ 0.30、OBJ_NOT_VETOED ≥ 0.70、

## 五、诚实边界（预注册阶段已知）

1. **真实域无阴影 GT、无光照 GT**（本格核心边界）：docs/260/261/263 的真值
   （θ_L、阴影掩码）是合成场景参数，DAVIS 真实视频不存在 → 本格的阴影标签、光照
   方向 θ_est **无真值可对**，全部是"判别机制在真实像素上的行为读数"（docs/243
   半真实精神：机制迁移检验）。唯一有 GT 锚的判据 = OBJ_NOT_VETOED（GT 目标物体
   不被否决门误判为阴影/纹理），且依赖"目标物体以暗候选形态出现"（锚覆盖率如实
   报告，锚不足则判据未被行使）。
2. **本格不是"真实域证明"**：本格证明的是"合成受控域成立的判别机制，在真实像素上
   的行为形态"（机制迁移检验，docs/243 同款口径），**不证明**"判别在真实域正确"。
   真正的真实域证明需要**带阴影 GT 的数据集**（阴影掩码 + 光源方位标注，如
   SBU-shadow / ISTD / SRD 等公开阴影数据集——超出本格数据域，写入下一步 §五 8）。
3. **零重调代价（预期行为）**：三连旋钮（δ=0.35、A_MIN=25、MOVE_IOU=0.05、
   TOL_H=15° 等）是合成场景标定值（docs/260 §五 8 / 261 §五 7 / 263 §五 7 声明），
   真实域下触发率是**行为读数**——V4 可能因真实 H/S 噪声/JPEG 伪影高触发（真实
   阴影边界色相不一定连续，docs/263 §五 2"真实相机噪声会扰动 H/S"），θ_est 可能
   常不可用（真实帧极少 >220 灰度的大块亮连通域）→ V3/E2 适用率低。这些如实报告，
   不调参（调参 = 破坏预注册冻结）。
4. **"纹理"标签的载体收窄**：本格"纹理/静态" = 静态暗区（时间门不过）；被 ref_dark
   吸收的静止纹理不构成候选（docs/187"静止纹理被预测掉"的真实域复现）；"随背景
   运动的纹理"（docs/187 完整缺口）未建模。
5. **判别对象 = 最大暗域**（单候选）：与合成三连一致（每帧一个最大暗域），多候选
   区域未建模；GT 掩码 resize 到 160×120（INTER_NEAREST）有像素化误差。
6. **θ_est 的自指性**：V3/E2 用帧内估计光照方向（θ_est = 亮候选质心→暗候选质心），
   与合成域已知 θ_L 的地位不同——对"沿光轴延伸的暗区"判阴影、对"偏离亮候选方向
   的暗区"判物体，是几何自洽的行为读数，不是光照方向真值验证（docs/260 C2 的
   0.48° 精度在真实域无对应）。
7. **与 docs/187 缺口的关系**：docs/187 要求"空间相关性/时间相干性度量"判别纹理 vs
   物体——本格给出真实域的**时间相干（时间门）+ 几何/反射率否决（V1/V3/V4）**的
   行为实例，但"纹理弥散 vs 物体相干"的完整判别（随背景运动的纹理）仍未闭环。
8. **下一步（真实域证明路径）**：带阴影 GT 的数据集（SBU-shadow/ISTD/SRD 等公开
   阴影分割集）→ 阴影检测 IoU / 边界分类可对真值；光源方位标注集 → θ 误差可算。
   本格不声称完成，只给出机制迁移形态与行为基线。
9. **统计口径**：单位 = 每视频一次运行（9 单位）；固定确定性流（无种子协议，
   docs/243 §1.1 声明）；帧级 + 单位级 mean±SD + bootstrap CI；OBJ_NOT_VETOED 用
   pooled（全部锚帧合并）+ 每视频分列。
