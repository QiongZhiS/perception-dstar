## 一、预注册设计（旋钮选择与判据先于最终运行冻结，docs/63+247 纪律）

### 1.1 缘起与目标（冻结）

docs/248 verdict=L3_PARTIAL：STABLE 四流全过（max 末/首比 1.3719 ≤ 1.5）、STRUCT 四流
全过（SC2 4/3/3/6）、CHURN 3/4 流过，唯一失败 = 快速剪辑流 S3 churn 0.6250（8 原型
创建仅 3 个 hits ≥ hits_min=3）。docs/248 §四机制判读（冻结引用）：

1. **内容切换太快 → 原型来不及累积 hits_min=3**：S3 创建窗口 2,5,8,11,18,29,36,39
   （41 窗），创建间距（gap）3,3,3,7,11,7,3——大量原型创建后 3 个窗口内内容已换，
   只剩创建窗本身可计数（hits=1），hits_min=3 在物理上不可达；
2. **不是半径过紧**：野域最近邻距离中位数 0.0733（docs/248 §3.5）≪ DAVIS r_base
   0.2659，工作半径 0.3989 相对野域是宽松的（匹配容易），churn 失守由内容变化率驱动；
3. **与 DAVIS 内短场景同构**：motorbike（4 窗）/soccerball（5 窗）的"创建被滞回推进
   短段尾部、剩余窗口不足"现象在野域重现（docs/245 §六4 归因 (a) 的形态）。

本实验目标（预注册）：用一个**预注册修复旋钮**在 docs/248 同一批野视频流上把 S3
churn 修到 ≤ 0.5，且不破坏 S1/S2/S4 已过判据（churn ≤ 0.5、ratio ≤ 1.5、SC2 > 0），
守卫 12/12 复现 docs/246。**其余机制/参数零改动**（r=0.39885、k=3、α=0.2、hits_min=3、
persist_win=5、window=10、LOOP_CFG 原样——沿用 docs/248 §1.4）。

### 1.2 修复旋钮选择（预注册三选一；选择理由冻结，先于任何结果）

| 候选 | 机制 | 选择/拒绝理由（冻结） |
|---|---|---|
| **1. 短段配额**（**选择**） | 原型创建后"剩余窗口预算 < hits_min"（短段尾部）时，按剩余窗口数折扣该原型的 hits_min（豁免配额）——直接解决"来不及固化" | **选择**。机制匹配：docs/248 §四判读 (1) 是"确认阈值在短段上物理不可达"，配额把不可达阈值改为可达阈值（finalize 级改判，零运行时反馈、零预测路径改动，MAE 序列逐位不变 → STABLE 侧构造性保持）。副作用（预注册声明）：可能把"过创建"原型（短命、hits=1）计入稳定 → SC2 膨胀、churn 下降——按判据 4 SIDE_EFFECT 如实报告 ΔSC1/ΔSC2/Δchurn。 |
| 2. 创建滞回降低（k=2） | 更快创建原型，让短段有更多窗口累积 | **拒绝**。docs/246 §3.2/§四已证伪：k=2 在 9 半径全部无工作点，M=1.5 处 R1 churn 0.7778（> k=3 的 0.4545）、R1 SC1 18（> 11）——更快创建 → 更多短命原型 → churn 反而更高；创建滞回 k=3 是**保护性**的。S3 与 DAVIS 短场景机制签名同构（§1.1），无任何理由认为跨域后 k=2 的结果反转；选它违背"不选已被相同机制证伪的旋钮"的预注册纪律。 |
| 3. 自适应半径 | 短段（连续高帧差段）用更小半径补偿判别 | **拒绝**。机制错位：docs/248 §四判读 (2) 明确"churn 失守不是半径过紧"（野域 NN 中位 0.0733，半径 0.3989 相对宽松）——收紧短段半径会降低本已足够的匹配密度，方向与失败机制相反；且 docs/245/246 已证半径-判别是连续权衡（收紧半径 → bridge 侧余量被吃），跨域重调半径违反 docs/248"零重调"精神；还需一个短段检测器，而 docs/248 §3.4 已证帧差尖峰在高运动流上灵敏度不足（S3 41 窗仅 2 个 μ+3σ 尖峰）。 |

**结论（冻结）：选旋钮 1 短段配额**，附加一个预注册快切门（§1.4）防 DAVIS 守卫路径
误触发。

### 1.3 配额规则（冻结；finalize 级改判，零运行时反馈，零预测路径改动）

对每个原型 p（SoftLoop entry_log 序，created=w_c、hits=h(p)、last_active）：

1. **剩余窗口预算 b(p)**：
   - 若 p 不是最后一个创建的原型（存在下一个创建窗口 w_next > w_c）：内容切换起点
     估计为 w_s = w_next − (k_consist − 1) = w_next − 2（下一个创建由连续 k_consist=3
     个未匹配窗口触发，首个未匹配窗 = 内容切换窗，p 最后一个可匹配窗 = w_s − 1）；
     预算 b(p) = max(1, w_s − w_c) = **max(1, w_next − w_c − 2)**。
   - 若 p 是最后一个创建的原型：预算 b(p) = **max(1, N_windows − w_c)**（创建窗到流尾）。
2. **豁免配额**：hits_min_eff(p) = max(1, min(hits_min, b(p)))。
3. **改判**：p 计入 SC2_q ⟺ h(p) ≥ hits_min_eff(p)；churn_q =
   #{p : h(p) < hits_min_eff(p)} / max(1, SC1)。SC1 不变（配额不创建/删除原型）。
4. **仅当该流快切门（§1.4）触发时应用**；门不触发 → hits_min_eff = hits_min（与
   docs/248 逐位一致）。

**单调性（预注册声明）**：hits_min_eff ≤ hits_min 恒成立 → churn_q ≤ churn（不增）、
SC2_q ≥ SC2（不减）、SC1 不变、MAE/ratio 不变（预测路径未动）。因此配额**不可能**
把已过流（S1/S2/S4 churn ≤ 0.5）推过线，也不可能破坏 STABLE/STRUCT——新破坏只能来自
实现漂移（守卫承担）。

**预算语义（冻结论证）**：gap = w_next − w_c = 3（最小，内容创建后 3 窗内即换）→
b=1：1 窗段无法支撑 3 次确认，hits_min=3 物理不可达 → 豁免为 1；gap=4 → b=2；gap ≥ 5
→ b ≥ 3 → 无豁免（段够长，hits_min=3 可达，短命是真实失败）。尾原型按流尾剩余窗数。

### 1.4 快切门（冻结；流级，防 DAVIS 守卫路径误触发）

- **参与窗**：E_w ≥ 10（与 SoftLoop 参与门逐字一致）。
- **连续位移**：d_w = ‖x_w − x_{w−1}‖₂（对数 (E,U) 域），对 (w−1, w) 双参与窗对。
- **FCF**（fast-cut indicator）= 上述对 d_w 的均值（对数为 0 时门不触发）。
- **NN_median** = 该流参与窗两两最近邻距离的中位数（与 soft_match_test.
  calibrate_radius / cross_domain_test.nn_median_wild 同公式，确定性）。
- **门触发** ⟺ 双参与窗对 ≥ 2 且 **FCF ≥ 2.0 × NN_median**。
- **理由（冻结）**：绝对位移轴无法分离快切与运动流（S3 与 DAVIS R1 的绝对位移同量级
  估计）；用**比值**——快切流的内容变化率相对其自身特征密度 ≥ 2×（"窗口特征移动比
  典型邻域间距快 2 倍以上"）。比值轴的分离由域特征密度差（wild 0.0733 vs DAVIS
  0.2659，~3.6×）放大：S3 预期 FCF/NN ≈ 4-5，DAVIS R0/R1 预期 < 1.5（DAVIS 场景内
  运动位移 < 邻域间距的 2 倍；R1 含 8 处边界但 58 对中占比低）。**预注册期望**：门在
  S3（必要时 S4，无害）触发，在 S1/S2/DAVIS R0/R1 不触发；守卫 12/12 是门设计正确性
  的运行验证。阈值 2.0 在最终运行前冻结，**不得因结果回调**。
- 门触发仅作用于 §1.3 配额应用，不改变任何匹配/创建/预测行为。

## 六、诚实边界

1. **快切门选择性期望未达成（本实验最大的诚实声明）**：预注册 §1.4 期望门在
