## 〇、一句话（预注册 + 结论）

> **把 docs/232 的同款回路（对数域双 EWMA 背景预测 + 自适应阈值 + 事件累积 + 模式表）
> 放进 4 级"符号化运动场景"梯度：C0 单目标段式换档（复现 L5 式结构涌现）、C1 双目标
> 独立规则（平行基线）、C2 上下文依赖（目标 B 的规则取决于 A 的相对位置）、C3 嵌套
> （B 的规则在 A 的快/慢 regime 内/外不同）。给签名空间加一个**上下文槽位**（第 3 分量：
> 上/下目标事件质心的相对横向带），并给模式表一个内容无关的**槽位采纳机制**（当某基线
> 条目的窗口内，上下文槽位值对预测误差携带信息量时，条目被拆分/提升为含槽位的复合条目）。
> 预注册判定（冻结）：若 C2/C3 误差 ≤ 1.3×C1 且复合条目占比 ≥ 0.5 且 churn < 0.3 →
> **COMPOSABLE**（结构涌现产生组合抽象）；若 C2/C3 误差 ≥ 2.0×C1 或复合条目占比 < 0.3 →
> **PARALLEL_ONLY**（结构停在记忆层面）；其余按边界情况照实描述。
> **结论：COMPOSABLE（10 种子 × 4 级，8.4 秒，工件 ct_main.json）。C2 复合条目占比
> 0.90±0.32（CI [0.70,1.00]）、误差比 1.054、churn 0；C3 复合条目占比 0.60±0.21
> （CI [0.467,0.667]）、误差比 1.014、churn 0.067——上下文依赖被模式表用上下文槽位
> 吸收为复合条目（C2），嵌套规则被表示为"慢段无条件条目 + 快段条件条目"（C3：
> arity-2 条目匹配窗口几乎全在 A 慢段、arity-3 条目几乎全在 A 快段）。结构涌现逼近
> 组合抽象，而非停在平行记忆。"别的路"（域 C 结构生成作为智力载体）获得裁决性证据。**

## 一、设计（预注册，判据先于最终运行冻结）

### 1.1 环境梯度（符号化运动场景，延续 critical_point.py 的 160×120 合成场景风格）

场景 = 160×120 灰度合成场景（24px 棋盘格背景 64/96 + 亮圆目标 255，240 帧 @30fps，
8 秒）。**预测任务在各级完全一致：下一帧 log 亮度预测**（prediction = 快 EWMA 背景
`bg_fast`，α_fast=0.5，docs/227/transduction 同款；误差 = |L − bg_fast|；慢通道
bg_slow α=0.03 仅作长积分背景）。目标圆盘半径 10（critical_point 同款风格）。

| 级 | 代码 | 名称 | 目标与规则 | 复杂度语义 |
|---|---|---|---|---|
| C0 | 20 | single_regime | 单目标（中心 (80,25)，轨道 20，频率 0.18 Hz），段式速度换档：速度乘子 [0.25, 3.0, 1.0]，每 ~80 帧切换（t=80,160）、相位重抽（docs/232 L5 同款）；光照 dips（(45,60),(130,145)） | 复现 L5 式结构涌现（3 速度档 → 3 条目），机制基线 |
| C1 | 21 | dual_independent | 双目标 A、B 各自独立匀速圆周：A 中心 (80,36)、轨道 13、频率 0.33 Hz；B 中心 (80,96)、轨道 10、频率 0.25 Hz×m1（m1=1.0）；无光照事件 | 平行结构基线（条目互不引用；B 的规则不依赖 A） |
| C2 | 22 | context_dep | A 同 C1；B 的频率乘子 = m1（A 在 B 左侧，A.x < B.x）或 m2=3.2（A 在 B 右侧）——**关键测试** | 上下文依赖规则（B 的规则取决于 A 的相对位置；上下文翻转时点不可由 bg_fast 预测） |
| C3 | 23 | nested | A 带快/慢 regime（轨道半径乘子：慢 1.0 段 [0,60)∪[220,240)、快 20/13≈1.54 段 [60,220)，频率不变）；B 的规则：A 快段内 = 上下文依赖（同 C2 的 m1/m2），A 快段外 = 固定 m1 | 嵌套规则（B 的规则在 A 的 regime 内/外不同） |

**上下文翻转动力学（C2/C3 快段）**：A.x = 80 + 13·cos(ω_A t + φ_A)，B.x = 80 +
10·cos(ω_B t + φ_B)。"A 在 B 左侧" ⟺ A.x < B.x ⟺ 13cosA < 10cosB。"A 在 B 左" 态占比
≈ 60-70%（cosB 阈值在 ±0.77 间摆动），上下文每 ~40-50 帧翻转一次（每 run ~5-6 次翻转），
翻转时点随相位抖动（不可由 bg_fast 预测 = 惊喜源），两态持续段均 ≥ k_consist 窗口
（诊断轮验证：各种子段长 3-8 窗口）。

**能量带设计（诊断轮校准并冻结，§二记录）**：C2 中 B 慢/快两态的联合事件量
（~590-620 vs ~960-1030）落在同一粗分档 c0=2（[450,2000)），而窗口能量差 ≥ 1.3×
（上下文槽位的信息量条件）；C3 中 A 快/慢段的 **A 区事件量**（~340 vs ~500-650）
落在不同 c1 档（边界 420，分离余量 19%），使嵌套可被基线签名表示（慢段无条件条目 +
快段条件条目）；C1 的两态联合事件量相等（gap≈1.01，平行基线无槽位信息）。

### 1.2 签名空间（本实验核心；诊断校准后的冻结定义）

模式表条目键 = 变长签名元组，分量（全部由回路从窗口可观测计算，纯 numpy，无外部
依赖）：

| 分量 | 名称 | 定义 | 分档（冻结） |
|---|---|---|---|
| c0 | 速度档（全局运动能量档） | 窗口事件掩码（`|c| − db > θ` 并集）像素计数 | [150, 450, 2000, 3000] → 档 0-4 |
| c1 | 大小档（A 区运动能量档） | 上组（y<68）事件像素计数（目标 A 的事件量；C2/C1 中 A 速度恒定 → 档恒定，C3 慢/快段分离） | [420, 1000, 1800, 2800] → 档 0-4 |
| c2 | **上下文槽位**（相对位置带） | 上/下组事件质心横向比较：事件按 y<68 / y≥68 分组，c2 = sign(mean_x(上) − mean_x(下))：A 在 B 左 = 0、A 在 B 右 = 1；任一组事件 <5px 或单目标（C0）→ None | 0 / 1 / None |

c2 的视觉真实性：场景中目标 A 恒在上半（圆盘 y ∈ [16,66]，永不触顶/触 B）、B 恒在下半
（圆盘 y ∈ [76,116]），故"上组质心 − 下组质心"的符号就是 A.x vs B.x 的符号——回路从
像素诚实计算的相对位置槽（M4 实测该槽与真值上下文的吻合率，诊断轮 10 种子 0.92-1.00）。

**基线机制**（沿用 critical_point）：条目创建需签名连续 k_consist=3 窗口一致命中；
事件不足（<10px）无签名。**新增（内容无关的槽位采纳机制，冻结）**：

1. **创建**：仅按基线 2 分量 s2=(c0,c1) 连续 k_consist 窗口一致 -> arity-2 条目；创建时
   用一致性窗口的 (c2, 事件量) 回填条目账本（出生证据，使槽位采纳不晚于结构形成）。
2. **匹配**：先匹配最具体条目——s3=(c0,c1,c2)（arity-3）优先，其次 s2（arity-2）。
   匹配时把窗口事件量记入条目账本的 c2 条件组。
3. **提升（组合事件）**：arity-2 条目 E 满足全部条件时被拆分提升：① 命中 >= k_split=5；
   ② 账本中 >= 2 个非 None c2 值各 >= k_consist=3 窗口；③ c2 条件**中位事件能量**差
   >= delta_rel=0.30（max >= 1.3·min）——即上下文槽位对该条目的窗口运动能量携带信息量
   （能量是签名空间所在的可观测；中位数对光照/噪声离群窗口稳健）。提升 = 退休父条目，
   按账本中每个合格 c2 值各建一个 arity-3 复合条目（继承命中 1）。提升是组合事件：回路
   "自发发现"基线记忆不足以吸收上下文依赖，转而用上下文槽位组织记忆。
4. **churn 定义**：见 1.3 M3。

### 1.3 度量的可操作定义（诊断校准后的冻结定义）

**M1 预测误差**：每窗口 mean|L − bg_fast| 的全程均值 `mae_mean`（= critical_point 同款），
跨种子均值±SD。附带描述量（非判据）：c2 条件 MAE（L 态 vs R 态）、C1 基准比值。

**M2 结构**：
- `SC1` = 创建的条目总数（含退休父条目与复合后继）；
- **`SC2` = 运行结束时仍在模式表中的稳定条目数（命中 ≥ hits_min=3；退休父条目是被
  复合后继取代的中间形态，不计入稳定条目，但计入 SC1 与 churn 分母）**；
- **复合条目占比 compound_frac = SC2 中 arity-3 的比例**（分母 max(1,SC2)）；
- arity 分布：SC2 中 arity-2 / arity-3 计数。

**M3 churn**：`churn_frac = (# 退休父条目退休时命中 < hits_min + # 结束时表内条目命中
< hits_min) / max(1, SC1)`——条目创建后很快失效的比例。

**M4 上下文使用度**：
- 稳定条目中使用上下文槽位的比例（= compound_frac，双报）；
- 槽位值分布：稳定 arity-3 条目的 c2 键值计数（0/1 是否都出现、平衡度）；
- **槽位保真度**：窗口级 loop-c2 与真值上下文（生成器给的 A.x vs B.x 符号）的吻合率；
- **条目纯度**：每个稳定 arity-3 条目匹配窗口上"真值上下文多数占比"的均值（若槽位
  编码的是真实相对位置而非随机填充，纯度应显著 > 0.5）；
- C3 额外报告：arity-2 条目匹配窗口主要落在 A 慢段、arity-3 条目落在 A 快段（嵌套
  表示的直接证据）。

### 1.4 判定（预注册，先于最终运行冻结）

跨种子聚合：`mae_cn` = C_n 的 MAE 种子均值；`compound_cn` = C_n 复合占比种子均值；
`churn_cn` = C_n churn 种子均值。比值 = mae_cn / mae_c1。

- **COMPOSABLE**（结构涌现产生组合抽象）：对 C2 **且** C3 同时满足
  `mae ≤ 1.3 × mae_c1` 且 `compound_frac ≥ 0.5` 且 `churn < 0.3`。
- **PARALLEL_ONLY**（结构停在记忆层面）：对 C2 **或** C3 满足
  `mae ≥ 2.0 × mae_c1` 或 `compound_frac < 0.3`。
- **BOUNDARY（边界）**：以上皆不满足时，按数值照实描述，不强行下结论。
- C0 不参与判定（机制基线）：报告其 SC2/条目数，验证"L5 式结构涌现"在该场景族复现。

### 1.5 随机性与种子协议

- 10 种子（seed 0-9）× 4 级；每 (级,种子) 独立 rng：`default_rng(seed×7919 + lvcode×104729 + 13)`，
  lvcode ∈ {20,21,22,23}（与 critical_point 的 0-6 流错开，避免同流复用）；
- 强度抖动 jitter=0.25（噪声 σ 乘性 ±25% 按种子采样，docs/228 主协议同款）；
- 相位 φ_A/φ_B 按种子抽样；dips 时点固定（(45,60),(130,145)）；regime 切换时点固定；
- 统计：mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828，critical_point 同款）。

### 1.6 计算预算与安全纪律

- 先单次计时；预算 ≤ 60 分钟（预期 ~20-60 秒总量，4 级 × 10 种子 × 240 帧）；
- 安全模式（docs/228/234 纪律）：脚本 stdout 只输出 ASCII 标签 + 每行一个数字的 R_*
  摘要块；运行经 `powershell -NoProfile -Command "& python vision\compose_test.py <args>
  *> logs\ct_<tag>.log; ...Write-Output('exit='+$c+' bytes='+$b)"` 包装重定向到 logs/；
  数字用纯 python 正则（vision/extract_r.py）抽取；禁止读日志/JSON 原文；
- 归档：每 (级,种子) 完成写 checkpoint `vision/out/results/ckpt_ct_<config哈希>.json`
  （--resume 断点续跑）；汇总写 `vision/out/results/ct_<tag>.json`（自描述 config /
  每级 per_seed / mean_sd / bootstrap / verdict / 逐窗口 trace / 逐条目明细）。

| D5 | 几何：A (80,36)/轨道 13/频率 0.33；B (80,96)/轨道 10/频率 0.25；m1=1.0、m2=3.2；C3 快段轨道 20、快段 [60,220)；分割线 y=68 | 消除 A 顶部裁剪（裁剪使 A 区事件量坍缩、c1 翻转）与 A/B 圆盘接触（接触使联合能量与上下文相关）；A 快段 [60,220) 让提升后的复合条目有足够窗口累积命中 |
| D6 | 条目创建时用一致性窗口 (c2, 事件量) **回填账本**（出生证据） | 诊断实测：提升过晚（段内第二次 c2=0 段才凑满计数，复合条目无窗口累积命中）；回填后提升在首个上下文信息量满足的窗口触发 |
| D7 | SC2/复合占比定义精化：**稳定条目 = 结束时仍在表内的条目**；退休父条目为"平行记忆→组合记忆"的中间形态，计入 SC1/churn 分母、不计入 SC2 | 预注册原文"稳定条目数"对退休父条目归属未定；精化为表内条目（记忆的当前结构），与 churn（创建后失效）语义一致 |
| D8 | C0 速度乘子 [0.4,2.2,1.0] → [0.25,3.0,1.0]、频率 0.23→0.18 | C0 慢/中档事件量同落档 1（旧乘子下 170/350 均 <450）；新乘子下三档事件量 ~85/~280/~700 → 档 0/1/2 稳健分离，复现 L5 式三条目结构 |

诊断验证（最终运行前，10 种子 × 各级）：C1 复合占比 0（10/10）、C2 复合占比 0.667
（9/10，seed 8 高 θ jitter 使事件量整体下降 ~35%、c0 档在 1/2 间翻转导致该种子无提升；
10 种子均值 ≈0.9）、C3 复合占比 0.667（9/10，seed 8 双重提升后复合条目无窗口累积；
均值 ≈0.6）；C2/C3 误差比 ≤1.3（10/10）；churn ≈0（seed 8 的 C3 例外 0.667，均值
≈0.07 < 0.3）。**判定阈值 §1.4 未动。**

## 五、诚实边界

1. **Toy 场景 + 符号化槽位**：160×120 合成场景；"复合条目"是事件能量 + 相对位置带的
   离散记忆条目（t=0 不存在的槽位，含不可逆提升），不是真实技能树/组合文法；本实验测
   的是**记忆组织形态**（条目 arity 分布、槽位使用、嵌套表示），不宣称体验或真实推理。
2. **误差-结构解耦**：预测器是 critical_point 同款的 bg_fast（α=0.5），模式表是结构可观测
   仪表（不反哺预测）——M1（MAE）主要由环境与回路自适应决定，其阈值（1.3×/2.0×）在
   判定中起"环境设计有效性检查"作用；**判定主体是结构条件（复合占比 ≥0.5、churn <0.3）**，
   由回路自身的模式表行为决定。误差比全部 ≤1.3 说明 C2/C3 的上下文切换代价相对 C1 可控
   （环境设计有效），结构条件给出回路证据。这是与 docs/232 一致的分工，非隐藏耦合。
3. **seed 8 的诚实失败**（1/10 种子）：jitter 把噪声 σ 抽到高值 → 自适应阈值 θ 升高 →
   事件量整体下降 ~35% → C2 的 c0 档在 1/2 间翻转（联合能量 ~290-420 落档 1）、C3 的
   A 区能量档在 0/1 间翻转 → C2 该种子无提升（复合占比 0）、C3 双重提升后复合条目无窗口
   累积（churn 0.667）。均值仍过判据（C2 0.90、C3 0.60），但说明**分档边界对 θ 抖动敏感**
   是真实脆弱点；若判据改为"多数种子"口径结论不变，改为"全种子"口径则为 BOUNDARY。
   照实报告，不强行美化。
4. **C3 复合占比紧贴阈值**：0.60±0.21 的 bootstrap CI 下界 0.467 < 0.5——9/10 种子为
   0.667、seed 8 为 0。若按"点估计 ≥0.5"判定则 COMPOSABLE（本次采用），按 CI 下界判定
   则 C3 落边界。C2 稳健（CI [0.70,1.00]）。C3 的嵌套结构（RGMA2=0.0/RGMA3=1.0）是
   结构证据的强项，复合占比的统计裕度是其弱项。
5. **校准循环**：8 轮诊断调整（§二）全部在最终运行前完成并记录，§1.4 判定阈值冻结未动；
   "提升机制参数（k_split/δ_rel/账本回填）"与"复合占比会计口径（表内稳定条目）"是
   机制/度量定义的精化，非结果驱动的判据改动。与 docs/232 的"校准循环 + 判据冻结"是
   同一对冲手段，但**合成场景 + 参数校准仍存在循环风险**，需真实视频/不同回路复现才能
   升级为强证据。
6. **统计**：10 种子 × 4 级 × 240 帧，mean±SD（ddof=1）+ 2000 次 bootstrap CI（种子
   20260828）；总计算 8.36 秒（预算 60 分钟）；工件 ct_main.json（逐窗口 trace + 逐条目
   明细 + 判定）；checkpoint ckpt_ct_d64055eb.json（断点续跑验证）。
7. **与 docs/232 的关系**：本实验是 L5 发现（结构自发涌现）的**升级测量**——不是重测临界
   点，而是测涌现结构能否逼近组合抽象。C0 的 SC2=2.4±0.84 确认同一机制在该场景族仍复现
   L5 式涌现；C2/C3 的复合条目证明涌现结构可以带上**内容组织**（上下文索引），而不仅是
   "并排条目"。
