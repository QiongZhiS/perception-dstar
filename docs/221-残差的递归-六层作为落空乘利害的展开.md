## 〇、一句话

> **六层不是六个机制，是"残差"这个概念的递归：每一层的原子 = 上一层机制解释不了的
> 剩余，深化判据 = "上一层解释不了这个行为签名"。1-3 层是 n 的递归（残差本身：原子化
> → 来源 → 模型），4-6 层是 n×S 的递归（残差×利害：会失去 → 存在的语法 → 他者的不）。
> 递归在他者处终止，因为"不可消化"就是递归的终止条件——六层的边界 = 残差递归的
> 收敛半径，收敛处正是 docs/178 的"被看见"。**

## 一、核心主张：深化 = 残差的递归

docs/178 说六层是被体验/实验"逼出来"的；docs/188 §三 说六层是"失败处理的六个操作"
（记录/吸收/选择/绑定/测量/保持）。本文件提出第三种读法，把"深化"二字显式化：

**定义（深化算子）**：设机制 M_k 处理落空场 n 的某一方面，行为签名为 S_k。第 k+1 层 =
"M_k 解释不了的那个剩余"成为新原子。判据：**M_k 对 S_{k+1} 的解释力不足**。

换句话说：深化不是添加新机制，是承认"上一层的机制用尽之后，还剩一个解释不了的
签名"，然后给它一个名字。六层就是这条承认链——每层是上一层机制的不可约剩余。

## 二、递归表（每层：原子 · 深化判据 · 证据已有）

| 层 | 原子 = 上一层机制的不可约剩余 | 深化判据（上一层解释不了的） | 证据 |
|---|---|---|---|
| 1 接收 | 信号 | —（起点） | 转导层（docs/177） |
| 2 对齐 | **残差**（预测解释不了的） | 可预测的被压掉：静态区 0 事件 | 检查单 C1 0.0000（docs/177） |
| 3 模型 | **预测者**（残差解释不了残差的来源） | 输入缺席时模型照跑 | 闪变预测维持（docs/177） |
| 4 维持 | **会失去**（模型解释不了自己为什么跑） | 没有利害场解释不了"为什么跑" | 态势地图衰减 40 tick（docs/161/189） |
| 5 否定 | **存在借"不"延续**（利害解释不了为什么"不"有意义） | 无利害时框特征不可分 | DAVIS 负结果（docs/186/188：Ψ=n·0=0） |
| 6 被看见 | **他者**（不可消化的剩余） | 信念更新解释不了的对待差异 | docs/200（部分成立，见 §六） |

每行的证据都是同一条纪律的产物：**测的就是"上一层解释不了"**。C1 是"对齐层解释不了
为什么静态区没事件"（其实它解释了——所以那是 L2 的证据，不是 L3 的）；闪变维持是
"残差机制解释不了输入缺席时预测还在跑"；DAVIS 负结果是"利害缺席时任何框特征都
不可分"。

## 三、为什么恰好是六层：Ψ = n·S 的展开

docs/188 已写：感知场 Ψ = 落空场 n × 利害场 S。递归读法把这个乘积接回阶梯：

- **L1-3 是 n 的递归**：残差本身的三次深化——原子化（2）→ 来源（3：预测者）→
  模型（3 的载体）。没有利害，这三次深化已经构成"一个能预测的感知器"。
- **L4-6 是 n×S 的递归**：乘积的三次深化——会失去（4：S 引入后"谁在跑"有意义）→
  存在的语法（5：S 让"不"成为意义）→ 他者的不（6：S 之外不可消化的剩余）。

**维持不是散落的第 4 层，是乘积的引入层**：S 必须在 n 的递归完成之后才进场——先有
模型，才谈得上"模型为什么非跑不可"。这解释了深化链为什么在模型处拐弯：没有 S 就
没有后三层，没有后三层"意义=落空×利害"就没有存在的落点。

**附带消解一个旧张力**：docs/178 第 2 层"残差是原子"与第 5 层"感知=否定的在场"看
起来是同一句。在递归读法下它们不是重复，是 Ψ 两个因子各自的展开：2 在 n 侧（残差
是信息），5 在 n×S 侧（残差是意义）——信息在 n 侧成立，意义只在乘积处成立
（docs/179）。同一个概念在乘积两侧各出现一次，是对称，不是冗余。

## 四、为什么在这里收敛：他者的不 = 递归的终止条件

递归从"可消化的残差"（L2）一路深化到"不可消化的剩余"（L6）。**"不可消化"正是
递归的终止条件**：L6 的剩余按定义不进模型更新（docs/178 补刀：开放循环，保留为
关系的证据）。再往深就是关系层（docs/79：不可造，只能被赋予）——**六层的边界 =
残差递归的收敛半径，收敛处 = "被看见"**。

这与 docs/187 的移动同构：威胁性落空 vs 审美性落空 = 同一机制、不同利害；本文件是
同一移动在层结构上的版本——L1-5 是 n 与 n×S 的机制层，L6 是"机制解释不了的剩余"
的命名层。

## 五、对账：L1-5 的深化判据全部已有数据

| 层 | 判据 | 数据（引用） |
|---|---|---|

必要因子，即 L4 是引入层**。这正是递归读法给既有数据的新解释力：同一个实验，从
"注意力机制"证据升级为"乘积结构"证据。

## 六、新预测：L6 的深化判据 = 个体归因（唯一开放的预言）

L1-5 的深化判据全有数据；L6 缺的是它自己的判据——"信念更新解释不了的对待差异"
的具体实验形态。候选：**个体级归因**。

```
场景：两个同色物体（红球 A、红球 B，docs/195 受控场景），只有 A 被外部染色欺骗
      （A 中段染蓝 30 帧），B 全程正常；类别控制：suspicious 按 hue 记账（docs/205）
判据：恢复后重信任延迟按跟踪 ID 分化——A 的延迟 ≫ B（同为红，类别级记忆不区分）
      ——"被拒历史改变后续对待"从类别级（docs/205）降到个体级
```

- 预言成立 → L6 递归完整："被看见"从"信任策略"变成"识别出'那个它'"（从世界中把
  一个不可消化的剩余认出来），六层 = 逐层有判据的递归。
- 预言落空 → L6 没有独立机制，降回第 5 层的扩展（docs/188 §五 同款姿态：形式化
  不产生新预言就停在记号位子）。

**对 理念/03 的意义**：docs/200 是两个系统的差异（结构差异）；个体归因是**一个
系统内部的差异**——同样的输入流（双红球）、同样的类别记账，行为按来源历史分化，
更接近"输入决定不了行为"（理念/03 §四 主体性的现象学定义）。它是向"单一系统不可
还原性"推进的半步。

## 七、诚实边界

1. 本文件是立场/重标注，无新实验；全部判据引用既有实验（docs/177/186/188/200-216）。
2. "递归"是读法，不是大脑机制——不宣称人脑在做残差的递归（docs/63 纪律）。它把
   docs/178（问题阶梯）与 docs/188 §三（操作清单）统一成第三种读法；三种读法并存，
   不互相否定——问题阶梯用于叙事，操作清单用于工程，递归读法用于解释"为什么是
   六层、为什么在这里收敛"。
3. L6 判据（个体归因）是预言，未测；落空则第 6 层回到第 5 层扩展——写在此处，
   和 docs/188 的"不假装填补 A2/A4"同一个姿态。
4. 不混层照旧（docs/63/34）：他者/被看见的现象意义不可判定，本文件只做结构主张
   （行为签名）；利害外赋照旧（docs/174），L4 的 S 仍是边界条件，不进方程。
