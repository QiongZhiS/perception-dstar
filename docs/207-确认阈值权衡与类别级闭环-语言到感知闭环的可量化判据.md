## 〇、一句话

> **语言→感知闭环有了可量化判据（误报-漏报权衡）：固定 thr 单调权衡（低 thr 高
> 误报低漏报，高 thr 反之）；但闭环必须类别级——全局 thr 闭环是病态（蓝段把
> 全局阈值冲高 0.20→0.60，目标回来认不出，漏报 0.325="永远怕井绳"），类别级
> thr（suspicious 表）完美（误报 0 漏报 0，净 0.000 优于最优固定点 0.025）。docs/101
> "越噪声越固执"的正确形态：固执是类别级的（被拒类别收紧、目标色永远基线），
> 不是全局的（否则一次错色污染一切）。**

## 一、机制（vision/confirm_threshold.py）

```
场景（确认度量 toy 版）：红段 40 帧(占比~0.55±0.15) → 蓝段 30 帧(~0.15±0.10) → 红段 40
度量：误报 = 蓝段确认通过比例；漏报 = 红段确认被拒比例
对照：
  固定 thr ∈ {0.2..0.6} → (误报, 漏报) 权衡曲线
  全局闭环（docs/206 原版）：失败无差别上调全局 thr（+0.05 封顶 0.6，信任回落）
  类别级闭环（docs/205 结合）：thr_by_hue[suspicious 表]——蓝被拒只调蓝的 thr
```

## 三、判读

1. **确认阈值的权衡是 docs/101 平衡带在阈值轴的形态**：thr = 先验强度（docs/206），
   低 thr 开放（误报高）vs 高 thr 固执（漏报高）——"世界越噪声自我越该固执"的
   连续谱。
2. **全局 thr 闭环是病态（P2 核心发现）**：无差别上调（把任何失败都当"需要更严"）
   在目标本底噪声下自我锁死——蓝段 30 帧把全局 thr 冲到 0.60，红段占比 ~0.55 过
   不了 → 红段也持续被拒 → thr 维持高位 → 恶性循环。"一朝被蛇咬"变"永远怕井绳"：
   目标（红）根本没变，只是被一次错色（蓝）污染了确认标准。
3. **类别级 thr 是解药（docs/205 suspicious 表的闭环版）**：被拒按颜色记账，蓝被
   拒只让蓝更严（误报 0）、红保持基线（漏报 0）——固执是**类别级**的：只对被拒
   过的类别收紧，目标色（外赋利害）永远开放。这比"全局固执"更符合 docs/101 的
   精神：世界噪声是局部的（某个类别不可信），固执也该局部。
4. **语言→感知闭环的净判据 = 误报+漏报最小化**：类别级闭环 0.000 优于任何固定
   阈值点——自适应（错色段收紧、目标段不动）比单一固定更优（docs/206 §五 1 兑现）。

## 四、诚实边界

1. 确认度量是 toy（合成占比序列 0.55/0.15±噪声）——真实图像的红区占比分布
   （docs/200 实测 ~0.78-0.97）更分离，权衡曲线的具体形状会变，但单调性与类别级
   结论不变（结构结论）。
2. 类别=色相（120° 蓝 vs 0° 红）——真实"类别"边界模糊（docs/205 泛化带宽），
   类别级 thr 也应有带宽（红与橙红怎么分）。
3. 阈值上调/回落的步长、封顶是手工标定——"被拒多少次该多严、信任多久该放松"
   的平衡是 docs/203 saturate 参数的阈值版（可学出来，docs/176 纪律）。
4. 现象层纪律照旧（docs/63）：测的是确认策略的权衡（误报/漏报），不宣称"怀疑/
   信任"体验。

## 五、下一步（按价值）

1. **类别级 thr + 带宽（docs/205 结合）**：thr_by_hue 的查询也带泛化带宽（蓝被拒
   → 距蓝 30° 内的颜色也稍严）——类别边界模糊时的阈值调节（docs/196 色温漂移
   是带宽物理锚）。
2. **回图像版**：把类别级 thr 装回 docs/200 图像场景（真实红球红区占比 ~0.78-0.97）
   ——验证真实分布下类别级闭环仍优于固定阈值（docs/206 §五 3 同一线）。
3. **误报/漏报的利害加权**：误报（错色当目标）与漏报（真目标被拒）的代价不同
   （docs/174 外赋）——权衡的最优点是利害加权的（"找红球"时漏报更贵 vs "警惕
   异常"时误报更贵），闭环应带利害权重。
4. **多类别闭环**：三通道分工（docs/195 灰度跟踪+位置锚+颜色确认）全接类别级
   thr——颜色确认的阈值自适应在真实管线里工作。
