## 一、机制（vision/continuous_image.py）

```
场景：非纯蓝（BGR 160,40,30）+ 4 种暖光强度（0/0.3/0.5/0.7，加法不对称）
  → 蓝真实漂移（docs/211）；hist[蓝] 沉积真实变异 → 自适应带宽（docs/208）
对比：二值 thr（docs/210 对照）vs 连续 thr（docs/214 距离加权）
训练：4 暖光 × 30 遍（蓝段被拒 + 记录观测色相）
```

## 二、结果

**P1 真实分布（不同暖光下染蓝的观测色相）**

| 暖光 | 蓝观测色相 |
|---|---|
| 0.0 | 118.0° |
| 0.3 | 121.0° |
| 0.5 | 123.0° |
| 0.7 | 126.0° |

总体 mean=122.0° std=2.9°（范围 118-126°）→ 自适应带宽≈5.8°

**P2 连续 thr vs 二值（距标准蓝的距离）**

| 距蓝 | 二值 thr | 连续 thr |
|---|---|---|
| 0-4° | 0.80 | 0.80（饱和顶格） |
| 6°+ | 0.20 | 0.20 |
| 120°（红） | 0.20 | 0.20 |

（真实 std 2.9° → 带宽仅 5.8° → 4° 已是边缘内、6° 出带宽；饱和顶格掩盖带内连续
差异——docs/213 的交互在图像版同样成立）

**P3 不误伤**：红（120°）二值/连续都 thr=0.20 ✓

## 三、判读

1. **docs/214 连续 thr 跨真实分布成立**：非纯蓝在 4 种暖光下的真实漂移（118-126°）
   沉积进带宽（2.9° std），thr(距离) 按见过的变异加权——带宽 = 真实变异范围
   （docs/211 同款，不是手调常数）。
2. **饱和交互在图像版重现**：带宽内（0-4°）连续/二值都 0.80（饱和顶格）——被拒
   累计（4 暖光 × 30 遍 × 30 帧/遍 = 3600）远超 cap_thr，连续差异被饱和掩盖
   （docs/213 交互）；可观测窗口在带宽边缘（6° 出带宽处）。
3. **不误伤保持**：红（距蓝 120° 远超带宽）永远基线——真实分布下目标色仍开放
   （docs/205 类别特异）。

## 四、诚实边界

1. 4 种暖光是离散强度——真实光照连续变化（docs/196 昼夜），漂移分布更连续
   （本实验是离散采样近似）。
2. 非纯蓝（160,40,30）的 G/R 分量固定——真实"蓝"因材质不同 G/R 比不同，漂移
   量级不同（docs/211 边界）。
3. 饱和顶格掩盖带内连续差异——未饱和区（少遍数）的完整曲线见 docs/213。
4. 现象层纪律照旧（docs/63）。
