## 二、核心结论（续接者必读）

1. **docs/196/197 是假象**（docs/199/199b）："红球被黄染 H 漂移 83°"是 patch 中位
   被背景污染的度量假象；"色相旋转校正 83→178"把球体推到 95（青）破坏确认。
   正解：**色相 MAD 集中度 × 帧间 \|Δ\| 一致性 + 通道级白平衡**；DAVIS 验证
   通过率全 1.0。
2. **纯色是光照变换的特征向量**（docs/199 修正④，211 再现）：BGR(200,0,0) 纯蓝
   在乘法/加法光照下色相都不动——颜色确认的鲁棒性讨论必须基于非纯色。
3. **"何时校正" = 类别级固执**（docs/207 核心）：全局 thr 闭环是病态（一次错色
   污染一切，目标回来认不出）；suspicious 表让被拒类别单独收紧、目标色永远开放
   （误报+漏报 0.000）。
4. **阅历的正确形态 = 饱和**（docs/203）：线性累积锁死（永不恢复），饱和累积
   （cap）谨慎但能恢复——"一朝被蛇咬"要有上限。阅历是阈值偏移不是拟合
   （目标级记忆对新位置仍谨慎）。
5. **两种否定的机制分界线 = 通道**（docs/201/202）：感知层的"不"（观察）永远不
   改判（自洽门拒）；任务层的"不"（利害更新）经验证涓流改判——"一次宣布够
   吗"取决于固执度 eta。
6. **语言 = 维持层状态投影**（docs/204/206）：符号槽（颜色/可疑/持续标签规则表
   自动贴）→ 态势转录（模板引擎，无 LLM）→ 自反接口（"我认错了"/"我固执"/
   "我需要更连续的证据"）；语言反向驱动感知参数（被拒→thr 上调）。

## 六、踩过的坑（续接者必读）

1. **演示"一直刷被拒"** = `_target()` 未与帧循环取模同步（tick>N 后帧回起点但
   目标出画面）——已修。
2. **任务按钮不生效** = 确认度量用"红区占比"（蓝任务下恒 0）+ 换任务不清 thr
   ——改为"彩色占比 + 距任务色相<30°"+ 换任务 thr 回基线（suspicious 保留）。
3. **thr 死锁（子代理发现）** = thr 上限 0.8 > 球体真实彩色占比 0.777 → 染蓝冲
   满后目标恢复也永远 frac<thr → 永久误拒——上限改 0.75（对照物理可达度量）。
4. **语言层分支不可达** = confirm 先推进 trusted/consec 再调 language → 需快照
   was_trusted/was_consec 回看本帧事件。
5. **纯色特征向量**（反复出现）：讨论颜色漂移/带宽时必须用非纯色，否则光照无效。
