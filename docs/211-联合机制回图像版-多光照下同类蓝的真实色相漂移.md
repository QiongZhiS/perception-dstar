## 一、机制（vision/joint_image.py）

```
场景：color_robust 真实图像 + 染非纯蓝（BGR 160,40,30）+ 不对称加法暖光
  （G 加少 R 加多 = 暖黄光 → 非纯蓝漂移；纯蓝不漂移，docs/199 修正④）
训练：bright / bright+暖光 / yellow+暖光 三光照染蓝 ×30 遍
  → hist[蓝] 沉积真实漂移（见过的变异）→ 自适应带宽（docs/208）
测试：新光照（更强暖光）漂移蓝——联合（带宽内共享怀疑）vs 单类别（精确 120°）
```

## 二、结果

**P1 真实漂移（不同光照下染蓝的观测色相）**

| 光照 | 蓝观测色相 |
|---|---|
| bright | 118.0° |
| bright + 暖光 0.7 | 126.0° |
| yellow + 暖光 0.7 | 126.0° |

跨光照漂移量级 = **8°**（docs/196 色温脆弱的同类量级）

**P2 联合 vs 单类别（测试漂移蓝 126°，距标准蓝 6°）**

| 系统 | 见过的蓝 std | 自适应带宽 | 漂移蓝 thr | 漂移蓝 k |
|---|---|---|---|---|
| 联合 | 3.8° | 7.5° | **0.80**（共享） | **21**（共享） |
| 单类别（精确 120°） | — | — | 0.20（新类别） | 1（漏掉） |

**P3 不误伤**：红（距蓝 60°）在自适应带宽外 → thr 0.20、k=1 ✓

## 三、判读

1. **docs/210 结论在真实图像分布下成立**："同类 = 见过的变异范围"——多光照训练
   沉积真实漂移（std 3.8°），漂移蓝 126°（距标准蓝 6°）在带宽内共享怀疑（thr/k
   升），不因光照漂移当新颜色漏掉；单类别（精确 120°）漏掉见过的同类。
2. **纯色特征向量（途中发现，docs/199 修正④的又一次现身）**：纯蓝（200,0,0）
   的 G/B=0 → 乘法（R×0.5）和加法（G/R 等量加）光照色相都不动——纯色是光照
   变换的特征向量。真实"蓝"不是纯色（带 G/R 分量），非纯蓝才有真实漂移
   （118→126°）。这印证 docs/199 的核心修正：**颜色确认的鲁棒性讨论必须基于
   非纯色**（纯色在光照下天然稳定，是特例不是常态）。
3. **物理锚的诚实性**：8° 漂移（本场景加法暖光 0.7）小于 docs/196 的 83°（那是
   patch 中位假象，docs/199 已修正）——真实纯色目标漂移量级远小于文档早期声称；
   非纯色的漂移取决于 G/R 分量比。带宽沉积的是"见过的真实变异"，与场景光照
   强度匹配。

## 四、诚实边界

1. 染蓝用非纯蓝（160,40,30）——真实"蓝"的 G/R 分量因物体而异（材质反射率），
   漂移量级不同（本场景 8°）。
2. 暖光是不对称加法（G/R 不同量）——真实光照是连续光谱（乘法+加法混合），
   漂移方向/量级因光源而异。
3. 三光照 ×30 遍是模拟"见过多种光照下的同类"——真实世界同类颜色在连续光照
   变化下的变异更大（docs/196 昼夜），带宽会沉积更大范围。
4. 现象层纪律照旧（docs/63）。
