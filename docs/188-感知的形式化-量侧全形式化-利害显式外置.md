## 一、两个原场

**落空场**（似然，世界给的）：
$$n_t(i) = L_t(i) - b_t(i)$$
位置 $i$、时刻 $t$ 的对数亮度减去预测背景 $b_t$。这是转导层已在算的残差
（`contrast = L - bg`），docs/178 第 5 层的"否定"，docs/125"通道=预期落空的事件"。

**利害场**（先验，外赋的）：
$$S_t(i) = \sum_{m \in M} w_m \cdot g_m\big(d(i, \mu_m)\big)$$
维持目标 $m$ 带权重 $w_m$（利害标量，**外赋**）和距离衰减 $g_m$（如高斯）——$S$ 是
"哪里重要"的地图。**$M$、$w_m$、$g_m$ 都是设计者/使用者定义（docs/174），不是感知层
学出来的。**

**感知场**（意义，后验）：
$$\Psi_t(i) = n_t(i) \cdot S_t(i)$$

这是 docs/179 的"意义=落空×利害"字面化，也是 docs/84"注意=预测误差×利害"的同一个
乘积。docs/125 的"后验 ∝ 先验 × 似然"结构在这里：$S$=先验（利害），$n$=似然（落空），
$\Psi$=后验（意义）。

## 三、求本：一切感知 = 对预测失败（n）的动态处理

摆在一起看，项目所有机制操作同一个实体——落空场 $n$（预测失败），区别只在"怎么处理"：

| 机制 | 对 n 的操作 | 文档/实验 |
|---|---|---|
| 落空 | 记录（残差是原子） | 转导层事件流 |
| 习惯化 | 吸收（模型更新→n→0→感知消失） | C1 静态 0 事件 |
| 注意 | 选择（按 Ψ 排序，Top-K） | topk 实验 ✓ |
| 维持 | 绑定（这个 n 是"它"的） | reader 轨迹 |
| d\* / 落空率 | 测量（n 累积到不可解释的距离） | docs/130/125；d\* 压缩率实验 |
| 欣赏 | 保持（不被吸收） | docs/187（无实验） |
| 闭眼走 | n 缺席时预测器照跑 | 闪变预测维持 |

docs/178 六层不是六个东西，是"失败处理"的六个操作——记录、吸收、选择、绑定、测量、
保持。这把"为什么要六层"答了：因为失败要被不同方式处理。docs/128 威胁仲裁、docs/186
d\* 压缩率、docs/125 落空率统一成"同一失败的不同聚合"。

## 四、关键边界（形式化的真正成果）

1. **$\Psi = n \cdot 0 = 0$**：利害场全零时，感知场恒零——任何框特征零信息。这就是 DAVIS
   负结果（五个框特征不可分）的数学表达：**先有在乎（S 非零），才有看见（Ψ 非零）**。
   目标不能从画面里"分出来"，是利害场里的持续峰。
2. **利害外置**：$M, w_m, g_m$ 是边界条件不是变量。docs/63 价值层外赋的数学版：方程内部
   全部可算（量侧），方程边界（利害）显式外置。docs/186 §五"威胁度需要维持目标"有了
   准确形式：威胁度定义在 Ψ 上，Ψ 需要 S，S 需要外赋。
3. **形式化的价值边界**：它统一了已实验的机制（有价值的压缩），但没有产生新预言（除了
   目标涌现的测试，见 §五）；不假装填补 docs/79 的 A2/A4 缺口（docs/34/35 的防御）。

## 五、一个可测的推论（裁决求本有没有用）

求本主张：**目标 = 失败被绑定最久的轨迹**（不是"看起来像物体"的区域）。可测：
在 DAVIS car-turn 上跑"失败绑定最久"的轨迹（不加外部指定，让 $S$ 用轨迹持续性近似），
看冒出来的目标是不是车。

- 预言成立 → 求本有用：目标涌现 = 失败绑定的持续性，$S$ 可以从轨迹内产生（量侧自洽）。
- 预言落空 → 求本是又一层"一体"式好听的词（docs/34 陷阱）：目标涌现必须外赋，$S$ 无法
  从量侧产生。

这是 docs/188 唯一产生新内容的点——其他都是对账/压缩。

## 六、诚实边界

1. 形式化是 docs/179/84/125 的展开，不是新理论；预测编码方向与 Friston 同源（docs/68

2. 量侧全部有对应实现/实验（除目标涌现、时间积分）；利害侧全部外置（docs/174），
