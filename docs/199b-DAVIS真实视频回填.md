## 三、判据二度修正（docs/199 → 199b，toy→真实暴露的两个问题）

1. **时间一致性度量：EWMA 方差 → 帧间 |Δshift|**。docs/197/199 用"shift 相对
   EWMA 均值的方差"测稳定性——但**渐变（黄昏色温帧间连续爬升）围绕移动均值，
   方差持续累积 → 被误判为噪声（门关）**。信号层验证：渐变 35→85 在旧度量下只开
   21/90，新度量（|Δ| EWMA）下开 79/90。docs/198 原话"**帧间**稳定该校正、**帧间**
   抖动该固执"字面就是帧间变化量。真实黄昏色温正是渐变——旧度量会把真实场景
   该校正的时刻全拒掉。修正后：渐变/阶跃/基线全开、噪声全关（上表）。
2. **真染色签名：frac 占比 → 色相分布 MAD**。docs/199 用 frac>0.5 区分真染色
   （toy yellow 0.667+）与噪声染色（toy dark 0.41）——但 DAVIS 真实场景 frac
   0.08-0.47 普遍 <0.5（真实背景大片灰/黑/低饱和，彩色像素占比天然低），frac 门槛
   会把真实场景全当噪声染色拒掉（baseline 门 0 开）。真染色的本质签名是**背景彩色
   像素色相分布的集中度**：真染色让像素色相集中在色温附近（toy yellow MAD 3°、
   DAVIS 全部 2-17°），像素级噪声让色相随机分散（toy dark MAD 47°）。修正后：
   真实场景 MAD 2-17° < 20° 门槛 → 全部识别为真染色（门开），toy dark MAD 47° 仍
   拒（门关）——toy 与 DAVIS 统一。

**最终判据**（TemporalGate）：
```
真染色（背景色相环形 MAD < 20°：色相集中=同一色温染的，像素级噪声 MAD~47° 分散）
AND 帧间一致（|Δshift| EWMA < 3°：渐变/稳定=帧间连续，增益跳变=帧间突变）
两条件 AND → 门开（白平衡校正）；否则固执（不校正，docs/101）
```

## 四、判读：docs/101 在颜色轴的最终落点

- **噪声有两个维度，都要固执**：
  - 像素级噪声（同一帧内）：色相分散（MAD 大）——"世界越噪声自我越该固执"的空间版；
  - 帧间噪声（时间上）：突变（|Δ| 大）——"世界越噪声自我越该固执"的时间版；
- **真染色也有两个维度，都要开放**：
  - 空间：色相集中（MAD 小）——整片背景被同一色温染；
  - 时间：帧间连续（|Δ| 小）——色温是环境属性，不突变；
- docs/196/197 的"何时校正"缺口：单帧占比（frac）是 toy 场景的偶然代理，真实
  场景失效；正解是**空间集中度（MAD）× 时间连续性（|Δ|）** 两维 AND。
- 校正动作不变（docs/199 ③）：通道级白平衡（乘性增益），不是色相旋转——真实背景
  同样证实（旋转通过率 0.183-0.850 vs 白平衡全 1.0）。

## 五、诚实边界

1. 合成红球叠在真实背景上（docs/183 合成方案）——确认度量可控（球体掩码），
   但球与背景的交互是合成的；真实视频的"自然彩色目标"（如 flamingo 本体）颜色
   确认需物体级真值（docs/195 §八 多视频补样本，后续）。
2. 扰动是乘性增益（黑天鹅帧标定）——真实黄昏是环境光照变化（更接近乘性），
   but 光照变化还含亮度、阴影、镜头响应，未建模。
3. MAD 门槛 20°、|Δ| 门槛 3° 是本场景标定；跨场景鲁棒性需更多视频（docs/195
   §八 多视频平均判据）。
4. 门开帧 29-49/60 不是 60/60——warmup 12 帧 + 阶跃/内容变化时的短暂关门（合理：
   突变后确认稳定再校正），以及部分视频内容运动（motorbike）导致的 |Δ| 波动。
5. 排除带坐标（x40-460,y130-270）按合成球轨迹定，对 DAVIS 背景是"排除中央带"的
   近似——真实目标位置由跟踪提供（docs/195 分工）时排除带应跟随目标。
