## 六、踩过的坑（续接者必读）

1. **flamingo 掩码"彩色占比"只有 0.13** → 确认度量必须按任务色相窗口（任务色占比），
   不是笼统彩色占比（docs/219 §四 ②）。
2. **白平衡掩盖他者的不**：真实偏色背景的 bg_gain 非 1，门一开全图乘就把 corrupt 的
   目标"校正"回原色 → 误通过；正解是相对基线增益门限 0.12（docs/219 §四 ①）。
3. **corrupt 破坏强度两难**：太强（std90 噪声）记账 hue 乱、带宽实验失效；太弱（kc 大）
   部分帧通过。flamingo 用温和冷增益 kc=0.05（漂移 15-25°、记账 hue 邻目标），surf 用
   强噪声（蓝绿对冷增益不敏感，漂不出 30° 窗口）。
4. **全局锁死被白平衡暂时掩盖**：C（wb）rest 一度 0.72 假恢复——加假恢复帧/去 wb 后
   锁死暴露（0.00）。对照必须 2×2（类别记忆 × 白平衡）都跑。
5. **surf 确认余量小**（frac 0.63）：thr 基线须按目标调（flamingo 0.60/surf 0.40），
   否则 surf 全部机制 rest 0.00（frac 波动跨过 thr，consec 永远到不了 k）。
6. **hue=None 保护**：surf 空掩码帧 → target_obs 返回 hue=None → thr() 距离加权
   circ(None, sh) 崩——thr(None) 直接返回基线。
