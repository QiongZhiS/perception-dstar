## 一、机制（vision/keep_learn.py，颜色轴 SEED-49）

```
theta : 期望色相（自我 = 任务利害），初始红 0°
o     : 目标区色相观察 = 真值 + N(0, sigma)
门控（SEED-25 自指过滤）：
  自洽：|o−theta|_circ < τ(30°) → 接受观察（世界的 不，可消化）
  或   验证涓流：每帧概率 nu → 接受任务层利害 o_v（他者的 不，唯一合法改判通道）
更新：theta ← theta + eta × (accepted − theta)_circ（有向最短环形差）

两场景（100 帧）：
  守住：目标 红30帧→蓝30帧→红40帧，任务恒"红" → theta 应终值红区
  改判：目标 红30帧→蓝70帧（永久），任务 前40帧"红"→后60帧"找蓝" →
        nu>0 应移蓝区；nu=0 应锁死红区
```

## 二、结果（3/3 PASS）

**P1 守住（18/18 组合）**：eta∈{0.05,0.2,0.5} × nu∈{0,0.05,0.2} × sigma∈{3,10}，
单次异常后 theta 终值全在红区（0°±2 或环形等价 180°±2）——自洽门拒染色观察、
验证涓流（=任务=红）只强化红，**感知层的"不"永不改判** ✓

**P2 改判（8/8 组合）**：eta=0.2 × nu∈{0,0.05,0.2,0.5} × sigma∈{3,10}：

| nu | sigma=3 终值 | sigma=10 终值 | 首次入蓝 |
|---|---|---|---|
| 0 | 0.7°（锁死） | 2.2°（锁死） | — |
| 0.05 | 119.2° | 117.5° | f81-86 |
| 0.2 | 119.6° | 122.5° | f52-58 |
| 0.5 | 119.7° | 117.8° | f48 |

**nu=0 锁死（docs/101 SEED-25：没有独立验证时固执变 100% 锁死）✓；
nu>0 全改判（任务层利害经涓流进入期望）✓**

**P3 平衡带**：15 组合（eta×nu 网格）改判速度 vs eta×nu 的 Spearman ρ = **-0.87**
（强负相关：乘积大入蓝快）。非严格单调——自洽门接管时机（theta 进入观察范围后
观察直接确认，不靠涓流）与 sigma 噪声叠加。

## 三、判读：两种否定的机制分界线（docs/178 补刀的回答）

1. **世界的 不（可消化）**：观察在自洽门内（|o−theta|<τ）→ 直接进期望更新——
   这是 docs/200 吸收系统该吸收的部分（越修正越准）。颜色轴：目标区色相在期望
   附近抖动 → 正常确认更新。
2. **他者的 不（不可消化）**：观察在自洽门外（染色 120° 离红 0° 远）→ 被拒在
   期望外，**但**任务层利害更新（"找蓝"）经验证涓流 nu 进入——这是唯一合法的
   改判通道。颜色轴：外部宣布目标变了 → 期望经涓流逐步移向新利害。
3. **分界线 = 通道**：观察（感知层）永远不改写任务层（利害外置，docs/188）；
   利害（任务层）经涓流改写期望。docs/200 的保留系统 = nu=0 特例（能守住但锁死
   改判）；本实验补上 nu>0（守住 + 有改判通道）。
4. **docs/101 平衡带在颜色轴的形态**：eta×nu 是"改判通道的强度"——太小改判慢
   （固执的代价是慢，docs/101 表 3），太大被噪声带动（sigma 大时终值抖动
   117-122）；最优在中间。这直接对应 docs/101 的"最优可塑性随世界硬度单调移动"。

## 四、诚实边界

1. 色相域 toy（标量 theta + 高斯观察）——没有真实图像，测的是**期望更新的门控
   结构**（自洽×涓流），不是完整视觉闭环；docs/200 的图像版 + 本实验的结构版
   互补。
2. nu 是固定概率（每帧独立）——真实"外部验证"是相关事件（任务层只在关键帧说
   话）；相关性会改变涓流的有效强度（后续可建模"验证到达过程"）。
3. 验证涓流的 o_v 也加 sigma 噪声——任务层利害本身可能含噪（利害更新也会错），
   sigma=10 时改判终值 117.5-122.5 抖动，这是 docs/101 sigma 的利害侧版本。
4. P3 的 ρ=-0.87 是 toy 参数下的相关性，非严格单调（自洽门接管机制叠加）；结构
   结论是"eta×nu 越大越快"，不是精确函数。
5. 现象层纪律照旧（docs/63）：测的是门控结构的行为（守/改判/速度），不宣称
   "信任/在乎"体验。
