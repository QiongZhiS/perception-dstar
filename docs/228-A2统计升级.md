## 一、方法

### 1.1 多种子协议（vision/davis_a2_stats.py）

- **种子数**：10 个随机种子（seed 0-9）重跑序列构造（build_sequence 的 rng 按种子重抽
  噪声/扰动，docs/221 A2"≥10 种子重跑序列构造"）。
- **随机性来源**（诚实拆开，见 §五）：
  ① 噪声抽样方差（rng 按种子重抽，纯 pattern 方差，`--jitter 0` 运行）；
  ② 扰动强度方差（`--jitter 0.25`：noise_std 与 corrupt_kc 按种子从独立 rng 流
  采样 ±25% 对称乘性，docs/219 源码 docstring"扰动强度参数化"的原意）。
  两个运行都做（`a2_flamingo.json` jitter 0.25 / `a2_flamingo_pure.json` jitter 0）。
- **指标**：每个 (视频,种子,变体) 报 P/R/F1 + flips（rest 段 claimed 翻转，docs/219
  定义不变）→ 跨 10 种子均值±SD（样本 SD，ddof=1）+ 百分位 bootstrap 95% CI
  （5000 次重采样，种子固定 20260828）。
- **GT/序列**：与 docs/219 完全一致（flamingo 20/20/15/25 thr 0.60 corrupt=gain；
  surf 14/12/10/19 thr 0.40 corrupt=noise；其余视频统一 gain、thr 按自动规则
  `thr = clip(median_frac − 0.30, 0.30, 0.60)`）。
- **变体**：A full / B nowb / C global-wb / C2 global / D template / E fixedbw10 /
  F fixedbw30（核心视频全 7 变体；其余视频 A+D 两变体）。

### 1.2 thr 扫描（PR 曲线操作点）

- 参考种子 seed 7、jitter 0（与 docs/219 单次协议逐字一致）扫确认阈值基线：
  flamingo 8 点 `0.25,0.35,0.45,0.55,0.60,0.65,0.75,0.85`；surf 5 点
  `0.20,0.30,0.40,0.50,0.60`。每点报 A（纪念机制）与 D（朴素模板）的 P/R/F1。
- **参考点校验**：flamingo thr=0.60 → A F1=0.8269（docs/219: 0.83）、D F1=0.9107
  （0.91）；surf thr=0.40 → A F1=0.7576（0.76）、D F1=0.8493（0.85）——逐字复现。

### 1.3 flips 重采样检验

- **配对符号翻转精确置换检验**（H0：均值差=0；2^10=1024 全枚举，双侧）：
  A（纪念）与 D（模板）在同一 10 个种子上的 rest 段 flips 配对。
- **配对 bootstrap 95% CI**（5000 次，成对重抽样）报均值差与各自均值。
- 判据：p<0.05 拒绝"两系统 flips 无差异"。

### 1.4 A5 JSON 归档

- 每次运行（视频×种子×变体）的逐帧 trace（帧号/段/frac/hue/ok/claimed/thr/k/gate）
  + 指标写入 `vision/out/results/a2_<video>[<tag>].json`；每完成一个种子写
  checkpoint（`ckpt_<video>_<config哈希>.json`，可断点续跑）。
- 工件 11 个（见 §六），全部自描述（config/task_hue/GT/种子列表/抖动参数）。

## 五、随机性来源分解（诚实边界 1-2）

同一 10 种子、jitter=0（纯噪声抽样）重跑：

| 运行 | A full F1 均值±SD | A flips 均值±SD | 说明 |
|---|---|---|---|
| flamingo pure（jitter 0） | 0.8269±0.0000 | 1.00±0.00 | **跨 10 种子零方差**：判定余量（frac≈0.94 vs thr 0.60）跨不过噪声 |
| flamingo jitter 0.25 | 0.8417±0.0273 | 1.10±0.57 | 方差全部来自强度抖动 |
| surf pure（jitter 0） | 0.7420±0.0200 | 2.00±0.00 | 余量小（frac≈0.63），噪声抽样已产生真实方差 |
| surf jitter 0.25 | 0.7340±0.0277 | 2.00±0.00 | 抖动在纯方差上叠加（SD 0.020→0.028） |

1. **方差来源诚实拆开**：flamingo 的"种子间方差"在纯噪声抽样下为零——docs/219 源码
   docstring 写"不同种子=不同扰动强度，结果才有真实方差"的原因即在此；本轮的
   ±25% 强度抖动把该方差兑现（SD 0.027）。surf 两者都有。论文若报均值±SD，必须
   注明方差来源是强度抖动而非纯噪声抽样（否则"SD"会误导为噪声鲁棒性）。
2. **抖动使均值偏离参考点**：flamingo 0.8417 vs 参考 0.8269、surf 0.7340 vs 参考
   0.7576——对称乘性抖动（±25%）的效应不对称（扰动更强时 R 掉得更多）。参考数字
   仍是 seed-7/jitter-0 的 docs/219 值（§四复现）。

## 八、诚实边界（除 §五 1-2 外）

3. **其余 7 视频注入未按目标验证**（docs/220 坑 3 的 A4 事项未做）：统一 corrupt=gain
   对 bear/blackswan/camel/dog/soccerball 分离力弱（A 的 P≈0.75-0.88，corrupt 帧未拒
   净）——这些视频的 P/R/F1 只能作"统一协议下机制跑通性"证据，不能作"拒绝对抗"
   证据。
4. **flips 指标在 5 个视频上不判别**：两系统 rest 段 claimed 恒定（全 0 翻转），
   置换 p=1.0——flips 只在 rest 段落在判定边界附近时有信息量（flamingo/surf/
   car-turn/motorbike 是判别样本）。
5. **D 模板 flips 双峰**（0/8）：强度抖动下"假恢复"帧整段通过（kc 弱→全 claim→
   0 翻转）或整段拒绝（→8 翻转）；flips 对模板匹配是分叉响应，均值±SD 是摘要不是
   分布形状。
6. **thr 扫描是参考种子操作点**，非多种子平均 PR 曲线（多种子均值只在默认 thr 点
   给出，§二）；若论文要平均 PR 曲线需再加一档（成本 ~2 分钟/视频）。
