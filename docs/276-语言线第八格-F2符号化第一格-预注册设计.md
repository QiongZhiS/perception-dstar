## 一、设计（预注册，冻结；符号化机制/判据/守卫/旋钮/流/划分先于实现冻结，运行后不改）

### 1.1 符号化机制（本格核心，冻结；先于任何机制运行）

**问题定义（docs/255 §八2 + docs/266 §五2 + docs/275 §五16 预告）**：docs/268-275 的 ctx
合成 = `ctx = sign(s − x_self)`（信道信号 s 与自身位置 x_self 的连续质心比较后设计二分）——
**符号映射是实验者设计的**（边界固定为 0、符号集固定为 {0,1}）。docs/255 §八2 明示 F2
形态："ctx_B 信号从'连续质心合成'变成'稳定符号（如 0/1 档或原型槽）'，测符号的稳定性/
压缩率/可预测性"；docs/240 F2 = "符号→意义的压缩/传递"。本格把**信号表示层**（ctx 的
生成方式）改造为**回路自身行为涌现的离散符号映射**：符号表边界由回路自己的信号/能量
统计决定（非人工指定），符号集大小由行为决定（信号非退化且能量可切分 → 2 个符号；
否则 0 个——诚实"无结构不符号化"），并测符号的稳定性/可预测性/压缩/脱情境引用。

**冻结的符号化机制（信号表示层；docs/275 逐字继承 + 本格唯一机制改动）**：

1. **连续信号合成（逐字继承）**：每窗口回路合成连续相对信号 `d(w) = s(w) − x_self(w)`
   （s = 收到的对方发布质心、x_self = 自身事件质心；任一侧 <5px → d=None）——与 docs/268
   §1.1 ctx 合成的输入逐字相同（机制可计算、不读真值；docs/250/251 纪律）。
2. **符号表（行为涌现，冻结）**：由回路**自身校准前缀窗 [0, N_C) 的观测历史**（感知管线
   输出：发布质心序列 + 窗口能量——机制无关、不读真值）计算：
   - **候选边界**：相邻 distinct d 值的中点（τ_j = (v_j + v_{j+1})/2）；
   - **边界选择**：对每个候选 τ，按 d 分两群（d<τ / d≥τ，各 ≥ SYM_GROUP_MIN=3 窗），
     两群中位能量 m0/m1，中位中点 mid = (m0+m1)/2；**组内能量纯度** p(τ) = max(
     min(f0, f1), min(1−f0, 1−f1))（f0 = 低群 E<mid 占比、f1 = 高群 E≥mid 占比；取向最优——
     符号 0/1 的映射方向任意，只要求群内一致）；**τ* = argmax p(τ)**；
   - **符号集大小由行为决定（激活条件，三条同时满足才符号化）**：
     ① **信号非退化**：接收信号在校准段 ≥ SYM_DISTINCT=**2** 个 distinct 值（常量信号
     s≡160（G1n）或无信号（G0a）→ 1 个/0 个 distinct → 不符号化 → ctx=None ——构造性
     保持 docs/275 的 G0A/G1n 零采纳语义）；
     ② **数据充分**：≥ 2×SYM_GROUP_MIN=6 个有效 (d,E) 对（两群各 ≥3 窗）；
     ③ **能量纯度**：p(τ*) ≥ SYM_PURITY_MIN=**0.80**（复用 docs/270 门阈值——符号必须把
     回路自己的能量结构切干净；随机/弱相关的信号切不出 ≥0.80 的群内一致性）；
   - **符号**：`symbol(w) = 0 if d(w) < τ* else 1`（激活时）；不激活 → ctx=None。
3. **固化（冻结）**：符号表自回路校准段行为固化、于 N_C 处冻结（docs/269 环境带预计算
   先例——符号表 = 表示层环境常量，校准段形成、留出段使用；每臂每侧一张表，由该臂
   该侧自己的接收信号与能量计算——G0A/G1n/G2s/G2R/W 各有自己的表，与 M 臂解耦）。
4. **脱情境引用（冻结）**：DC 臂于 N_C 处切断信道信号（s=None → d=None），符号层引用
   **最后固化符号**（寄存器 = 最近一个有有效符号的窗口的符号；确定性）作为 ctx——
   "提到不在场的事物"（docs/255 §八2 的最强形态）。

**论证——为何"符号是涌现的不是设计的"（冻结；§二 C1 设计期实测佐证）**：

1. **边界不是固定常量**：docs/268-275 的边界 = 设计常数 0（sign 比较）；本格 τ* 由回路
   自己的 (d,E) 统计决定，逐种子/逐侧变化（设计期实测 A：−7.4~+4.0、B：−5.0~+3.8，见
   §二 C1）——回路从自己的观测经验中"发现"符号边界，非实验者指定。
2. **符号集大小由行为决定**：激活条件 ①②③ 全部由回路自己的数据满足与否决定——信号
   退化（常量/无信号）→ 0 个符号（ctx=None）；信号有结构但能量切不干净（随机信号）→
   0 个符号；信号有结构且能量可切分 → 2 个符号。符号集 {0, 2} 的取舍是行为判断（"无结构
   不符号化"的诚实语义），非人工指定 {0,1} 恒成立。
3. **回路不读真值、不预设符号表**：符号表仅由感知管线输出（质心/能量）计算（docs/269
   预计算协议同款）；真值 ctx 只进评估统计/守卫（C1 一致率/保真度），机制路径零接触
   （docs/250/251 纪律）。
4. **自适应 vs 设计二分**：若世界几何改变（如 A/B 中心或轨道变化），设计二分 sign(s−x)
   边界恒为 0（不自适应）；本格符号表随回路的实际观测重算（自适应）——"符号 = 回路对
   自己经验的压缩"的行为涌现语义。
5. **合成先例**：docs/235 _band 能量分档（D1 校准把能量边界从 [150,450,1000,2500] 移到
   [150,450,2000,3000]——边界由环境能量统计决定非人工指定）是"行为统计决定分档"的既有
   先例；docs/269 环境带预计算是"机制无关预计算冻结表示常量"的既有先例——本格把同一
   纪律应用到信号域（符号槽 = 信号值域的能量一致性分档）。
