## 一、设计（预注册，冻结；门定义/判据/旋钮/守卫/流/划分先于实现冻结，运行后不改）

### 1.1 采纳门收紧（本格核心，冻结；先于任何最终运行）

**问题定义（docs/269 §四/§五11 照实）**：docs/269 能量带抬升后，G2s（错乱信号）spurious
采纳 6/10（S0/S1/S3/S5/S6/S8 提升，compound=1.0）——随机 ctx_B 分裂把窗口能量恰好分到
两组并越过 1.30 中位能量比条件（条件③）。这暴露条件③是**能量分离的代理**：它对"真值
ctx 对齐的分裂"与"随机分裂"同样敏感。**本格目标（冻结）**：给采纳机制加一个**保真度/
纯度门**，使"信息量"从能量分离代理升级为**语义对应**（分裂与该条目的真实上下文对应），
同时保住 G1 正证据（docs/269 COMM_EMERGES 不变差：adopt_frac/JR 配对比值/compound/
transfer 不显著恶化）并新增 G2s 零 spurious 判据。

**候选机制门评估（冻结；本格核心决策）**：

| 候选 | 定义 | 裁决 | 理由（冻结） |
|---|---|---|---|
| (a) 真值保真度门 | 提升时要求该条目 ctx_B 与真值 ctx 窗口吻合率 ≥ 阈值（如 0.7） | **否决** | 真值 ctx 是**世界级事实**，机制在运行中不可见（docs/268/269 明确：真值只用于评估统计/守卫，不进机制决策；docs/250/251 纪律）；用真值做门 = 机制作弊，且破坏"两格同尺可比"（真值在任何格都不进机制） |
| (b) 纯度门字面版 | 子条目匹配窗口的 ctx_B 值与其 tag 一致率 ≥ 阈值 | **否决** | 恒真无筛选力：匹配 arity-3 (c0,c1,v) 本身要求 ctx_B==v，子条目被匹配的窗口的 ctx_B 与其 tag 一致率 = 1 是构造性的；门必须检验**账本分裂的组内同构性**而非匹配事后一致性 |
| (b') **组内能量纯度门（机制可计算版）** | 提升触发时，账本两个合格 ctx 组的窗口能量各自 ≥ GATE_PURITY_MIN 比例落在两中位中点 mid 的自身一侧（低中位组：E<mid；高中位组：E≥mid） | **采纳（本格条件④）** | 纯行为可计算（只读账本 c2_ene 的 (ctx, 能量) 窗口记录，不读真值）；直接检验"分裂对应数据真实双峰结构"——本环境能量模式 = 真值 ctx 状态的机制可见投影（docs/269 §1.1：E0 481-530/E1 697-746 两态分离），故"每组内部能量同构"= "ctx_B 分裂与该条目的真实上下文对应"的机制可计算等价物；随机分裂（G2s）每组是两态混合 → 纯度 ≈ 0.5；真值对齐分裂每组单态 → 纯度 ≥ 0.75-1.00（§二 设计期实测） |
| (c) G2s 反错乱判据升级 | spurious(G2s) 从诊断级升为判据（== 0，10/10） | **采纳（C5）** | 与机制门配合：机制门负责"杀"，判据负责"可证伪地测"——spurious 从"照实报告"升级为"判据级主张"，是本格核心主张 |
| (d) 其他门（如组间无重叠分离门 max(低)<min(高)） | 要求两组窗口能量完全无重叠 | **不采纳为门**（报告为候选分析） | 对真值保真度污染（docs/269 保真度 0.9292 → ~7% 窗口错配跨态）过于脆弱：任一错配窗口即破坏无重叠 → 真值对齐分裂也会被误杀；纯度门对错配窗口有容忍（80% 同侧即可），稳健性更优（§二 设计期实测对比） |

**冻结的门定义（条件④，机制加法最小）**：在 docs/268/269 提升条件（① 命中 ≥ k_split=5；
② ≥2 个非 None ctx_B 值各 ≥ k_consist=3 窗；③ ctx_B 条件中位事件能量比 ≥ 1+δ_rel=1.30）
之后加**条件④**：

- **组（冻结）**：Q = {v : v 非 None 且 账本组 v 窗口数 ≥ k_consist=3}（与条件②同源）；
- **中位（冻结）**：med_v = 组 v 中位事件能量（与条件③同源）；mid = (min_v med_v +
  max_v med_v) / 2；
- **组内纯度（冻结）**：对 v ∈ Q：若 med_v 为低侧（= min_v med_v）：purity_v =
  |{e ∈ 组 v : e < mid}| / |组 v|；否则（高侧）：purity_v = |{e ∈ 组 v : e ≥ mid}| /
  |组 v|；
- **门（冻结）**：`min_v∈Q purity_v ≥ GATE_PURITY_MIN = 0.80`；不满足 → 该窗口不提升
  （父条目继续累积账本证据，后续窗口仍可触发——**无回退、无降级**，仅延迟或阻止；
  docs/235 退休语义逐字不变）。

**门阈值冻结与论证（GATE_PURITY_MIN=0.80）**：① **概念来源（冻结，先于任何本格机制
运行）**：docs/235 M4 条目纯度概念 = "匹配窗口上真值上下文多数占比，应显著 > 0.5"
（随机填充基线 = 0.5）；docs/264 的 0.5 语义（相对/绝对阈值远离随机基线）。本门 = 该
纯度的**机制可计算版**（组内能量模式一致性替代真值多数），阈值取"4/5 语义一致" =
0.5 + 0.30 清晰余量；② **设计期实测（§二 C1 记录，环境行为而非结果调参）**：随机混分
（G2s 实况 + 蒙特卡洛随机分裂）纯度 ~0.50-0.67（单种子 S5 错乱臂晚窗峰值 0.78）；
真值对齐分裂（真实臂）纯度 ≥0.75-1.00（8/8 可采纳种子在 W8-W12 达 ≥0.80，其余种子
≥0.83）；0.80 落在分离区中点（距随机上沿 0.78 余量 0.02、距真实下沿 0.75 余量 0.05——
**最紧点两侧余量均非零**，且设计期实测门关闭时恰复现 docs/269 6/10 spurious → 门开启
后 G2s 全灭为可检验预言，§二 C4 核对）；③ **判据阈值零回调声明**：C1-C4 阈值（0.85/
0.6/0.5/0.10/0.5×）逐字沿用 docs/269 未动；0.80 是本格新冻结的机制门阈值（新预注册
新冻结量，docs/63：第二格不回调、第三格重新冻结机制加法），非看结果后调整。

**关键约束满足性论证（冻结）**：

1. **机制门纯行为可计算**：门只读账本 c2_ene（(ctx_B, 事件能量) 窗口记录，全部来自
   回路自身窗口可观测），与真值 ctx **零接触**——真值仍只进评估统计（M4 保真度诊断）
   与守卫；docs/250/251 纪律不破。
2. **杀 G2s spurious 的机制依据**：G2s 的 ctx_B 分裂与真值 ctx 不相关（docs/268 信道
   定义）→ 每组 = 两能量态的随机混合 → 组内纯度 ≈ 0.5 ≪ 0.80 → 门阻止提升（设计期
   实测预言 spurious 6/10 → 0/10，§二 C4 核对）。
3. **保 G1 正证据的机制依据**：真实臂 ctx_B 与真值 ctx 对齐（保真度 0.9292）→ 每组 =
   单一能量态为主 → 组内纯度 ≥ 0.75-1.00 → 门通过（设计期实测 8/8 可采纳种子在
   W8-W12 达门，全部仍落校准段 [0,14) → C4 转移前提不破）；门对部分种子延迟提升
   （如 docs/269 首提升 W6-10 → 本格 W8-12）——**这是被测的机制差异，非回调**（§四
   对比要点：JR/transfer 的相应变化如实报告）。
4. **机制加法最小**：仅 _maybe_promote 条件③后加一个条件④（LangCommGateLoop 覆写

## 五、诚实边界（预注册阶段已知边界）

1. **门 = "语义对应的机制可计算等价物"，不是真值保真度本身（本格最核心边界）**：条件④
   检验的是**组内能量纯度**（每组窗口能量与自身模式的一致性）——它是"ctx_B 与该条目
   真值 ctx 一致"的**行为等价物**（本环境能量模式 = 真值 ctx 状态的机制可见投影），不是
   真值对应本身（机制运行中真值不可见，docs/250/251 纪律）。门保证的是"分裂对应数据
   真实双峰结构"（反随机混分），其与真值语义的一致性由评估侧保真度诊断（M4，~0.93）
   佐证——门自身不宣称读取语义，只宣称**行为同构性**。若未来环境能量模式与真值 ctx
   解耦（如 ctx 不影响能量），本门将失去语义代理性——如实声明。
2. **门阈值 0.80 的分离余量不对称**：设计期实测随机混分纯度上沿 0.78（单种子晚窗峰值，
   蒙特卡洛 W24 概率 ≤0.03）、真实对应纯度下沿 0.75——0.80 距两者余量分别为 0.02/0.05，
   非对称且偏紧于随机侧；若某种子错乱臂在提升窗恰好高纯度（>0.80），C5 会如实失败
   （COMM_EMERGES 残留形态），不回调阈值。
3. **门可能延迟/阻止真实采纳（机制差异正是被测对象）**：设计期实测门把部分种子首提升
   从 docs/269 的 W6-10 延迟到 W8-12（如 S1 W7→W8、S3 W9→W12、S8 W10→W12）——均在
   校准段 [0,14) 内（C4 前提保持），但 JR 配对比值/transfer/calib_baseline 数字必然与
   docs/269 有差（子条目创建更晚、匹配窗集不同）；若某种子门纯度不足被阻止 → adopt_frac
   下降 → 照实判定（C2 阈值 0.6 不动）。任何 G1 数字变化均在 §三/§四 与 CELL2_REPRO
   （门关闭基线）逐项对比声明。
4. **G2s 判据升级的语义边界**：C5 的零假阳性只针对"与真值 ctx 不相关的错乱信号"
   （docs/268 信道定义）；与真值 ctx **弱相关**的信号（保真度 < 0.8 的真实信道变体）是
   后续格候选，本格不宣称。C5 也不宣称"门在所有环境/信号族普适"——只宣称本冻结环境 +
   本冻结信道定义下 G2s 零 spurious（判据级，可证伪）。
5. **两/三格同尺可比的前提与局限**：本格判据 C1-C4/机制基座/守卫与 docs/268/269 逐字
