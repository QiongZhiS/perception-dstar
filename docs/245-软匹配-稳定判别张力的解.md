## 〇、一句话（预注册 + 结论）

> **预注册：把 docs/243/244 的"精确档位匹配"替换为"原型距离软匹配"——窗口特征
> x=(ln(1+E), ln(1+U))（E=窗口事件像素总数，U=上区 y<68 事件像素数，对数域使乘性
> 能量差可比），条目 = 连续空间原型（中心 μ + 命中统计），匹配 = 到最近原型欧氏距离
> ≤ r（r 只在校准集统计 = 校准窗口最近邻距离的中位数），创建 = 连续 k_consist=3 个窗口
> 无原型在 r 内 → 新原型（时间滞回防边界抖动），原型自适应启用（α=0.2 滑动跟踪场景
> 漂移）；数据/预处理/确定性流与 docs/243/244 完全一致（DAVIS 9 视频灰度 + resize

> 只有留出过线才算泛化）、STRUCT_STILL（SC2>0 且 churn≤0.5，R0+R1）、STABLE_STILL
> （末/首四分之一 MAE 比 ≤ 1.5，R0+R1）。判定：全过 = SOFT_PASS；桥过但留出不过 =
> SOFT_PARTIAL（半径过拟合校准集）；结构/稳定破坏 = SOFT_FAIL。张力解除的判定：
> 三列对比（SC2/bridge/churn）同时取得 docs/243 的一致性（SC2 保持 >0、churn 低）与
> docs/243/244 都没拿到的判别（bridge ≥ 0.5，且留出过线）。**

> **结论：SOFT_FAIL（STRUCT_STILL 失败：R1 churn 0.7692 > 0.5）。** 判别侧大幅修复
> ——桥对应率 **0.25 → 1.0（8/8）**，校准 1.0（4/4）、**留出 1.0（4/4）**（docs/243/244

## 一、预注册设计（判据先于最终运行冻结，docs/63 纪律）

### 1.1 张力回顾（docs/243/244 两格，冻结引用）

| 格 | 分档法 | R0 SC2 | R1 SC2 | R1 churn | bridge_sw | 结果 |
|---|---|---|---|---|---|---|
| docs/243 | 旧粗档（toy bins） | 1 | 3 | 0.0 | **0.25** | REAL_PARTIAL（判别失败） |
| docs/244 | 校准集等频分位数 | **0** | 1 | 0.5 | 0.25 | RECAL_FAIL（结构破坏） |

判读：旧粗档的**一致性**与等频分位数的**判别企图**互斥——精确档位匹配把"窗口落在
哪个离散格"当成唯一信号：粗格保一致性但抹平场景差异（9 场景 → 2 基签名）；细格把
边界切进场景内部，场景内窗口频繁跨档，k_consist=3 精确相等一致性失守 → 结构坍缩。
**假设：量化（精确档位匹配）本身是张力的来源，不是档位边界的选择。**本实验把匹配
从"精确档相等"改为"连续原型距离 ≤ r"：场景内窗口落在原型邻域内 → 一致性；场景间
窗口落在所有原型邻域外 → 新原型 → 判别。档位（bins）不再参与主匹配路径。

### 1.2 软匹配机制（预注册，冻结）

**特征空间（每窗口）**：
- E_w = 窗口 w 的事件像素总数（`loop.energy_trace[w]`，CPLoop 预测/阈值路径原样，
  与 docs/243/244 逐位一致）；
- U_w = 窗口 w 的上区（y < 68）事件像素数（`loop.up_trace[w]`）；
- 特征向量 **x_w = (ln(1+E_w), ln(1+U_w))**（对数域：乘性能量差可比，两轴同为
  log-像素单位；零事件窗 U=0 → ln1=0 自然处理）。
- **参与门**：E_w ≥ 10 的窗口参与匹配/创建（与 docs/235/243 的 `_window_sig` None
  条件逐字一致：事件不足的窗口无签名，不参与、不推进、不重置计数）。E_w < 10 的窗口
  记入 trace（matched=None），计数保持。

**原型（条目）**：连续空间对象 p = {中心 μ=(μE, μU)（对数域）、hits、created_win、
last_active、n_match}。**无档位量化**（bins 仅存在于继承的 CompLoop 配置槽，不参与
本匹配路径）。原型不退休（软匹配无提升机制，无 arity-3——槽位采纳/组合事件不在本
实验范围，compound_frac=0 按设计，不进判据）。

**匹配（每参与窗口）**：对全部原型取最近者 p* = argmin_i ‖x_w − μ_i‖₂；若
‖x_w − μ_p*‖₂ ≤ r → 匹配：hits += 1、last_active = w、n_match += 1。**自适应（启用，
预注册 α=0.2）**：匹配后 μ_p* ← (1−α)·μ_p* + α·x_w（原型均值向窗口滑动，流式跟踪
场景内漂移；只动中心，不动命中统计）。

**创建（带时间滞回，防边界抖动）**：若无任何原型在 r 内 → 连续未匹配计数
n_unmatched += 1；当 n_unmatched ≥ k_consist=3 → 在**当前窗口特征处**创建新原型
（hits=1、created_win=w、last_active=w、n_match=1），当前窗口计为新原型的首次命中，
n_unmatched 清零。任何匹配（既有原型或新创建）→ n_unmatched 清零。k_consist 连续
未匹配要求就是滞回：单个异常窗口不会触发创建，场景切换需 3 个连续窗口确认。

**确定性**：无 RNG、无 jitter、无逐场景统计；全部操作（np.log1p / 欧氏距离 / 中位数）
确定性。k_consist=3、hits_min=3、persist_win=5 沿用 docs/241/243 冻结值。

### 1.3 半径定义与校准/测试分离（预注册，冻结）

- **半径 r 的标定**（数据定标，只允许在校准集统计）：
  - 校准 pass = 默认 LOOP_CFG 的 CompLoop 冷启动跑**校准集拼接流**（= R1 前 367 帧 =
    flamingo/surf/bear/camel/dog，37 窗口），收集每窗口 (E, U)。事件检测路径与测试
    pass 完全相同（bins/软匹配都不改事件掩码），故校准窗口特征与完整流前 37 窗口
    逐位一致（docs/244 §1.4 同款论证）。
  - **r = 校准集参与窗口（E ≥ 10）两两最近邻距离的中位数**：
    r = median_w ( min_{v≠w} ‖x_w − x_v‖₂ )——"典型窗口间距"的相对尺度，对数域
    单位不变。预注册：不加乘子（×1.0）、不取分位数、不逐场景统计。
  - 回退（预注册，预期不触发）：参与窗口 < 4 时 r = 0.5（对数单位 ≈ 65% 乘性）。
- **测试分离（防循环，与 docs/244 §1.2 同款）**：留出集（blackswan/car-turn/motorbike/
  soccerball，4 视频 221 帧）在 r 的估计中**零贡献**；留出切换对应率是泛化检验的
  唯一证据。**禁止逐场景归一化**（把每个场景能量按自身范围缩放/定档会把场景边界
  泄漏进特征，使切换编码平凡化）——本实验特征只用原始窗口统计，零场景身份。
- **防循环声明**：单次确定性校准（一个标量 r）；若校准切换对应率高而留出不过线 →
  如实报告"半径过拟合校准集"（SOFT_PARTIAL 分支）；不允许用留出集结果回调 r。

### 1.5 判据（预注册，先于最终运行冻结；不得在看过结果后修改）

1. **BRIDGE_FIX**：完整 9 视频流（软匹配）`bridge_corr_switch ≥ 0.5`（docs/243/244
   均为 0.25）。
2. **HELD_OUT**：`holdout_switch ≥ 0.5`（留出视频切换对应率——只有留出集过线才算
   泛化；`calib_switch` 分开报告，不进判据；若留出不过线 → 如实报告"半径过拟合校准集"）。
3. **STRUCT_STILL**：`SC2 > 0` 且 `churn ≤ 0.5`，**R0 与 R1 均要求**（与 docs/243
   STRUCT_EMERGES / docs/244 STRUCT_STILL 同口径：软匹配不破坏结构涌现）。
4. **STABLE_STILL**：`MAE 末/首四分之一窗口均值比 ≤ 1.5`，**R0 与 R1 均要求**

### 1.6 判定规则（冻结）

- 四条全过 = **SOFT_PASS**（软匹配同时取得一致性 + 判别 + 泛化）。
- 判据 3/4 过，但 1 或 2 不过 = **SOFT_PARTIAL**——其中 BRIDGE_FIX 过而 HELD_OUT 不过
  → 注明"半径过拟合校准集"；BRIDGE_FIX 本身不过 → 注明"软匹配未修复桥（数字见报告）"。
- 判据 3 或 4 失败（结构/稳定被破坏）= **SOFT_FAIL**。
- 判据无法计算（数据缺失等）= **PARTIAL**（照实）。

### 1.7 张力解除的判定方式（冻结，附带报告）

把 docs/243 / docs/244 / 本实验三列（SC2、bridge_corr_switch、churn）并排比较：

- **一致性侧**：软匹配的 R0 SC2 与 R1 SC2 均 ≥ docs/244 的对应值且 > 0（结构不坍缩，
  对齐 docs/243 的"一致性"格）；
- **判别侧**：软匹配的 bridge_corr_switch ≥ 0.5 且 holdout_switch ≥ 0.5（拿到
  docs/243/244 都没拿到的判别 + 泛化）；
- **churn 侧**：R0/R1 churn ≤ 0.5（不引入新的不稳定）。
- **判定**：SOFT_PASS 且三列同时满足上式 = **张力解除（YES）**；SOFT_PARTIAL =
  部分解除（判别只在校准场景，半径过拟合校准集）；SOFT_FAIL = **张力未解除（NO）**
  （软匹配自身破坏一致性或稳定——量化不是唯一张力源，或 r 选择不当）。

## 六、诚实边界

1. **半真实妥协（预注册，§1.4）**：R0 循环（flamingo ×5）与 R1 硬切拼接是仅有的人为
   元素；像素/运动/噪声/色相全部真实（docs/243 同款）。
2. **STABLE_STILL 是控制项（预注册 §1.5 声明，实证）**：软匹配只改模式表路径不改
   预测路径，MAE/Q1/Q4/比/pin/θ 与 docs/243/244 **逐位一致**（0.097127/0.069522、
   比 0.907701/0.951261）——本判据通过是构造性的（回归守卫角色），不是软匹配的
   独立证据。
3. **半径旋钮的单点采样（本实验核心诚实声明）**：r=0.2659 是预注册的单值（校准集
   最近邻距离中位数、无乘子、单次确定性 pass）。结果落在判别极（bridge 1.0、churn
   0.77）。**更大的 r 很可能降低 churn 但可能牺牲判别（场景合并）**——这是半径旋钮
   的连续权衡，本实验**没有**做多半径扫描（那会是"看过结果后回调参数"的二次校准
   循环）；跨半径工作点搜索必须作为新实验（docs/246+）预注册后运行。
4. **过创建机制归因（诚实判读）**：R1 churn 0.7692 的直接机制是 (a) 创建被
   k_consist=3 连续未匹配滞回推迟进场景尾部（motorbike 4 窗口、soccerball 5 窗口在
   创建后只剩 1-2 窗口），(b) 场景内窗口特征散布超过 r 的比例高（4 个 U=0 原型创建后
   不再匹配）。这不是 docs/244 的"一致性被分档破坏"（R0 SC2 保持 3），是**判别成功
   的代价形态**（每场景都建了原型，但短场景的原型来不及固化）。
5. **无 arity-3 / 无槽位采纳（预注册 §1.2）**：软匹配只测 (E,U) 基判别；compound=0
   按设计，docs/235 的组合机制（c2 槽位采纳/提升）不在本实验范围，不进判据。
6. **防循环合规**：r 只依校准集（5 视频 367 帧 34 参与窗口）统计；留出集（4 视频）
   在 r 估计中零贡献；单次确定性校准，无任何"看过结果后回调 r/α/k"的轮次；逐场景
   归一化未使用（特征只用原始窗口统计，零场景身份）。留出 1.0 如实报告。
7. **回归守卫**：旧档精确匹配重跑 R0/R1 = R0 SC2=1/churn 0、R1 bridge_sw 0.25/SC2=3/
   churn 0，与 docs/243 逐位一致——数据加载、span、桥度量实现无漂移。
8. **统计与计算**：固定确定性流（无种子协议，声明）；窗口级 mean±SD（ddof=1）+
   2000 次 bootstrap CI（种子 20260828）；工件 smt_main.json（config/calib/逐级/桥/
   逐场景原型/判据/verdict/timing）+ smt_timing.json（数字逐位一致，仅 elapsed
   1.99 vs 1.94）；总计算 ≈ 3.9 秒（预算 60 分钟）；安全纪律全程遵守（powershell
   包装 + extract_r 纯正则抽取，未读任何日志/JSON 原文）。
