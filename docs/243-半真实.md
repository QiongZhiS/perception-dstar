## 一、预注册设计（判据先于最终运行冻结，docs/63 纪律）

### 1.1 环境与预处理（冻结）

- **数据**：vision/out/davis/<video>/ 的 JPEG 帧（854×480 彩色，每视频 N 张 .jpg：
  flamingo 80 / surf 55 / bear 82 / camel 90 / dog 60 / blackswan 50 / car-turn 80 /
  motorbike 43 / soccerball 48，共 **588 帧**）。
- **预处理（固定流水线，冻结）**：`cv2.imread(IMREAD_GRAYSCALE)` →
  `cv2.resize(160×120, INTER_AREA)` → uint8。理由：能量分档是"窗口事件像素数"这一
  **分辨率归一化**的量，校准工作分辨率是 160×120；迁移问题测的是**同一工作点的真实
  像素统计**（自然运动/噪声/色相），不是分辨率缩放。原生 854×480 下分档必然饱和
  （信息性诊断单独报告 R_RST_NATIVE_*，不进判据）。
- **无注入、无 jitter、无 RNG**：真实像素流本身是确定性的（固定 JPEG 序列）。
  声明：docs/228 的多种子协议在此无意义（无种子随机性），统计外壳改为**窗口级**统计
  （mean±SD + bootstrap CI over 窗口 + 全 trace 归档 + checkpoint/resume 断点续跑）；
  "必要 jitter"不注入——真实流没有合成噪声参数，注入反而是人为扰动，如实声明。

### 1.4 判据（预注册，先于最终运行冻结；不得在看过结果后修改）

1. **REAL_STABLE（真实流稳定性）**：对每级 L ∈ {R0,R1}，
   `ratio(L) = mean(mae 末四分之一窗口) / mean(mae 首四分之一窗口)`。
   **通过（每级）**：`ratio(L) ≤ 1.5`（误差有界、不发散）。附报 Q1/Q4 均值。
2. **STRUCT_EMERGES（结构涌现 = 机制迁移）**：`SC2(R0) > 0` **且** `SC2(R1) > 0`
   （SC2 = 结束时仍在表内、命中 ≥ hits_min=3 的稳定条目，docs/235 M2 冻结定义）。
   **通过**：两者都 > 0。任一 = 0 → **机制不迁移**（toy 校准过拟合风险照实报告）。
3. **STATE_PERSIST（状态持久）**：每级 × 3 中断点（R0: p1=120 / p2=133（窗口内）/
   p3=250；R1: p1=240 / p2=355（窗口内）/ p3=500）在中断点 save 状态 → load → 续跑，
   与不中断运行**逐帧全等**（从 p 起的每帧 (mae,att,ev,theta,db) 输出全等 且 finalize
   全部输出全等）。**通过**：全部 6 个测试点（2 级 × 3 点）SEQ_EQ=1（docs/234
   round-trip 流式版；状态快照含 bg_fast/bg_slow/prev_L/sigma_hat/θ/db/参数位移/
   SC 计数/模式表（含 c2_ene 账本与退休态）/签名史/窗口内事件掩码/帧缓冲/匹配史，
   JSON 落盘，float 无损往返）。
4. **BRIDGE_TO_REAL（桥到真实）**：`churn(R1) ≤ 0.5`（**放宽自 0.3**，预注册：短视频
   （43-90 帧 = 4-9 窗口）尾部窗口创建的条目无法累积命中是拼接流的固有 churn 源）
   **且** `bridge_corr_switch ≥ 0.5`。定义：switch i（i=1..8，切换帧 S_i = 下一视频
   起始帧）**被编码** ⇔ ≥ 1 个新条目创建窗口 w 满足 `S_i ≤ w×10 < S_i + len(下一视频)`
   （创建时点落在下一视频跨度内——真实场景切换被结构编码）；`bridge_corr_switch =
   被编码切换数 / 8`。附报：`bridge_corr_video`（跨度内有 ≥1 条目的视频数 / 9）、
   `spurious_rate`（不落在任何视频跨度内的条目数 / max(1,SC1)）、条目-场景对应明细。

**判定（冻结）**：1-4 全过 = **REAL_PASS**；判据 2 失败（任一 SC2=0）= **REAL_FAIL_STRUCT**
（诚实报告校准过拟合风险）；其余任一失败 = **REAL_PARTIAL**（报告哪条失败 + 数字）；
判据无法计算（如数据缺失）= **PARTIAL**（照实）。

### 1.5 统计协议（docs/228 精神，冻结）

- 固定确定性流（无种子、无 jitter）；窗口级 mean±SD（ddof=1）+ bootstrap 95% CI
  （2000 次，种子 20260828，critical_point 同款）over 窗口。
- 每 (级) 完成写 checkpoint `vision/out/results/ckpt_rst_<config哈希>.json`
  （--resume 断点续跑）；汇总写 `vision/out/results/rst_<tag>.json`（自描述 config /
  每级 per_level / mean_sd / bootstrap_ci95 / 判据逐项 / verdict / 逐窗口 trace /
  逐条目明细）；持久化测试写 `rst_persist.json`；漂移观测写 `rst_drift.json`。
- 计算预算：先单次计时（R0+R1+R2，含 6 个持久化 round-trip）；预算 ≤ 60 分钟。

### 1.6 安全纪律（docs/228/234 同款，冻结）

- 脚本 stdout 只输出 ASCII 标签 + 每行一个数字的 R_RST_* 摘要块；运行经
  `powershell -NoProfile -Command "& python vision\real_stream_test.py <args> *> logs\rst_<tag>.log;
  ...Write-Output('exit='+$c+' bytes='+$b)"` 包装重定向到 logs/；
- 数字用纯 python 正则（vision/extract_r.py）抽取；禁止读日志/JSON 原文；
  未用 read 工具读取任何输出文件（davis JPEG 目录是数据，只读文件名/帧数元数据）。
