## 一、预注册设计（判据先于最终运行冻结，docs/63 纪律）

### 1.1 流式运行时（本实验核心定义，冻结）

- **环境流**：连续帧序列 T = 2400 帧 = **10 个 chunk × 240 帧**（10× docs/235 的单
  run 长度），window=10 → **240 窗口**（vs 批处理的 24 窗口）。
- **chunk 构造（复用 make_scene，不重置）**：第 c 个 chunk（c=0..9）由
  `compose_test.make_scene(lvcode, seed_c, n_frames=240)` 生成，`seed_c = seed × 10 + c`
  （派生种子 → 每 chunk 是同一场景族的**新鲜重抽**：regime 相位、上下文翻转时点、
  噪声 σ 乘性抖动（±25% jitter）均按 chunk 重抽）——"场景在流上重抽 regime 序列"。
  10 个 chunk 依序拼接成流；**CompLoop 实例在 chunk 间不重置**（bg_fast/bg_slow/
  θ/db/模式表/条目账本全部持续累积），状态在整条 2400 帧流上连续演进。
- **预测任务**：与 docs/235 完全一致（下一帧 log 亮度预测 = bg_fast(α=0.5)，误差
  = |L − bg_fast|；bg_slow α=0.03 仅作长积分背景）。回路参数与 docs/235/237 逐字一致
  （LOOP_CFG：thresh 0.15 / deadband 0.015 / k_theta 6.0 / k_db 1.5 / thresh_max 0.6 /
  db_max 0.15 / k_consist 3 / hits_min 3 / persist_win 5 / k_split 5 / delta_rel 0.30 /
  energy_bins [150,450,2000,3000] / bbox_bins [420,1000,1800,2800]）。
- **签名空间/模式表**：CompLoop 原样（c0 运动能量档 / c1 A 区能量档 / c2 上下文槽位；
  变长 arity；槽位采纳提升机制，docs/235 §1.2 冻结定义），零改动。

### 1.2 流式级别（预注册，冻结）

| 级 | 代码 | 名称 | 流构造（lvcode 复用 compose_test.LEVELS） | 测什么 |
|---|---|---|---|---|
| **S0** | 20 | stream_single_regime | C0 式：单目标三档速度（[0.25,3.0,1.0]，每 ~80 帧段式切换、相位重抽），每 chunk 重抽；光照 dips 每 chunk 同固定时点（(45,60),(130,145)） | 结构涌现的长程保持（L5 式，240 窗口） |
| **S1** | 22 | stream_context_dep | C2 式：双目标，B 规则依赖 A 相对位置（m1=1.0/m2=3.2，上下文翻转），每 chunk 重抽轨道相位 → 翻转时点变化 | 组合结构（复合条目）的长程保持（COMPOSABLE 长程版） |

每 (级,种子) 独立 rng：`default_rng(seed×7919 + lvcode×104729 + 13)`（docs/235 同款，
chunk 内 rng 由 seed_c 派生）；jitter=0.25（噪声 σ 乘性 ±25% 按 chunk 抽样）。

### 1.3 判据（预注册，先于最终运行冻结；不得在看过结果后修改）

批处理参考（取自 logs/ct_main.log 的 R_C*_SC2 摘要，docs/235 工件 ct_main.json 同源）：
**SC2_batch(C0)=2.4、SC2_batch(C2)=2.0**。

**判据 1 — STREAM_STABLE（流式稳定性）**：对每级 L ∈ {S0,S1}、种子 s，设 mae 序列
240 窗口；`ratio(L,s) = mean(mae[180:240]) / mean(mae[0:60])`（末四分之一 / 首四分
之一窗口均值）。**通过（每级）**：跨种子均值 `mean_s(ratio) ≤ 1.5`（误差有界、不发散）。
附报 per-seed max（透明性）。

**判据 2 — STRUCT_BOUNDED（结构保持）**：对每级 L：`SC2_mean(L) ≤ 3 × SC2_batch(L)`
（S0 ≤ 7.2、S1 ≤ 6.0；SC2 = 结束稳定条目 = 结束时仍在表内且命中 ≥ hits_min 的条目）
**且** `churn_mean(L) ≤ 0.3`（churn 定义同 docs/235 §1.3 M3：创建后很快失效的比例）。
**通过（每级）**：两者均满足（结构不无限膨胀也不塌缩）。

**判据 3 — STATE_PERSIST（状态持久）**：对每级 L × 10 种子 × **3 个中断点**
（p1=720 帧（72 窗口，窗口边界）、p2=1440 帧（144 窗口，窗口边界）、p3=1333 帧
（133 窗口 + 3 帧，窗口内））：在中断点 **save 状态 → load → 续跑**，与不中断运行
**逐帧全等**：从 p 起的每帧 (mae, att, ev, theta, db) 输出全等 且 finalize 全部输出
全等。**通过**：全部 60 个测试点（2 级 × 10 种子 × 3 点）SEQ_EQ=1
（docs/234 round-trip 升级为流式版：状态快照含 bg_fast/bg_slow/prev_L/sigma_hat/θ/db/
参数位移/SC 计数/模式表（含 c2_ene 账本与退休态）/签名史/窗口内事件掩码/帧缓冲/匹配史，
JSON 落盘 vision/out/state/st_persist_<lv>_<seed>_<p>.json，float64/float32 无损往返）。

**判据 4 — BRIDGE（桥实验）**：`SC2_mean(S0) ≥ SC2_batch(C0)=2.4`（L5 式结构涌现
长程保持/增强）**且** `SC2_mean(S1) ≥ SC2_batch(C2)=2.0` **且** `compound_mean(S1) ≥ 0.5`
（COMPOSABLE 长程保持；compound = SC2 中 arity-3 复合条目占比，docs/235 §1.3 M2 冻结定义）。

**判定（冻结）**：四条全过 = **DYNAMIC_PASS**；任一判据计算过且不过 = **DYNAMIC_FAIL**
（报告哪条失败 + 数字）；判据无法计算（如批处理参考缺失） = **PARTIAL**（照实）。

## 六、诚实边界

1. **Toy 场景 + 符号化槽位**（docs/235/237 同款边界）：160×120 合成场景；"复合条目"
   是事件能量 + 相对位置带的离散记忆条目；本实验测的是**记忆组织形态与状态持续性的
   行为签名**，不宣称体验/真实技能/意识。
2. **chunk 边界不连续性**：流 = 10 段同族重抽的拼接（每 chunk 新派生种子 → 相位/噪声
   重抽；C2 的 ctx_prev 每 chunk 重置为 1），不是严格平滑的单一世界；但 **CompLoop 状态
   在 chunk 间不重置**——"流式不重置、状态持续累积"正是被测对象，chunk 边界本身是流中
   的额外事件。
3. **S0 结构饱和而非持续增长**：SC_late=0（后半程无新条目）——长程下结构进入稳态维护；
   BRIDGE 的"增强"体现在 SC2 从批 2.4 提升到全种子 3 条目（10/10）。这是"结构不无限
   膨胀"的直接形态，也意味着本判据测的是**有界保持**而非"无限学习"。
4. **STATE_PERSIST 的边界**：60/60 点逐帧全等，但状态文件 ~450KB/个（float32 数组
   base64 落盘，60 文件 ~27MB）——JSON 落盘代价大；RNG 流不落盘（世界按 seed 重建，
   docs/234 同款边界："记忆持久化"非"世界持久化"）。
5. **SO 复测的效应量与范围**：S1 r=+0.085 显著为正但效应量小（AUC 0.608，接近 0.5+）；
   它只说明 docs/237 负结果受尺度限制、账本史在长程上携带真实（弱）预测信息，**不构成
   H-SO 的完整验证**（只测信号存在性，不做完整二阶场）；S0 的反向伪信号在长程上未消失
   （−0.080 仍显著为负）——"最自信时最将误配"的形态在 regime 级仍存在。
6. **校准循环风险**：环境/回路参数全部沿用 docs/235 冻结值（零新校准）；判据 §1.3 自
   预注册起冻结未动；流式设计选择（10×240、chunk 重抽 seed_c=seed×10+c、3 中断点）在
   预注册时确定并记录于本文件（§1.1/§1.3）——合成场景 + 参数沿用仍存在循环风险，需真实
   视频/不同回路复现才能升级为强证据。
7. **统计**：10 种子 × 2 级 × 2400 帧 + 60 持久化 round-trip；mean±SD（ddof=1）+
   2000 次 bootstrap CI（种子 20260828）；总计算 190.58 秒（预算 60 分钟）；工件
   st_main.json（逐窗口 trace + 逐条目明细 + 判据 + verdict）、st_persist.json（60 点
   明细）、st_so.json（SO 复测逐种子 r）；checkpoint ckpt_st_<hash>.json（断点续跑验证）；
   状态文件 vision/out/state/st_persist_<lv>_<seed>_<p>.json × 60。
