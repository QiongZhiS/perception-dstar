## 一、设计（预注册，冻结；判据/旋钮/守卫先于实现冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/187 明说没做的判别——"物体的落空空间相干、时间连续；纹理的落空空间弥散、随背景
运动；需要空间相关性/时间相干性度量"——本实验把该度量落到**明度通道**并做首验，但范围
收窄为**单一移动暗区（阴影）vs 静态明暗/纹理**的判别（合成受控域）：阴影 = 暗于长期
背景 + 空间相干 + 时间移动；静态球面暗侧/棋盘纹理被背景预测吸收（docs/187"静止纹理
被预测掉"机制的直接复现），不构成阴影。docs/187 的完整缺口（纹理弥散 vs 物体相干的
度量、随背景运动的纹理）超出本实验范围，见 §五 3。

docs/199b 时间门的推广：TemporalGateDavis（MAD 集中 × 帧间 |Δ| 一致，两条件 AND）在
颜色通道判"真染色 vs 噪声"。本实验把它推广到明度/纹理通道判"真阴影 vs 静态/噪声"：
**空间相干（面积 ≥ A_min）AND 帧间移动（|Δcentroid| ≥ move_min）** 两条件 AND。明度
通道无色相 MAD 等价物（无颜色轴），时间侧用质心位移 |Δ|（诚实：与颜色通道的门同构
不同构实现，§五 4）。

### 1.2 合成场景（冻结；critical_point/compose_test 风格，光源方位已知受控）

场景 = 160×120 灰度合成场景（24px 棋盘格背景 64/96，240 帧 @30fps = 8 秒），与
critical_point/compose_test 同族。**光源方位 θ_L 是场景参数（真值已知）**，四级
lvcode ∈ {30,31,32,33} → θ_L ∈ {45°,135°,225°,315°}（图像坐标，x 右 y 下，度 CCW
从 +x 起）。光源方向单位向量 L = (cos θ_L, sin θ_L)，光线沿 −L 传播（光源在 +L 侧）。

| 元素 | 定义（冻结） | 来源/理由 |
|---|---|---|
| 背景 | 24px 棋盘 64/96 | critical_point 同款（docs/232 §1.1） |
| 静态朗伯球面（SfS 载体） | 圆心 (18,60)、半径 16，亮度 = 25 + 170·max(0, n·L)，n = (p−c)/r（平面内光，L_z=0）；亮侧峰值 195、暗侧 25 | 半圆亮暗分界 → 光源方位可推断（docs/235"圆形目标上可用半圆亮暗分界"）；平面内光 = SfS 雏形范围（§五 5） |
| 移动遮挡物（亮圆） | 圆心 (80,60) 半径 14 轨道、频率 0.18 Hz（compose_test C0 a_freq 同款）、半径 10、灰度 255（OBJ_GRAY）、相位按种子抽样 | 遮挡物 = docs/187"物体的落空"载体；几何保证与球面永不接触（球面右缘 34 vs 遮挡物左缘 56，间隙 22px） |
| 投影阴影 | 遮挡物把光挡住：p 被阴影 ⟺ dist_perp(p, o, L) ≤ 10 且 (p−o)·L < 0（半无限暗带）；亮度 ×0.5（critical_point dips light=0.5 同款）；只投在背景（地面），不投球面/遮挡物（§五 6） | 阴影带宽 20px、沿 −L 延伸 → 阴影质心方向 = −L → 反推光源（C2 的几何基础） |
| 噪声 | σ=3.0（compose_test C0-C3 noise=3.0 同款）× 每种子 jitter 0.25（docs/228 主协议） | 沿用冻结值 |

几何验证（预注册，先于任何运行的分析）：球面中心到四条对角线带（过 (80,60) 沿 ±L）
的垂直距离 = |18−60−20|/√2 = |18+60−140|/√2 = 43.84px；阴影扫描带半宽 = 轨道 14 +
半带宽 10 = 24 → 球面边缘最近距离 43.84−16 = 27.84 > 24（余量 3.84px）→ 阴影永不
触及球面（SfS 亮度场纯净，阴影检测连通域不被球面打断）。四方向阴影带均不出界
（遮挡物 x∈[66,94]、带长 ~35px 均落在 160×120 内）。此几何在诊断轮 D1 已用独立
数值脚本复核（§二）。

### 1.3 机制（冻结；预测路径零改动，检测路径为新加法）

**预测回路**：`CPLoop(window=10)`（critical_point 原样 import，LOOP_CFG 冻结值：
alpha_fast 0.5 / alpha_slow 0.03 / thresh 0.15 / deadband 0.015 / k_theta 6.0 /
k_db 1.5 / thresh_max 0.6 / db_max 0.15 / k_consist 3 / hits_min 3 / persist_win 5），
每帧 step；检测路径读回路自己的 **bg_slow**（慢 EWMA 背景 = 长期背景模型）与 L =
log(gray+1)。

**阴影/遮挡物检测（明度通道，每帧）**：
```
dark_mask   = (bg_slow − L) > δ_shadow     # 暗于长期背景（阴影；静态被吸收≈0）
bright_mask = (L − bg_slow) > δ_bright     # 亮于长期背景（遮挡物 255）
8-连通域（cv2.connectedComponents），保留面积 ≥ A_min 的域
最大暗域 = 阴影候选；最大亮域 = 遮挡物候选
时间门（docs/199b 两条件 AND 的明度版）：
  shadow_active[t] = (阴影候选面积 ≥ A_min) AND (质心位移 |c_t − c_{t−K}| ≥ move_min)
  —— 空间相干 AND 帧间移动；静态球面暗侧/棋盘纹理被 bg_slow 吸收（残差≈0）且不移动，
     不构成阴影
```
旋钮（冻结，来源论证）：δ_shadow = δ_bright = **0.35**（log 域）= log(2)/2（0.5 倍
亮度阴影深度的半量，docs/232 dips 同款 0.5 派生）；远高于噪声（σ=3 灰度 → log 域
σ̂ ≈ 0.047，0.35 ≈ 7σ̂），远低于阴影残差 ≈ log(2) ≈ 0.693。A_min = **25 px**（遮挡物
面积 π·10²≈314、阴影带 ≈ 20×~35≈700，25 只滤单像素噪声点）。K = **10 帧**（= window
冻结值），move_min = **3 px**（遮挡物/阴影角速度 2π·0.18/30 ≈ 0.0377 rad/frame ×
半径 14-30 ≈ 0.5-1.1 px/frame → 10 帧位移 5-11 px，3 px 为保守下限）。

**SfS（静态亮度场，每 (级,种子) 一次）**：
```
M = mean(灰度帧[WARMUP:])                       # 时间平均压噪声（静止读层）
region = 最大 8-连通域 of {(M < 45) OR (M > 115)}   # 球面暗侧 25 / 亮侧 195 超棋盘
                                                    # 64/96 ± 中带；遮挡物路径均值≈70-100、
                                                    # 阴影带均值≈56-84 均落带内被排除
sphere_center_hat = region 的包围盒中心           # 半圆亮暗两半均在带外 → 包围盒=整圆
p_max = region 内 argmax M                        # 亮侧峰值 = 圆心 + r·L
θ_sfs = angle(p_max − sphere_center_hat)          # 反推光源方位（法线粗略方向）
```
SfS 阈值 [45,115] 冻结：球面暗/亮 25/195 与棋盘 64/96 之间取中带，球面两半均在带外
（包围盒=整圆，中心无偏），遮挡物/阴影带均值在带内（排除）。WARMUP = **60 帧**
（≈2× bg_slow 时间常数 1/0.03≈33，静态内容残差 (1−0.03)^60 ≈ 0.16 → 球面残差
≈0.15-0.18 < δ 0.35，吸收完毕）。

### 1.4 判据（冻结；每条带 docs/247 层级标签；合成受控、非真实域证明）

评估窗口 = 帧 [60, 240)（180 帧）；GT 阴影掩码 = 场景生成器按 §1.2 公式逐帧计算
（只用于评估，绝不进入机制）。统计外壳 = mean±SD（ddof=1）+ bootstrap 95% CI
（2000 次，种子 20260828，critical_point 同款），聚合单位 = 每 (级,种子) 一次运行
（40 运行）。

| 判据 | 标签 | 定义（冻结） | 阈值（冻结） |
|---|---|---|---|
| **C1 SHADOW_DETECT** | `[新][机制][合成受控]` | 检出率 det_rate = 评估帧中 [IoU(阴影候选掩码, GT 阴影) ≥ 0.30] 的占比（跨帧/级/种子均值）；误报率 fp_rate = 评估帧中 [shadow_active 且 IoU < 0.20] 的占比 | det_rate ≥ **0.80** 且 fp_rate ≤ **0.10** |
| **C2 LIGHT_DIR** | `[新][机制][合成受控]` | 每帧 θ_est = angle(遮挡物质心 − 阴影质心)（阴影在 −L 侧 → 反向即 +L），环形误差 vs θ_L；按帧聚合 | 每运行中位误差的跨运行均值 ≤ **15°** 且准确率（|err| ≤ 15° 帧占比）均值 ≥ **0.70** |
| **C3 SFS** | `[新][机制][合成受控]` | 每运行 θ_sfs 环形误差 vs θ_L | 跨运行平均误差 ≤ **15°** 且正确率（运行平均误差 ≤ 15° 的运行占比）≥ **0.75** |

阈值论证（冻结）：IoU 0.30/0.20 = 标准检测度量低杠（docs/218 TP/FP 语义）；15° =
四级光源间隔 90°，1/6 象限（跨级不混淆的下限，合成首验的宽松精度）；0.80/0.10/0.70/
0.75 = 多数制（docs/235 种子多数派 + docs/246 过线精神）。均为合成场景标定值，跨场景
/真实域需重标定（§五 8）。

### 1.6 守卫（冻结）

1. **R_LT_GUARD_CP5**（同代码路径复现前一格）：`critical_point.make_scene(5, seed)` +
   `CPLoop(window=10)`（10 种子 × 240 帧）→ 复现 docs/232 L5 已知数字：SC2 均值 ∈
   [2.0, 3.6]（docs/232: SC2=2.8±0.42）且 SC_late 均值 ≥ 0.5（docs/232: 0.9）。
   同代码、同种子 → 确定性复现。
2. **R_LT_GUARD_MAD**（MAD 噪声估计复现）：恒定灰度 64 + 已知高斯噪声 σ=3.0 序列 →
   CPLoop 的 σ̂（log 域 MAD of ΔL）应收敛到理论值 √2·σ/gray = √2·3/64 ≈ 0.0663；
   断言 |σ̂ − 0.0663| / 0.0663 ≤ 0.25。
3. **R_LT_REPRO**（内部确定性复现）：--repro 时同一配置整体重跑第二遍，逐项比对
   R_LT_* 关键数字位级一致 → R_LT_REPRO = 1（docs/257 确定性复现纪律）。

### 1.7 随机性与种子协议（冻结）

- 10 种子（seed 0-9）× 4 级（lvcode 30-33）= 40 运行 × 240 帧；
- 每 (级,种子) 独立 rng：`default_rng(seed×7919 + lvcode×104729 + 13)`（critical_point
  同款公式；lvcode 30-33 与 0-6（critical_point）/20-23（compose_test）错开）；
- 噪声 σ = 3.0 × jitter 乘子（±25% 按种子抽样，docs/228 主协议）；遮挡物相位按种子抽样；
  光源方位 θ_L 每级固定（场景参数，不抽样）；
- 统计：mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828）。

## 五、诚实边界（预注册阶段已知）

1. **合成受控、非真实域证明**：三判据均为 `[新][机制][合成受控]`——新机制首验，docs/247
   阶梯的 L0/L1 域（同分布多种子），**不构成任何 L2+ 泛化主张**，不宣称真实域证明。
   光源方位已知受控是角度误差可计算的必要条件，也是合成域优势（docs/183 方案 1 立场）。
2. **阴影 vs 暗色移动物体不可区分**：检测路径 = 暗于长期背景 + 空间相干 + 时间移动，
   一个"暗色移动物体"同样会被检为阴影类；本实验**未做遮挡几何验证**（阴影必须依附于
   遮挡物、沿光源方向延伸）。这是 docs/187 缺口的直接边界：本实验只把"空间相干 + 时间
   移动"落成可操作度量，不解决"这是阴影还是暗物体"的语义判别。
3. **与 docs/187 缺口的关系（部分回应，未闭环）**：docs/187 要求"空间相关性/时间相干性
   度量"——本实验给出了明度通道的实例（面积门 × 质心位移门），并复现了"静止纹理被
   预测掉 = 0 残差"（球面暗侧/棋盘被 bg_slow 吸收）；但**纹理的"空间弥散、随背景运动"**
   未建模（本场景只有单一静态纹理背景），"纹理落空 vs 物体落空"的完整判别未完成。
4. **与 docs/199b 时间门的关系（同构推广，非同构实现）**：TemporalGateDavis 的
   "MAD 集中 × 帧间 |Δ| 一致"推广为明度通道的"空间相干（面积）AND 帧间移动（|Δcentroid|）"
   两条件 AND；明度通道无色相 MAD 等价物，且"真/假阴影"在本实验由 GT 掩码定义（合成域），
   真实域的真假判别（如噪声风暴 docs/101、真实遮挡）未验。
5. **SfS 是雏形**：平面内光（L_z=0）→ 只恢复光源方位角（法线的粗略 2D 方向），不恢复
   法线仰角（3D n_z）；球面暗帽检测用场景标定亮度阈值 45（诊断轮 D4 后实现：暗帽质心
   + 全局最亮像素连线，不用亮侧阈值），非通用分割；只在单个球面上验证，非真实表面。
   docs/196/197 的"亮度稳健/色温脆弱/何时校正"轴未涉及（灰度通道无色温）。
6. **阴影只投在背景地面**，不投在球面/遮挡物上——投影阴影在曲面上的形状未建模；无
   半影/环境光/多光源（单定向硬阴影）。
7. **噪声鲁棒性未测**：σ=3.0 固定 + jitter 0.25，"越噪声越固执"（docs/101）在明度通道
   阴影检测上的行为未验。
8. **判据阈值为合成场景标定值**（IoU 0.30/0.20、15°、0.80/0.10/0.70/0.75、δ 0.35、
   A_min 25、move_min 3、SfS [45,115]），跨场景/真实域需重标定（docs/199 §五 同款声明）。
