```
与 docs/201 唯一区别：验证从"每帧概率 nu"变为"关键帧宣布集合 announce"
```

## 二、结果

**P1 到达强度：一次宣布够吗？（改判场景，eta 扫描 × 到达形态）**

| eta | 涓流nu=0.1 | 事件×1 | 事件×3 | 事件×6 | 持续f50-70 |
|---|---|---|---|---|---|
| 0.05 | 166 ✗ | 177 ✗ | 172 ✗ | 164 ✗ | **123.8 ✓ f77** |
| 0.20 | **120.7 ✓ f60** | 169 ✗ | **119.4 ✓ f75** | **119.3 ✓ f58** | **119.9 ✓ f56** |
| 0.50 | **117.7 ✓ f42** | **118.5 ✓ f57** | **118.5 ✓ f57** | **118.5 ✓ f48** | **121.2 ✓ f52** |

- **eta=0.05（固执）**：单次/3 次/6 次都不够（移 3°/次，需 ~15 次），只有持续宣布
  改判 → **固执系统需要利害重复到达**（"重要的话要说够"）
- **eta=0.5（可塑）**：单次宣布即改判（f57）→ 可塑系统"一次就信"
- **eta=0.2（中间）**：单次不够、3 次够 → 边界在 ~2-3 次

**P2 宣布时机（eta=0.2，3-4 次宣布）**

| 形态 | 宣布帧 | 首次入蓝 | 终值 |
|---|---|---|---|
| 立即 | f40/45/50 | **f57** | 119.3 ✓ |
| 中等 | f55/60/65 | f75 | 119.4 ✓ |
| 延迟 | f70/80/90 | f98 | 130.0 ✓ |
| **提前（任务预判）** | f25-40 ×4 | **f45**（最快） | 119.3 ✓ |

- 宣布越早改判越快；**任务预判**（目标 f30 才蓝、任务 f25 就宣布"找蓝"）最快——
  docs/190"想看什么就看见什么"的利害侧：利害先于观察，期望先移、目标变蓝后自洽确认
- 意外：预判 3 次宣布卡半路（158°），4 次才入蓝——环形路径 0→120 走 -60° 短径，
  theta 中途（168/158）离目标反而远（38°>自洽门 30°），需多一步进自洽确认区

**P3 抗错误宣布（守住场景任务层误说"找蓝"）**

| eta | 单次误说 | 持续误说（f50-70） |
|---|---|---|
| 0.05 | 178.8 守住 ✓ | 176.1 守住 ✓ |
| 0.20 | 178.3 守住 ✓ | **120.4 被带偏 ✗** |
| 0.50 | **120.1 被带偏 ✗** | 118.9 被带偏 ✗ |

- eta 小（固执）抗错：单次/持续误说都守住（自洽门+红观察拉回）
- eta 大（可塑）单次误说即被带偏：**错误利害把期望推离红后，异常段（30-60 真蓝）
  的观察经自洽门确认它 → 异常结束仍锁蓝**——错误利害+真实观察联合带偏，这是
  docs/101"完全可塑=没有自我"的利害侧：可塑系统连错误利害都吸收

## 三、判读：docs/101 验证机制的完整形态

1. **涓流 vs 事件是同一机制的两种到达统计**：nu=0.1 涓流 100 帧 ≈ 10 次事件；
   docs/201 的"速度 ∝ eta×nu"在事件形态下对应"速度 ∝ eta×事件数"（P1 表逐列
   验证）。事件形态更真实：任务层不会每帧说话，利害更新是离散宣布。
2. **"一次宣布够吗"= 到达强度 vs 系统固执度的对比**：单次强度 = eta×60°。固执
   系统（eta 小）需要重复到达——这解释 docs/101 平衡带为什么"物软时最优 eta 小"：
   固执系统不会因单次噪声/单次错误利害而改判（P3 守住），代价是真正改判时需要
   利害重复到达（P1 持续宣布）。
3. **错误利害+真实观察联合带偏（P3 深层机制）**：单次错误宣布本身只推 30°（eta
   大时），但推离红后，异常段目标恰好是蓝 → 观察经自洽门（|观察−期望|<30°）确认
   新位置 → 期望锁在蓝。**利害给方向、世界给确认**——docs/178"他者的 不"与
   "世界的 不"的边界不是绝对：错误利害可以把"世界的 不"（异常段的真蓝）变成
   "确认"（自洽门接受）。这是可塑系统的深层风险：不是被利害带偏，是被
   "利害+世界"联合重写。
4. **docs/178 补刀的完整形态**：他者的 不（利害更新）必须到达**足够强度**
   （次数×eta）才改写期望——"重要的话要说够"；而系统对这句话的信任度由固执度
   （eta）决定：固执=要求重复确认，可塑=一次就信。

## 四、诚实边界

1. 色相域 toy（标量 + 高斯观察 + 二值宣布集合）——测验证到达的**强度-固执度**
   结构，不测完整视觉闭环（docs/200 图像版互补）。
2. 宣布集合是离散帧集；真实任务层宣布有"宣布内容+时长+相关性"（利害更新是
   持续状态不是孤立事件）——持续宣布窗口（f50-70）已近似，但无"宣布后记忆衰减"
   （docs/54 召唤-巩固闭环的未来落点）。
3. P2 预判的"3 次卡半路"是环形几何（0→120 短径 -60° 中途离目标远）的 toy 特例；
   真实色相环同样存在（0° 与 180° 相邻），但"到达强度不足→卡中间态"是结构结论。
4. P3 的"错误利害+真观察联合带偏"依赖异常段目标恰好是蓝（守住场景设计）；
   真实场景异常段颜色任意，联合带偏的后果取决于异常内容（后续可扫异常颜色）。
5. 现象层纪律照旧（docs/63）：测的是到达-信任结构（改判/守住/速度），不宣称
   "信任/说服"体验。
