## 一、设计（预注册，冻结；f 形式与系数/判据/守卫先于实现与最终运行冻结，运行后不改）

### 1.1 目标与范围（冻结）

docs/270（第六格）完成 recall 修复后，判别机制的工作点是**固定先验**（DELTA_SHADOW
=0.35 等全程不变）。用户洞察（方向冻结）——"光影是光的变化……能不能让参数自动变化，
找变量去影响参数"——本格把 docs/208 自适应带宽的范式（**f 形式冻结 + 输入运行时阅历**
：bw = k_band × 见过的 std）推广到判别参数：**DELTA_SHADOW 从冻结常数变为运行时可观测
统计的冻结函数**。本格目标：

1. **自适应机制（核心）**：`DELTA_SHADOW(t) = f(候选内部亮度方差(t))`——硬阴影
   （内部均匀，方差小）vs 软阴影/半影（内部有梯度，方差大）：方差大 → 门槛放宽
   （DELTA 降低 → 软阴影浅层边缘 ΔL ∈ (0.25, 0.35) 的像素被纳入 → recall 提升）；
   方差小 → 门槛保持先验（防把硬阴影漏掉或把暗物体误纳）。**f 形式与系数预注册冻结**
   （§1.3），运行后不改。
2. **判据（与 docs/270 同尺可比）**：pooled P/R/F1（P ≥ 0.90 且 R ≥ 0.68 且 F1 ≥
   0.79——"自适应抬 recall + P 不崩"双目标，任务指定阈值方向）+ WHITE_OBJ_RECALL
   （≥ 0.65）——直接量化"R 提升 + P 不崩"。
3. **KEEP（能力不退化）**：守卫——本脚本基线路径逐位复现 docs/267 冻结数字
   （R_LA_GUARD_BASE：0.9913/0.4131/0.5832/0.4265 + 标签分布 + 门率）、自适应前
   （fix@DELTA0）路径逐位复现 docs/270 冻结数字（R_LA_GUARD_FIX：0.9813/0.6382/
   0.7734/0.6172 + obj 24）、合成三连（SYNTH）+ 第四格 flamingo（CELL4）逐位 +
   DET/MASK/REPRO。
4. **C4（报告性）**：自适应后 DELTA_SHADOW 的分布（min/med/max、触发率）、var_inner
   分布、recall 提升归因（按 softness 分裂 SOFT/HARD 的 pooled recall 前后 Δ、软
    阴影 SOFT 单位 recall Δ、label 变化单位与 TS/NS 构成）。

范围收窄（诚实，同 docs/267/270）：判别对象 = 最大暗域候选（单候选）；"纹理"通道在
静态域近零；多候选未建模；真实图无光照 GT → θ_est 仍是帧内估计行为读数；**自适应
只细调 DELTA0 已有候选的工作点**（DELTA0 下无候选的 none 单位不触发自适应——"从无到
有"的检出非本格机制，留作后续格）。

### 1.2 数据与预处理（冻结；逐字同 docs/270 §1.2）

- **数据源（冻结）**：ISTD（D:\datasets\ISTD），1870 场景三元组（train 1330 + test
  540），目录映射 _A=阴影图 / _B=阴影掩码（GT）/ _C=无阴影参考图（docs/267 §二 D1
  实测并冻结）。图像/掩码是数据（可读），非毒文件。
- **预处理（固定流水线，docs/267 §1.2 同款冻结）**：PNG → cv2.imread(IMREAD_COLOR)
  （BGR 640×480）→ 灰度 cv2.resize(160×120, INTER_AREA) → uint8；彩色帧同样 resize
  到 160×120（INTER_AREA）供 V4/E3 边界环带采样；GT 掩码 cv2.resize(160×120,
  INTER_NEAREST) → bool（>0）；V4/E3 前显式 cv2.cvtColor(bgr, COLOR_BGR2RGB)。
- **单位（冻结）**：每场景一次运行（1870 单位）；每单位 2 帧 [B（无阴影参考）, A
  （阴影帧）]；Pass A 在 [B,A] 上算逐像素 0.95 分位（= 逐元素 max）；评估帧 = A
  （GT 掩码 C）；B 只作适应参考。
- **无注入、无 jitter、无 RNG**（docs/243 §1.1 声明同款）；统计外壳 = 单位级
  mean±SD（ddof=1）+ bootstrap 95% CI（2000 次，种子 20260828）。

### 1.3 机制（冻结；测量层逐字 import 第五/六格零改动；自适应只在 DELTA_SHADOW 工作点）

**输入统计（运行时可观测，从像素算；不进 GT、不进 θ_est 自指）**：

```
L(p) = log(gray_A(p) + 1)                       # A 帧 log 亮度（与 diagnose_frame 同式）
d_mask0 = DELTA0=0.35 检测的种子候选掩码（diagnose_frame 在 A 帧上的候选；
          面积 ≥ A_MIN=25；空候选 → 不自适应，delta(t) = DELTA0）
var_inner(t) = Var_{p ∈ d_mask0(t)}[ L(p) ]     # 候选内部亮度方差（本格唯一输入变量）
```

**f 形式与系数（冻结；docs/208 范式：f 冻结、输入=运行时阅历）**：

```
softness(t) = var_inner(t) / VAR_REF            # 软度指数（无单位，相对冻结参考尺度）
DELTA_SHADOW(t) = clamp(DELTA0 − K_ADAPT × softness(t), DELTA_LO, DELTA_HI)
```

| 系数 | 值 | 来源（冻结论证） |
|---|---|---|
| DELTA0 | 0.35 | docs/260 §1.3 冻结先验（= log(2)/2，半量阴影深度）；本格自适应中心 |
| VAR_REF | 0.040 | **物理锚**：完整 0.5× 半影的 log 亮度方差 = range²/12（均匀/线性梯度最大熵形态）= (log 2)²/12 ≈ 0.0400——"一个完整半影梯度"的参考尺度（docs/208 用色温漂移做物理锚同构） |
| K_ADAPT | 0.10 | **最大放宽幅度**：softness=1（完整半影）时阈值 0.35 → 0.25（放宽 0.10 ≈ DELTA0 的 29%）；系数=DELTA0−DELTA_LO，使 softness=1 恰触下限（几何自洽） |
| DELTA_LO / DELTA_HI | 0.25 / 0.35 | **有界区间**：上限 = DELTA0（只放宽不收紧——收紧方向不做，诚实声明）；下限 0.25 ≈ log(1/0.78)，检测浅到 22% 变暗的软阴影边缘（防方差爆炸把门槛推出有意义区间） |

**单调性论证（冻结）**：∂DELTA/∂var_inner = −K_ADAPT/VAR_REF < 0——**常数负斜率**，
DELTA 随 var_inner 严格单调递减（方差越大 → 门槛越低 → 软阴影召回；方差越小 → 门槛
越接近 DELTA0 = 保持先验）。**有界性论证（冻结）**：clamp 保证 DELTA ∈ [0.25, 0.35]
对任意 var_inner ∈ [0, ∞)（var_inner=0 → DELTA=0.35=DELTA0；var_inner=VAR_REF →
DELTA=0.25 触底；var_inner→∞ → DELTA=0.25 被钳制，不越界）；softness 无单位（var 比
冻结参考），跨场景可比。

**两遍法（每单位，冻结）**：

```
Pass 0（参考，DELTA0）：db = diagnose_frame(B, ref_dark_log, None)     # dark_prev
Pass 1（种子，DELTA0）：da0 = diagnose_frame(A, ref_dark_log, db.mask)  # 种子候选 d_mask0
    var_inner ← d_mask0 内 L 方差（d_mask0 空 → delta = DELTA0，不自适应）
    delta_adapt ← f(var_inner)（f 冻结，§1.3）
Pass 2（自适应）：运行时注入 DELTA_SHADOW = delta_adapt
    da = diagnose_frame(A, ref_dark_log, db.mask)      # 同一条测量链，只变参数工作点
    → 恢复 DELTA_SHADOW = DELTA0（try/finally 保证）
标签合成（逐字 import docs/270 apply_fix，计分制 v1+v4 ≥ 2 判 object）：
    base_label  = da0["label"]                          # 基线（docs/267 口径）
    fix_label   = apply_fix(da0["label"], da0 v1/v3/v4) # 自适应前（docs/270 口径）
    adapt_label = apply_fix(da["label"], da v1/v3/v4)   # 自适应后（本格结果）
pred = d_mask if label == shadow else 空（三套各算 tp/fp/fn/white——同一单位三列）
```

**运行时注入实现（冻结）**：`import light_shadow_real_test as _lsr`；调用
`_lsr.diagnose_frame(...)` 前设 `_lsr.DELTA_SHADOW = delta_adapt`，调用后恢复
`_lsr.DELTA_SHADOW = DELTA0`（diagnose_frame 在模块命名空间解析 DELTA_SHADOW，

R_LA_GUARD_BASE（docs/267 逐位）+ R_LA_GUARD_FIX（docs/270 逐位）位级证明）。注入
只围绕 da 单次调用（try/finally），db/da0/守卫全部在 DELTA0 语义下运行。

**旋钮（冻结；全部继承 docs/270 冻结值，唯一变化 = DELTA_SHADOW 由 f 给出而非常数）**：

**自适应选型的预注册论证（冻结；docs/208 范式 + 物理/几何派生，先于任何 var_inner
观测）**：

1. **单变量选候选内部亮度方差**：硬阴影 = 同一表面 × 乘性变暗 → 内部 log 亮度近乎
   常数（方差≈噪声级）；软阴影/半影 = 变暗幅度渐变 → 内部 log 亮度有梯度（方差大）。
   这是判别机制自身最直接可得的"软硬"签名（从 d_mask 内像素算，零新通道、零 GT、
   零 θ_est 自指）。
2. **方向**：方差大 → 门槛放宽（软阴影浅层边缘 ΔL ∈ (0.25, 0.35) 被纳入，recall
   提升）；方差小 → 门槛保持 DELTA0（clamp 上限，防把均匀暗区——硬阴影或暗物体——
   过度纳入）。"收紧"方向不做（诚实声明：反向自适应留作后续格）。
3. **系数预注册而非拟合**：VAR_REF = (log2)²/12（完整半影的方差——物理量，非数据）；
   K_ADAPT = DELTA0 − DELTA_LO（几何自洽：softness=1 恰触下限）；DELTA_LO=0.25（浅到
   22% 变暗的半影边缘）；DELTA_HI=0.35=DELTA0。全部先于任何运行冻结，不因诊断/结果
   调整（改 f 任何系数 = 隐式调参，违规）。
4. **机制不调参**：自适应是**机制**（f 冻结 = 参数自动变化的规则），不是调参（调参 =
   结果后改系数）；判据测行为（P/R/F1）不测 f 系数（docs/261 §五 2 纪律）；f 的唯一
   自由度 = 输入统计 var_inner（运行时可观测、从像素算）。

## 五、诚实边界（预注册阶段已知）

1. **f 冻结 = 机制 vs 隐式调参的边界（本格核心纪律）**：f 形式与全部系数（VAR_REF /
   K_ADAPT / DELTA_LO / DELTA_HI）在 §一 预注册期冻结——系数全部物理/几何派生
   （VAR_REF = (log2)²/12 完整半影方差；K_ADAPT = DELTA0 − DELTA_LO 几何自洽；
   DELTA_LO = 浅至 22% 变暗的半影边缘；DELTA_HI = DELTA0 只放宽不收紧），**先于任何
   var_inner 数据观测**；诊断轮只报告 var_inner/DELTA 分布（§二），不因分布调整 f；
   运行后改 f 的任何系数 = 隐式调参（违规，任务失败）。"自适应是机制不是调参"：
   自适应 = 参数自动变化的**规则**（f 冻结），调参 = 结果后改规则（禁止）；f 的唯一
   自由度 = 输入统计 var_inner（运行时可观测、从像素算），判据测行为（P/R/F1）不测
   f 系数（docs/261 §五 2 纪律）。
2. **单变量局限（本格只用第一个候选变量，最干净）**：候选内部亮度方差是唯一输入；
   docs/208 范式下的其他变量——边界锐度→TOL_H 自适应、全局对比度→整体缩放、阅历
   累积（跨单位，docs/234 持久化）→慢自适应——留作后续格（§五 10）。单变量意味着：
   纹理表面的硬阴影（var_inner = 表面纹理方差，乘性变暗不改变 log 域方差）会被误判
   为"软"→ 门槛放宽 → 其 FP 代价由 C1 P ≥ 0.90 直接量化（诚实：机制接受此风险，P
   判据兜底）。
3. **两遍法的诚实边界**：自适应只细调 DELTA0 已有候选（面积 ≥ A_MIN）的工作点；
   DELTA0 下无候选的单位（none 111 个）不触发自适应——"从无到有"的检出（浅阴影在
   DELTA0 下无候选）非本格机制，留作后续格；"收紧"方向（DELTA > DELTA0）不做（clamp
   上限 = DELTA0），诚实声明。
4. **运行时注入的边界**：DELTA_SHADOW 通过对 light_shadow_real_test 模块全局的运行时
   注入改变（try/finally 保证恢复；不修改任何脚本文件）；测量层 = 第五/六格逐字同源
   （GUARD_BASE/GUARD_FIX 位级证明）；注入只围绕 da 单次调用，db/da0/守卫全部在
   DELTA0 语义下运行。
5. **P 是否守住**：由 C1 P ≥ 0.90 直接量化（docs/270 自适应前 0.9813）。自适应把
   软阴影浅层边缘（及可能的阴影外纹理背景）纳入预测——其 FP 代价被 P 判据直接测出；
   若 P < 0.90 → 按冻结映射报 P_FAIL（自适应过度，诚实否定）。
6. **方向性诚实（自适应可能不抬 recall）**：放宽门槛也可能让更多单位被否决门判为
   object（掩码变大 → V1/V3/V4 在更大掩码上测量）→ recall 可能不升反降；R ≥ 0.68
   判据直接测"自适应是否真的抬了 recall"，不抬 = R_FAIL 照实报。
7. **单候选局限不变**（docs/267 §五 4）：判别对象 = 最大暗域；多阴影区域/阴影外暗
   物体未建模；GT 掩码 resize INTER_NEAREST 有像素化误差。
8. **数据选择不变**（docs/267 §五 1）：ISTD（SBU/SRD 无可达镜像）；hf-mirror 镜像
   目录映射 _A=阴影图/_B=掩码/_C=参考（D1 冻结）。
9. **静态域适配代价不变**（docs/267 §五 2）：2 帧场景对 [B, A]；时间门近恒过、
   texture 标签近零（如实报告）；B 帧与 A 帧非阴影区一致性假设同前。
10. **下一步（超出本格）**：边界锐度→TOL_H 自适应（第二候选变量）、全局对比度→
    整体缩放、跨单位阅历累积（docs/208 的 std 阅历 + docs/234 持久化）→慢自适应、
    多候选判别、跨数据集验证、光照方向真值验证。
