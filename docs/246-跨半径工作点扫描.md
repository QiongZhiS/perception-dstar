## 一、预注册设计（判据与网格先于最终运行冻结，docs/63 纪律）

### 1.1 缘起与目标（冻结）

docs/245 判明：软匹配（原型距离匹配）把"精确档位匹配"的判别失败彻底修复，但把张力
表现为"半径旋钮"的连续权衡——**r 越小（判别极）判别越好但场景内匹配密度不足
（churn↑）；r 越大（合并极）场景内越稳（churn↓）但场景可能合并（bridge↓）**。docs/245
只采了单点（r=中位最近邻距离 0.2659），落在判别极。本实验的目标（预注册）：**沿半径
旋钮做对数稀疏扫描，寻找"判别 + 稳定同时泛化"的工作点**——即同时满足
BRIDGE_FIX / HELD_OUT / CHURN / STABLE 四判据的半径；并检验创建滞回 k_consist 是否是
docs/245 §六4 所指短场景尾部创建问题的有效第二旋钮。

### 1.2 主旋钮：半径网格（预注册，冻结；先于任何结果）

- **r_base** = 校准集参与窗口（E ≥ 10）两两最近邻距离的中位数，对数 (E,U) 域
  （docs/245 §1.3 同款定义，vision/soft_match_test.calibrate_radius 复用，单次确定性
  校准 pass；docs/245 实测 **0.2659**，本实验脚本重算并作守卫核对）。留出集在 r_base
  估计中零贡献（docs/245 §1.3 防循环条款沿用）。
- **网格（冻结）**：乘子 M ∈ {0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, 8.0}，绝对半径
  r = M × r_base。对数稀疏（乘子序列 log2 步进 0.32-0.58），覆盖"判别极（0.5×，比
  docs/245 更紧）→ docs/245 点（1.0×）→ 合并极（8.0×，邻域半径 ≈ 2.13 对数单位，
  预期场景合并/桥下降）"全程。**9 个半径**。网格先于任何结果冻结；不因结果增删格点
  （docs/63 纪律；不得在看过结果后回调网格）。
- 标称半径（r_base=0.2659，4 位小数；实际使用值为 M × 未取整的 r_base）：

| M | 绝对半径 r（对数域） | 预期行为带（预注册，不作判据） |
|---|---|---|
| 0.5 | 0.13295 | 判别极更紧端：churn 更糟（创建更多、命中更难累积） |
| 0.75 | 0.19943 | 判别极：接近 docs/245，churn 大概率仍 > 0.5 |
| 1.0 | 0.26590 | docs/245 点（守卫复现点） |
| 1.5 | 0.39885 | 过渡带：churn 开始回落，bridge 应仍 ≥ 0.5 |
| 2.0 | 0.53180 | 过渡带：churn 继续回落，bridge 观察 |
| 3.0 | 0.79770 | 过渡带：churn 低，bridge 可能开始掉 |
| 4.0 | 1.06360 | 合并带：场景内全匹配，场景间判别开始合并 |
| 6.0 | 1.59540 | 合并带：bridge 预期明显下降 |
| 8.0 | 2.12720 | 合并极：全流少量原型，bridge 预期接近 0 |

### 1.3 第二旋钮：创建滞回 k_consist（预注册，启用）

- **启用（预注册决定）**：k_consist ∈ {2, 3}。理由（docs/245 §六4，冻结引用）：
  R1 churn 的直接机制之一 = (a) 创建被 k_consist=3 连续未匹配滞回推迟进短场景尾部
  （motorbike 4 窗口、soccerball 5 窗口，创建后只剩 1-2 个窗口可累积命中）。
  **k=2 假设**：滞回减为 2 个连续未匹配窗口 → 短场景内原型提前 1 窗口创建 → 更多窗口
  可累积命中 → 短场景原型更容易达到 hits_min=3 → churn 下降。这是机制变体检验
  （docs/245 未测 k；k=3 是 docs/241/243/245 冻结值）。
- **二维网格（预注册，冻结）**：9 半径 × k ∈ {3, 2} = **18 格**。**主分析 = k=3**
  （与 docs/245 同口径的创建滞回，主判据/工作点/判定都在 k=3 主网格上）；**变体 =
  k=2**（机制发现，单独报告，不进主判定）。
- 其余软匹配机制逐字沿用 docs/245（冻结）：特征 x=(ln(1+E), ln(1+U))、最近原型欧氏
  距离 ≤ r 匹配、自适应 α=0.2（启用，只动中心）、创建在当前窗口特征处（hits=1）、
  无退休、无 arity-3（compound=0 按设计）、hits_min=3、persist_win=5、参与门 E ≥ 10。

### 1.4 判据（每 (r, k) 格，预注册，冻结；不得在看过结果后修改）

1. **BRIDGE_FIX**：完整 9 视频流 `bridge_corr_switch ≥ 0.5`。
2. **HELD_OUT**：`holdout_switch ≥ 0.5`（留出切换对应率；`calib_switch` 分开报告，
   不进判据——留出过线才算泛化，docs/244/245 同款）。
3. **CHURN**：`R0 churn ≤ 0.5` **且** `R1 churn ≤ 0.5`（churn = 最终 hits < hits_min=3
   的原型数 / max(1, SC1)，docs/245 同款；两级均要求，防"只修 R1"的假通过）。
4. **STABLE**：`R0 末/首四分之一 MAE 比 ≤ 1.5` **且** `R1 比 ≤ 1.5`。
   **控制项声明（预注册，docs/245 §六2 实证）**：软匹配只改模式表路径不改预测路径，
   MAE 序列与 docs/243/244/245 逐位一致，**与半径/k 无关**——STABLE 在所有 18 格预期
   恒为 R0 0.907701 / R1 0.951261（回归守卫角色，非独立证据），但仍按冻结判据逐格报告。

**格通过** = 四判据同时满足（全部为 1）。

### 1.5 工作点定义与余量（预注册，冻结）

- **工作点（主网格 k=3）** = 满足全部四判据的半径（乘子 M 的集合，非空则每个都是工作
  点）。**最小/最优工作点** = 满足全部判据的**最小 M**（半径最小的工作点 = 在稳定的
  前提下保留最多判别分辨率——判别极方向的最近可达点，预注册定义）。
- **余量（每判据，距阈值的距离，正 = 过线侧）**：
  - bridge 余量 = bridge_corr_switch − 0.5；
  - heldout 余量 = holdout_switch − 0.5；
  - churn 余量 = 0.5 − max(R0 churn, R1 churn)；
  - stable 余量 = 1.5 − max(R0 ratio, R1 ratio)。
  - 报告工作点的四判据数字 + 四余量。
- **判定（预注册，冻结）**：
  - 主网格（k=3）存在工作点 → **TENSION_RESOLVED**（报告最小/最优工作点 + churn/
    bridge 曲线 + 与 docs/245 单点对比）；
  - 主网格无工作点 → **TENSION_PERSISTS**（如实报告"张力不可仅靠半径解除"，并给出
    **机制改向建议**——逐场景自适应半径 / 原型分裂 / 短场景特殊处理——作建议不作
    回调；若 k=2 变体存在工作点，注明"创建滞回 k 是张力分量，k=2 变体可解除，见机制
    发现"，仍不改主判定）。
