## 四、踩过的坑（续接者必读，细节在 vision/README）

1. **假指标**：闪变检出"1.000"是度量 bug（分子分母同分支 +1），已独立统计修正为真实值
   （67%/22%）——假指标比坏指标危险（docs/31 纪律）。
2. **单窗口读不快不慢** → 双读者（window=2 读快 + window=10 读慢，并集）。
3. 碎片合并按**质心距离**不按 IoU（运动前后沿不重叠但挨着）；距离太大会并不同物体
   （dist=28 + IoU 规则）。
4. 闪变期**密度不吸收洪泛**（只衰减）→ 闪变结束 1-2 帧重捕获。
5. 噪声随机游走：blur（光学模糊）+ 死区 + σ 校准 → C1/C4 从 2.9%/3.1% 压到 0/2.2%。
6. **设计域**：机制成败取决于时间尺度——预测维持放 0.5s 降幅（暗适应尺度）几乎全丢、
   放 ~0.1s 眨眼尺度就工作；settle 度量走过三版（连续静默→5×中位→最后活跃帧/组件分测）
   才对。
