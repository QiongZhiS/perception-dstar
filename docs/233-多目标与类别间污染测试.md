## 〇、一句话

> **类别记忆对色相不相交的类别是隔离的（FAR：T2 污染 ΔF1 = 0.0000±0.0000，thr 外源
> 贡献 0.000）；但当被拒类的记账色相落在邻类的颜色族内（NEAR：T1 被拒后记账 hue ~133°
> 距 T2 135° 仅 ~3°），类别级 thr 提升跨类生效——T2 的 rest 段通过率从 solo 1.000 跌到
> dual 0.616（Δ−0.384）、ΔF1 −0.078±0.090，thr 提升的 66% 来自 T1 的记账。全局 thr
> 变体在两个 regime 都污染（FAR ΔF1 −0.314、rest −1.000；共享单值阈值被 T1 被拒抬高，
> T2 锁死）。这是 hue 键类别粒度的固有边界：系统无法区分"此 hue = T1 的瞬时伪装"与
> "此 hue = T2 的真实身份"，除非利害绑定到对象（docs/224 的"利害落点"）而不是只按颜色。**

## 一、实验设计（vision/multi_target_test.py）

### 1.1 场景选择与理由：合成双目标场景（真实 DAVIS 背景 + 两个纹理色块）

| 选项 | 理由 |
|---|---|
| 合成双色块（采用） | ① **完整 hue 控制**：NEAR regime 需要两个任务色相距 30-40°（如 170° vs 135°），而 DAVIS 现有 9 目标的任务色两两最近也有 63°（flamingo 170 vs surf 73）——真实目标给不出"相邻色族"场景，而相邻色族正是污染问题的核心；② 掩码/GT 干净（纯色块无空掩码帧）；③ 机制管线（target_obs / DavisMind / WB 门）逐字复用 davis_suspicious.py，机制与颜色无关 |
| 两个 DAVIS 目标抠图合成 | 真实纹理（帧内 std 5-44°）但有拼接伪影，且只能做 FAR（无相邻色对）；留作后续 |
| demo 式两对象 | demo_app.py 是交互演示，非度量实验 |

- **背景**：blackswan（854×480，真实视频帧，60 帧循环取帧；docs/230 §3.1 门探针在此背景门行为正常）。两个目标块位于帧内固定相对位置（左 16%/右 52% 宽、22% 高、9%×9% 大小）。
- **T1**（被拒类）：flamingo 同款任务色 **170°**（粉），块内 hue 纹理 σ=10° → clean frac 0.999。
- **T2**（受害类）：NEAR regime **135°**（蓝紫，σ=22° → frac 0.816，thr 0.60 余量 0.216）；FAR regime **73°**（surf 同款蓝绿，σ 相同 → 同样的 frac 0.816，只换 hue）。
- **corrupt 注入方式**（他者的不，docs/178）：T1 区**重着色到 ~133°±4°**（确定性记账 hue）。为什么不用 docs/219 的 gain 物理注入：探测显示 gain 对纯色块漂移太弱（kc=0.25 仅 16° < 30° 确认窗口，T1 不会被拒、记账 hue 无法控制，docs/220 坑 3 的纯色推广）——recolor 是把"目标变色"受控化的选择（受控实拍立场 docs/185/186），记账 hue 位置决定污染强度，且按种子 ±4° 抖动产生真实方差。
- **序列**（docs/219 协议）：base 20 → dusk 20（暖色温渐变）→ corrupt 15（仅 T1 变色）→ rest 25（T1 前 8 帧混 4 帧假恢复；T2 全程 clean）。
- **GT**：T1 = 61 正/80（corrupt + 假恢复 = 负，与 docs/219 flamingo 相同）；T2 = 80 正（从不被破坏）。
- **dual vs solo 对照**：两场景**帧级完全相同**（solo 中 T1 以"幽灵"存在——视觉在场、同样被 corrupt、掩码同样从背景统计中排除，但**不被任何 mind 维持**）。唯一差异 = 共享记忆里有没有 T1 的记账/被拒。Δ(dual − solo) 即污染。

### 1.2 共享记忆多目标 mind（MultiTargetMind）

- 一个共享类别记忆核：`rejected`（suspicious 表，docs/205）、`thr_by`（类别 thr 提升，docs/206/207）、`hist`（带宽记账，docs/208）、`rej_total`（全局纪念，docs/200/203）、`thr_cur`（全局变体）。
- 每目标独立信任态：trusted/consec/persist（按任务 hue 键）。
- 确认与单目标完全同构：`frac > thr(hue)` 且 `circ(hue, task_hue) < 30°`；被拒 → 按观察 hue 记账 + 类别级 thr 提升；通过 persist≥3 帧 → relax。
- 污染通道（在代码中显式仪器化）：
  - **ch1 记账**：T2 的 `thr_excess = thr(hue_T2) − thr_base`，逐帧。
  - **ch2 带宽**：记账按 `_w_wide(circ, bw)` 距离加权进入 T2 的 thr；hist 分箱（bin=10°）使 T1/T2 观测同 bin 混合 → bw 扩张（bin 130 同时收 T1 重着色帧与 T2 帧）。
  - **ch3 纪念**：共享 rej_total → T2 的 k（重信任延迟）上升，逐帧 k 最大值。
  - **归属**：`rej_origin` 记录每个记账 hue 由哪个目标产生 → `foreign_frac` = T2 thr 提升中外源（T1）贡献占比（全局变体用被拒计数份额）。

### 1.3 2×2 对照（docs/220 §六.4：类别记忆 × 白平衡，四格全跑）

| 格 | 类别记忆 | 白平衡 | docs/219 对应 |
|---|---|---|---|
| A | 类别级 suspicious | 有（时间门+相对基线增益门） | A full |
| B | 类别级 suspicious | 无 | B nowb |
| C | 全局 thr | 有 | C global-wb |
| C2 | 全局 thr | 无 | C2 global |

- 每个 (regime, cell, scene, seed) 一套完整管线：序列构造（seed 定噪声/recol 抖动）→ WB 门（门开 AND |g−g_base|>0.12 才校正，docs/219 §四 ①）→ 双目标观测 → 共享记忆 step。
- **种子与方差**：10 种子（seed 0-9）；`--jitter 0.25` = noise_std ±25% 乘性采样（docs/228 主协议）；recol hue 每种子 ±4°（`--recol-jitter 4`）。
- 每次运行（视频×种子×cell×scene）逐帧 trace + 指标写入 JSON 工件 + 每种子 checkpoint（docs/228 §1.4 模式，断点续跑）。

### 1.4 污染度量（三通道 + 行为）

1. **行为层（主判据）**：`ΔF1_T2 = F1_T2(dual) − F1_T2(solo)`，逐种子配对，10 种子均值±SD；分段 Δ（base/dusk/corrupt/rest 通过率）。
2. **ch1 记账**：T2 逐帧 thr_excess（均值/最大值，跨种子平均）。
3. **ch2 带宽归属**：foreign_frac（外源记账占比；0 = 无外源贡献）。
4. **ch3 纪念**：T2 逐帧 k 的最大值（共享 rej_total 的恢复延迟代价）。

### 2.3 判读

1. **FAR：类别记忆对色相不相交类别完全隔离**。A 格 ΔF1 = 0.0000、thr_excess 0.0005、foreign 0.000
   ——T1 被拒 19 次、记账 hue 距 T2 59°（远超自适应带宽 8-12°），`_w_wide=0`，T2 的阈值从未被抬。
   docs/220"被拒一类会不会污染另一类"在色相分离时的答案是**不会**；"suspicious 表按 hue 键天然
   支持多目标"获实测。
2. **NEAR：记账落进邻类色族 → 类别级污染出现**。A 格 T2 rest 通过率 1.000→0.616（Δ−0.384），
   ΔF1 −0.078，thr 提升 66% 外源（T1 记账）。机制链：T1 在 corrupt 被拒 15 次 → thr_by[~132]
   累积（cap 0.85）→ T2 的 thr(135) 被距离加权抬高 → T2 在 corrupt 末段/rest 被误拒。rest 部分
   恢复（0.616）不是记忆消退，而是污染 thr（0.85）与 T2 frac（~0.82±噪声/校正抖动）的余量允许
   间歇通过——**类别记忆的污染是持久的（记账 hue 永不 relax：T1 恢复后以 170° 通过，relax 只作用于
   thr_by[170]，不作用于 thr_by[132]）**。
3. **白平衡与污染交互（2×2 的第二个旋钮）**：NEAR B（nowb）ΔF1 −0.222 vs A −0.078——无 WB 时 T2
   确认余量更薄（dusk 色相漂移直接压低 frac），被抬 thr 咬得更狠；WB 给邻类留出生存余量。FAR B
   Δ−0.007 仍近零（隔离不受 WB 影响）。A vs B 的 dusk 通过率差（T2 0.95 vs 0.25）复现 docs/199 的
   WB 必要性。
4. **全局 thr 是跨类别污染的最大来源（两个 regime 都锁死）**：FAR C ΔF1 −0.314、rest −1.000（T2
   永久锁死）、NEAR C −0.220——docs/207 病态的多目标推广：单一共享阈值无法维持两个类别，被拒一类
   的记账直接抬高全系统阈值。**类别记忆 vs 全局的病态对照在双目标下比单目标更尖锐**（单目标 C 只是
   自己锁死；双目标 C 是"一类的被拒杀死另一类"）。
5. **C2 的 Δ=0 是测量地板**：solo 基线自身已锁死（无 WB 时 T2 自己的 dusk 被拒已把全局 thr 顶到
   cap），T1 的记账在增量上无可见效果——污染存在但不可再增量观测（诚实边界 4）。
6. **纪念通道（ch3）**：T2 的 k_max 在 dual 中升到 7-21（solo ~1-2）——共享 rej_total 使 T2 的重
   信任延迟增长。FAR A 中 T2 从未被拒，故无行为后果；NEAR 中叠加在 thr 污染上（恢复更慢）。
7. **T1 自身**：cell A 下 NEAR 0.890 / FAR 0.911、P=1.0——T1 的 recall 成本（R 0.80-0.84）来自
   纪念延迟（k=7-9 连续证据）而非 T2 在场；与 docs/219 flamingo A（rest 0.36）同构。

## 三、与 docs/224（单物到双物：利害的落点）的关系

docs/224 的主张：**单物 → 双物 = 利害从"外赋的锚"变成"绑定到对象的历史"**；表征侧只有
比较能力（L1-3），关系侧才有利害（L4-6），中间是绑定。本轮给出该主张在类别记忆机制上的
直接对照：

1. **FAR 隔离 = 行为上等价于对象隔离**：按 hue 的类别记忆在色相分离时，把 T1 的被拒历史完全
   封在 T1 的类别内——"粉的被拒不污染蓝绿"。类别（hue 键）在此充当了对象的代理，docs/224 的
   "两个单物放进同一个利害场（态势）"在机制上成立（两目标共享一个 suspicious 表却互不干扰）。
2. **NEAR 污染 = 类别记忆的粒度极限**：当 T1 的瞬时伪装色（记账 hue 133°）与 T2 的真实身份色
   （135°）同族时，系统**无法仅凭 hue 区分"这是 T1 的他者的不"还是"这是 T2 的本色"**——被拒
   记账按 hue 落点而非对象归属。这正是 docs/224 预言的缺口：利害必须绑定到**对象历史**（谁是
   这个 hue 的主人在过去是谁）而不是只按颜色落账，否则颜色族重叠的对象必然互相污染。
3. **全局 thr = 连类别粒度都没有**：docs/207 病态（全局锁死）在双目标下从"自伤"变成"他杀"——
   进一步支持"类别级记忆是维持系统的必要件"（docs/219 §3.3 结论 2 的多目标强化版）。
4. **对策方向（未实现，留作 B1.2 态势转录/后续）**：记账时绑定对象（观察掩码身份）而非纯 hue，
   即"利害的落点 = 对象"的工程化——把 suspicious 表从 hue→count 升级为 hue→(对象→count)；
   docs/224 §五 的预言（行动通道区分"世界的噪声"与"他者的不"）是同一方向的行为侧验证。

## 四、诚实边界

1. **合成色块 vs 真实目标**：块内 hue 纹理 σ 10-22°（真实目标帧内 std 5-44°，docs/219 §2.1）；
   本实验隔离的是"类别污染"问题本身，色相-饱和度几何更简单的代价是 gain 注入区分力弱（见 2）。
   真实双目标合成（flamingo+surf 同框）留作后续——抠图拼接会混入伪影，且现有 9 目标无相邻色对。
2. **corrupt 用 recolor 而非 gain 物理注入**：探测实测 gain 对纯色块漂移 <30°（kc=0.25 → 16°，
   确认窗口 30° 内 T1 不会被拒）——docs/220 坑 3"蓝绿对冷增益不敏感"推广为"纯色对冷增益不敏感"。
   recolor 是确定性记账的选择；gain 物理漂移分布下的污染强度未测。
3. **零方差行**：SD=0 = 真实零方差（阈值余量跨不过噪声/抖动，claim 模式 10 种子逐帧相同）；
   NEAR A/B 的高 SD 来自 recol 抖动把记账 hue 推到带宽边缘（双峰分布，均值±SD 只是摘要，docs/228
   §八 5 同款诚实）。
4. **C2 测量地板**：Δ=0 不表示无污染——solo 基线已全局锁死（无 WB 的自伤），T1 记账无增量可见
   空间；"全局 thr 污染"由 C 格（FAR −0.314）与 C2 的绝对锁死（rest 0.000）共同支撑。
5. **背景门活动高**：n_open 73/80、n_corr 46/80——blackswan 水面背景通道均值自然变化 >0.12 门限，
   WB 频繁校正（docs/219 §四 ① 的真实背景教训再现）；solo/dual 同帧同门，不改变污染对照。
6. **覆盖范围**：单背景（blackswan）、单序列结构（20/20/15/25）、单 corrupt 强度（recol 133±4°）、
   10 种子。多背景/多强度/真实目标合成未做。
7. **态势转录未实现**：docs/160/217"它在靠近我"级多目标态势报告不在本轮（B1.2 第二项仍开放，
   docs/221 已注明）。
