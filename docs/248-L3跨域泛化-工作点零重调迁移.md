### 1.3 预处理（预注册，冻结）

- cv2.VideoCapture 逐帧解码，**间隔抽帧**：step = max(1, round(T/500))（T = 视频总帧数；
  目标每视频 ~400-600 采样帧）；取帧索引 0, step, 2·step, …（顺序解码、每 step 帧取一，
  确定性；实际 step 按各视频帧数声明：V1≈20、V2≈35、V3≈2）。
- 每采样帧：BGR→GRAY（cvtColor）→ `cv2.resize(160×120, INTER_AREA)` → uint8——与
  docs/243 §1.1 预处理流水线逐字一致（能量是 160×120 工作点的分辨率归一化量）。
- 流式输入：窗口 = 10 帧/窗（WINDOW=10 沿用），逐窗口 SoftLoop 处理；**视频内连续 = 流**。
- 无注入、无 jitter、无 RNG——真实像素流确定性。

### 1.6 判据（预注册，冻结；每判据带 docs/247 层级标签；不得在看过结果后修改）

对每个流 s ∈ {S1, S2, S3, S4}：

1. **`[L3][参数][跨域零重调]` STABLE**：`ratio(s) = mean(MAE 末四分之一窗口) / mean(MAE
   首四分之一窗口) ≤ 1.5`（误差有界，换域不爆；MAE = 窗口级 mean|L−bg_fast|，SoftLoop
   预测路径未动）。
2. **`[L3][参数]` STRUCT**：`SC2(s) > 0`（hits ≥ hits_min=3 的稳定原型 ≥ 1——结构在野域
   视频上涌现，原型能形成）。
3. **`[L3][参数]` CHURN**：`churn(s) ≤ 0.5`（churn = 最终 hits < hits_min 的原型数 /
   max(1, SC1)——原型不过度短命）。
4. **`[L3][诊断]` SCENE_SWITCH**（无 GT，诊断级**不进主判定**）：帧差尖峰近似场景切检测，
   看新原型创建时点是否与切点对应（报告对应率，不设阈值判据——野域无 GT，诚实声明；
   设计见 §1.7）。

**全局通过**：STABLE = 全部流 ratio ≤ 1.5；STRUCT = 全部流 SC2 > 0；CHURN = 全部流
churn ≤ 0.5。

**判定（预注册，冻结）**：
- 1-3 全过 → **L3_PASS**（DAVIS 校准工作点跨域迁移成立）。
- **结构性失败**（→ **L3_FAIL**）：STRUCT 任一流 SC2 = 0（结构无法在野域涌现 = 机制不
  迁移；docs/243 REAL_FAIL_STRUCT 同构：校准过拟合野域）**或** STABLE 任一流
  ratio > 2.5（误差爆表 = 换域发散）。
- 其余（STRUCT 全过，但 STABLE 任一流 1.5 < ratio ≤ 2.5 或 CHURN 任一流 > 0.5）→
  **L3_PARTIAL**（报告哪条失败 + 数字）。
- 数据不可用（解码失败、流采样帧数过少等）→ **L3_BLOCKED**（如实报告）。

### 1.7 SCENE_SWITCH 诊断设计（预注册，冻结；诊断级，不进主判定）

- 帧差序列：`d_i = mean|f_i − f_{i−1}|`（i ≥ 1；f = 与回路输入相同的采样灰度 160×120 帧
  ——诊断与模型看到同一输入，诚实）。
- 尖峰：`d_i > μ + 3σ`（μ、σ = 该流 d 序列的 mean / std，ddof=1）。
- 切点窗口：`w_s = i // 10`（切后内容所在窗口）。
- 创建窗口：`w_c` = SoftLoop entry_log 的 created。
- 对应：`|w_c − w_s| ≤ 1`（±1 窗容差，理由：k_consist=3 滞回使创建晚于切点 1-2 窗）——
  预注册容差。
- 报告：`switch_corr`（新原型创建时点与切点对应率）、`spike_coverage`（有创建对齐的尖峰
  窗占比）、逐流创建/尖峰窗口列表（数字）、S4 的 2 处构造性边界是否被尖峰检出（参考）。
- **无阈值判据、无 GT**——野域没有场景切真值，诚实声明为近似诊断。

## 四、判定结果

**R_L3_VERDICT = L3_PARTIAL。** 判定数字（确定性流，工件 cdt_cdt.json；守卫 12/12）：

- **STABLE（[L3][参数][跨域零重调]）✓**：四流末/首四分之一比 1.155669 / 1.371908 /
  0.732642 / 0.370964，全部 ≤ 1.5——误差有界，换域不爆（S1 的 MAE 0.196 ≈ 2.8× DAVIS R1
  0.0695，但比值判据域内自归一，全过）。
- **STRUCT（[L3][参数]）✓**：SC2 = 4 / 3 / 3 / 6，全部 > 0——结构在野域视频上涌现，
  原型能形成（机制跨域迁移，无 docs/243 式结构不迁移）。
- **CHURN（[L3][参数]）✗**：S1 0.4286 ✓ / S2 0.2500 ✓ / **S3 0.6250 ✗** / S4 0.4545 ✓——
  仅快速剪辑流 S3 失守（8 个创建原型仅 3 个 hits ≥ 3）。
- **判定（按 §1.6 冻结规则）**：无结构性失败（无 SC2=0、无 ratio > 2.5）→ 非 L3_FAIL；
  1-3 未全过 → **L3_PARTIAL（CHURN：S3 churn 0.6250 > 0.5）**。

**判读**：DAVIS 校准工作点跨域迁移**部分成立**——稳定侧（STABLE）与结构侧（STRUCT）在
全部野域流上通过，churn 侧 3/4 通过；唯一失败是 13.5s 快速剪辑梗短片：多场景硬切使窗口
特征持续跳变，原型创建后内容已换、来不及累积 hits_min=3 → churn 0.625。这与 DAVIS 内
短场景（motorbike/soccerball，docs/245 判读 §六4）的 churn 机制**同构**——不是野域特有
的新失效，而是同一"快速内容变化 → 原型短命"现象在野域重现。S4（跨视频拼接，1394 帧）
churn 0.4545 与 DAVIS R1 工作点 churn 0.4545 同值（5/11），且 SC2 同为 6——拼接流的整体
行为与 DAVIS R1 高度平行。

## 六、诚实边界

1. **预注册纪律（docs/63+247）**：视频选择（§1.2）、预处理（§1.3）、工作点（§1.4）、
   流（§1.5）、判据与判定（§1.6）、诊断设计（§1.7）、守卫（§1.8）全部在任何运行之前写入
   §一（冻结）；运行后未改判据/参数/网格，未做任何看过结果后的回调。
2. **野域分类是尽力推断**：V1/V2/V3 的内容类别按文件名线索 + 探针元数据推断，未人工逐帧
   审查像素内容；实际内容可能不同于推断类别（这正是野域测试意图——不预筛）。若某视频
   实际为其他内容（如 V2 近静态），如实报告（V2 MAE 0.0215 暗示低运动内容，不影响判据，
   判据只看机制数字）。
3. **无 GT（野域无场景切真值）**：SCENE_SWITCH 是近似诊断（帧差 μ+3σ 尖峰），corr
   0.125-0.75 不作判定；快速剪辑流（S3）尖峰检出率低——高运动/剪辑流的帧差基底高，硬切
   不产生 μ+3σ 尖峰，该诊断在高运动流上灵敏度不足（诚实声明）。S4 的 2 处构造性边界全部
   检出，说明尖峰检测在"静止→新内容"型切点上有效。
4. **采样步长差异**：V1 step=20（60fps → 每采样窗覆盖 ~3.3s）、V2 step=35（30fps →
   ~11.7s）、V3 step=2（60fps → ~0.33s）——各流窗口时间跨度不同，窗口能量尺度不可跨流
   直接比较；机制参数（含 window=10）未动——这本身是零重调测试的一部分（机制对采样密度
   不敏感性的边界未单独测，诚实声明）。
5. **MAE 绝对值域相关**：MAE 0.021-0.196 跨域差异大（内容运动量/压缩噪声/亮度水平驱动）；
   STABLE 用域内比值（自归一）故可跨域比较；绝对 MAE 跨流不可比。
6. **pin 两极**：S1 pin 0.98（θ 顶格常态，docs/243 §六7 同款解释：真实流高噪声底）、
   S2 pin 0.00（θ 全程低位——低运动流）；结构仍在两种极端下形成（SC2>0），不裁决 θ 域。
7. **churn 0.4545 巧合**：S4 与 DAVIS R1 的 churn 同为 0.4545（都是 5/11）——数值相同但
   是独立流上各自算出的，诚实标注为巧合，不作迁移证据。
8. **单次确定性运行**：每流一次运行（不重复、不重试后改参）；elapsed 140.93 秒（解码为
   主；预算 60 分钟）；一次 mechanical 修复（frames 字段缺失，§二），非判据/机制改动。
9. **安全纪律**：stdout 只输出 ASCII 标签 + 每行一个数字的 R_L3_* 摘要块；运行经
   powershell 包装重定向（exit=0）；数字用 extract_r/log_diag 纯 python 正则抽取；未用
   read 工具读取任何输出文件（logs/*.log、vision/out/results/cdt_cdt.json）；Downloads
   视频只读帧数/文件名（cross_domain_probe.py）；未修改任何既有脚本（新文件
   cross_domain_probe.py / cross_domain_test.py / log_diag.py）。
10. **L3 层级的精确表述**：本实验证明的是**参数跨域零重调迁移（L3 参数侧）**：同一 DAVIS
    校准的 (r,k,α) 在野域上稳定侧与结构侧成立、churn 侧 3/4 成立——"判别/结构 + 稳定"
    跨域部分迁移；快速剪辑域的 churn 失守说明**参数泛化的域界**：内容变化速率超过
    hits_min 累积窗口的域，工作点余量不足。机制泛化（docs/247 §二 定义：学习过程本身
    跨域高效获取技能）不在本实验范围。
