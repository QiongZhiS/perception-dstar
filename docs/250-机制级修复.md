## 一、预注册设计（冻结；判据/旋钮/守卫先于任何运行写入本文件，docs/63+247 纪律）

### 1.1 缘起与目标（冻结）

docs/249 verdict=L3_FIX_PASS 但修复在**评估规则层**：短段配额对 hits_min 做 finalize 级
改判（预算 < hits_min 的原型豁免确认阈值），docs/249 §六3 明确"不改变原型如何形成/匹配/
创建，不声称改变学习过程本身"。docs/247 §二 的"参数泛化 vs 机制泛化"区分：配额修复是
参数/评估侧，本实验是**机制侧**——让学习过程本身适应段长。

docs/248 的失败机制（冻结引用）：S3 快切流 churn 0.6250 失守 = "原型创建后内容已换、
来不及累积 hits_min=3"；docs/246 已证伪 k=2（更快创建 → 更高 churn，单通路口径）。
docs/249 判读：churn 失守由**内容变化率**驱动，不是半径过紧（野域 NN 中位 0.0733，
半径 0.3989 宽松）。

本实验目标（预注册）：用**快慢双原型机制**让时间尺度从行为涌现——快通路抓内容（gist，
短命但正确，不逐切巩固 = 变化盲的正确行为），慢通路只固化反复重匹配的内容（记忆巩固）；
配额完全关闭下慢原型 churn ≤ 0.5，且 gist 正确性在 R1 真值段边界上成立。

### 1.2 人眼机制参考与机制 B'（冻结）

| 人眼参考 | 机制等价物（B'） |
|---|---|
| M/P 双通路并发（快粗动 vs 慢细形） | 快慢双原型并发匹配：快原型粗半径 r_fast、慢原型细半径 r_slow |
| gist 先行（~150ms 景概） | 快通路对高残差新奇段**立即**创建原型（k_consist_fast=1，无 3 窗滞回） |
| 扫视-注视（采样式注意） | 快原型 = 采样式粗抓（短命可弃）；慢原型 = 注视式细整合（升级固化） |
| 记忆巩固（重匹配驱动，非硬跳变） | 快 → 慢升级由**重匹配计数**驱动（hits ≥ k_promote，计数/滞回，非一次硬跳变决策） |
| 变化盲（快切内容不逐切巩固） | 快切段只产生快原型（短命但正确 = 正确行为）；慢原型只由反复重匹配升级 |
| 遗忘（记忆不活跃即衰减） | 失配 = 回收：快原型连续 k_decay 窗未重匹配 → 遗忘（移除） |

**不做段长预测（冻结）**：不使用帧差、位移、任何外部信号估计段长/切点；时间尺度
（什么内容被固化、什么内容保持短命）完全由行为（命中率 → 升级/回收）涌现。帧差只用于
野流**诊断**（近似段边界，诚实声明为无 GT 近似），不进入任何机制决策。

### 1.3 旋钮初值选择与理由（冻结；先于任何结果）

| 旋钮 | 初值 | 选择理由（冻结） |
|---|---|---|
| r_slow | **0.39885**（= RADIUS_L3 = 1.5×0.2659，docs/246 M=1.5 工作点） | 慢原型 = 已验证记忆路径，必须工作在 docs/246 已校准的判别-稳定工作点上（零重调精神）；细半径 = 注视/精细形 |
| r_fast | **1.5 × r_slow = 0.598275 ≈ 0.5983** | 粗半径 = gist 粗抓，须大于细半径（粗 = 更大邻域、更低精度）。1.5× 的理由：落在 docs/246 工作点族内（M=2.0=0.5318 与 M=3.0=0.7977 均为工作点，r_fast=0.5983 介于其间）——粗到成为独立通路、又不过粗到合并场景（保护 R1 gist 对齐与判别） |
| hits_min_fast | **1** | 低门槛：快原型 ≥1 次命中即"抓对内容"（gist 正确性的低阈值口径）；短命不构成失败（变化盲） |
| hits_min_slow | **3** | 高门槛（任务冻结值，= docs/241/243/245/246/248/249 的 hits_min=3）——慢类固化完成的确认阈值 |
| k_promote | **2** | 升级门槛 = 2 次重匹配（"反复重匹配"的最低反复数）。**语义（冻结解释）**：hits 达 k_promote → 升级为慢类（注视开始、固化候选：半径收紧 r_fast→r_slow、受回收豁免）；稳定（固化完成）需在细半径下再累积至 hits_min_slow=3。此安排使慢类 churn 非平凡（升级后内容切换 → 无法完成固化 → 计 churn），避免"升级即稳定"的平凡通过；"升级即固化"解释为：升级使原型进入固化慢类（受保护、半径收紧） |
| k_decay | **5** | 回收门槛 = 连续 5 窗未重匹配 → 遗忘（= persist_win=5 冻结窗口：5 窗无活动 = 不持久；docs/241 冻结语义复用）。只作用于快原型（慢 = 固化记忆，受升级保护不回收） |
| k_consist_fast | **1**（立即创建） | gist 先行：快通路对高残差新奇段立即响应（首个未匹配参与窗即创建），无 3 窗滞回。**预注册理由（冻结）**：① docs/246 对 k=2 的证伪在**单通路口径**（k=2 更快创建 → 更高 churn）——双通路下快创建不产生 churn（churn 判据只看慢类，快原型短命=正确行为），该证伪不适用；② 保护性滞回在双通路下由慢类承担（升级需 k_promote=2 次重匹配 + hits_min_slow=3，等效时间一致性确认）；③ gist 对齐判据（|Δ|≤1 窗）要求创建时点贴近切点，3 窗滞回会使创建恒晚 2 窗（|Δ|=2 结构性失配），立即创建才测得到"gist 先行" |
| α | **0.2** | 原型中心滑动学习率（= SoftLoop 冻结值，只动中心） |

### 1.4 匹配/升级/回收算法（冻结；FastSlowLoop(CompLoop)，预测路径零改动）

特征空间与参与门与 SoftLoop 逐字一致：x_w = (ln(1+E_w), ln(1+U_w))，E_w = 窗口事件像素
总数、U_w = 上区（y<68）事件像素数；参与门 E_w ≥ 10（事件不足窗口无签名，不匹配、不创建、
不推进计数器）。原型 p = {pid, mu（对数域中心）、hits、created、last_active、n_match、
kind ∈ {fast, slow}、promoted_at}。

每参与窗口（**快慢并发；慢优先、快兜底**，冻结顺序）：

1. **慢优先**：对全部 kind=slow 原型取最近者，欧氏距离 ≤ r_slow → 匹配慢原型（hits += 1、
   last_active=w、n_match += 1、μ 滑动 α=0.2）。
2. **快兜底**：否则对全部 kind=fast 原型取最近者，距离 ≤ r_fast → 匹配快原型（同更新）；
   匹配后若 hits ≥ k_promote → **升级**：kind → slow、promoted_at=w（半径收紧为 r_slow，
   升级计数 +1，受回收豁免）。
3. **高残差新奇段触发创建（k_consist_fast=1）**：否则（无慢在 r_slow 内、无快在 r_fast 内）
   → **立即**在窗口特征处创建快原型（hits=1、created=w、kind=fast、n_created_fast +1）。
4. **回收**（每窗口末）：对全部 kind=fast 原型，若 w − last_active ≥ k_decay → **回收**
   （从原型集移除、n_recycled +1；创建计数保留——创建时点是 gist 度量的时间戳，回收只
   移除活跃原型）。慢原型不回收（固化记忆）。

确定性：无 RNG、无 jitter、无逐场景统计；全部操作（log1p/欧氏距离/比较）确定性。
**预测路径零改动**：step/事件/阈值路径原样继承 CompLoop → MAE 序列与 docs/245-249 逐位
一致 → STABLE 是构造性控制项（与 docs/246-249 同款）。

### 1.5 度量定义（冻结）

- SC1_fast = 快原型累计创建数（含已回收）；SC2_fast = 快原型 final hits ≥ hits_min_fast=1
  数（诊断：gist 抓取结构；创建即 hits=1 → SC2_fast=SC1_fast 按定义，诊断级）。
- SC1_slow = 累计升级数（= 升级计数）；SC2_slow = 慢原型 final hits ≥ hits_min_slow=3 数
  （**结构判据的 SC2 口径**）。
- **churn_slow（CHURN_MECH 判据口径，配额完全关闭）** = #{慢原型：final hits < hits_min_slow}
  / max(1, SC1_slow)。快原型**不参与**（变化盲豁免）。
- churn_legacy（诊断，docs/248 口径）：全部原型（快+慢，累计创建）final hits < 3 /
  max(1, SC1_total)——展示"旧口径 churn 仍高 = 短命快原型存在，但机制度量拆分后不再算
  失败"（稳定/gist 拆分本身是结论的证据）。
- n_promo = 升级数；n_recycle = 回收数。
- 命中率证据：promoted 快原型的 final hits 均值 vs 未升级（含回收/存活）快原型的 final
  hits 均值（PROMOTION 判据 4 两侧均值）。
- MAE/ratio/SC1/SC2/pin/θ：与 run_soft 同款（ratio = 末/首四分之一窗口 MAE 均值比）。

### 1.6 GIST 真值（DAVIS R1 视频切换 = GT，冻结；野流 = 诊断）

- **R1 GT 段边界**：R1 = 9 视频按序拼接（flamingo 80 / surf 55 / bear 82 / camel 90 / dog
  60 / blackswan 50 / car-turn 80 / motorbike 43 / soccerball 48 帧），切换帧 =
  [80, 135, 217, 307, 367, 417, 497, 540] → **切换窗口（10 帧/窗，0 基）=
  [8, 13, 21, 30, 36, 41, 49, 54]**。
- **对应率**：gist_cov（主判据）= #{切换 s : ∃快原型创建窗 c 且 |c − w_s| ≤ 1} / 8
  （真值段边界被 gist 抓取的比例）；gist_prec（诊断）= #{快原型创建窗 c : ∃切换 s 且
  |c − w_s| ≤ 1} / max(1, SC1_fast)（创建是边界抓取的比例）。另报 |Δ|≤2 的覆盖作诊断

  诚实声明为近似。

### 1.7 判据（预注册，冻结；每判据带 docs/247 层级标签；不得在看过结果后修改）

1. **`[L3][机制][无配额]` CHURN_MECH**：配额**完全关闭**（机制本身不含配额）下，

3. **`[L3][机制]` STABLE/STRUCT 保持**：`ratio ≤ 1.5` 于 S1-S4 **且** R1（构造性控制项，
   预测路径未动）；`SC2_slow > 0` 于 S1-S4 **且** R1（慢类结构在野域与 DAVIS 均涌现）。
4. **`[L3][机制][行为证据]` PROMOTION**：`n_promo > 0`（全局，升级确实发生）、

   （升级非随机——报告两侧均值；确定性流无显著性检验，报告数字与分离程度，如实）。
5. **`[L3][诊断]` QUOTA_ORTHOGONAL**（诊断级，不进主判定）：机制 + docs/249 配额叠加

   若四流 + R1 的 churn/SC2/ratio **逐项不变** → **配额可退役**（机制下配额不再改变
   结果）；否则报告 Δ 并判"仍需"。

## 七、诚实边界

1. **gist_cov=1.0 的精确语义**：8/8 真值段边界在 |Δ|≤1 窗内被快创建覆盖（判据口径 =

   二次抓取，由 k_decay=5 回收清理）。覆盖是判据，精度为诊断——不声称"每次创建都是
   边界抓取"。
2. **快创建 k_consist_fast=1 是预注册机制选择（§1.3）**：gist 先行立即响应（无 3 窗
   滞回），滞回保护移交给慢类（k_promote=2 重匹配 + hits_min_slow=3 完成）；docs/246
   对 k=2 的证伪是**单通路**口径（更快创建 → 更高 churn），双通路下快创建不产生 churn
   （豁免）故不适用——诚实声明该设计偏差及其理由。
3. **churn_legacy（docs/248 旧口径）高（0.67-0.82）是度量拆分的预期结果**：短命快原型 =
   变化盲的正确行为（gist 抓对内容但不逐切巩固）；R1 GT gist_cov=1.0 支持"抓对"。
   若坚持旧口径，机制"修复"不可见（churn 仍高）——这正是本实验要拆分的两度量。
4. **守卫语义**：12/12 是**共享基座**（SoftLoop + 数据加载 + 桥度量，docs/249 守卫同款
   代码路径）的配额关闭字段复现 docs/246；快慢机制自身是新增代码，其正确性由 ① 判据
   全过、② 两轮运行核心数字逐位一致（确定性 + pid 簿记修复未动机制）、③ 守卫证明
   基座无漂移 共同承担。
